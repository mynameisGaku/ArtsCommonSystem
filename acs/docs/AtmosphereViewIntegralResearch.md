# 大気の視線単散乱積分：解析解による検査計画（2026-09-12）

> 未合格。有限地表判定の修正後に着手する次の小単位。
> この段階では解析的な期待値を導出しただけであり、製品CPU／GPUの失敗・修正成功をまだ主張しない。

## 分離する入力と出力

太陽方向と視線方向をともに鉛直上向きとし、地表反射、多重散乱、太陽円盤を含めない単散乱を調べる。
CPUは公開`CAtmosphere::EvaluateSkyRadiance`、GPUは現製品の`EvaluatePhysicalSky`を呼ぶ。
高度、太陽入射量、評価点数を入力とし、線形RGBの放射輝度を出力とする。ゲームやEditorの状態には依存させない。

距離は本書ではkmへ統一する。CPU公開高度はmなので1000倍して渡し、GPUにはkmを渡す。
地表半径は6360km、大気上端高度Hは100km。係数の単位はkmの逆数である。
入射量Sは現製品の平行な太陽光を表す係数であり、太陽円盤の単位立体角当たりの輝度とは区別する。
現APIのコメントには両者を混同し得る「ピーク輝度」という記述があり、単位の統一は別途必要である。

## 解析解

視点高度をh0、散乱点高度をhとする。同じ鉛直光路なので、乗法性により

```text
T(h0,h) T(h,H) = T(h0,H)
```

となり、散乱位置から独立になる。レイリー／ミー密度の積分量をCR／CM、オゾンをCOとすると、

```text
Cj = Hj exp(-h0/Hj) [-expm1(-(H-h0)/Hj)]
CRのHj = 8km、CMのHj = 1.2km
T = exp[-(βR CR + βMext CM + βO CO)]
L = S T [βR PR(1) CR + βMscat PM(1) CM]
```

オゾン密度は高度10／25／40kmで0／1／0の三角形。COはh0より上の残り面積を直接求める。
PR(1)=3/(8π)。ACSのミー位相はg=0.8のHenyey–GreensteinなのでPM(1)=(1+g)/(4π(1−g)²)。
βMext=0.0044、βMscat=0.003996を混同せず、散乱を消散へもう一度加算しない。
入射光子は−太陽方向、出射光子は−視線方向へ進むため、今回の散乱角の余弦は+1である。

S=(1,1,1)の独立した倍精度計算例：

## 先行試験の契約

高度0／1.2／8／10／25／40／80／90／99.9375／100kmと、色別の入射量を使う。
高度100kmでは厳密0、それより下では有限かつ正値を要求する。
初期の相対誤差目標は0.1%。絶対誤差だけで高高度の微小な光を0へ潰す実装を通さない。
GPUの現16点、CPUの標準32点を基準とし、単なる点数増加を修正としない。
CPUの0点指定から1点への互換動作、入射量への線形性、太陽積分の評価点数依存も分離して検査する。

既存の50区間試験は視線の中点近似を固定した消散係数の回帰試験であり、連続積分の精度保証ではない。
視線アルゴリズムを変えると期待値の前提も変わるため、その試験を無説明に削除・許容差拡大せず、
新しい解析解の試験へ係数検査の責務を引き継ぐ必要がある。

別の処理順の不具合として、CPUは太陽遮蔽時のcontinueで視線側の消散更新も飛ばしている。
太陽が届かない場所も奥の散乱光を減衰させるため、散乱源が0であることと媒質が存在しないことは区別する必要がある。
例えば正規化した太陽方向のyが−0.05なら、鉛直上向き光路は地表から約7.965kmまで地球の影になる。
この問題は鉛直上向きの太陽だけでは検出できず、影のある入力の独立積分を別のRedとして用意する。
鉛直光路で高さ0kmと6kmの二視点を選ぶと、その間は全て地球の影なので、L(0)=T(0,6)×L(6)が成り立つ。
T(0,6)は指数密度とオゾンの解析積分で独立に求められる。太陽側の数値積分を正解として複製する必要はない。
旧法の対照には地表側1000区間／6km側940区間を使い、共通の100m幅にして明るい部分の標本位置をそろえる案がある。
これは影区間の消散を切り出す試験であり、製品の点数増加による解決案ではない。実際の交点と標本の一致は別途確認する。

また、区間内の太陽透過率を中点に固定して視線透過だけ解析積分しても、積全体の厳密積分にはならない。
同方向・一定媒質の局所例でも、真の値への倍率はsinh(Δτ/2)/(Δτ/2)>1となる。
密度に沿う求積ではR/Mそれぞれの重みと、同じ標本位置のTview×Tsunを評価し、重みを距離順の区間幅へ読み替えない。

## 一次資料と適用範囲

[Brunetonの著者実装](https://ebruneton.github.io/precomputed_atmospheric_scattering/atmosphere/functions.glsl.html)の
透過率と単散乱の節を読み、太陽から散乱点、散乱点から視点の二つの透過率を掛ける順序を照合した。
そこで使われる50区間の台形則は、ACSの16点で十分という証明ではない。また著者実装のミー位相は
Cornette–Shanks型で、ACSのHenyey–Greenstein型とは異なる。位相の値をそのまま参照へコピーしない。

[PBRT第4版の透過率](https://pbr-book.org/4ed/Volume_Scattering/Transmittance)も光路分割の乗法性を説明する。
閲覧時の数式表示に欠落があるため、本文で確認できる性質と上記の独立導出を区別する。
同ページの光学的厚さ推定を指数化する際の偏りの向きには、凸性から得る不等式と食い違って見える記述がある。
この段落は根拠として採用しない。資料名や掲載だけで全主張を正しいと扱わない。

鉛直の解析解だけでは斜め・地平線・地中の打切り・太陽遮蔽境界の精度は保証できない。
次の実装では密度に沿う求積と透過率の積を検討するが、まず現製品のRedを保存してから変更する。
地上／上空／雲内の画像、連続フレーム、実解像度の性能、配布物・外部Frameworkは別の受入条件である。
