# 起動確認用の非公開展開

起動確認は公開済みZIPをその場で実行せず、OSの`TEMP`配下に作成した一意の非公開ディレクトリで検証と展開を行います。

## ZIPの固定と検証

元のZIPは再解析ポイントを拒否したうえで非公開領域へ複製し、複製中にSHA-256を計算します。複製したZIPは書き込み共有を許さない読み取りハンドルで固定し、次の順序を守ります。

1. 複製後のSHA-256が複製中の値と一致することを確認する。
2. `PackageCore.VerifyPackageArchiveAsync`でマニフェスト、パス、サイズ、SHA-256を検証する。
3. 検証済みの展開後合計サイズが設定上限内であることを確認する。
4. 同じ固定済みZIPから非公開領域へ展開する。

展開後の実行ファイルは、マニフェストのSHA-256と照合し、[実行ファイルの事前検証](executable-preflight.md)を再度通します。実行ファイルの読み取りハンドルはプロセス開始まで保持します。

## 容量上限

展開後の合計サイズは既定で16 GiBです。`--max-extract-mib`には16〜131,072 MiBを指定でき、絶対上限は128 GiBです。上限はZIP内の各エントリの宣言サイズを合計しながら適用し、実際の読み取り量が宣言サイズを超えた場合も拒否します。

```pwsh
dotnet run --project tools/acspackage -- smoke `
  C:\Games\MyGame\Build\Packages\MyGame-1.0.0-win64.zip `
  --max-extract-mib 16384
```

## パスと作成規則

- 各エントリは検証済みのパッケージルート配下でなければならない。
- 絶対パス、親ディレクトリへの脱出、重複または衝突する展開先を拒否する。
- 展開先の親ディレクトリにある再解析ポイントを拒否する。
- ファイルは`CreateNew`で作成し、既存ファイルを上書きしない。
- 各ファイルは宣言サイズと同じバイト数を書き終えた場合だけ受理する。

起動確認の終了後は、成功か失敗かにかかわらず非公開領域を回数制限付きで削除します。成功後に削除できなかった場合は起動確認全体を失敗にします。

[起動確認プロトコル](launch-smoke.md)と[パッケージ作成の概要](overview.md)も参照してください。
