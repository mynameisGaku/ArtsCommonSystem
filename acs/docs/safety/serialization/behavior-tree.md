# FBehaviorTree 永続化の安全性

`FBehaviorTreeEditorPanel` は編集可能なビヘイビアグラフを、行指向の
`ACSBT` テキスト形式で永続化します。新規コードでは次の検証付き API を使います。

- `TryParseGraphText(text, size)` — 長さを明示したメモリ上の文書を解析する。
- `TryLoadGraph(path)` — 上限付きの完全なファイルスナップショットを読み込む。
- `TrySaveGraph(path)` — 正準 v4 形式でシリアル化し、原子的に置換する。

従来の `LoadGraph` と `SaveGraph` は互換ラッパーとして残り、対応する検証付き操作が
成功したかを返します。新しいシリアル化処理は `ACSBT 4` を書き出し、読み取り側は引き続き
バージョン 1〜4 を受け付けます。

## 上限と文法

- 文書: 最大 256 KiB、物理行 256 行。
- 1 行: CR/LF を除いて最大 255 バイト。
- グラフ: 最大 128 ノード、親の連鎖深度 64。
- 動的ブラックボード: 最大 64 変数。
- ノード表示名と変数名: 最大 47 バイト。
- パス: 終端 NUL を除いて最大 1,023 バイト。

すべてのノード ID は `0..node_count-1` にちょうど 1 回だけ現れる必要があります。
親参照は宣言済みノードを指すか、ルートを示す `-1` でなければなりません。親の循環、
深さ超過、末端ノードへの子の追加、2 個以上の子を持つデコレーターは拒否します。
列挙値は範囲を検証し、ノード座標、比較定数、浮動小数点のブラックボード値は有限値だけを
受け付けます。

v4 のブラックボード区画は必須で、`BB <count>` の後に正確に
`<name> <type> <value>` レコードが続きます。名前は印字可能な単一字句とし、
重複を拒否します。真偽値は `0` または `1`、整数は `i32` の範囲、浮動小数点数は
ロケール非依存の文法でなければなりません。埋め込み NUL、不完全または余分な非空
レコード、長すぎる行、未対応バージョン、誤ったマジック値はすべてエラーです。

## トランザクションとファイル保証

解析器はノードとブラックボード値を準備領域に構築します。参照、構造、深さ、
重複の検証を完了してから最終ノード配列を確保し、検証と確保がともに成功した場合
だけ公開中のグラフを置き換えます。失敗時はグラフ、選択とレイアウトの状態、呼び出し側が渡した
動的ブラックボードのいずれも変更しません。ブラックボード区画を持たない従来の v1〜v3
文書では、現在の動的ブラックボードを維持します。

ファイル読み込みは初期サイズを記録し、そのバイト数を正確に読み、予期しない
伸長、読み取り、終了の失敗を検証してからトランザクション解析器を呼びます。短縮または
同時伸長されたファイルは `FileChanged` として報告します。

保存前にメモリ上の全フィールドを検証し、整数と浮動小数点数をロケール非依存の
`to_chars` でシリアル化します。出力先ディレクトリに一意な一時ファイルを書き、
永続化、終了後に出力先を原子的に置換します。シリアル化、書き込み、永続化、終了、
置換のいずれかが失敗した場合、既存の出力先を維持して一時ファイルを削除します。

## 診断とテスト

`FBtGraphPersistenceResult` は安定した `EBtGraphPersistenceError`、元の行番号、
処理済みバイト数、任意の OS エラーを返します。`ErrorName` はログ向けの安定した
診断名を提供します。

`tests/behavior_tree_persistence_safety_tests.cpp` は正準解析と実行用データ生成、
v1 互換、グラフとブラックボードの状態不変、ID と名前の重複、不正参照、循環、非有限値、
埋め込み NUL とサイズ上限、正準ファイルの読み書き往復、検証失敗時の出力先保護、
安定したエラー名を検証します。
