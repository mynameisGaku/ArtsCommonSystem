# エディター設定の永続化境界

`FEditorTheme` の `.acstheme` と `FEditorWorkspace` の `.acslayout` は、
明示長を受け取る検査付き API、全件検証後の一括反映、原子的な保存を共通契約とする。
従来の `SaveTheme` / `LoadTheme` / `SaveLayout` / `LoadLayout` は互換ラッパーとして残し、
詳細な失敗理由が必要な呼び出し元は検査付き API を使う。

## 検証付き API

- `FEditorTheme::TryParseThemeText`
- `FEditorTheme::TryLoadTheme`
- `FEditorTheme::TrySaveTheme`
- `FEditorWorkspace::TryParseLayoutText`
- `FEditorWorkspace::TryLoadLayout`
- `FEditorWorkspace::TrySaveLayout`

結果型は安定したエラー分類、入力行、処理済みバイト数、OS エラーを返す。
ワークスペースの結果は検証した `PANEL` 項目数も返す。

## 形式

両形式とも JSON ではなく、マジック値とバージョンを持つ行指向テキストである。
したがって共通 JSON DOM の深さ制限や DOM アロケーターは適用対象外であり、
各解析器が明示長の範囲だけを直接走査する。

`.acstheme` v1 は `ACS_THEME 1` に続き、プリセット、3 個の寸法値、13 個の RGBA 値
を記述する。v1 の 17 キーはすべて必須で、未知キー、重複キー、欠落キー、
余分な字句を拒否する。数値変換は C ロケールに依存せず、非有限値を許可しない。
RGBA は `[0, 1]`、フォント倍率は `[0.25, 4]`、角の半径は `[0, 32]`、
項目間隔は `[0, 64]` に限定する。

`.acslayout` v1 は次の順序で構成する。

1. `ACS_EDLAYOUT 1`
2. `IMGUI_INI <byte-size>`
3. 指定バイト数の ImGui 設定
4. `PANEL <title> <visible> <dock-target>` 行

ImGui 設定は ImGui が所有する不透明データとして扱うが、明示バイト長、全体上限、
埋め込み NUL を検証してから ImGui に渡す。パネル名は空白を含まない表示可能な
ASCII に限定し、重複する名前、重複区画、未知の末尾データを拒否する。
未登録パネルの行は互換性のため検証後に無視する。

## 入力上限

| 対象 | 上限 |
| --- | ---: |
| テーマ全体 | 64 KiB |
| テーマ 1 行 | 255 バイト |
| テーマ行数 | 64 |
| レイアウト全体 | 4 MiB |
| ImGui 設定 | 2 MiB |
| レイアウト 1 行 | 255 バイト |
| レイアウト行数 | 4096 |
| パネル数 | 32 |
| パネル名 | 127 バイト |
| 永続化パス | 1023 ワイド文字 |

上限超過は走査や確保より先に拒否する。ファイル読み込みでは開始時サイズを
記録し、全バイトを読み、EOF の試し読みと最終サイズ確認を行う。途中で伸縮したファイルは
`FileChanged` として失敗させる。

## トランザクション読み込み

テーマは一時パレットと寸法値に、ワークスペースは固定長のパネル変更配列に準備
する。構文、重複、範囲、上限、ImGui コンテキストの全検証が成功するまで、既存テーマ、
パネル表示状態、ドッキング先、登録パネル配列、選択サービスのポインターを変更しない。
ワークスペースはその後に ImGui 設定を読み、パネル状態を反映する。

## 原子的な保存

保存前に全状態を検証・シリアル化し、同一ディレクトリの衝突しにくい一時ファイルへ
全量書き込み、永続化、終了してから置換する。Windows の通常置換が共有する読み取り側に
阻まれた場合は POSIX 置換方式を試す。いずれも失敗した場合は一時ファイルを
削除し、既存の保存先を保持する。

## テスト観点

`editor_core_persistence_safety_tests.cpp` は正準 v1、重複、非有限値、埋め込み NUL、
切断された ImGui 設定、入力上限、失敗時の状態不変、開いた旧読み取り側を維持した原子的なテーマ置換と
読み書き往復を検証する。
