# シリアル化の安全境界

ACS の保存・読み込み API は、入力全体を検証してから既存状態へ反映します。個別形式の契約は次の文書に分かれています。

- [FSaveArchive](save-archive.md)
- [シーンテキスト](scene-text.md)
- [FScene3D](scene-3d.md)
- [FSettings](settings.md)
- [FBehaviorTree](behavior-tree.md)
- [エディター設定](editor-core.md)
- [FFxeditSerializer](fxedit.md)

## 共通契約

- 入力サイズ、件数、深度、文字列長を形式ごとの上限で検証する。
- 厳密な UTF-8、マジック値、バージョン、予約フィールド、CRC を必要に応じて確認する。
- 未知フィールドの扱いは形式ごとに定める。`FFxeditSerializer` v1 は未知キーを無視し、既知キーの重複、型、範囲を検証する。
- パス検証は API ごとに異なる。`FSaveArchive` は空パス、長さ、I/O 結果を検証する。許可ルート、上位移動、再解析ポイントを拒否する API は個別文書に明記する。
- 読み込み失敗時は既存状態を部分更新しない。
- ファイルを置換する保存 API は、同じディレクトリの一時ファイルを完成させてから置換または移動で公開する。メモリ出力 API は必要容量を検証し、容量不足時に出力を変更しない。

互換読み込みを行う形式では、受理する旧バージョンと変換規則を個別文書へ明示します。未知バージョンを最新形式として推測しません。
