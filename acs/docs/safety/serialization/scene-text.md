# シーンテキスト読み込みの安全性

`SceneTextLoader` API は `.acscene` と `.acsprefab` のテキストを非信頼入力として扱います。
新規コードは `TryLoadAcsceneText` または `TryLoadAcsceneFile` を呼び、
`FSceneTextLoadResult` を確認してください。従来の `LoadAcsceneText` と
`LoadAcsceneFile` は互換ラッパーとして残します。

## トランザクション保証

検証付きローダーはオブジェクトを構築する前に文書全体を検証します。次に、取り込むツリーを
隔離した準備ノード配下へ構築し、完成した最上位ノードを 1 回の構造反映で
出力先へ移します。完全に置換する要求配列も反映前に呼び出し側アロケーターで
準備するため、確保失敗では呼び出し側の容量、要素アドレス、内容を
維持し、公開だけが途中で失敗することもありません。読み込み失敗時は次を保証します。

- 出力先ノードの子は呼び出し前と同じ。
- スプライト、剛体、マテリアルテクスチャーの要求配列へ追加しない。
- 検証付き API に渡した `out_root` を変更しない。

互換ラッパーは読み込みを試みる前に `out_root` を消去する従来挙動を維持します。

## 強制する境界

`SceneTextLoader.h` の公開定数は、テキスト/ファイル読み込みの両方へ次の上限を適用します。

- NUL 終端入力テキスト 8 MiB。
- 1 行 2,047 バイト。
- 4,096 ノード。
- 262,144 命令レコード。
- 1 ノードあたり 1,024 コンポーネント。
- スプライトまたはマテリアルのパス 259 バイト。
- 共通の `kNodeMaxTreeDepth` 階層上限。

ノード変換と命令値は有限値でなければなりません。ノード ID は一意かつ
非負で、親 ID は解決可能である必要があります。自身を親とする関係と長い循環を拒否します。
既知命令は文法を検証し、取り込み対象ノードを参照しなければなりません。
未知命令は無視し、新しい書き込み側がレコードを追加しても旧ランタイムを壊しません。

## 診断

`FSceneTextLoadResult` は安定した `ESceneTextLoadError`、テキストエラーの 1 始まりの
行番号、検証済みノード数と命令数、成功時の読み込み済み境界を返します。
`SceneTextLoadErrorName` はログやエディターメッセージに使える安定した文字列へ変換します。

ファイル読み込みは開始、移動、サイズ上限、不完全な読み取り、埋め込み NUL を区別します。
内容をテキスト解析器へ渡す前にファイル全体を読み、途中の NUL バイトは文書終端として
扱わず拒否します。
