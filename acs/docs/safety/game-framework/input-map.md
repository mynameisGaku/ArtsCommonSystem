# InputMap の検査済み軸割り当て

`FInputMap::TryBindGamepadAxis` は、アクション、ゲームパッド軸、プレイヤー番号、
`FInputAxisOptions` をすべて確認してから割り当てを 1 件追加します。

- アクション ID 0 は登録しません。
- 軸は `EGamepadAxis` の各列挙子を明示的に判定します。永続形式や別スキーマの列挙数値を
  ACS の列挙値へ直接変換しません。
- プレイヤー番号は 0 から 3 だけを受け付けます。
- デッドゾーンは `[0, 1)`、倍率は 0 以上で、いずれも有限値だけを受け付けます。
- 検査に失敗した場合、`FInputMap` の割り当て数と既存の割り当ては変化しません。

軸値はデッドゾーン除去後の範囲を再び 0 から 1 へ正規化し、反転、倍率の順で変換します。
従来の `BindGamepadAxis` はデッドゾーン 0、反転なしの互換入口として検査済み処理へ委譲します。
