# アセットパスの正規化契約

`asset/AssetPath.h` の `TryNormalizeAssetPath` は、資産クラスや
`FAssetId` とは別責務の、識別用パス正規化境界です。

- ASCII 大文字は小文字へ変換する。
- `\` は `/` と同一視し、連続する区切りを一つへまとめる。
- 先頭区切りは維持し、ルート相対パスと通常の相対パスを同一 ID にしない。
- `.` セグメントは除去する。
- `..` セグメントは親領域を参照し得るため拒否する。
- 失敗時は呼び出し側の出力を変更しない。

`CAssetRegistry` はファイルを開く際には受け取った OS パスを使い、
キャッシュ用の `FAssetId` を作る際だけ正規形を使います。そのため、
ローダーや `FImageAsset` などの資産クラスと、識別子・ハンドルの責務は
混ざりません。

正規化規則を変えると永続化済み ID との対応も変わるため、互換性を伴う
形式変更として扱ってください。
