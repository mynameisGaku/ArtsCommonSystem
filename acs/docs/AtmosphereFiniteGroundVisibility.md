## 係数生成と有限区間の判定

入力を`o,d,L`、球中心からの位置を`O=o+(0,R,0)`とすると、球面の二乗差は次の放物線になる。

```text
F(t) = a t² + 2 b t + c
a = dot(d,d)
b = dot(o,d) + R d.y
c = dot(o,o) + 2 R o.y + (R-r)(R+r)
D = b² - a c
```

球内はF<0、球面はF=0。方向長1を仮定しない。惑星半径へ微小高度を加算してから二乗しない。
最初の二つのfloatによる補償案は、係数加算で三つ目以降の残差を捨てていたため棄却した。
既存ペア乗算も下位同士の積を省略する。これらの近似演算の厳密性を、新しい遮蔽判定の前提にしない。

`L>0,a>0`に対する遮蔽は、「0からLまでにF<0となる区間があるか」で定義する。
製品は根との距離比較をせず、c、b、D、F(L)、aL+bの符号から判定する。

- c<0なら地中始点なので遮蔽。
- c=0なら内向きb<0のときだけ遮蔽。
- 球外でb>=0なら遠ざかるため非遮蔽。
- D<=0なら地中の正の区間がないため非遮蔽。
- 残りはF(L)<0、またはaL+b>0なら遮蔽。後者は球を通り抜けて終点が再び球外へ出る光路も拾う。

L<=0と零方向は恒等透過を維持する。近交点ちょうどの終端は遮蔽せず、そこを越えて地中へ入れば遮蔽する。
北極上の安定した交点専用式は位置計算用に維持する。一般位置の地表近交点も新しい符号を共有する。
太陽の`PhysicalTransmittance`と視線の`EvaluatePhysicalSky`は同じ有限区間判定を共有する。

## 誤差認証と境界だけの厳密計算

`PhysicalGroundPolynomial`は、非零の入力が2^-16以上2^16以下の場合に通常のfloat演算を先に行う。
この範囲は物理量を調整する制限ではなく、通常演算の途中で範囲超過・極小値への丸めが起きないことを証明できる範囲である。
範囲外でも入力を切り詰めず、厳密計算へ送る。

単位丸め誤差をu=2^-24、γn=nu/(1-nu)とする。元の入力単項式の絶対値の和を用い、
b/cはγ4、aL+bはγ5、F(L)はγ7、Dはγ10で誤差を覆える。
実装は絶対値和と誤差上限自身の丸めも含めてγ64を使う。独立監査で、この上限はγ10の約6.4倍以上の余裕を持つと確認した。
`abs(value)>bound`でのみ符号を確定する。誤差帯を0や接触とみなす処理ではない。

境界と範囲外では、floatの元のbitから仮数と指数を取り出し、四因子の積を整数で計算する。
32bit整数の積は16bitへ分解して上下位を得るため、GPUの64bit整数・倍精度・STLを必要としない。
最小の基準単位は2^-596。四因子の積と係数2を含む項の和は符号込み1114bit以内に収まり、
35個のuintで1120bitを保持する。桁の繰上がり・借りは項の上端を越えて消えるまで伝える。

判別式は係数を丸めてから掛けず、次の14単項式を直接加減する。

```text
D = R² dy² - Σ_i o_i² Σ_(j≠i) d_j²
    + 2 Σ_(i<j) o_i o_j d_i d_j
    - 2 R oy (dx²+dz²) + 2 R dy (ox dx+oz dz)
```

c/bは4項、F(L)は11項、aL+bは7項。戻り値のy成分が厳密な符号で、x成分は交点位置用の近似floatである。
x成分は最近接丸めを保証せず、参照から1ULP異なる例もある。極小値では0になるため、xを符号判断へ流用しない。
近交点距離もfloatであり、これを区間長と比較して遮蔽を決めない。
視線側の地表反射選択には、共通の遮蔽判定に加えて近交点距離が非負という条件も残る。

入力がNaN／無限大なら透過率0で拒否する。有限な零長・負長の恒等透過は維持する。
正の非正規数の長さはbitで判定して残し、地中の正長区間をfloat比較で零長へ変えてしまわない。
位置と方向も、動的に成分を選ぶ前にuint3へ移す。floatの成分選択をコンパイラーが内積へ変換すると、
asuintを呼ぶ前に非正規数が0へ失われるためである。整数に変換した後の積だけを厳密にしても十分ではない。

追加の反例は`o=(0,1,0), d=(0,-2^-127,0)`で、距離をbit表現`0x7effffff, 0x7f000000, 0x7f000001`とする。
鉛直変位は順に`-1+2^-24, -1, -1-2^-23`km。最後だけ地中へ約0.119mm入るため遮蔽する。
最後の真のF(L)は約−0.00151634216307である。修正前はRelease実GPUで非遮蔽・透過率1となった。
係数を変更せず、因子の選択から整数表現を保つ修正により、非遮蔽・接触・遮蔽の3条件を通した。

## コンパイラーと実GPUを区別する

旧二成分補償案では、単独の加算・乗算は実GPUでも残差を復元できる一方、係数の組立結果では下位が0になった。
実RHIが使用したDXBCを保存し、独立監査で逐次計算した結果には残差が存在した。
関係命令のprecise欠落・FTZでは説明できず、具体的な誤実行命令やドライバー原因は未確定である。
この実行環境で成立しなかった補償演算を、誤差認証の前提から外した。

整数案の最初の版は、HLSLの配列引数による一時配列の複製で、複数の光路を一つのシェーダーから呼ぶと4096レジスター上限を超えた。
積、加減、結果変換を一つの配列の所有場所へ集めて解消した。ループのfastopt指定は整数処理のコンパイル負荷を抑えるものに限定し、
浮動小数点演算の最適化を全体で無効にする変更やRHI公開構造体の変更は行っていない。
検証用の手動コンパイルにはX4000（未初期化の可能性）警告が残る。配列は35語すべて初期化し、
最新の独立監査でも配列の初期化とゼロ／非ゼロ両経路の戻り値代入を確認した。
各構成156警告は、この診断用シェーダーの範囲では分岐合流に対する誤警告と判断した。
ループ変数の再宣言は固有名へ直し、警告の一括抑制は行わない。
因子選択もDebug／Release各20か所すべて整数の選択・転送命令であり、floatの内積や数値演算は含まれない。
ただし診断用シェーダーでは戻り値xの近似値計算が除去されるため、これを製品の全入口・全警告の保証へ広げない。

## 点接触は明示的な挙動変更

旧規約では`o=(1000,0,0), d=(-1,0,0), L=2000`の全体が遮蔽される一方、接点の1000で二分すると
前半は終点接触、後半は地表上の接線方向として、両方が非遮蔽だった。
実GPUでも全体T=0、分割の赤T約0.01141033を先行再現した。

接するだけで地中を通らない光路は、全体・始点・終点・分割後とも非遮蔽へ統一した。
これは丸め精度の変更だけではなく、厳密接線D=0に対する挙動の変更である。
視線の地表反射選択も同じ規約へ合わせ、太陽側だけ規約を変える状態を残さない。

## 一次資料との照合

[PBRT第4版の球面交差](https://pbr-book.org/4ed/Shapes/Spheres)は、単位方向を仮定しない係数と、
桁落ちしにくい根の計算、区間演算による判定を示す。PBRTのbは本書の2bに相当する。
今回も近い根を差で求めないが、PBRTの区間演算を移植したわけではない。
[丸め誤差の解説](https://pbr-book.org/4ed/Shapes/Managing_Rounding_Error)にある誤差管理と、
単なる固定幅の原点移動を区別する。ACSの2つのfloatによる補償を同じ保証へ読み替えない。
有限区間の分類は放物線の最小値から独立に導出し、資料のコードを正解の出力として複製しない。

[Shewchukの著者解説](https://www.cs.cmu.edu/~quake/robust.html)も、丸めで幾何判定の符号が逆転する問題と、
必要な場合だけ計算精度を増やす考え方を説明している。今回確認したのは著者の解説であり、
原論文の全証明やC実装をそのままHLSLへ移したものではない。ACSの式・容量・誤差上限は別途検証している。

[Direct3Dの浮動小数点規約](https://learn.microsoft.com/en-us/windows/win32/direct3d11/floating-point-rules)では、
単精度の数値演算は非正規数を符号付き0へ落とす一方、値を操作しない転送は例外とされる。
したがって成分選択をfloat内積に変える命令列は、入力の元のbitを保つという今回の契約に適合しない。
整数表現で選択する修正を、規約だけでなく前後の実GPU出力でも検査した。

## 試験と再現ログ

現在の製品HLSLに検査入口だけを加え、原点・方向・距離を定数バッファから渡す。

分割の積は読み戻した二つのTをCPUの倍精度で掛ける。遮蔽条件・半分が丸められる非正規長・不正入力には分割一致を要求しない。
新しい`PhysicalFiniteGroundPathsKeepEndpointAndTangency`は初期15条件に残差消失2条件、極小値1条件、非有限入力3条件、非正規方向3条件を追加した24条件。

- ±1mmで球面をかすめる2000km光路と、負側の入口直後で終わる光路。
- 同一路線の方向倍率0.125／1／2／16と、XからZへ回転した条件。
- (3816,-1272,0)で球面に達する長さ1.65625と、その前後1ULP。
- 零長、地表を始点とする接線、接点での二分割。
- 非北極の球面上で厳密な接線になる方向(4,-3,0)。

球面参照は倍精度の直接二次式、遮蔽参照は区間内の最小点を直接評価する式を使う。
透過率は直接3D球面座標の32768点中点則と65536点を照合し、参照差1e-7以下、製品誤差2e-4以下を要求する。
全値の有限性、非遮蔽時の厳密な正値、遮蔽時の厳密0も検査する。交点誤差は方向長を掛けた物理距離で2e-4km以下。
非有限入力は拒否結果を検査し、積分参照へ渡さない。極端な非正規方向3条件は遮蔽真偽と遮蔽時T=0のみを受入対象にする。
これは方向倍率の全範囲で積分・近交点距離も正確という試験ではない。

終点±1ULPの3条件は、GPUで計算した終点座標が同じfloatへ丸まる。
反転ではその実終点を独立参照の原点に使い、理想的な反転と同じ入力だとは仮定しない。
同一でない光路に無条件の反転一致を要求しない。地中始点も含む遮蔽参照と、球外からの入口参照は分ける。

## 適用限界

整数多項式の符号は有限float入力を対象とする。実GPUで全bitパターンを列挙した保証ではなく、
