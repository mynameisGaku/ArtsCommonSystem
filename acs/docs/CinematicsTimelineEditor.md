# シネマティクスタイムライン

`CCinematicTimelineDocument` は編集用キー列と明示的な再生時間を所有する非多相の文書型です。時刻は有限値で、同時刻のキーは追加順を保ちます。

追加・削除・置換・再生時間変更は検証後に一括反映されます。不正値または確保失敗では文書と既存の再生列を変更しません。再生時間を短くすると、範囲外のキーだけを新しい終端へ移します。

`TryBakeTo` は全キーを検証して一時列へ構築してからディレクターを置き換えます。カメラは座標と拡大率1.0、色は量子化した終了色、時間倍率は固定小数、エフェクトとコールバックは下位24ビットの識別子へ変換します。フェード開始色とエフェクト位置は編集データだけで、現在の再生列には含めません。

実行列には編集時間だけを理由にした待機キーを追加しません。明示的な時間は文書に保持し、キーが空でも編集時間を保持します。

パネルはディレクターを所有せず、文書の読み取り表示と編集操作を担当します。再生列の置換に失敗した場合は再生状態を変更せず、成功した変更だけを反映します。
