症状

ACSで可変長配列、文字列、キー付きキーから値を引く入れ物。 ハッシュで高速に検索する(THashMap)。を使うには、どの型を選びますか？

tags

  • ACS はビルド時間や予測しやすさのため使わず独自コンテナを用いる。
  • 値をまとめて入れておく入れ物(TArray や THashMap など)。 ACS は STL の代わりに独自のものを使う。

対処

可変長配列には 末尾追加が速く要素は連続メモリに並ぶ。 コピー禁止・ムーブ専用。、文字列には 短い文字列はヒープ無しで持つ最適化付き。、キー付きキーから値を引く入れ物。 ハッシュで高速に検索する(THashMap)。には THashMap を使用してください。
