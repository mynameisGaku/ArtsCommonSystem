TSharedPtr 同士が互いを持ち合って、いつまでもメモリが解放されない

症状

複数で共有するスマートポインタ。 参照カウントが 0 で自動解放。 同士が互いを持ち合って、いつまでもプログラムが使う記憶領域。 確保と解放の管理が性能と安全性を左右する。が解放されない
