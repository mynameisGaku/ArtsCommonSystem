2D のスプライトが思った場所と上下逆/ずれる

症状

2D の2D の 1 枚絵(キャラ・アイコン等)。 矩形にテクスチャを貼って描く。が思った場所と上下逆/ずれる

tags

  • 2D
  • 座標
  • Y-down

対処

シーン、コンポーネント、各ジャンル用機能、アセット読み書きの抽象 API など、ゲーム構築用の部品を提供する acs::game モジュールです。 の 2D world は scene/camera 中心で +Y が下向きです。 HUD / screen / easy の pixel 座標だけが左上原点です。 world の picking は AScene::ScreenToWorld を使ってください。
