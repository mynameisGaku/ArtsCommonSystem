ACS トラブルシューティング

TObjectPtr / TWeakObjectPtr を生ポインタから作ったら空になる

症状

TObjectPtr / TWeakObjectPtr を生メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。から作ったら空になる

tags

  • 確保したメモリを自動で解放してくれるポインタ風オブジェクト。 手で delete しなくてよい。 RAII の代表例。
  • 参照カウント管理されるオブジェクトの基底。 生ポインタからも強/弱参照を作れる。

対処

その対象が NewObject<T>() 経由で作られていないと、内部の制御ブデータを守るための『鍵』。 取った人だけが対象を触れ、他は解放されるまで待つ。が無く空になります。 参照カウント管理されるオブジェクトの基底。 生ポインタからも強/弱参照を作れる。 派生は NewObject で生成してください(関数の呼び出しに沿って自動で確保/解放される高速なメモリ。 寿命はスコープに縛られる。や素の new ではダメ)。
