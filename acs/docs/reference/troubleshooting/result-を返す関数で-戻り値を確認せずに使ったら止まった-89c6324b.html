症状

成功なら値、失敗なら理由を入れて返す型 Result<T,E>。 例外の代わり。 を返す関数で、戻り値を確認せずに使ったら止まった

対処

IsOk() で確認する前に Value() を呼ぶと、失敗時にそこで(条件が偽ならその場でプログラムを止めてバグを知らせる仕組み（ACS_ASSERT 等）。で)停止します。 必ず if (r.IsOk()) を通してから Value()、失敗時は r.TResult が失敗を表す側。 err.subcode で原因を見分ける。 成功側は Ok。or() を見て分岐してください。
