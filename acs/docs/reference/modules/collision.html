機能

BuildConvexHull33D の点群(メッシュ頂点など)から凸包を作り、三角形メッシュ(頂点配列 + インデックス列)として出力する関数。 凹んだメッシュを軽い「凸の当たり判定」に近似するのに使う。関数CMeshCollider3D の三角形メッシュから当たり判定を作るクラス。 内部で BVH(三角形を空間で階層分けした木)を組み、レイキャストや AABB との重なり判定を高速に行う。クラスCSpriteCollider2D スプライトのアルファチャンネル(透明度)から、絵の形に沿った当たり判定形状を作るクラス。 凸包(扱いやすい)と簡略化済みの輪郭ポリゴン(凹形状にも追従)の両方を生成し、点の内外判定や AABB も得られる。クラス

acs::CMeshCollider三角形メッシュから median-split AABB BVH を構築する 3D メッシュコライダー。 レンダリング用の AMeshAsset や生の頂点/インデックス配列から collider を作り、 レイキャスト (最近接ヒット) と AABB 重なりクエリを BVH で高速化する。 中身は 三角形リスト + 最長軸の空間中点で分割する BVH。 視覚に依存しない純 CPU ロジックで、 ACS 規約に従い non-copy・全 noexcept・TResult を用いる。クラス →acs::CSpriteColliderスプライトのアルファチャンネルから形状に沿ったコライダーを生成する 2D コライダー。 不透明画素の境界から凸包 (Jarvis march、順序非依存で堅牢) と簡略化済み輪郭ポリゴン (Moore 近傍トレース + Douglas-Peucker 簡略化) を作る。 凸包は物理で扱いやすく常に有効、 輪郭は凹形状にも追従する。 座標はピクセル空間 (左上原点) で、単一連結成分・穴なしを前提。 ACS 規約に従い non-copy・全 noexcept・TResult を用いる純 CPU ロジック。クラス →

関数

acs::BuildConvexHull3点群から 3D 凸包の三角形メッシュを構築する (incremental hull)。 初期四面体を affinely independent な 4 点で張り、残りの点を可視面を剥がしながら 1 点ずつ追加していく。 out_verts には凸包の頂点、out_indices には三角形を構成する 頂点インデックスを 3 個 1 組で埋める (out_verts は使用頂点だけに remap される)。 そのまま CMeshCollider::BuildFromTriangles に渡せる。 点が 4 個未満、全点一致、共線、 同一平面 (coplanar) など退化した入力ではエラーを返す。 points: 入力点群の先頭ポインタ。 count: 入力点の個数 (4 以上が必要)。 out_verts: 凸包頂点を格納する出力配列 (呼び出し時に Clear される)。 out_indices: 三角形インデックス (3 個 1 組) を格納する出力配列 (Clear される)。 戻り値: 成功なら空の TResult、点が不足・退化していればエラー。関数 →
