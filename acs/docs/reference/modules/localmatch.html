機能

CLocalMatchmakerマッチメイクの本体。 acs::game::IMatchmaker を実装し、同じプロセス内で出された検索同士をレートが近い順に組ませる決定的な実装です。 最大 32 件の検索を同時に扱えます。 コピー/ムーブは禁止。クラスFLocalMatchmakerConfigCLocalMatchmaker の設定。 今は『どれだけレーティングが離れていてもマッチさせてよいか』の上限値だけを持ちます。構造体GetDefaultLocalMatchmaker()プロセス全体で共有される既定の CLocalMatchmaker(シングルトン)を acs::game::IMatchmaker& として返します。関数InstallLocalMatchmakerAsDefault()gameframework の matchmaker provider にローカル実装を登録します。 これ以降 acs::game::GetDefaultMatchmaker() がローカル matchmaker を返すようになります。関数

クラス

acs::localmatch::CLocalMatchmakerプロセス内で完結する決定論的なローカル matchmaker 実装。 acs::game::IMatchmaker を固定長スロット (kMaxTickets) のプールだけで実装する。 StartSearch で空き / 退役済みスロットに ticket を発行し、同 mode かつ rating 差が MaxRatingDelta 以内の Searching な相手が居れば双方を Matched にする。 終端状態 (Cancelled / 双方 Accept 済み) に入ったスロットは退役させ、満杯時に最古の退役 スロットを再利用することで ticket リークを防ぐ。 ネットワークは一切使わない。クラス →
