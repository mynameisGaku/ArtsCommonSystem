機能

ACS_TEST(Suite, Name)テストケースを 1 つ宣言するマクロ。 直後に { ... } でテスト本体を書く。 プログラム起動時に自動でテスト一覧へ登録され、RunAll() で実行される。 Suite はグループ名、Name はその中の個別テスト名。マクロEXPECT_EQ / EXPECT_NE2 つの値が等しい(または等しくない)ことを検証するアサートマクロ。 内部で a == b を 1 度だけ評価して比べる。 条件を満たさなくてもテストは続行する。マクロEXPECT_NEAR2 つの値の差が許容誤差 eps 以内であることを検証する、浮動小数用のアサートマクロ。 |a - b| > eps なら失敗を記録する。マクロEXPECT_TRUE / EXPECT_FALSE式が真(または偽)であることを検証するアサートマクロ。 条件を満たさなければ失敗を記録するが、テストはそのまま続行する(以降のチェックも走る)。マクロFTestCase1 つのテストケースの記述子。 スイート名・テスト名・ソース位置・テスト本体への関数ポインタを持ち、next で次のケースへ繋がる連結リストのノードでもある。 ACS_TEST が内部で自動生成するので、通常は手で触らない。構造体RecordFailure()テスト本体内から失敗を 1 件記録する関数。 失敗してもテストはそこで止まらず続行する。 EXPECT_* マクロが条件不成立のときに内部で呼ぶ。 printf 風の書式で詳細メッセージを付けられる。関数RecordInfo()テスト本体内から補助的な情報メッセージを出力する関数。 失敗扱いにはならず、ログとして残るだけ。 printf 風の書式が使える。関数Register()テストケースを実行リストへ登録する。 ACS_TEST が起動時(main 開始前)に自動で呼ぶため、利用者が直接呼ぶことはまずない。関数RunAll()登録済みの全テストケースを順に実行する。 失敗が 1 件でもあれば 1 を、すべて成功なら 0 を返す。関数TestFnテスト本体の関数ポインタ型。 void (*)() の別名で、引数なし・戻り値なしの関数を指す。型エイリアス
