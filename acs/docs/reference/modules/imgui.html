FImGuiCtxDear ImGui を ACS に統合する入口クラス。 内部で Win32 backend(入力)と DX12 backend(描画)を初期化し、ImGui::Begin() などの素の ImGui API をそのまま使えるようにします。 コピーは禁止(片付けを 1 つに保つため)。クラス
