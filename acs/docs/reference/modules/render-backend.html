ACS_SAFE_RELEASECOM ポインタを安全に解放するマクロ。 非 null なら Release() を呼び、ポインタを nullptr に戻します(二重解放防止)。 DX12 バックエンドのデストラクタ・リソース破棄で多用されます。マクロCDiligentCommandListDiligent のコマンドリスト(IRhiCommandList 派生)。 Diligent は IDeviceContext 自体が即時 API なので、本クラスはその薄いラッパです。 CDx12CommandList と同じインターフェイスで、加えて MRT(複数 RT 同時描画)を実装します。クラスCDiligentDeviceDiligent Engine 経由のRHIデバイス(IRhiDevice 派生)。 内部に IRenderDevice・IDeviceContext・EngineFactory を持ち、D3D12 と(ビルド次第で)Vulkanを 1 つの API で扱えます。 ヘッダは Diligent 依存を漏らさず前方宣言だけで完結します。クラスCDiligentMemoryAdapterDiligent の内部 malloc を ACS のアロケータ(IAllocator)へ橋渡しするアダプタ。 EngineCreateInfo::pRawMemAllocator にこれを渡すと、Diligent のメモリ確保が ACS のメモリ管理(ESegment::RenderInternal 等)を経由するようになります。クラスCDx12CommandListDX12 のコマンドリスト(IRhiCommandList 派生)。 1 フレーム分の描画命令(クリア・パイプライン設定・バインド・Draw)を ID3D12GraphicsCommandList へ記録し、GPU に投入します。 リソース状態のバリアも内部で面倒を見ます。クラスCDx12DeviceDX12 ネイティブのRHIデバイス実装(IRhiDevice 派生)。 ID3D12Device・コマンドキュー・ディスクリプタヒープ(SRV/RTV/DSV)・フレームフェンスを抱える、DX12 描画の中枢です。クラスEFormatAspecttexture format が color、depth、stencil のどの aspect を持つかを示す bit 分類。列挙ERhiPipelineBindDomainpipeline binding が graphics、compute、ray tracing のどの command domain に属するかを表す。列挙FDiligentBufferDiligent の GPU バッファ(IRhiBuffer 派生)。 Diligent の IBuffer を頂点・インデックス・定数バッファとして確保し、FDx12Buffer と同じ API で更新できます。クラスFDiligentPipelineDiligent のグラフィックスパイプライン(IRhiPipeline 派生)。 IPipelineState と SRB(シェーダリソースバインディング)を作ります。 Diligent は名前でリソースを引くため、FPipelineDesc の HLSL リソース名(cbuffer_names/texture_names)を保持します。クラスFDiligentShaderDiligent のシェーダ(IRhiShader 派生)。 HLSL を Diligent 内部で SPIR-V/MSL/GLSL へ変換するため、Bytecode() は便宜上 nullptr を返し、パイプライン作成時に生 IShader* を直接使います。 HLSL ソースを parse して register(bN/tN) → 名前の対応も取得します。クラスFDiligentSwapchainDiligent のスワップチェイン(IRhiSwapchain 派生)。 Diligent の ISwapChain を薄くラップし、取得・提示・リサイズを FDx12Swapchain と同じ API で提供します。クラスFDiligentTextureDiligent のテクスチャ(IRhiTexture 派生)。 ITexture と、その SRV/RTV/DSV ビューを持ちます。 cubemap・テクスチャ配列・per-slice RTV にも対応します。クラスFDx12BufferDX12 の GPU バッファ(IRhiBuffer 派生)。 頂点・インデックス・定数バッファを ID3D12Resource として確保します。 Uniform かつ cpu_writable なら自動でフレームリングバッファ化され、毎フレーム安全に書き換えられます。クラスFDx12PipelineDX12 のグラフィックスパイプライン(IRhiPipeline 派生)。 FPipelineDesc(VS+PS・頂点レイアウト・ブレンド・深度/ステンシル・ターゲットフォーマット)から PSO とルートシグネチャを組み立てます。クラスFDx12ShaderDX12 のシェーダ(IRhiShader 派生)。 HLSL ソース文字列を D3DCompile でコンパイルし、バイトコードを保持します。 パイプライン作成時に VS/PS として参照されます。クラスFDx12SwapchainDX12 のスワップチェイン(IRhiSwapchain 派生)。 IDXGISwapChain3 と、最大 3 枚のバックバッファ・その RTV ヒープを管理し、毎フレーム描画先を切り替えて画面に提示します。クラスFDx12TextureDX12 のテクスチャ(IRhiTexture 派生)。 通常の 2D 画像のほか、レンダーターゲット・深度バッファ・cubemap・テクスチャ配列を扱い、SRV/RTV/DSV のディスクリプタを必要に応じて持ちます。クラスFFormatTraitsRHI format の block size、byte 数、aspect、圧縮特性を一度に返す静的 trait。構造体FHrResultDX12 内部用の小さな結果ラッパ。 HRESULT(Win32 のエラーコード)を保持し、ACS の Result 系と橋渡しします。構造体FPipelineStateKeyshader、layout、render state、target format
