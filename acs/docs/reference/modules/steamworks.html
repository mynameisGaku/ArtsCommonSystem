CSteamworksBridgeImplSteamworks SDK を実際に呼ぶ本物の実装(acs::game::ISteamworksBridge を Override)。 SteamAPI_Init() を起点に、実績解除・リーダーボード・統計(Stats)・DLC 所有・リッチプレゼンス・フレンド・クラウドセーブ・Workshop・ボイス・Steam Input を提供します。クラスGetDefaultSteamworksBridge()プロセス共有の実 Bridge シングルトンを返す。 初回アクセス時に Init() を 1 回だけ走らせる(Steam 未起動でも参照は返す — 成否は IsInitialized() で判定)。関数InstallSteamworksAsDefault()実 Bridge を acs::game 側の既定 providerとして登録する。 これを呼ぶと、以降ゲームコードは バックエンド非依存に acs::game::GetDefaultSteamworksBridge() で実 Bridge を取得できる(未登録なら自動で Stub が返る)。関数kSubSteamworks* (エラー subcode)TResult が Err の時に err.subcode で原因を見分けるための定数群(カテゴリは ErrCategory::Generic)。 実装固有の失敗理由を表します。定数(u16)
