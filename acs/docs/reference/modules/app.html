マクロ

ACS_DEFINE_MAINAppClass を既定 FAppConfig で起動するエントリポイントを自動生成する。 AppClass をスタックに構築し、`FAppConfig{}` を渡して Run() を呼ぶ実装関数を作り、 main と、UNICODE 契約に対応する WinMain または wWinMain を出して そこへ委譲する (コンソール・Win32 両サブシステム対応)。 AppClass: CApplication を継承したアプリ型。マクロ →ACS_DEFINE_MAIN_WITH_CONFIGcfg_factory が返す FAppConfig で AppClass を起動するエントリポイントを生成する。 ACS_DEFINE_MAIN と同じだが、既定設定の代わりに cfg_factory() の戻り値を Run() に渡す。 AppClass: CApplication を継承したアプリ型。 cfg_factory: FAppConfig を返す呼び出し可能オブジェクト (関数等)。マクロ →
