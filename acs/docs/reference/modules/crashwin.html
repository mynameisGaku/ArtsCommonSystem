機能

CWindowsCrashReporterWindows 専用のクラッシュ報告 backend。 gameframework の ICrashReporterBackend を実装し、DbgHelp の MiniDumpWriteDump でミニダンプを、合わせて人間が読めるテキスト報告書を書き出します。 直前の パンくず（breadcrumb）も最大 32 件まで添付します。 コピー／ムーブは禁止。クラスFWindowsCrashReporterConfigCWindowsCrashReporter の初期設定。 今はダンプ／報告書の出力先フォルダを 1 つ指定するだけのシンプルな設定です。構造体GetDefaultWindowsCrashReporter()プロセス全体で共有される既定の CWindowsCrashReporter singletonを返す。 これが provider として登録される実体。関数InstallWindowsCrashReporterAsDefault()gameframework の CrashReporter provider に本 Windows backend を登録する結線ヘルパ。 これを起動時に一度だけ呼ぶと、以降 acs::game::GetDefaultCrashReporter() が stub でなく本物の Windows backend を返すようになる。関数
