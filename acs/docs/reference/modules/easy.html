機能

Ease / TryEase / EEasingTypeGameFramework と同じイージング catalog の評価可能な全 33 曲線を easy から型付きで利用する入口。 EEasingType は Linear、Quad/Cubic/Quart/Quint/Sine/Expo/Circ/Back/Elastic/Bounce の In/Out/InOut と SmoothStep/SmootherStep を列挙する。 Count = 33 は末尾 sentinel で、評価可能な曲線ではない。 Easy は GameFramework へ一方向に依存し、曲線の数式を重複実装しない。関数・列挙FColor色を表す値。 各成分 r,g,b,a は 0.0〜1.0。 a は不透明度（0=透明, 1=不透明）。 FColor::Red などの定数を使うか、Rgb(255,0,0) で作ります。構造体FJobBatch / FJobNode並列処理のハンドル。 FJobBatch は RunAsync で投げた非同期ジョブ群を、FJobNode は依存グラフの 1 ノードを指す軽量値型（id==0 は無効）。構造体FSprite / FSoundLoadSprite / LoadSound が返す、コピー可能な軽い素材ハンドル（中身は番号 id だけ）。 id==0 は無効。構造体Job / Then / RunJobs依存つきの並列実行。 Job でノードを作り、Then で「A の後に B」と順序を張り、RunJobs で全ノードを依存順に実行して全完了まで待つ。 内部は依存グラフ。関数LoadSprite / LoadSound画像・音を読み込んでハンドルを返す。 同じパスは読み直さず同じハンドルを返す。 失敗しても落ちず、無効ハンドル（id==0）を返す。関数OpenWindow / NextFrame / Quitゲームの開始・1 フレーム進行・終了。 OpenWindow を最初に 1 回だけ呼び、while (NextFrame()) でループします。関数ParallelFor[begin,end) を全コアで分担して fn(i) を呼び、完了まで待つ（同期）。 内部は本格的なワークスチールスレッドプール。 並列にできない環境では自動的に順次実行へフォールバック。関数テンプレートRgb / Rgba / Fade0〜255 の整数から FColor を作るヘルパと、不透明度だけ変える Fade。関数RunAsync / WaitJobs / JobsDone1 つの処理を非同期に走らせて即座に戻り、FJobBatch を返す。 後で WaitJobs で完了を待つか JobsDone で待たずに確認する。 同じ batch に追加投入もできる。関数SetClipRect / ClearClipRect描画をある矩形の中だけに制限するクリップ。 座標は画面座標（カメラの影響を受けない）。関数SetFullscreen / ToggleFullscreen / IsFullscreen全画面表示（ボーダーレス）の ON/OFF。 次のフレームから反映されます。関数SetWindowTitle / SetBackgroundウィンドウのタイトル文字列と背景色を変える。 背景色の既定は濃い紺色。関数WorkerCount / IsWorker並列ワーカ数と、今のコードがワーカスレッド上で動いているかを返す。関数カメラ（SetCamera ほか）ワールド座標と画面を分ける仕組み。 SetCamera 後に描く図形はワールド座標として扱われ、カメラの位置・ズームに応じて画面に映る。 カメラ設定は毎フレーム呼ぶ（呼ばなければカメラ無し）。関数キーボード入力（IsKeyDown ほか）キーの状態を読む。 Down=押されている間ずっと、Pressed=押した瞬間だけ、Released=離した瞬間だけ true。 TextInput() はIME確定後の入力文字（名前入力用）。 キーの種類は EKey 列挙。関数ゲームパッド入力（IsGamepadDown ほか）最大 4 台（player 0〜3、省略時 0）のゲームパッドを読む。 ボタンは EGamepadButton、スティックは -1.0〜+1.0、トリガーは 0.0〜1.0。関数セーブ／ロード（SaveInt ほか）実行ファイルの場所の save.dat に key-value で永続化する。 整数・小数・文字列を保存／読み出し。 Load 系は未保存ならデフォルト値を返す。 OpenWindow の前でも後でも呼べる。関数ポストプロセス（SetBloom ほか）Bloom（発光）・ビネット・カラーグレーディング等、画面全体にかかる効果。 Diligent バックエンドでビルドした時だけ有効（DX12 raw では無視）。 IsPostProcessAvailable() で可否を確認。 既定はすべて無効。関数マウス入力（MouseX ほか）マウス座標（ウィンドウ内ピクセル＝画面座標）・ボタン状態・ホイール。 ボタンは EMouseButton（省略時は左）。 Down/Pressed/Released の違いはキーボードと同じ。関数乱数（RandomInt ほか）整数・小数・真偽値の乱数。 RandomSeed で種を固定すると、毎回同じ並びになる（再現性が必要なテストやリプレイに）。関数入力コード（EKey / EMouseButton / EGamepadButton）easy が再公開している入力用の列挙。 using acs::EKey; 等で acs::easy 名前空間からそのまま EKey::Space のように書ける。 実体は platform モジュールの InputCodes.h で定義され、easy 側では値一覧が見えないため、よく使う値をここにまとめる。 IsKeyDown / IsMouseDown / IsGamepadDown などに渡す。列挙図形を描く（DrawRect ほか）四角・円・線・三角・点を描く関数群。 (x,y) は図形の左上（円だけは中心）、回転は図形の中心まわりで角度は度。 Outline 版は枠線だけ、thickness で太さを指定。関数当たり判定（RectsOverlap ほか）矩形どうし・円どうしの重なり、点が矩形/円の中にあるかを判定する。 重なっていれば true。関数情報（DeltaTime / Fps ほか）フレーム間隔・累積時間・FPS・画面サイズを得る。 DeltaTime を移動量に掛けると、フレームレートに依らず一定速度で動かせる。関数数学ヘルパ（Clamp / Lerp / Sin ほか）範囲制限・線形補間・距離・最小最大・絶対値・平方根・三角関数・向きの角度。 三角関数の角度は度（°）で渡す（C++ 標準の sin/cos はラジアンなので注意）。関数文字を描く（DrawString ほか）UTF-8 の文字列（日本語可、\n で改行）を描く。 中央そろえ版や、文字の幅・高さを測る関数もある。 size で文字サイズを指定。関数画像を描く（DrawSprite ほか）LoadSprite で読んだ画像を描く関数群。 元サイズ・伸縮・回転・色掛け（ティント）・反転・一部切り出し（スプライトシート）に対応。 位置 (x,y) は画像の左上。関数音（Play ほか）効果音の 1 回再生・BGM のループ再生・停止・音量制御。 音量はすべて 0.0〜1.0。関数（最小プログラム）OpenWindow で開き、while (NextFrame()) ループの中で入力を読んで図形を描く、が基本形。 ゲームの状態は main の中のローカル変数でよく、すべての関数をメインスレッド 1 本から呼びます。 座標は左上が原点・ピクセル単位・Y は下向き、角度は度（°）で正が時計回り。使い方
