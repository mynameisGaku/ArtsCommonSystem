acs::AAsset全アセット型が継承する共通基底クラス。 テクスチャ・メッシュ・音声・スクリプトなどがすべてこの基底を共有する。 Type() で実行時の型 ID を取得でき、Id()/State() でレジストリ管理用の 識別子とロード状態を参照する。クラス →acs::AAudioAssetデコード済み音声 (PCM) を保持するアセット。 全フォーマットを 16-bit もしくは float PCM に統一してインターリーブ保持する。 再生は CAudioEngine (XAudio2Backend) が本アセットの PCM を直接扱う。クラス →acs::ABinaryAssetバイト列をそのまま保持する汎用バイナリアセット。 専用ローダがない拡張子のフォールバック用、またはテストデータ用に使う最小実装。クラス →acs::AImageAsset画像 1 枚分の CPU
