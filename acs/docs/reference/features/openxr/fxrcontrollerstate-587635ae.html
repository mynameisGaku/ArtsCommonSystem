FXrControllerState

左右コントローラ 1 ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。分のキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。ある瞬間の状態をまとめて切り取ったコピー。 ここでは 1 フレーム分の入力値の束。。 各対象とする機種/環境の種別。 ここでは Meta Quest や Valve Index など XR 機器の系統。差を吸収した最小公倍数(位置と向きをまとめた姿勢情報。 XR では頭や手の ポーズ を追跡する。+重なりだけを検出する当たり判定。 物理の押し戻しはせず「触れたか」だけを通知する。 関連語は トリガワールド。+グリップ+2 ボタン+ス高精度タイマ（QPC）が刻む最小単位の時間。 TicksPerSecond() で秒に換算する。)。

構造体
対応するAPI: acs::game::FXrControllerState

使う場面

VR コントローラのキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。(撃つ・掴む・移動)を読むとき。

使用例

if (c.trigger > 0.5f) Fire();             // 引き金
if (c.button_a) Jump();
