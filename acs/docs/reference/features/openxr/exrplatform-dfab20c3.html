EXrPlatform

想定する XR 対象とする機種/環境の種別。 ここでは Meta Quest や Valve Index など XR 機器の系統。(Head-Mounted Display。 頭に被る VR/AR ディスプレイ(ヘッドセット)。 種別)の列挙。 Init() に渡して指定するか、ActivePlatform() で今どれが選ばれたかを知る。

列挙(enum)
対応するAPI: acs::game::EXrPlatform

使う場面

特定機種向けの分岐や、自動検出させたい(Unknown)時。
