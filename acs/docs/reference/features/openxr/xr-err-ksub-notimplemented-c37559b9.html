xr_err::kSub_NotImplemented

「未実装」を表すエラー細分番号(99)。 stub の Init() や、インターフェースの裏で実際に仕事をする具象実装。 ここでは OpenXR ローダ等の XR 実装本体。 未統合時に 成功なら値、失敗なら理由を入れて返す型 Result<T,E>。 例外の代わり。 へ載る。 他モジュール(ML 等)と番号を揃え、横断で「未実装」を一律に扱える。

定数(エラー subcode)
対応するAPI: acs::game::xr_err::kSub_NotImplemented

使う場面

Init 失敗が「ランタイム無し」ではなく「そもそも未実装/未リンク」なのかを判別したい時。

使用例

auto r = acs::game::GetDefaultOpenXrBridge().Init();
if (r.IsErr() && r.Error().subcode == acs::game::xr_err::kSub_NotImplemented) {
    // backend 未リンク。常に 2D で動かす。
}
