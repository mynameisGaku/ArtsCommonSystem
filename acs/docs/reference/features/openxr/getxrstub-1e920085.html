GetXrStub()

プロセス内に 1 個だけ存在する静的 CHMD が無くても落ちないよう「常に未初期化・原点ポーズ」を返す IOpenXrBridge の スタブ実装。 実 backend 未リンクでも 2D 経路へフォールバックできる。 への参照を返す。 『既定の実装を返す関数』を後から登録する仕組み。 登録するとアプリ全体の既定実装が差し替わる。 未登録時に GetDefaultOpenXrBridge() が返すのもこれ。

関数
対応するAPI: acs::game::GetXrStub

使う場面

明示的に stub を使いたい/テストで原点位置と向きをまとめた姿勢情報。 XR では頭や手の ポーズ を追跡する。を期待する時。
