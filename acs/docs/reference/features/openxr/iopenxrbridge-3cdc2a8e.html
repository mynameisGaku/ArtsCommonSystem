IOpenXrBridge

XR ランタイム/Head-Mounted Display。 頭に被る VR/AR ディスプレイ(ヘッドセット)。 を抽象化した共通実装を差し替えられるようにするための約束事(純粋仮想クラス)。 I で始まる。(差し替え可能な境界面。 実装(backend)を後から入れ替えられるよう、インターフェースだけを切り出した接合点。)。 ゲームロジックはこの型越しに頭・手の位置と向きをまとめた姿勢情報。 XR では頭や手の ポーズ を追跡する。やヘッドセットの外向きカメラ映像を画面に映し、現実の景色を見られるようにする MR モードの機能。を叩き、具象 インターフェースの裏で実際に仕事をする具象実装。 ここでは OpenXR ローダ等の XR 実装本体。(OpenXR 公式ローダ(Khronos loader)を使った実backend。 HMD や手のポーズを提供する。 / stub 等)は差し替えで選ぶ。 シングル1 つのプログラム内で同時に進む実行の流れ。 複数あると処理を並列にできる。専用・中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。/中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。不可。

使用例

void UpdateVr(acs::game::IOpenXrBridge& xr, float dt) {
    xr.Tick(dt);
    if (!xr.IsTracking()) return;     // 未追跡なら 2D へ
    auto head = xr.HeadPose();
    if (xr.LeftController().trigger > 0.5f) Shoot();
}
