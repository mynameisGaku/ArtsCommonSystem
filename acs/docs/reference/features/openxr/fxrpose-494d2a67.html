FXrPose

Head-Mounted Display。 頭に被る VR/AR ディスプレイ(ヘッドセット)。 やコントローラの位置と向き。 向きは 回転を 4 要素で表す数学表現。 オイラー角の弱点(gimbal lock)が無く、補間にも強い。 ではなく 向きを pitch/yaw/roll の 3 つの回転角で表す方式。 直感的だが gimbal lock の弱点がある。(pitch, yaw, roll)をラジアンで持つ簡素な表現。

構造体
対応するAPI: acs::game::FXrPose

使う場面

頭や手の姿勢を読むとき。 tracked が false の時は原点なので姿勢として使わない。

API項目

API項目 1

FVec3 position
説明
world-space の位置(メートル)。 既定は原点。
対応API
acs::game::FXrPose::position メンバー変数

API項目 2

FVec3 orientation_euler
説明
向きを (pitch, yaw, roll) のラジアンで。 精密な計算が要るなら自分で 回転を 4 要素で表す数学表現。 オイラー角の弱点(gimbal lock)が無く、補間にも強い。/複数の変換（移動・回転・拡大）をまとめて表す数値の表。 3D では FMat4(4x4)。 ベクトルに掛けて座標変換する。へ変換する。
対応API
acs::game::FXrPose::orientation_euler メンバー変数

API項目 3

bool tracked
説明
この位置と向きをまとめた姿勢情報。 XR では頭や手の ポーズ を追跡する。がライブ追跡由来なら true。 false の時 position/orientation は原点で、有効な姿勢として使ってはならない。
戻り値
有効か
対応API
acs::game::FXrPose::tracked メンバー変数

使用例

acs::game::FXrPose p = xr.HeadPose();
if (p.tracked) {
    acs::FVec3 pos = p.position;            // world 位置 (m)
    float yaw = p.orientation_euler.y;      // 向き(ラジアン)
}
