CFixedStepClock

可変な経過秒を描画frameの長さに左右されず、一定の秒数ずつsimulationを進める方法。回数へ同じ入力なら必ず同じ結果になる性質。 replay / netcode / record-replay の同期で必須。 ML 推論や浮動小数のドライバ差はこれを壊すので隔離する。的に変換する、利用側所有の値。

クラス
対応するAPI: acs::timing::CFixedStepClock

使う場面

物理や規則処理を画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。frameとは独立した刻み幅で進める時。
