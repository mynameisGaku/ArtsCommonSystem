TryWriteJson

FJsonValue を UTF-8 JSON へ書き出し、成功時だけ出力文字列を置き換える。

関数
対応するAPI: acs::TryWriteJson

使う場面

ACS の JSON 値を保存用文字列へ変換し、深さと出力バイト数を制限する時。

API項目

API項目 1

bool TryWriteJson(const FJsonValue& Value, FString& Output, u32 MaxDepth = 256u, usize MaxBytes = kMaxJsonInputBytes)
説明
Output の allocator で一時文字列を構築し、制御文字を escape する。 非有限数、深さ超過、サイズ超過、確保失敗では false を返して Output を維持する。
戻り値
完全に書き出せれば true
