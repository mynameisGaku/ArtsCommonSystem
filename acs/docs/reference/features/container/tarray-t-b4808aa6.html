TArray<T>

要素を連続領域へ所有する可変長配列。 末尾追加と range-for に対応し、中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。は禁止、複製は Clone() で明示する。 確保元は IAllocator で指定できる。

クラステンプレート
対応するAPI: acs::TArray

使う場面

個数が動的に変わる要素列を持ちたい時の既定の入れ物。 敵リスト・メッシュを構成する点。 位置・法線・UV などの属性を持つ。・コマンド列など、ほぼ全ての『複数』はこれ。

使用例

TArray<int> xs;
xs.Add(10);
xs.Emplace(20);          // 直接構築
for (int v : xs) { /* range-for 可 */ }
auto copy = xs.Clone();      // 複製は明示的に
