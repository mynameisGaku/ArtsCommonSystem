Json エラー subcode (kSubJson*)

ParseJson が失敗時に 成功なら値、失敗なら理由を入れて返す型 Result<T,E>。 例外の代わり。 へ載せるエラー エラーコードの細目番号。 ACS の Result が持つ FErrorCode.subcode で、どの段階・原因の失敗かを区別する。 AssetPack は 1300 番台を使う。。 ETResult が失敗を表す側。 err.subcode で原因を見分ける。 成功側は Ok。Category::Generic 配下の u16 定数で、構文・深さ・末尾内容・途中終端・数値・" や改行などの特殊文字を、壊れないよう安全な表現に置き換えること。・サイズ超過を区別できる。 全て inline constexpr u16。

定数群

使う場面

ParseJson の TResult が失敗を表す側。 err.subcode で原因を見分ける。 成功側は Ok。or() を受け取り、どの種類の構文エラーかで分岐・ログ出ししたい時。

使用例

auto r = acs::ParseJson(text, len);
if (!r.IsOk()) {
    const FErrorCode& e = r.Error();
    if (e.subcode == kSubJsonDepth) { /* nesting が深すぎ */ }
    else if (e.subcode == kSubJsonBadEscape) { /* \u 等が不正 */ }
}
