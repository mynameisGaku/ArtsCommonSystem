FString

NUL 終端を維持する UTF-8 可変長文字列。 22 バイト以下は本体内に保持し、超過時だけ指定 IAllocator から確保する。 文字列を所有せず参照だけする軽量ビュー。 へ暗黙変換できる。

クラス
対応するAPI: acs::FString

使う場面

中身を書き換えたり連結したりする文字列が欲しい時。 名前・ログ・組み立て中のテキストなど。
