THashMap<K, V, H>

キーから値を検索するキーから値を引く入れ物。 ハッシュで高速に検索する(THashMap)。。 探索距離と指紋を持つバケット列と密な値配列を分け、削除済み目印を残さず連続イテレーションに対応する。 中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。禁止・中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。専用。

クラステンプレート
対応するAPI: acs::THashMap

使う場面

ID から実体、名前から設定値、のように『キーで素早く引きたい』時。
