ACS 機能 / container

TPair<K, V>

キーと値を first / second に保持する値型。 THashMap の EntryType として密な値配列に格納される。

構造体テンプレート
対応するAPI: acs::TPair

使う場面

THashMap を range-for で回した時の各要素。 あるいは 2 値をまとめて返したい時。

使用例

    u32 key = kv.first;
    FString& val = kv.second;
