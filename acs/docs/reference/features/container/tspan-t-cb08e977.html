TSpan<T>

連続プログラムが使う記憶領域。 確保と解放の管理が性能と安全性を左右する。領域を指す中身を所有(確保/解放)せず、既存データをポインタ+長さで参照するだけの軽い型。 元データより長生きさせないこと。。 先頭メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。と要素数だけを持ち、末尾追加が速く要素は連続メモリに並ぶ。 コピー禁止・ムーブ専用。、生配列、連続バッファを同じ引数形で受け取れる。

クラステンプレート
対応するAPI: acs::TSpan

使う場面

関数の引数で『連続した要素列をまとめて見たい』時。 そのメモリ/資源を『誰が解放する責任を持つか』。 はっきりさせると安全。を渡さず、配列か生配列かを問わず受けられる。 参照先の寿命には注意。

API項目 7

bool TrySubSpan(usize offset, usize count, TSpan& out)
説明
外部キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。向けの fail-closed 版。 null と非 0 size の不正 view、範囲外、加算 overflow を条件が偽ならその場でプログラムを止めてバグを知らせる仕組み（ACS_ASSERT 等）。なしで拒否し、失敗時は out を変更しない。
戻り値
範囲が有効なら true
使う場面
ファイルや通信など信頼できない長さから部分 view を切り出す時。
使用例
TSpan<const u8> part;
if (!bytes.TrySubSpan(offset, count, part)) {
    return InvalidRange();
}
