FStringView

UTF-8 バイト列を指す中身を所有(確保/解放)せず、既存データをポインタ+長さで参照するだけの軽い型。 元データより長生きさせないこと。。 先頭メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。とバイト長だけを持ち、確保せずに比較、検索、接頭辞・接尾辞判定を行う。

クラス
対応するAPI: acs::FStringView

使う場面

文字列を『読むだけ』の関数引数。 短い文字列はヒープ無しで持つ最適化付き。 でも C 文字列リテラルでも同じ型で受け取れる。 元の文字列より長生きさせないこと。
