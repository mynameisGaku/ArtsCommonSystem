CSsr

Screen-Space Reflection。 画面に映っている情報だけから反射(映り込み)をリアルタイムに作る技法。(Screen-Space Reflection)。 タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。の High Dynamic Range。 明暗の幅を float で広く保持する描画。 最後にトーンマップで表示用に圧縮する。 色 + 深度 + 面や線に垂直な向きのベクトル。 当たった面の向きやライティングの計算に使う。 G-buffer から、各ピクセルの反射レイを画面空間で レイに沿って少しずつ進みながらヒットを探す手法。 SSR 等の画面空間効果で使う。(Dynamic Difficulty Adjustment。 プレイヤーの腕前に応じてゲーム難易度を自動で調整する仕組み。)して映り込みを作る。 複数フレームにわたって結果を累積/平均し、ノイズやジャギーを減らす手法。累積でジャギーを均し、Hi-Z で高速化できる。

クラス
対応するAPI: acs::CSsr

使う場面

床や水面に周囲が映り込む反射を、リアルタイムで(Image-Based Lighting。 環境マップを事前積分し、周囲全体からの光として材質に映り込ませる手法。 より動的に)出したいとき。 CPbrShader::SetSsr や CPostProcess に渡す。
