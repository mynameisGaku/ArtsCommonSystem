CPbrShader::FAreaLight / CPbrShader::FLightProbe

CPbrShader 専用のキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。。 FAreaLight=矩形の面(矩形等)から放射される光。 点光源より柔らかい陰影になる。(中心 + 2 軸の半幅向きと大きさを持つ量。 2D/3D の位置・速度・方向を FVec2/FVec3 で表す。 + 色)、FLightProbe=静的光プローブ(位置 + 方向ごとの光を少数の係数(SH)で表す近似。 間接光(irradiance)の圧縮表現に使う。9 係数)。
