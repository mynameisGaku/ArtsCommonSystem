ACS 機能 / render-core

TDrawPacketSortKeyLayout

優先順に並べた整数fieldのbit幅から、64 bit画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。sort keyのshiftとmaskをcompile time生成するlayout。

テンプレート構造体
対応するAPI: acs::TDrawPacketSortKeyLayout

使う場面

pipeline、material、depthなど複数fieldのkey配置を型として固定し、手書きshiftの重複やbit超過を防ぐとき。

説明
field数 / 全fieldの合計bit数。 合計64 bit超過はcompile error。

対応API

API項目 2

対応API

対応API

API項目 3

template<u32 I> static constexpr u64 Insert(u64 value)
説明
値をfield幅でmaskし、優先順の位置へ配置する。
対応API
acs::TDrawPacketSortKeyLayout::Insert メンバー関数

使用例

using FKey = TDrawPacketSortKeyLayout<12u, 20u, 32u>;
u64 key = FKey::Insert<0u>(pipeline) |
          FKey::Insert<1u>(material) |
          FKey::Insert<2u>(depth);
