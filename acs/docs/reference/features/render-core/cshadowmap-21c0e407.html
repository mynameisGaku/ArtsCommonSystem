CShadowMap

太陽光のように無限遠から来る、向きだけを持つ平行光。の光源視点の深度を焼いたテクスチャ。 各点が影かどうかを判定して影を落とす技法。(ortho 投影 depth)。 単一カスケード(伝統的)とCascaded Shadow Map。 カメラの距離帯ごとに解像度の違うシャドウマップを使い、遠景まで鮮鋭な影を保つ。(視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。 frustum を距離で 2〜4 分割し近景高解像・遠景広範囲を 1 枚の atlas に並べる)の 2 モード。

クラス
対応するAPI: acs::CShadowMap

使う場面

3D タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。に影を落としたいとき。 広い屋外で遠くまで鮮鋭な影が要るなら Cascaded Shadow Map。 カメラの距離帯ごとに解像度の違うシャドウマップを使い、遠景まで鮮鋭な影を保つ。。 CStandardShader/CPbrShader の SetShadowMap に渡す。

使用例

CShadowMap sm;
sm.Init(*dev, /*size=*/2048);              // 単一カスケード
sm.SetDirectionalLight(light_dir, scene_center, 15.0f);
// 毎フレーム。各 cascade に実際に記録する caster 数を正確に渡す
if (!sm.BeginFrame(static_cast<u32>(casters.Size()))) return;
cl->BeginShadowPass(*sm.DepthTexture(), 1.0f);
cl->SetPipeline(*sm.CasterPipeline());
cl->SetConstantBuffer(0, *sm.LightCB());
for (auto& c : casters) {
    if (!sm.TrySetCaster(c.model)) continue;
    cl->SetConstantBuffer(1, *sm.CasterObjectCB());
    /* キャスターを描画 */
}
cl->EndShadowPass(*sm.DepthTexture());
pbr.SetShadowMap(sm.DepthTexture(), sm.LightViewProjection());
