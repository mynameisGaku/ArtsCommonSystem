FDebugDraw3D

3D のデバッグ線画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。(LineList)。 コライダーの面を塗らずエッジ(線)だけで形を描く表示。 デバッグに使う。・Axis-Aligned Bounding Box。 軸に平行な直方体の境界ボックス。 当たり判定の粗い包囲に使う。・レイなどを色付きで重ねる。 深度なしで常に手前に見える overlay。

クラス
対応するAPI: acs::FDebugDraw3D

使う場面

当たり判定や面や線に垂直な向きのベクトル。 当たった面の向きやライティングの計算に使う。、デバッグ用の補助線を画面に重ねて確認したいとき。

使用例

dd.Begin();

dd.Wireframe(positions, vcount, indices, icount, FVec4{0.4f,1,0.4f,1});
dd.End(*cl, view_proj);   // RT が bind 済みの状態で
