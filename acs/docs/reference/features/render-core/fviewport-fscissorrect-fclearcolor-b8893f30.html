FViewport / FScissorRect / FClearColor

画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。の基本パラメータ。 FViewport=画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。する画面領域(x,y,幅,高さ,深度範囲)、FScissorRect=この矩形外を捨てるこの矩形の外側のピクセルを描かないクリッピング設定。、FClearColor=塗りつぶし色(RGBA 各 0..1)。

構造体

対応するAPI候補

  • acs::FViewportstruct FViewport;
  • acs::FScissorRectstruct FScissorRect;
  • acs::FClearColorstruct FClearColor;

使う場面

画面の一部だけに描く・分割画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。する・クリア色を指定するとき。
