ACS 機能 / render-core

CLighting2D / FLight2D / CBlobShadow

複数のカラーある位置から全方向に広がり、距離で減衰する光。と、2D の 1 枚絵(キャラ・アイコン等)。 矩形にテクスチャを貼って描く。のシルエットから落ちる柔らかい影を扱う。 CBlobShadow は光源計算なしの激軽な足元の楕円影(fallback)。

クラス / 構造体

対応するAPI候補

  • acs::CLighting2Dclass CLighting2D;
  • acs::FLight2Dstruct FLight2D;
  • acs::CBlobShadowclass CBlobShadow;

使う場面

暗い洞窟をたいまつで照らす等、トップダウン/横スクロール 2D で雰囲気のあるライティングをしたいとき。

使用例

CLighting2D li;
li.Init(*dev, rdr.ColorFormat(), w, h);
li.BeginScene(cl);  sb.Begin(cl,w,h); /* ワールド描画 */ sb.End();  li.EndScene(cl);
li.BeginOccluders(cl); sb.Begin(cl,w,h); /*影を落とす絵を白tintで*/ sb.End(); li.EndOccluders(cl);
li.SetAmbient(FVec3{0.06f,0.06f,0.09f});
li.ClearLights();
li.AddLight({ {px,py}, 256.0f, {1,0.8f,0.5f}, 1.0f, 0.5f });
cl.BeginRenderToSwapchain(sc, idx, clear);
li.Composite(cl, w, h);
cl.EndRenderToSwapchain(sc, idx);
