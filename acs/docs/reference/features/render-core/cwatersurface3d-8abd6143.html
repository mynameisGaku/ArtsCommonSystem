CWaterSurface3D

3D水面の画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。資源、反射、屈折、波、surface別interactionを管理する。

クラス
対応するAPI: acs::CWaterSurface3D

使う場面

有限な矩形水面またはlocal XZの任意形の縁(ふち)をなぞった線。 凸包と違いへこみ(凹み)にも沿う。水面をsceneへ画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。する時。 旧名FWaterSurface3Dも互換別名として使える。
