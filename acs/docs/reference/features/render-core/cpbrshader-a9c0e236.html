CPbrShader

物理ベースレンダリング(Physically Based Rendering。 金属度・粗さなど物理量で材質を表すリアルな描画手法。、Cook-Torrance / Metalness-Roughness)の本格GPU 上で頂点やピクセルを計算する小さなプログラム。 ACS では HLSL で書く。。 金属/粗さ + 環境光 + Image-Based Lighting。 環境マップを事前積分し、周囲全体からの光として材質に映り込ませる手法。 + 影に加え、面や線に垂直な向きのベクトル。 当たった面の向きやライティングの計算に使う。マップ・Screen-Space Ambient Occlusion。 深度から隙間や接地部の遮蔽を求めて陰影を足す技法。/Screen-Space Global Illumination。 画面情報から 1 バウンスの間接光(色のにじみ)を加える技法。/Screen-Space Reflection。 画面に映っている情報だけから反射(映り込み)をリアルタイムに作る技法。・フォグ・布(Sheen)・薄膜(Iridescence)・肌や蝋のように光が表面下で散乱して透ける質感(subsurface scattering)。など多彩な質感を載せられる。

クラス
対応するAPI: acs::CPbrShader

使う場面

Image-Based Lighting。 環境マップを事前積分し、周囲全体からの光として材質に映り込ませる手法。、影、画面空間効果を組み合わせる 3D 画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。。 金属・プラスチック・肌・布などを描き分けたいとき。
