CParticleSystem / FEmitterDesc

中央演算装置。 対応するSIMD命令により計算速度が変わる。 あらかじめ確保した固定数の枠を使い回す仕組み。 確保/解放のコストとフレーム落ちを避けられる。式の2D 炎・煙・火花などを表現する大量の小さな粒子。 1 つ 1 つが位置・速度・寿命を持って動く。コンポーネントを持つエンティティ群を毎フレーム処理する関数(移動・AI など)。 CSystemScheduler で順に実行する。。 火花・煙・爆発・魔法などのエフェクトを FEmitterDesc で定義し、毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。 Update して 多数のスプライトをまとめて効率よく描画する仕組み。 に積む。 Fire/Sparks/Fountain/Smoke のプリセット付き。

クラス / 構造体

対応するAPI候補

  • acs::CParticleSystemclass CParticleSystem;
  • acs::FEmitterDescstruct FEmitterDesc;

使う場面

ゲームの視覚エフェクト全般。 打撃の火花、たき火の炎、噴水など。
