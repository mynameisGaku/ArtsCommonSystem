CTransientUploadArena

同じ大きさの一時シェーダに渡す小さなパラメータ群(行列・色・ライト等)を入れる GPU バッファ(cbuffer / CB)。を256 byte境界の論理sliceへ分け、少数の共有画像処理に特化した演算装置。 描画はここで行われる。 pageで保持するframe arena。

クラス
対応するAPI: acs::CTransientUploadArena

使う場面

多数drawの定数をdrawごとに上書きせず保持しながら、画像処理に特化した演算装置。 描画はここで行われる。 buffer生成数を減らすとき。 Standard/Physically Based Rendering。 金属度・粗さなど物理量で材質を表すリアルな描画手法。 shaderが内部で使用する。
