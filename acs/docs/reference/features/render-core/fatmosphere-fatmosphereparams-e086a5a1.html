FAtmosphere / FAtmosphereParams

物理大気散乱(Rayleigh + Mie 単散乱)を 中央演算装置。 対応するSIMD命令により計算速度が変わる。 で評価して equirect 画像に焼く。 結果を CImageBasedLighting::LoadEquirectHdrFromMemory に通せば、物理ベースの空から env→irradiance→prefilter の Image-Based Lighting。 環境マップを事前積分し、周囲全体からの光として材質に映り込ませる手法。 一式が組める。

クラス / 構造体

対応するAPI候補

  • acs::FAtmosphereusing FAtmosphere = CAtmosphere;
  • acs::FAtmosphereParamsstruct FAtmosphereParams;

使う場面

プリセット空ではなく、物理的に正しい青空/夕焼けを太陽方角から生成して背景・環境光に使いたいとき。
