ACS 機能 / render-core

EFormat

テクスチャ 1 ピクセルのデータ形式。 フォーマット参照。(1 ピクセルのビット配置)を表す論理的な列挙。 Direct3D 12。 Windows の低レベル GPU API。 ACS の Dx12* 系がネイティブ実装。 / Vulkan で共通の名前で扱える。

列挙(enum)
対応するAPI: acs::EFormat

使う場面

テクスチャ・レンダーターゲット・メッシュを構成する点。 位置・法線・UV などの属性を持つ。要素のデータ形式を指定するとき。

API項目 1

R8G8B8A8_UNorm / _sRGB / _UInt
説明
8bit×4ch。 画像の標準。 sRGB は 表示用の非線形な明るさ変換(sRGB)。 リニア計算後に適用する。解釈、UInt は整数(スキンメッシュを動かす骨。 階層を組み、頂点がこれに追従して変形する。 index 等)。
対応API
acs::EFormat::R8G8B8A8_UNorm 列挙値

API項目 2

B8G8R8A8_UNorm
説明
BGRA 配置。 Win32 ネイティブの描画先の裏画面。 1 フレーム描き終えたら表に提示(present)して画面を更新する。既定。
対応API
acs::EFormat::B8G8R8A8_UNorm 列挙値

API項目 3

R16G16B16A16_Float
説明
High Dynamic Range。 明暗の幅を float で広く保持する描画。 最後にトーンマップで表示用に圧縮する。 レンダーターゲット用の半精度 4ch。
対応API
acs::EFormat::R16G16B16A16_Float 列挙値

API項目 4

R11G11B10_Float / R16G16_Float
説明
32bit パックの省プログラムが使う記憶領域。 確保と解放の管理が性能と安全性を左右する。 High Dynamic Range。 明暗の幅を float で広く保持する描画。 最後にトーンマップで表示用に圧縮する。(環境/Image-Based Lighting。 環境マップを事前積分し、周囲全体からの光として材質に映り込ませる手法。 向け)、2ch 半精度(BRDF LUT 等)。
