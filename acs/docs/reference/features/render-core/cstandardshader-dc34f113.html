CStandardShader

DirectX 系のシェーダ言語(High-Level Shading Language)。 を書かずに使える標準ライティングGPU 上で頂点やピクセルを計算する小さなプログラム。 ACS では HLSL で書く。。 Lambert 拡散 + Blinn-Phong スペキュラ + 環境光 + アルベドテクスチャで、太陽光のように無限遠から来る、向きだけを持つ平行光。 最大 4 灯 + ある位置から全方向に広がり、距離で減衰する光。 4 灯 + 光源視点の深度を焼いたテクスチャ。 各点が影かどうかを判定して影を落とす技法。に対応。

クラス
対応するAPI: acs::CStandardShader

使う場面

とりあえず 3D メッシュをまともなライティングで描きたいとき。 Physically Based Rendering。 金属度・粗さなど物理量で材質を表すリアルな描画手法。 まで要らない手軽な経路。

             FVec3{-0.5f,-1,0.3f}, FVec3{1,1,1}, FVec3{0.1f,0.1f,0.15f});
shd.DrawMesh(*rdr.CommandList(), gm, model, FVec3{1,1,1}, 0.5f, 64.0f);
