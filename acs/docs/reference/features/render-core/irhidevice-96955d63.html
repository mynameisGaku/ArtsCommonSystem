IRhiDevice

画像処理に特化した演算装置。 描画はここで行われる。 そのものとの対話を表す抽象(Render Hardware Interface。 DX12 / Vulkan / Diligent などの GPU API の違いを隠す、バックエンド非依存の薄い抽象層。 ACS では IRhiDevice 等がこれ。 の中心)。 抽象的な機能呼び出しを、実際のライブラリや OS API につなぐ実装側のこと。 差し替え可能。(Direct3D 12。 Windows の低レベル GPU API。 ACS の Dx12* 系がネイティブ実装。 / Diligent Engine。 1 つの API で D3D12 / Vulkan 等を扱えるクロスバックエンド層。 ACS の Diligent* 系が利用する。)はこれを実装し、各種リソースはこのGPU とのやり取りを表す IRhiDevice のこと。から作る。

インターフェース
対応するAPI: acs::IRhiDevice

使う場面

テクスチャ・バッファ・GPU 上で頂点やピクセルを計算する小さなプログラム。 ACS では HLSL で書く。・1 回の描画方式(VS+PS・頂点レイアウト・ブレンド・深度等)を丸ごと固めたオブジェクト。 PSO とも。など、あらゆる 画像処理に特化した演算装置。 描画はここで行われる。 リソース作成の第一引数に渡す。 普通は CRenderer::Device() から得る。
