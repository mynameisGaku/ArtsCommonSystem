FTextureDesc / IRhiTexture / CreateRhiTexture

画像処理に特化した演算装置。 描画はここで行われる。 上のテクスチャ(画像)の抽象と作成。 2D だけでなく6 面の正方形テクスチャで全方位を覆う画像。 環境マップやスカイボックスに使う。・配列・縮小版を段階的に持つテクスチャ。 距離や粗さに応じて使い分けジャギーを防ぐ。・レンダーターゲット・深度バッファも表せる。

使う場面

画像を 画像処理に特化した演算装置。 描画はここで行われる。 に置きたい / 自分で RT や深度バッファを用意したいとき。 ゲームで使う画像・音・モデル・データなどの素材ファイル。からは UploadTexture が裏で作る。

struct FTextureDesc{ width, height, format, mip_levels, array_size, is_cubemap, is_render_target, is_depth_target, shader_visible_depth, per_slice_rtv, initial_data, initial_data_size }
説明
サイズ・1 ピクセル/要素のビット配置と型(RGBA8、HDR float、深度など)。 ACS では EFormat。のほか、RT/深度/cubemap/配列/ミップ/per-slice RTV などの用途ON/OFF を表す印。 ここでは暗号化/圧縮の有無。。

使用例

FTextureDesc d;
d.width = 256; d.height = 256;
d.format = EFormat::R8G8B8A8_UNorm;
d.initial_data = pixels;
d.initial_data_size = 256*256*4;
auto tex = CreateRhiTexture(*dev, d).Value();
cl->SetTexture(0, *tex);
