FDirLight / FPointLight

ライトのパラメータ。 FDirLight=向きと色だけを持つ太陽光のように無限遠から来る、向きだけを持つ平行光。(太陽光のような無限遠の平行光)、FPointLight=位置と到達距離を持つある位置から全方向に広がり、距離で減衰する光。。

構造体

対応するAPI候補

  • acs::FDirLightstruct FDirLight;
  • acs::FPointLightstruct FPointLight;

使う場面

SetLights / SetPointLights に渡す配列の要素として。 CStandardShader / CPbrShader / CSkinnedShader で共通。

使用例

FDirLight lights[2];
lights[0].direction = FVec3{0.5f,-1,0.3f}; lights[0].color = FVec3{1,0.9f,0.7f};
lights[1].direction = FVec3{-0.4f,-0.6f,-0.8f}; lights[1].color = FVec3{0.3f,0.4f,0.6f};
shd.SetLights(vp, eye, lights, 2, FVec3{0.1f,0.1f,0.15f});
