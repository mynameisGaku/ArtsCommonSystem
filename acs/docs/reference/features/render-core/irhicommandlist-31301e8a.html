IRhiCommandList

画像処理に特化した演算装置。 描画はここで行われる。 に送る命令を記録するバッファ(GPU に送る描画命令を記録しておくバッファ。 最後にまとめて GPU へ投入する。)。 RT のソケットを特定のアドレス/ポートに結び付けて、そこで送受信できるようにすること。・1 回の描画方式(VS+PS・頂点レイアウト・ブレンド・深度等)を丸ごと固めたオブジェクト。 PSO とも。設定・バッファ/テクスチャの割当・画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。命令をここに積み、最後に 画像処理に特化した演算装置。 描画はここで行われる。 へ投入する。

インターフェース
対応するAPI: acs::IRhiCommandList

使う場面

実際の画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。はすべてこれ経由。 CRenderer::CommandList() から得たものに命令を積む。
