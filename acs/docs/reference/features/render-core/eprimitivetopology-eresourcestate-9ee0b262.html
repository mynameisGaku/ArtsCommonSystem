EPrimitiveTopology / EResourceState

EPrimitiveTopology=メッシュを構成する点。 位置・法線・UV などの属性を持つ。をどう繋いで図形にするか(点/線/三角形列)。 EResourceState=画像処理に特化した演算装置。 描画はここで行われる。 リソースが今どんな用途オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。かを表す抽象(Direct3D 12。 Windows の低レベル GPU API。 ACS の Dx12* 系がネイティブ実装。/Vulkan のGPU リソースの用途状態を切り替える同期。 ACS では普段は内部で自動管理される。共通化)。

使う場面

EPrimitiveTopology は1 回の描画方式(VS+PS・頂点レイアウト・ブレンド・深度等)を丸ごと固めたオブジェクト。 PSO とも。作成時に。 EResourceState は普段は内部で自動管理され、手で触ることはまれ。
