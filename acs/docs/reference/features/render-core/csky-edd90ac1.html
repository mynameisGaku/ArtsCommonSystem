CSky

テクスチャ不要の手続き生成スカイ。 ピクセルGPU 上で頂点やピクセルを計算する小さなプログラム。 ACS では HLSL で書く。で天頂・地平線・地面の色と太陽を2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。して背景の空を描く。 Day/Sunset/Night プリセット付き。

クラス
対応するAPI: acs::CSky

使う場面

3D タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。の背景に空を出したいとき。 タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。より先に呼ぶ。 Image-Based Lighting。 環境マップを事前積分し、周囲全体からの光として材質に映り込ませる手法。 の環境マップ元にもなる。
