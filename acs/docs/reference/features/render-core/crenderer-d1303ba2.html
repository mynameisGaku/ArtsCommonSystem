CRenderer

OS が画面に出す四角い領域。 タイトルバーや × ボタンを持ち、ゲームの描画先になる。 ACS では FWindow。への画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。ループを統括する司令塔。 GPU とのやり取りを表す IRhiDevice のこと。・画面に表示する複数のバックバッファを回しながら、描画と表示を分けて行う仕組み。・GPU に送る描画命令を記録しておくバッファ。 最後にまとめて GPU へ投入する。・深度バッファをまとめて初期化し、毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。の「開始→描く→終了」を 1 つにまとめる。

使用例

CRenderer rdr;
rdr.Init(window);                       // Device+Swapchain+CmdList+深度を一括作成
while (!window.ShouldClose()) {
    window.PollEvents();
    rdr.BeginFrame({0.1f, 0.2f, 0.3f, 1.0f});   // クリア色で塗る
    // rdr.CommandList() にコマンドを積む
    if (!rdr.EndFrame()) break;           // Submit/Present failure は継続しない
}
rdr.Shutdown();
