CHiZ

Hi-Z(Hierarchical-Z)粗い min-depth バッファ。 タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。深度から 1/8 解像度の「ブデータを守るための『鍵』。 取った人だけが対象を触れ、他は解放されるまで待つ。内最近接 NDC depth」を一発で焼く。 Screen-Space Reflection。 画面に映っている情報だけから反射(映り込み)をリアルタイムに作る技法。 のレイに沿って少しずつ進みながらヒットを探す手法。 SSR 等の画面空間効果で使う。が空中の texel を一気にスキップ(skip-ahead)するのに使い、4〜6 倍高速化する。

クラス
対応するAPI: acs::CHiZ

使う場面

CSsr の高速化に。 毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。主パス深度の完成後・Screen-Space Reflection。 画面に映っている情報だけから反射(映り込み)をリアルタイムに作る技法。 の前に Build して Texture() を渡す。
