CImageBasedLighting

Image-Based Lighting。 環境マップを事前積分し、周囲全体からの光として材質に映り込ませる手法。(環境マップから事前積分した光)を構築する。 BRDF LUT・環境6 面の正方形テクスチャで全方位を覆う画像。 環境マップやスカイボックスに使う。・拡散 irradiance・鏡面 prefilter を生成し、CPbrShader::SetIbl に渡す。 equirect High Dynamic Range。 明暗の幅を float で広く保持する描画。 最後にトーンマップで表示用に圧縮する。(.hdr)読込や 方向ごとの光を少数の係数(SH)で表す近似。 間接光(irradiance)の圧縮表現に使う。(SH9)計算、skybox 画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。も持つ。 Diligent Engine。 1 つの API で D3D12 / Vulkan 等を扱えるクロスバックエンド層。 ACS の Diligent* 系が利用する。 インターフェースの裏で実際に仕事をする具象実装。 ここでは OpenXR ローダ等の XR 実装本体。 専用。

クラス
対応するAPI: acs::CImageBasedLighting

使う場面

Physically Based Rendering。 金属度・粗さなど物理量で材質を表すリアルな描画手法。 の環境光を本格化して、金属に映り込みを、全体に自然な間接光を与えたいとき。
