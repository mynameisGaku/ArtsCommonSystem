FSpriteSortList

sprite commandをlayer、depth、提出順で安定整列して多数のスプライトをまとめて効率よく描画する仕組み。へ再生する。 大量時はcompile-time keyと安定LSD radixを使う。

クラス
対応するAPI: acs::FSpriteSortList

使う場面

2D world、HUD、半透明spriteの前後関係を明示し、同じlayer/depthの合成順を維持したいとき。

API項目 2

void Sort()
説明
24件以下は挿入sort、それ以上は最大8 byte passの安定radixでlayer/depth昇順へ並べる。
対応API
acs::FSpriteSortList::Sort メンバー関数

対応API

対応API

対応API

API項目 4

u32 LastSortPassCount() / u64 LastSortItemVisits()
説明
直前sortのradix pass数とkey生成、比較、radixを含む同じ入力なら必ず同じ結果になる性質。 乱数や時刻に依存せず、テストや再現がしやすい。なitem走査数。
対応API
acs::FSpriteSortList::LastSortPassCount メンバー関数
対応API
acs::FSpriteSortList::LastSortItemVisits メンバー関数

使用例

FSpriteSortList list;
list.SubmitRect(0, 0, w, h, color, /*layer=*/0, /*depth=*/0);
list.Submit(tex, x, y, w, h, /*layer=*/1, /*depth=*/y);
list.Sort();
list.Replay(sprite_batch);
