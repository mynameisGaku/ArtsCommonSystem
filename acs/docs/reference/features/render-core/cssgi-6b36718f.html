CSsgi

Screen-Space Global Illumination。 画面情報から 1 バウンスの間接光(色のにじみ)を加える技法。(Screen-Space Global Illumination)。 各ピクセルから面や線に垂直な向きのベクトル。 当たった面の向きやライティングの計算に使う。半球にレイを画面空間で march し、当たった先の色を 1 バウンスの間接光として集める。 Screen-Space Ambient Occlusion。 深度から隙間や接地部の遮蔽を求めて陰影を足す技法。 に色サンプリングを足した発展版。 ブラー + 複数フレームにわたって結果を累積/平均し、ノイズやジャギーを減らす手法。累積でノイズを抑える。

クラス
対応するAPI: acs::CSsgi

使う場面

壁の色が床に移る等の「色のにじみ(color bleeding)」を加えて、間接光のリアル感を出したいとき。 出力を CPbrShader::SetSsgi に渡す。

使用例

CSsgi ssgi;
ssgi.Init(*dev, w, h);
ssgi.Render(*dev, *cl, scene_color, scene_depth, mv.OutputNormalTexture(),
            vp, inv_vp, prev_vp, eye,
            /*intensity=*/1.0f, /*max_distance=*/5.0f, mv.OutputTexture());
pbr.SetSsgi(ssgi.OutputTexture(), 1.0f);
