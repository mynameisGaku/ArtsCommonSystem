FEntityId

1 つのゲームの登場物を表すただの ID(番号)。 データ自体は持たず、コンポーネントを付けて意味を与える。を指す軽い識別子。 中身は index(スロット番号)と generation(ハンドルに埋め込む小さなカウンタ。 スロット再利用後に古い参照を検出するために使う。)の組。 スロットが再利用されても再利用される番号(ID)に付ける通し番号。 古いハンドルと新しい中身を取り違えないための目印。が違うので、古い ID を使うと検出できる(オブジェクトを直接ポインタで指す代わりに「配列の index + 世代カウンタ」で指す仕組み。 slot が再利用されても世代が食い違うので、破棄済みの古いハンドルを安全に検出できる。)。

構造体
対応するAPI: acs::FEntityId

使う場面

キャラや弾など『1 つの実体』を指して持ち回る時。 メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。代わりの安全な軽量参照として使う。
