CWorld

ゲームの登場物を表すただの ID(番号)。 データ自体は持たず、コンポーネントを付けて意味を与える。とANode に付ける部品。 1 つの機能 (物理・描画・当たり判定など) を担い、組み合わせて挙動を作る。を束ねる ECS の中心。 ゲームの登場物を表すただの ID(番号)。 データ自体は持たず、コンポーネントを付けて意味を与える。の生成/破棄、ANode に付ける部品。 1 つの機能 (物理・描画・当たり判定など) を担い、組み合わせて挙動を作る。の追加/取得/削除、条件(指定コンポーネントを全部持つ)に合うエンティティを選んで反復する仕組み。 ECS の主役。反復をすべてここから行う。 中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。不可。
