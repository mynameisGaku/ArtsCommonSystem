ASparseSetBase

ACS の Sparse Set 実装。 エンティティ番号→コンポーネント値の高速対応表。 の型に依らない共通部分。 ゲームの登場物を表すただの ID(番号)。 データ自体は持たず、コンポーネントを付けて意味を与える。番号 → 密配列上の位置の対応や、要素数・dense 走査を提供する。 CWorld が型を知らずに集合を扱うための基底。

基底クラス
対応するAPI: acs::ASparseSetBase

使う場面

ふつう直接使わない。 CWorld がANode に付ける部品。 1 つの機能 (物理・描画・当たり判定など) を担い、組み合わせて挙動を作る。型を区別せず保管・破棄するための内部基盤。
