CSystemScheduler

コンポーネントを持つエンティティ群を毎フレーム処理する関数(移動・AI など)。 CSystemScheduler で順に実行する。関数(ECS のシステム関数の型 void(*)(World&, f32 dt)。 World とデルタタイムを受け取り毎フレーム呼ばれる処理単位。)を登録し、毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。まとめて順番に呼ぶ実行器。 登録順に実行される。

クラス
対応するAPI: acs::CSystemScheduler

使う場面

ゲームループの中で複数のコンポーネントを持つエンティティ群を毎フレーム処理する関数(移動・AI など)。 CSystemScheduler で順に実行する。(移動→当たり判定→画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。準備…)を一括で回したい時。
