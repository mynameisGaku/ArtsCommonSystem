CComponentRegistry

ANode に付ける部品。 1 つの機能 (物理・描画・当たり判定など) を担い、組み合わせて挙動を作る。型ごとの操作(型を消去したコンポーネントのサイズ・破棄・ムーブなどの操作束。)を登録・引き出す静的読み込んだアセットをキー(FAssetId)で保持・共有し、再利用する管理表。 ACS では CAssetRegistry。。 型 T を 1 度登録すれば、以後は番号から型を知らずに操作を取り出せる。

クラス
対応するAPI: acs::CComponentRegistry

使う場面

コンパイル時の型情報を隠し、サイズや破棄/移動操作だけを実行時に扱えるようにする手法。したANode に付ける部品。 1 つの機能 (物理・描画・当たり判定など) を担い、組み合わせて挙動を作る。管理を自作する時の土台。 通常は CWorld の内側で使われる。
