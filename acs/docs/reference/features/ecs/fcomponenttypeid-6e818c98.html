ACS 機能 / ecs

FComponentTypeId

ANode に付ける部品。 1 つの機能 (物理・描画・当たり判定など) を担い、組み合わせて挙動を作る。型ごとに一意な番号(u32)を割り当てる仕組み。 GetComponentTypeId<T>() は型 T に固有の番号を返し、ストレージ配列の添字に使う。 初回呼び出しで割り当て、以降は同じ値(1 つのプログラム内で同時に進む実行の流れ。 複数あると処理を並列にできる。安全)。

型エイリアス
対応するAPI: acs::FComponentTypeId

使う場面

通常ユーザーが直接触ることは少なく、CWorld 内部がANode に付ける部品。 1 つの機能 (物理・描画・当たり判定など) を担い、組み合わせて挙動を作る。の保管場所を引くために使う。 低レベルに自前管理したい時のみ。
