SystemFn

コンポーネントを持つエンティティ群を毎フレーム処理する関数(移動・AI など)。 CSystemScheduler で順に実行する。関数の型 void(*)(CWorld&, 32bit の浮動小数(float 相当)。 座標・時間・係数など小数値に使う基本型。 dt)。 CWorld と前フレームから今フレームまでの経過秒（dt）。 速度 × dt で動かすとフレームレートに依存しない。を受け取り、毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。呼ばれる処理の単位。

型エイリアス
対応するAPI: acs::SystemFn

使う場面

移動・AI・物理など『毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。やること』を 1 つの関数にまとめ、スケジューラに登録する時。

使用例

void MovementSystem(CWorld& w, f32 dt) {
    w.Query<Position, Velocity>().Each(
        [dt](FEntityId, Position& p, Velocity& v){ p.x += v.x * dt; });
}
