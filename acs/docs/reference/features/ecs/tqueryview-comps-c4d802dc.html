API項目 1

void Each(Fn fn)
説明
条件に合う各ゲームの登場物を表すただの ID(番号)。 データ自体は持たず、コンポーネントを付けて意味を与える。へ fn(1 つのエンティティを指す軽量な識別子。 index と generation の組。, Comps&...) を呼ぶ。 反復前に dense 列をある瞬間の状態をまとめて切り取ったコピー。 ここでは 1 フレーム分の入力値の束。するので、fn 内で Add/Remove しても安全。
使う場面
通常の毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。処理。
使用例
w.Query<Health>().Each([](FEntityId e, Health& h){ if (h.hp <= 0) {/* 死亡処理 */} });

API項目 2

void EachParallel(Fn fn, u32 grain = 1024)
説明
タスクを並列実行するスレッドプール(ワークスチール方式)。 で chunk 分割し並列に fn を呼ぶ。 各ゲームの登場物を表すただの ID(番号)。 データ自体は持たず、コンポーネントを付けて意味を与える。は独立に処理される前提。 共有資源を触るなら自分で処理が終わるまでその場で待つやり方。 結果がすぐ手に入る代わりに止まる。する。 grain は 1 chunk の最小ゲームの登場物を表すただの ID(番号)。 データ自体は持たず、コンポーネントを付けて意味を与える。数。
使う場面
ゲームの登場物を表すただの ID(番号)。 データ自体は持たず、コンポーネントを付けて意味を与える。数が非常に多く、各処理が独立しているとき。
使用例
w.Query<Position, Velocity>().EachParallel(
    [](FEntityId, Position& p, Velocity& v){ p.x += v.x; }, 1024);
