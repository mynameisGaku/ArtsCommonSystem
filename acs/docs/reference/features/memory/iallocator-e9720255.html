IAllocator

プログラムが使う記憶領域。 確保と解放の管理が性能と安全性を左右する。確保/解放の実装を差し替えられるようにするための約束事(純粋仮想クラス)。 I で始まる。。 すべてのメモリの確保/解放のやり方を担当する部品。 用途に応じて差し替えられる。はこれを実装し、差し替え可能。

インターフェース
対応するAPI: acs::IAllocator

使う場面

確保方法を切り替えたい/独自メモリの確保/解放のやり方を担当する部品。 用途に応じて差し替えられる。を差し込みたい時に、この型で受け渡す。
