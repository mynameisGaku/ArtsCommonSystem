AObject

そのオブジェクトを今いくつの所有者が指しているかの数。 0 になったら破棄する。 TSharedPtr が使う仕組み。で管理される『オブジェクト』の基底。

クラス
対応するAPI: acs::AObject

使う場面

エンジン上の実体(キャラ・アクター等)を表し、生メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。を持ち回りつつ安全に生死を監視したい時。 NewObject で生成する。

使用例

class AEnemy : public AObject {
public:
    int hp = 100;
};

AEnemy* raw = e.Get();
