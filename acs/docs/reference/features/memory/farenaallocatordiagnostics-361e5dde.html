FArenaAllocatorDiagnostics

Arena の batch と再利用される番号(ID)に付ける通し番号。 古いハンドルと新しい中身を取り違えないための目印。 Reset の効果を観測する 40 byte の値 ある時刻の世界全体の状態を 1 つに固めたもの。 server がこれを配信し、client は受信した複数 snapshot を補間して表示する (FPS/MMO 系で標準)。。 owner や寿命は持たない。

構造体
対応するAPI: acs::FArenaAllocatorDiagnostics
