CTlsfAllocator / CShardedTlsfAllocator

TLSF=任意サイズを O(1)・低断片化で確保できる汎用メモリの確保/解放のやり方を担当する部品。 用途に応じて差し替えられる。。 確保開始位置を 16B ごとの外部ビットマップ(あらかじめ確保した固定数の枠を使い回す仕組み。 確保/解放のコストとフレーム落ちを避けられる。容量の約 0.78%)でも照合し、内部メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。の偽装解放を拒否する。 Sharded=N 個の TLSF に分けて複数1 つのプログラム内で同時に進む実行の流れ。 複数あると処理を並列にできる。からの同時確保でも競合しにくくした版(kMaxShards=8)。 どちらも既定構築してから Init() で初期化する二段階(コンストラクタにサイズは渡さない)。

クラス

対応するAPI候補

  • acs::CTlsfAllocatorclass CTlsfAllocator final : public IAllocator;
  • acs::CShardedTlsfAllocatorclass CShardedTlsfAllocator final : public IAllocator;

使う場面

汎用の高速確保が欲しい時。 マルチ1 つのプログラム内で同時に進む実行の流れ。 複数あると処理を並列にできる。で確保が多いなら Sharded。

使用例

// TLSF: 自前のプール buffer を渡して Init する
alignas(16) static acs::u8 pool[1u << 24];   // 16MB
FTlsfAllocator tlsf;
if (tlsf.Init(pool, sizeof(pool)).IsErr()) { /* 失敗 */ }
void* p = tlsf.Alloc(200, 16, FSourceLoc::Current());

// Sharded: 予約サイズ・初期コミット量で Init(shard_count 0=コア数で自動)
FShardedTlsfAllocator sharded;
sharded.Init(256u << 20, 8u << 20);          // 256MB 予約 / 8MB コミット
