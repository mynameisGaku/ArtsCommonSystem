FMemorySystemConfig / FSegmentConfig / FSegmentStats

メモリを目的・寿命別のセグメントに分け、各領域に独立予算を持たせるメモリ管理の中枢。 の設定・統計を運ぶ Plain Old Data。 コンストラクタ等の特別な振る舞いを持たない単純な構造体。 コピーが速く扱いやすい。 群。 FSegmentConfig はメモリを目的・寿命で分けた論理ヒープ(Default/Permanent/Temp/Resource/Develop)。 CMemorySystem が各セグメントに独立した予算を持つ。種別・要求量ハード予算・frame arena 使用を指定する。 FMemorySystemConfig は全メモリを目的・寿命で分けた論理ヒープ(Default/Permanent/Temp/Resource/Develop)。 CMemorySystem が各セグメントに独立した予算を持つ。設定と既定メモリの確保/解放のやり方を担当する部品。 用途に応じて差し替えられる。への導入を指定する。 FSegmentStats は要求量・ピーク・予算・未解放件数を返す。

メモリを目的・寿命別のセグメントに分け、各領域に独立予算を持たせるメモリ管理の中枢。::Init に渡す設定の組み立てや、GetStats の結果受け取りに使う。

FSegmentConfig: ESegment segment; usize hard_budget_bytes; bool use_frame_allocator
