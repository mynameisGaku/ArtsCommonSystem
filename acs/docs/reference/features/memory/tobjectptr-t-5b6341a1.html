TObjectPtr<T>

参照カウント管理されるオブジェクトの基底。 生ポインタからも強/弱参照を作れる。 派生への強参照(生かし続ける所有メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。)。 別名 TStrongObjectPtr<T>。 生メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。 T* からも構築できる。

クラステンプレート
対応するAPI: acs::TObjectPtr

使う場面

オブジェクトを確実に生存させたい所有者側。

e->hp -= 10;
TObjectPtr<AEnemy> e2 = e;  // 共有(カウント+1)
