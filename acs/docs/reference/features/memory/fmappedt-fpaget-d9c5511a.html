FMappedT / FPageT

Virtual Machine。 スクリプトを読み込んで実行する仮想機械。 CLuaVm は Lua の VM。 層がマップ済み領域・連続ページ群を各 8 バイトにデータを規則性を使って小さくすること。 ここでは LZ4 を使う。して持つビットフィールド Plain Old Data。 コンストラクタ等の特別な振る舞いを持たない単純な構造体。 コピーが速く扱いやすい。。 アドレスとページ数・ON/OFF を表す印。 ここでは暗号化/圧縮の有無。をパックする。 static_assert で 8 バイトを保証。

API項目 1

u64 packed_virtual_addr : 44 / page_count : 16 / sparse : 1 / misc : 3
説明
FMappedT: マップ領域の仮想アドレス・ページ数・スパース/その他ON/OFF を表す印。 ここでは暗号化/圧縮の有無。。

packed_virtual_addr は複数の宣言に対応します。
