ACS 機能 / memory

New / Delete / NewArray / DeleteArray

グローバル new/delete を使わず、メモリの確保/解放のやり方を担当する部品。 用途に応じて差し替えられる。からオブジェクトを構築/破棄する基本ヘルパ。 確保→配置 new→オブジェクトが破棄される時に自動で呼ばれる後始末の関数(~ClassName)。→Free を 1 関数化。

関数テンプレート

対応するAPI候補

  • acs::Newtemplate<typename T, typename... Args> ACS_FORCEINLINE T* New(IAllocator& a, Args&&... args) noexcept;
  • acs::Deletetemplate<typename T> ACS_FORCEINLINE void Delete(IAllocator& a, T* p) noexcept;
  • acs::NewArraytemplate<typename T> ACS_FORCEINLINE T* NewArray(IAllocator& a, usize n) noexcept;
  • acs::DeleteArraytemplate<typename T> ACS_FORCEINLINE void DeleteArray(IAllocator& a, T* arr, usize n) noexcept;

使う場面

IAllocator 直下で生のオブジェクトを作りたい低レベルな場面。 通常は MakeUnique/MakeShared を使う。

API項目

API項目 1

T* New<T>(IAllocator& a, Args&&... args)
説明
確保してコンストラクタ引数をテンプレート関数が受け取った引数を、lvalue/rvalue の区別を保ったまま別の関数に渡すこと（Forward）。。 失敗時 null。
戻り値
T*
対応API
acs::New 関数

API項目 2

void Delete<T>(IAllocator& a, T* p)
説明
オブジェクトが破棄される時に自動で呼ばれる後始末の関数(~ClassName)。(トリビアルなら省略)→Free。 null は 何もしない処理。 呼んでも安全で副作用が無いこと。。
対応API
acs::Delete 関数

API項目 3

T* NewArray<T>(IAllocator& a, usize n)
説明
n 個確保して各要素を既定構築。 オーバーフローは null。
戻り値
T*
対応API
acs::NewArray 関数

API項目 4

void DeleteArray<T>(IAllocator& a, T* arr, usize n)
説明
後ろから順にオブジェクトが破棄される時に自動で呼ばれる後始末の関数(~ClassName)。→一括 Free。
対応API
acs::DeleteArray 関数

使用例

IAllocator& a = DefaultAllocator();
MyObj* p = New<MyObj>(a, args...);   // 確保 + コンストラクタ
Delete(a, p);                        // デストラクタ + Free

int* arr = NewArray<int>(a, 64);
DeleteArray(a, arr, 64);
