TWeakPtr<T>

対象の寿命を延ばさない。 生きているか確認し、生きていれば一時的に強参照を得る。

クラステンプレート
対応するAPI: acs::TWeakPtr

使う場面

対象を所有したくないが生死は監視したい時。 とくにAがBを、BがAを参照カウント付きで持ち合い、互いに 0 にならず解放されない状態。 片方を弱参照にして解消する。(親子が持ち合う)を断ち切る側に使う。

API項目 4

void Reset()
説明
対象を所有せず(寿命を延ばさず)、生きているかだけを見られる参照。 循環参照を断ち切るのに使う。を手放す。
対応API
acs::TWeakPtr::Reset メンバー関数

使用例

auto p = MakeShared<FEnemy>();
TWeakPtr<FEnemy> w = p;        // 弱参照(寿命は延ばさない)
if (auto s = w.Lock()) {          // 生きていれば強参照を取得
    s->Update();
}
p.Reset();                        // 強参照ゼロ → 破棄
// w.Lock() は以後ずっと空を返す
