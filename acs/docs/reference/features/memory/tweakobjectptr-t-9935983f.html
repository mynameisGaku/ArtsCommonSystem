TWeakObjectPtr<T>

参照カウント管理されるオブジェクトの基底。 生ポインタからも強/弱参照を作れる。 派生への対象を所有せず(寿命を延ばさず)、生きているかだけを見られる参照。 循環参照を断ち切るのに使う。。 対象が破棄されると自動的に無効になる。 生メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。からも作れる。

クラステンプレート
対応するAPI: acs::TWeakObjectPtr

使う場面

『さっき掴んだ敵がもう死んでいるかもしれない』ような、所有せず生死だけ追う参照。
