AlignUp / IsPow2 / kDefaultAlignment

メモリの確保/解放のやり方を担当する部品。 用途に応じて差し替えられる。実装で多用する整列ヘルパ。 AlignUp=値/メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。を 2 のべき乗の倍数へ切り上げ。 IsPow2=2 のべき乗判定。 kDefaultAlignment=既定整列(1 命令で複数のデータをまとめて計算する CPU 機能。 ベクトル計算を高速化する。 16B と一般 8B の妥協で 16)。

関数 / 定数

対応するAPI候補

  • acs::AlignUpACS_FORCEINLINE usize AlignUp(usize Value, usize Alignment) noexcept;
  • acs::AlignUpACS_FORCEINLINE void* AlignUp(void* Pointer, usize Alignment) noexcept;
  • acs::IsPow2ACS_FORCEINLINE bool IsPow2(usize Value) noexcept;
  • acs::kDefaultAlignmentinline constexpr usize kDefaultAlignment = alignof(void*) > 8 ? alignof(void*) : 16;

使う場面

独自メモリの確保/解放のやり方を担当する部品。 用途に応じて差し替えられる。やバッファ計算で整列を扱う時。 AlignUp の a は必ず 2 のべき乗(Debug で ACS_Ax86 CPU のSIMD命令セットの一系統。 SSE2 は 64bit で常に使える。RT)。
