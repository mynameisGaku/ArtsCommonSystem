CArenaAllocator

確保はメモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。を進めるだけ(超高速)、解放はまとめて Resetのみ、という使い捨てメモリの確保/解放のやり方を担当する部品。 用途に応じて差し替えられる。。 容量は固定せず、満杯になるとページを足して自動で伸びる(ページバック式バンプ)。 同形状の領域は batch 予約でき、Reset は再利用される番号(ID)に付ける通し番号。 古いハンドルと新しい中身を取り違えないための目印。を進めて先頭 page だけを即時初期化する。

クラス
対応するAPI: acs::CArenaAllocator

使う場面

1 ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。だけ使って次ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。に全部捨てる一時データ(画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。コマンド等)。 個別解放はしない。

API項目 5

void Reset(bool release_pages = false)
説明
全確保を一括無効化。 開始済み Alloc の完了を待ち、Reset 中の新規 Alloc は null で拒否する。 既定経路は再利用される番号(ID)に付ける通し番号。 古いハンドルと新しい中身を取り違えないための目印。を進め、先頭以外の保持 page を再利用直前に必要になるまで計算を先延ばしにする方式(lazy)。 現行 TDerived は生成時と依存通知時に即時評価し、Get の再計算は dirty が残った場合の補完経路。初期化する。 release_pages=true で backing に全ページを返す。
対応API
acs::CArenaAllocator::Reset メンバー関数

API項目 6

FArenaAllocatorDiagnostics Diagnostics() const
説明
保持 page、batch 回数/領域数、直前 Reset の page visit、必要になるまで計算を先延ばしにする方式(lazy)。 現行 TDerived は生成時と依存通知時に即時評価し、Get の再計算は dirty が残った場合の補完経路。初期化数を返す。 通常 Alloc に診断用 atomic 更新は追加しない。
