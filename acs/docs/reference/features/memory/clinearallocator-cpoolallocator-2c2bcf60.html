CLinearAllocator / CPoolAllocator

Linear=前から詰める単純高速メモリの確保/解放のやり方を担当する部品。 用途に応じて差し替えられる。(Arena に近い)。 Pool=同じサイズの塊を大量に出し入れする用途に最適化したメモリの確保/解放のやり方を担当する部品。 用途に応じて差し替えられる。。

クラス

対応するAPI候補

  • acs::CLinearAllocatorclass CLinearAllocator final : public IAllocator;
  • acs::CPoolAllocatorclass CPoolAllocator final : public IAllocator;

使う場面

Linear: 連続確保して一括破棄。 Pool: 弾・炎・煙・火花などを表現する大量の小さな粒子。 1 つ 1 つが位置・速度・寿命を持って動く。等、同サイズを高速に取り回す時。
