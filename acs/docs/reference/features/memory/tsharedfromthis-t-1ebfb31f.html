TSharedFromThis<T>

class T : public TSharedFromThis<T> と継承する。

基底クラステンプレート
対応するAPI: acs::TSharedFromThis

使う場面

オブジェクトが『自分を共有する 複数で共有するスマートポインタ。 参照カウントが 0 で自動解放。』を他へ渡したい時(あとで呼んでもらうために登録しておく関数。 ACS では関数ポインタ + void* ユーザーデータの形を取る(STL 不依存方針)。登録など)。 必ず MakeShared 経由で生成すること。

使用例

struct FNode : TSharedFromThis<FNode> {
    TSharedPtr<FNode> Self() { return AsShared(); }
};
auto n = MakeShared<FNode>();
auto same = n->Self();   // n と同じ対象を共有(カウント+1)
