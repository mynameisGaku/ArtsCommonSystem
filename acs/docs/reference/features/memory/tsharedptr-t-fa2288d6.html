TSharedPtr<T>

中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。でそのオブジェクトを今いくつの所有者が指しているかの数。 0 になったら破棄する。 TSharedPtr が使う仕組み。が増え、最後の持ち主が消えた時に対象を破棄。 カウントは複数スレッドから同時に触っても途中状態が見えず、分割されずに完了する操作。 TAtomic が代表。で1 つのプログラム内で同時に進む実行の流れ。 複数あると処理を並列にできる。安全。
