FMemorySnapshot

メモリを目的・寿命別のセグメントに分け、各領域に独立予算を持たせるメモリ管理の中枢。 の現状(メモリを目的・寿命で分けた論理ヒープ(Default/Permanent/Temp/Resource/Develop)。 CMemorySystem が各セグメントに独立した予算を持つ。別の予約/使用/予算)を SVG / BMP / コンソールに可視化出力するユーティリティ。 全メソッド static、外部依存ゼロ(自前ライタ)。 各メモリを目的・寿命で分けた論理ヒープ(Default/Permanent/Temp/Resource/Develop)。 CMemorySystem が各セグメントに独立した予算を持つ。を 1 行のバーとして画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。する。

クラス(静的)
対応するAPI: acs::FMemorySnapshot

使う場面

プログラムが使う記憶領域。 確保と解放の管理が性能と安全性を左右する。使用率を人間が読める形で書き出してデバッグ/プロファイルしたい時。 SVG はブラウザで開け、BMP は外部ツールに流せる。
