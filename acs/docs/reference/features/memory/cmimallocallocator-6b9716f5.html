CMimallocAllocator

mimalloc v3 の first-class heap を所有する汎用メモリの確保/解放のやり方を担当する部品。 用途に応じて差し替えられる。。 要求量の厳密なハード予算、未解放件数、ピーク、サイズ帯ヒストグラム、独立ブデータを守るための『鍵』。 取った人だけが対象を触れ、他は解放されるまで待つ。走査を提供する。 malloc/new のグローバル上書きは行わない。

クラス
対応するAPI: acs::CMimallocAllocator

使う場面

独立した仮想プログラムが使う記憶領域。 確保と解放の管理が性能と安全性を左右する。実行中に好きなサイズを確保できるメモリ領域。 確保/解放のコストがある。、並列確保、用途別予算、終了時のリーク照合が必要な時。 通常は メモリを目的・寿命別のセグメントに分け、各領域に独立予算を持たせるメモリ管理の中枢。 経由で使う。

使用例

CMimallocAllocator allocator;
if (allocator.Init(64u << 20).IsOk()) {
    void* memory = allocator.Alloc(4096, 64, FSourceLoc::Current());
    allocator.Free(memory);
    MimallocHeapInspectionStatistics inspection = allocator.InspectHeap();
    allocator.Shutdown();
}
