ACS 機能 / test

ACS_TEST(Suite, Name)

テストケースを 1 つ宣言するコンパイル前に決まった形へ展開される短い記述(#define)。 定型コードを一行で書ける。。 直後に { ... } でテスト本体を書く。 プログラム起動時に自動でテスト一覧へ登録され、RunAll() で実行される。 Suite はグループ名、Name はその中の個別テスト名。

マクロ
対応するAPI: ACS_TEST

使う場面

新しいテストを 1 つ書くとき。 関数を自分で main から呼ぶ必要はなく、書いただけで実行対象になる。

使用例

ACS_TEST(MathVec3, Add) {
    EXPECT_EQ(FVec3(1,2,3) + FVec3(4,5,6), FVec3(5,7,9));
}

ACS_TEST(MathVec3, Length) {
    EXPECT_NEAR(Length(FVec3(3,4,0)), 5.0f, 0.001f);
}
