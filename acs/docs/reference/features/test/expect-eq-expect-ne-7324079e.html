EXPECT_EQ / EXPECT_NE

2 つの値が等しい(または等しくない)ことを検証する条件が偽ならその場でプログラムを止めてバグを知らせる仕組み（ACS_ASSERT 等）。コンパイル前に決まった形へ展開される短い記述(#define)。 定型コードを一行で書ける。。 内部で a == b を 1 度だけ評価して比べる。 条件を満たさなくてもテストは続行する。

マクロ

対応するAPI候補

  • EXPECT_EQ#define EXPECT_EQ(a, b) \ do { \ auto m_Av = (a); \ auto m_Bv = (b); \ if (!(m_Av == m_Bv)) { \ ::acs::test::RecordFailure(::acs::FSourceLoc::Current(), \ ACS_STRINGIFY(a) " == " ACS_STRINGIFY(b), \ "values differ"); \ } \ } while (0)
  • EXPECT_NE#define EXPECT_NE(a, b) \ do { \ auto m_Av = (a); \ auto m_Bv = (b); \ if (m_Av == m_Bv) { \ ::acs::test::RecordFailure(::acs::FSourceLoc::Current(), \ ACS_STRINGIFY(a) " != " ACS_STRINGIFY(b), \ "values equal"); \ } \ } while (0)

使う場面

計算結果が期待値と一致するかを確かめたいとき。 型は == が定義されていれば何でもよい。
