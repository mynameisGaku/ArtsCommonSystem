Register()

テストケースを実行リストへ登録する。 ACS_TEST が起動時(main 開始前)に自動で呼ぶため、利用者が直接呼ぶことはまずない。

関数
対応するAPI: acs::test::Register

使う場面

テストランナーを自作する等の特殊用途のみ。 普段は ACS_TEST 経由で間接的に使われる。
