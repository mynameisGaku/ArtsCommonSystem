FTestCase

1 つのテストケースの記述子。 スイート名・テスト名・ソース位置・テスト本体への関数そのものを指し示す値。 あとで fn() のように呼び出せる。 テスト本体を一覧に登録する仕組みに使う。を持ち、next で次のケースへ繋がる各要素が「次の要素」への参照を持って数珠つなぎになったデータ構造。 テストケースを順に辿るのに使う。のゲーム世界に置く部品の単位。 位置やコンポーネントを持ち、親子のツリーで並ぶ。でもある。 ACS_TEST が内部で自動生成するので、通常は手で触らない。

構造体
対応するAPI: acs::test::FTestCase

使う場面

通常は意識しなくてよい(ACS_TEST が裏で作る)。 テストランナーを自作したり一覧を走査したい上級者向け。
