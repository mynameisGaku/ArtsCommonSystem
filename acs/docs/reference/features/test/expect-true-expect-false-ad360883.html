ACS 機能 / test

EXPECT_TRUE / EXPECT_FALSE

式が真(または偽)であることを検証する条件が偽ならその場でプログラムを止めてバグを知らせる仕組み（ACS_ASSERT 等）。コンパイル前に決まった形へ展開される短い記述(#define)。 定型コードを一行で書ける。。 条件を満たさなければ失敗を記録するが、テストはそのまま続行する(以降のチェックも走る)。

マクロ

対応するAPI候補

  • EXPECT_TRUE#define EXPECT_TRUE(expr) \ do { \ if (!(expr)) { \ ::acs::test::RecordFailure(::acs::FSourceLoc::Current(), \ ACS_STRINGIFY(expr), "expected true"); \ } \ } while (0)
  • EXPECT_FALSE#define EXPECT_FALSE(expr) \ do { \ if ((expr)) { \ ::acs::test::RecordFailure(::acs::FSourceLoc::Current(), \ ACS_STRINGIFY(expr), "expected false");\ } \ } while (0)

使う場面

bool を返す条件をそのまま確かめたいとき。 一番素朴な検証。
