FUiRect

UI 座標の矩形。 左上原点・ピクセル単位で x, y, w, h を持つ。 点が中に入っているか判定できる。

構造体
対応するAPI: acs::FUiRect

使う場面

ボタンやラベルなど画面上の UI 部品 1 つ 1 つのこと。 AWidget を継承して作る。の領域(rect / requested)を表す基本型。 当たり判定にも使う。
