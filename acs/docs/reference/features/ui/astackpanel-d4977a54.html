AStackPanel

子ボタンやラベルなど画面上の UI 部品 1 つ 1 つのこと。 AWidget を継承して作る。を縦または横に等間隔で並べる各ウィジェットを画面のどこにどの大きさで置くかを決めて配置すること。 Layout で行う。ImGui で作る、デバッグや編集用の小さな子ウィンドウ(調整画面)。。 並べる向き・間隔・余白を指定できる。

クラス
対応するAPI: acs::AStackPanel

使う場面

ボタンやラベルを上から順に積みたい/横一列に並べたい時。 UI の一番外側のルートとしてもよく使う。

使用例

AStackPanel panel;
panel.dir = EStackDir::Vertical;  // 縦積み
panel.spacing = 6.0f;             // 部品の間隔
panel.Add<ALabel>("設定");
panel.Add<AButton>("閉じる");
