FUiKeyModifiers

UI キー『× ボタンが押された』『キーが押された』のような、その瞬間に起きた出来事の通知。 ACS では FEvent として届く。を配信する瞬間の修飾キー押下オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。。 左右キーをまとめた Shift / Ctrl / Alt / Super の4ON/OFF を表す印。 ここでは暗号化/圧縮の有無。を持つ。

構造体
対応するAPI: acs::FUiKeyModifiers

使う場面

独自 widget が Shift や Ctrl を組み合わせたキー操作を実装する時。 通常は CUiキーボード・マウス・ゲームパッドの状態を問い合わせで読む静的クラス。 毎フレーム先頭で Update() を呼んでから状態を読む。 が構築して3引数版 OnKey へ渡す。
