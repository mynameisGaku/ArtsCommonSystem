FUiColors

UI 全体のテーマ色をまとめた構造体。 ImGui で作る、デバッグや編集用の小さな子ウィンドウ(調整画面)。背景・ボタン・スライダー・チェック・文字・キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。欄などの色を 4 次元ベクトル(x, y, z, w)。 RGBA 色や同次座標、行列との掛け算に使う。(RGBA) で持つ。

構造体
対応するAPI: acs::FUiColors

使う場面

アプリの配色を一括で変えたい時。 AWidget ツリーを CSpriteBatch/FFont で描き、UTF-8 全体・prefix の幅も測る UI renderer。::Colors() から取得して書き換える。
