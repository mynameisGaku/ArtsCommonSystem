AButton

押せるボタン。 クリック(同じボタン上で押して離す)が完結した瞬間に clicked が一瞬だけ true になり、Subscribe した処理が走る。

クラス
対応するAPI: acs::AButton

使う場面

『OK』『攻撃』などの 1 回押すと何かが起きるボタンが欲しい時。

ui

API項目

API項目 1

TObservable<FString> text
説明
ボタンに出すラベル文字列。
対応API
acs::AButton::text メンバー変数

API項目 2

TObservable<bool> clicked
説明
クリック完了時に true→false とパルス発火する。 Subscribe 側は true の時だけ反応する。 subscriber が current button を親ツリーから処理が終わるまでその場で待つやり方。 結果がすぐ手に入る代わりに止まる。除去した場合は、破棄後の false 書き戻しを行わず安全に終了する。
使う場面
ボタンの押下を受け取る標準の方法。
使用例
btn->clicked.Subscribe([](const bool& on, void*){ if(on) DoIt(); }, nullptr);
対応API
acs::AButton::clicked メンバー変数

API項目 3

using FButton = AButton
説明
旧名を使う既存コード向けの互換別名。 新しいコードでは click 完了を TObservable<bool> の pulse として公開する UI button。 を使う。
対応API
acs::FButton 型alias
overload候補
AButton は複数の宣言に対応します。
  • acs::AButtonclass AButton : public AWidget;
  • acs::AButton::AButtonexplicit AButton(const char* label = "Button") noexcept;

使用例

AButton* btn = root.Add<AButton>("開始");
btn->clicked.Subscribe([](const bool& on, void*){
    if (on) StartGame();   // true の瞬間だけ反応
}, nullptr);
