ASlider

つまみをドラッグして範囲内の数値を選ぶボタンやラベルなど画面上の UI 部品 1 つ 1 つのこと。 AWidget を継承して作る。。 下限〜上限を指定し、現在値は T監視できる 1 個の値。 Set で変えると購読者へ通知が飛ぶ。 MVVM の中核。 で公開される。

クラス
対応するAPI: acs::ASlider

使う場面

音量・難易度・パラメータなど連続値をマウスで調整させたい時。 value を MVVM の橋渡し層。 実型 CViewModel と TObservable で状態を公開し、View(画面)がそれを購読して自動反映する。 と双方向 Observable 同士を結びつけ、片方が変わると相手も自動で更新する MVVM のデータバインド。 双方向版は TwoWayBind。 すると便利。
