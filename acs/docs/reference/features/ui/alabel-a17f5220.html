ALabel

静的テキストを表示するだけのボタンやラベルなど画面上の UI 部品 1 つ 1 つのこと。 AWidget を継承して作る。。 文字列は T監視できる 1 個の値。 Set で変えると購読者へ通知が飛ぶ。 MVVM の中核。 なので、データを Observable 同士を結びつけ、片方が変わると相手も自動で更新する MVVM のデータバインド。 双方向版は TwoWayBind。 すれば自動で表示が更新される。

クラス
対応するAPI: acs::ALabel

使う場面

見出し・説明・スコア表示など、押せない文字を出したい時。
