CUiRenderer

retained-mode UI ツリーの基底。 子を TUniquePtr で所有し、layout・render・hit test・入力 hook を提供する。 ツリーを 多数のスプライトをまとめて効率よく描画する仕組み。 + FFont で1 ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。分まとめて画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。する画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。役。 矩形・枠線・文字・カーソル位置用の文字列計測ヘルパを持ち、各ボタンやラベルなど画面上の UI 部品 1 つ 1 つのこと。 AWidget を継承して作る。の Render がこれに画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。を依頼する。 中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。不可。
