AWidget

すべての UI 部品の共通の親。 子を コピー不可・ムーブのみで、スコープを抜けると自動解放。 で所有してツリーを作り、各ウィジェットを画面のどこにどの大きさで置くかを決めて配置すること。 Layout で行う。(配置)・画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。・画面上のある点(マウス位置など)がどのウィジェットの上にあるかを判定すること。(クリック判定)・キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。『× ボタンが押された』『キーが押された』のような、その瞬間に起きた出来事の通知。 ACS では FEvent として届く。の仮想メソッドを持ちます。 中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。不可。

ボタンやImGui で作る、デバッグや編集用の小さな子ウィンドウ(調整画面)。など具体的な部品はこれを継承して作る。 直接インスタンス化するより、派生型(子ウィジェットを縦または横へ spacing/padding 付きで並べる layout panel。 / click 完了を TObservable<bool> の pulse として公開する UI button。 等)を使うのが普通。

API項目 11

virtual void OnKey(i32 key, bool pressed)
説明
従来互換のキー押下/解放『× ボタンが押された』『キーが押された』のような、その瞬間に起きた出来事の通知。 ACS では FEvent として届く。。 CUiキーボード・マウス・ゲームパッドの状態を問い合わせで読む静的クラス。 毎フレーム先頭で Update() を呼んでから状態を読む。 は押下を true、解放を false で配信する。 修飾キー付き既定実装からも転送されるため、既存の override はそのまま動作する。
overload候補
OnKey は複数の宣言に対応します。
