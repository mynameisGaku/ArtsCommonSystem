EGizmoSpace

viewport 上で選択 ANode の Transform(移動 / 回転 / 拡縮)を直接ドラッグ操作するハンドル。 ACS では CEditorGizmo が実装する。の操作座標系。 World は固定ワールド軸、Local は対象 2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。 の rotation を考慮したローカル軸を表示・操作する。
