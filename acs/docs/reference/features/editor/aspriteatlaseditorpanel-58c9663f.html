ASpriteAtlasEditorPanel

1 枚のアトラスと名前付きフレーム矩形を持つデータ層。 の atlas texture path + 名前付き sprite atlas 内の 1 枚分の矩形領域 (x/y/w/h + pivot + 名前) を表す単位。 FSpritePack が名前付きで複数保持する。 列を Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 で対話編集する エディタImGui で作る、デバッグや編集用の小さな子ウィンドウ(調整画面)。。 toolbar (New Frame / Delete / Pivot 切替) + viewport (atlas placeholder + 矩形 overlay + 8 handle resize) + frame list + inspector の構成。 1 枚のアトラスと名前付きフレーム矩形を持つデータ層。 は そのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。 (caller 所有)。 新規 frame 名は内部静的あらかじめ確保した固定数の枠を使い回す仕組み。 確保/解放のコストとフレーム落ちを避けられる。に書き込む。 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。・非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。・全 noexcept。

使用例

namespace sa = acs::game::spriteatlas;
sa::ASpriteAtlasEditorPanel panel;
panel.Init();
acs::game::FSpritePack pack;  // 別途 Init 済とする
panel.SetSpritePack(&pack);
workspace.RegisterPanel(&panel);
panel.AddFrame();
panel.SetPivotPreset(sa::EPivotPreset::Center);
workspace.UnregisterPanel(&panel);
panel.Shutdown();
