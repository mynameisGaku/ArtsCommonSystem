AModelMaterialPanel

ModelViewer 内で、現在 load されたモデルの各 material slot に対し Physically Based Rendering。 金属度・粗さなど物理量で材質を表すリアルな描画手法。 マテリアルをライブ編集する Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 ImGui で作る、デバッグや編集用の小さな子ウィンドウ(調整画面)。。 ACS の editor_core が提供するエディタパネルの抽象基底クラス。 Title / DrawUI / OnInit などを override し、CEditorWorkspace に登録して使う。 を継承し、slot ごとの FMaterial基底クラスの仮想関数を派生クラスで上書き実装すること。 を内部 末尾追加が速く要素は連続メモリに並ぶ。 コピー禁止・ムーブ専用。 に保持して CollapsingHeader + ColorEdit / SliderFloat で編集する。 編集 UI と override 値の保持だけを担い、実 shader への反映は MaterialChangeCallback(raw 関数そのものを指し示す値。 あとで fn() のように呼び出せる。 テスト本体を一覧に登録する仕組みに使う。 + void*) 経由で外部が行う。 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。 / 非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。・全 noexcept。

クラス(AEditorPanel 派生)
対応するAPI: acs::game::modelview::AModelMaterialPanel

使う場面

モデルのマテリアルを試行錯誤で調整するImGui で作る、デバッグや編集用の小さな子ウィンドウ(調整画面)。として使う。 モデル load 時に SetMaterialSlotCount で slot 数を設定し、ある出来事が起きた時に呼んでもらう関数。 を登録して変更を shader に流す。

使用例

AModelMaterialPanel mat;
mat.Init();
mat.SetMaterialSlotCount(3);          // モデルの slot 数
mat.SetOnMaterialChangeCallback(&OnMatChanged, nullptr);
workspace.RegisterPanel(&mat);

if (FMaterialOverride* ov = mat.GetOverrideMutable(0)) {
    ov->roughness = 0.2f;
    ov->is_overridden = true;          // panel 自身は変更検知しない
}
