ABehaviorTreeEditorPanel

CBehaviorTree を 可視化 + step debug する Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 ImGui で作る、デバッグや編集用の小さな子ウィンドウ(調整画面)。。 実体 BT は private で覗けないため、利用側が AddNode で「親 id / kind / 表示名」を push する 実体オブジェクト (ここでは CBehaviorTree) を直接覗けない時に、ユーザが構造情報 (親 id / 種別 / 名前) を別途 push して作る描画用のミラー (写し)。 CBehaviorTree エディタが RTTI 無効下で tree を可視化するために使う。方式を採る。 node オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。は SetNodeStatus で push。 root status の履歴を 60-frame ring に保持。 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。・非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。・全 noexcept。

クラス(AEditorPanel 派生)
対応するAPI: acs::game::btedit::ABehaviorTreeEditorPanel

使う場面

実行中の BT を観察 / step 実行したい時。 BT 構築直後にミラーも組み立て、tick のたびに status を push する。

使用例

namespace bt = acs::game::btedit;
bt::ABehaviorTreeEditorPanel panel;
panel.Init();
acs::game::CBehaviorTree tree;  // 別途構築済とする
panel.SetTree(&tree);
acs::u32 root = panel.AddNode(bt::EBtKind::Selector, "Root", bt::ABehaviorTreeEditorPanel::kInvalidId);
acs::u32 act  = panel.AddNode(bt::EBtKind::Action, "Move", root);
panel.SetNodeStatus(act, acs::game::EBtStatus::Running);
panel.StepOnce();
panel.Shutdown();
