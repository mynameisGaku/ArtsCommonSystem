EBtKind

ABehaviorTreeEditorPanel の実体オブジェクト (ここでは CBehaviorTree) を直接覗けない時に、ユーザが構造情報 (親 id / 種別 / 名前) を別途 push して作る描画用のミラー (写し)。 CBehaviorTree エディタが RTTI 無効下で tree を可視化するために使う。上の node 種別。 実体 BT は Run-Time Type Information。 C++ 標準の実行時型情報。 ACS では使わず、軽量な型 ID / リフレクションで代替する。 無効で種別判定できないため、editor 側で明示保持する。 ABtSelector→Selector / ABtSequence→Sequence / ABtAction→Action に 1:1 対応。

列挙(enum class : u8)
対応するAPI: acs::game::btedit::EBtKind

使う場面

AddNode で node の種別を指定する時、および tree view の色分け / アイコン判別。
