ACS 機能 / editor

AEditorCommand

undo / redo の原子単位(GoF Command パターン)。 1 操作 = 1 派生インスタンス。 Execute / Undo / Description を必ず override し、CanMerge / MergeWith は既定で merge 拒否、連続 drag をまとめたい派生のみ override する。 Run-Time Type Information。 C++ 標準の実行時型情報。 ACS では使わず、軽量な型 ID / リフレクションで代替する。 を避けるため Kind() が返す静的アドレスで型を識別する。 純粋抽象 + virtual dtor、非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。 / 非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。、全 noexcept。

クラス(抽象基底)
対応するAPI: acs::game::editor_core::AEditorCommand

使う場面

新しい undo 可能な操作を CUndoStack 経由で実装する時に継承する。
