EEditorThemePreset

CEditorTheme のプリセット種別。 ApplyPreset に渡すと色 / spacing / corner のある瞬間の状態をまとめて切り取ったコピー。 ここでは 1 フレーム分の入力値の束。が適用される。 SetCustomColors を呼ぶと自動で Custom になる。

列挙(enum class : u8)
対応するAPI: acs::game::editor_core::EEditorThemePreset

使う場面

エディタの配色を切り替える時。
