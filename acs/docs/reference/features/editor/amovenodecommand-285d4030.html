AMoveNodeCommand

2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。 の 2D position を変更する AEditorCommand 派生の基本実装。 old / new 位置を保持し、Execute / Undo から SetPosition2D で new / old を設定する。 同一 target の連続 AMoveNodeCommand を 1 件にまとめる CanMerge / MergeWith を実装(Kind tag のメモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。一致 + target 一致で判定、new 値だけ更新し old 値は始点を保持)。

クラス
対応するAPI: acs::game::editor_core::AMoveNodeCommand

使う場面

ドラッグでゲーム世界に置く部品の単位。 位置やコンポーネントを持ち、親子のツリーで並ぶ。位置を変えた操作を undo 可能にする時のひな形として。
