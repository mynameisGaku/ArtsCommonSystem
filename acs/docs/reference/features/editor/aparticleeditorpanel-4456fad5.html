AParticleEditorPanel

FParticleEmitterDef を Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 で実機編集するための emitter プロパティエディタ ImGui で作る、デバッグや編集用の小さな子ウィンドウ(調整画面)。。 editor_core::ACS の editor_core が提供するエディタパネルの抽象基底クラス。 Title / DrawUI / OnInit などを override し、CEditorWorkspace に登録して使う。 を継承し、内部に 末尾追加が速く要素は連続メモリに並ぶ。 コピー禁止・ムーブ専用。<FParticleEmitterDef> を持つ。 emitter handle や pool への反映 (CreateEmitter 等) は呼び出し側の責務で、本 panel は def の編集のみを担う。 Save / Load は ある出来事が起きた時に呼んでもらう関数。 hook に委譲。 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。・非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。・全 noexcept。

クラス(AEditorPanel 派生)
対応するAPI: acs::game::fxedit::AParticleEditorPanel

使う場面

Editor / DevTool ビルドで emitter パラメータをライブ編集したい時。 CEditorWorkspace::RegisterPanel(&panel) で登録する。

使用例

namespace fx = acs::game::fxedit;
fx::AParticleEditorPanel panel;
panel.Init();
panel.AddEmitter();
if (auto* def = panel.GetEmitterDefMutable(0)) {
    def->lifetime_sec = 1.5f;
}
if (panel.IsDirty()) {
    // ... 保存 ...
    panel.ClearDirty();
}
panel.Shutdown();
