CParticleEditorPreview

編集中の FParticleEmitterDef を 1 個だけ instance 化して、リアルタイムに visual feedback を返す preview canvas + stats。 外部の CParticleEffectSystem 上に 1 emitter を立てる方式で system は所有しない。 frame budget は 60-frame の 複数スロットを順番に使い回すバッファ。 毎フレーム書き換える定数バッファを安全に更新するためにフレームインフライトと組み合わせる。で保持。 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。・非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。・全 noexcept。

クラス
対応するAPI: acs::game::fxedit::CParticleEditorPreview

使う場面

ParticleEditor で emitter を編集しながら見た目を即時確認したい時。 値変更時に RecreatePreviewEmitter で再生成すると即反映される。

使用例

namespace fx = acs::game::fxedit;
fx::CParticleEditorPreview preview;
preview.Init();
acs::game::CParticleEffectSystem system;  // 別途 Init 済とする
acs::game::FParticleEmitterDef def {};
preview.RecreatePreviewEmitter(system, &def);
preview.Tick(0.016f, system);
preview.DrawUI(system, &def);
preview.StopAll(system);
preview.Shutdown();
