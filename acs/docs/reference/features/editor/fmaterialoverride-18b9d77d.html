FMaterialOverride

1 つの material slot 分の Physically Based Rendering。 金属度・粗さなど物理量で材質を表すリアルな描画手法。 override データ(base color / metallic / roughness / normal strength / AO strength / emissive / emissive intensity)。 is_overridden が false の slot は「元の material そのまま」を意味し、各値は物理的に neutral な default で初期化される。 ユーザーが UI で 1 つでも触ると is_overridden が true になる。 末尾追加が速く要素は連続メモリに並ぶ。 コピー禁止・ムーブ専用。 Resize 時に MemSet ゼロ初期化される trivially-constructible 各ウィジェットを画面のどこにどの大きさで置くかを決めて配置すること。 Layout で行う。。

構造体(POD)
対応するAPI: acs::game::modelview::FMaterialOverride

使う場面

AModelMaterialPanel から ある出来事が起きた時に呼んでもらう関数。 で 1 件ずつ外部に渡され、受け側が CPbrShader 等の constant buffer に反映する。 CUndoStack には「変更前 → 変更後」を 1 件分として atomic に積める。

API項目

API項目 1

u32 slot_index = 0u
説明
slot 番号(0..SlotCount()-1)。 末尾追加が速く要素は連続メモリに並ぶ。 コピー禁止・ムーブ専用。 index と一致する冗長情報だが、ある出来事が起きた時に呼んでもらう関数。 で外部に渡す際に index を引き直さずに済む。
対応API
acs::game::modelview::FMaterialOverride::slot_index メンバー変数

API項目 2

FVec4 base_color = {1,1,1,1}
説明
Physically Based Rendering。 金属度・粗さなど物理量で材質を表すリアルな描画手法。 base color(RGBA)。 既定 white opaque。
対応API
acs::game::modelview::FMaterialOverride::base_color メンバー変数

API項目 3

f32 metallic = 0.0f
説明
0=dielectric(非金属) / 1=metal。 Physically Based Rendering。 金属度・粗さなど物理量で材質を表すリアルな描画手法。 Metallic workflow に直結。 範囲 [0,1]。
対応API
acs::game::modelview::FMaterialOverride::metallic メンバー変数

API項目 4

f32 roughness = 0.5f
説明
0=mirror smooth / 1=perfectly rough。 GGX の roughness にそのまま渡す。 範囲 [0,1]。
対応API
acs::game::modelview::FMaterialOverride::roughness メンバー変数

API項目 5

f32 normal_strength = 1.0f
説明
normal map 影響度の倍率。 1.0 で neutral、<1 で flatten、>1 で誇張。 範囲 [0,2]。
対応API
acs::game::modelview::FMaterialOverride::normal_strength メンバー変数

API項目 6

f32 ao_strength = 1.0f
説明
ambient occlusion 影響度。 1.0 で AO テクスチャをそのまま、0 で AO 無効。 範囲 [0,1]。
対応API
acs::game::modelview::FMaterialOverride::ao_strength メンバー変数

API項目 7

FVec3 emissive = {0,0,0}
説明
自己発光色(ColorEdit3 値域 [0,1])。 既定 黒(= 発光 OFF)。
対応API
acs::game::modelview::FMaterialOverride::emissive メンバー変数

API項目 8

f32 emissive_intensity = 1.0f
説明
発光強度倍率。 emissive との積で >1 に増幅され bloom / High Dynamic Range。 明暗の幅を float で広く保持する描画。 最後にトーンマップで表示用に圧縮する。 で光って見える。 範囲 [0,10]。
対応API
acs::game::modelview::FMaterialOverride::emissive_intensity メンバー変数

API項目 9

bool is_overridden = false
説明
ユーザーがこの slot を 1 度でも編集したか。 false なら ModelViewer は override を無視して元 material を使う。
対応API
acs::game::modelview::FMaterialOverride::is_overridden メンバー変数

使用例

void OnMatChanged(void* user, u32 slot, const FMaterialOverride& ov) noexcept {
    if (!ov.is_overridden) return;        // 元のマテリアルそのまま
    // ov.base_color / ov.metallic / ov.roughness を shader CB に書く
    (void)user; (void)slot;
}
