CUndoStack

全エディタが共有する undo / redo の中央ハブ。 AEditorCommand 派生を所有し、Push で 1 操作を実行・登録、Undo / Redo で巻き戻し / やり直す。 Push 内で Execute も実行(Execute 忘れを構造防止)、Push は redo stack を破棄、連続 drag は CanMerge / MergeWith で 1 件にまとめる、上限超過時は最古を drop。 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。 / 非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。、全 noexcept、内部は 末尾追加が速く要素は連続メモリに並ぶ。 コピー禁止・ムーブ専用。<コピー不可・ムーブのみで、スコープを抜けると自動解放。<AEditorCommand>>。

クラス(サービス)
対応するAPI: acs::game::editor_core::CUndoStack

使う場面

エディタ操作の undo / redo を統一管理する時。
