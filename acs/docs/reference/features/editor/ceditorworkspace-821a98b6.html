CEditorWorkspace

複数の ACS の editor_core が提供するエディタパネルの抽象基底クラス。 Title / DrawUI / OnInit などを override し、CEditorWorkspace に登録して使う。 を統括する複数のエディタ panel を 1 つの editor アプリとしてまとめ、ライフサイクル・メインループ・レイアウト永続化・イベント broadcast を統括する中央 hub。 ACS では CEditorWorkspace。。 panel 群の登録・探索、毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。の main loop(OnFrameBegin → DockSpace → MenuBar → DrawUI)、Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 DockSpace / Window メニュー、.acslayout での各ウィジェットを画面のどこにどの大きさで置くかを決めて配置すること。 Layout で行う。永続化、選択 / asset 選択『× ボタンが押された』『キーが押された』のような、その瞬間に起きた出来事の通知。 ACS では FEvent として届く。の全 panel への broadcast を担う。 panel は raw pointer のそのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。保持(caller 所有)で、登録順 = dispatch 順。 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。 / 非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。、全 noexcept。

クラス(サービス hub)

複数 panel を 1 つの editor アプリとしてまとめて配線する中央 hub が要る時。

使用例

CEditorWorkspace ws;
ws.Init();
ws.RegisterPanel(&inspector_panel);   // panel は caller 所有
ws.RegisterPanel(&model_viewer);
// 毎フレーム:
ws.TickAllPanels(dt);
// 終了時:
ws.Shutdown();
