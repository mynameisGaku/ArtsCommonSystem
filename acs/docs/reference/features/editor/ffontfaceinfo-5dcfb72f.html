FFontFaceInfo

1 font face のメタ情報 (= 複数の font face を優先順位付きで並べ、ある文字が前の face に無ければ次の face で補う仕組み。 CJK や emoji を別 face で埋める用途に使う。 の 1 要素)。 全フィールド Plain Old Data。 コンストラクタ等の特別な振る舞いを持たない単純な構造体。 コピーが速く扱いやすい。 (trivially copyable)。 文字列 (file_path / family_name) は caller 所有のリテラル前提で そのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。保持 (ACS 規約: <string> 禁止)。

構造体(POD)
対応するAPI: acs::game::fontedit::FFontFaceInfo

使う場面

AFontEditorPanel::AddFontFace に渡す font face 定義として。 loader が file_path を CreateFile / WIC 等に渡す。

API項目

API項目 1

const wchar_t* file_path = nullptr
説明
font file の絶対 / 相対 path (Windows wide)。 そのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。。
対応API
acs::game::fontedit::FFontFaceInfo::file_path メンバー変数

API項目 2

const char* family_name = nullptr
説明
UI 表示用 family 名 (UTF-8、"Noto Sans JP" 等)。 そのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。。
対応API
acs::game::fontedit::FFontFaceInfo::family_name メンバー変数

API項目 6

u32 fallback_index = 0u
説明
chain の何番目か。 panel が Add/Move のたびに 末尾追加が速く要素は連続メモリに並ぶ。 コピー禁止・ムーブ専用。 index と処理が終わるまでその場で待つやり方。 結果がすぐ手に入る代わりに止まる。して再書き込みする冗長情報。
対応API
acs::game::fontedit::FFontFaceInfo::fallback_index メンバー変数

API項目 7

bool is_msdf = false
説明
MSDF 多数の小画像(グリフやタイル)を 1 枚にまとめたテクスチャ。 UV で各部分を取り出す。で焼くか (true) / 通常 bitmap か (false)。
対応API
acs::game::fontedit::FFontFaceInfo::is_msdf メンバー変数

使用例

acs::game::fontedit::FFontFaceInfo primary {};
primary.file_path      = L"assets/fonts/NotoSansJP-Regular.otf";
primary.family_name    = "Noto Sans JP";
primary.base_size_px   = 24.0f;
primary.char_range_min = 0x0020u;
primary.char_range_max = 0xFFFFu;
primary.is_msdf        = true;
