ACS 機能 / editor

FBoneInfo

1 つの bone の情報(名前 + 親 index)。 parent_index < 0 は root bone を意味する。 Inspector は子リストを保持せず、画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。時に parent_index から子を線形走査して TreeNode 階層を再構築する。

構造体(POD)
対応するAPI: acs::game::modelview::FBoneInfo

使う場面

Inspector のスキンメッシュを動かす骨。 階層を組み、頂点がこれに追従して変形する。階層ツリーを表示するため、bone ごとに 1 件作って配列で渡す。 配列内 index が親参照のキーになる。

API項目

API項目 1

const char* name = nullptr
説明
bone 名(例: "Hips", "Spine_01")。 caller 所有のメモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。。
対応API
acs::game::modelview::FBoneInfo::name メンバー変数

API項目 2

i32 parent_index = -1
説明
同 bones 配列内の親 index。 root は -1。
対応API
acs::game::modelview::FBoneInfo::parent_index メンバー変数

使用例

FBoneInfo bones[2];
bones[0].name = "Hips";  bones[0].parent_index = -1; // ルートボーン
bones[1].name = "Spine"; bones[1].parent_index = 0;   // Hips の子
