FEditorKeyframe

ACinematicsTimelineEditorPanel が内部保持する keyframe (リッチ ImGui のドラッグ & ドロップで運ばれるデータ本体。 ACS の CAssetBrowser では "ASSET_PATH" id で wchar_t* を渡す。 付き)。 runtime の CCinematicsDirector::FTimelineKeyframe より広い ImGui のドラッグ & ドロップで運ばれるデータ本体。 ACS の CAssetBrowser では "ASSET_PATH" id で wchar_t* を渡す。 (3 次元ベクトル(x, y, z)。 3D の位置・方向・色などに使う最重要型で、SIMD演算に最適化されている。 / 色 / scale / event_id) を持つ。 Play 時に kind に応じた FTimelineKeyframe へ変換 (ベイク) される。 active な kind に対応するフィールドのみ意味を持つ。

構造体
対応するAPI: acs::game::cinetimeline::FEditorKeyframe

使う場面

panel 内部の keyframe 配列の要素として。 通常は AddKeyframe 経由で生成され、直接構築はあまりしない。
