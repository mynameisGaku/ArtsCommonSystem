FAnimationClipBinding

モデルに含まれる 1 個の animation clip のメタ情報。 AModelAnimationPanel::SetClips で外部から渡す Plain Old Data。 コンストラクタ等の特別な振る舞いを持たない単純な構造体。 コピーが速く扱いやすい。 で、panel は値中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。で内部 末尾追加が速く要素は連続メモリに並ぶ。 コピー禁止・ムーブ専用。 に保持する(呼出側はビルド済み temp 配列を渡してよい)。 name は中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。所有しないため寿命は呼出側責任。

構造体(POD)
対応するAPI: acs::game::modelview::FAnimationClipBinding

使う場面

モデル load 時に clip 一覧を組み立てて SetClips に渡す。 clip_index は外部 CAnimationPlayer のクリップ ID で、ある出来事が起きた時に呼んでもらう関数。 にそのまま返る。

API項目 1

const char* name = nullptr
説明
clip 表示名。 const char* リテラル / 永続バッファ想定(panel は中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。所有しない)。

API項目 2

f32 duration_sec = 0.0f
説明
clip の長さ(秒)。 0 以下が来た場合は内部で clamp される。

API項目 3

説明
clip 既定のループ可否。 UI の Loop checkbox で override 可能。
対応API

API項目 4

u32 clip_index = 0u
説明
外部 CAnimationPlayer 内のクリップ ID。 ある出来事が起きた時に呼んでもらう関数。 にそのまま渡される。 panel は中身を解釈しない。
対応API
acs::game::modelview::FAnimationClipBinding::clip_index メンバー変数

使用例

FAnimationClipBinding clips[] = {
    { "Idle", 2.0f, true,  0 },
    { "Walk", 1.2f, true,  1 },
    { "Jump", 0.8f, false, 2 },
};
anim.SetClips(clips, 3);
