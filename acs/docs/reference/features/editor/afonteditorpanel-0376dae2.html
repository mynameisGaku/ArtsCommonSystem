AFontEditorPanel

複数 font face の 複数の font face を優先順位付きで並べ、ある文字が前の face に無ければ次の face で補う仕組み。 CJK や emoji を別 face で埋める用途に使う。 を Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 で対話編集 + プレ同じリソースを「どう解釈して読むか」を表す窓。 1 つのテクスチャに SRV / RTV / DSV など複数のビューを作れる。する エディタImGui で作る、デバッグや編集用の小さな子ウィンドウ(調整画面)。。 FFontFaceInfo の順序保持配列を持ち、add / remove / reorder (MoveUp/Down) と、任意 UTF-8 テキストの擬似プレ同じリソースを「どう解釈して読むか」を表す窓。 1 つのテクスチャに SRV / RTV / DSV など複数のビューを作れる。 (実 atlas は持たず Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 デフォルト font で代用) を提供。 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。・非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。・全 noexcept。

クラス(AEditorPanel 派生)
対応するAPI: acs::game::fontedit::AFontEditorPanel

使う場面

font の fallback 優先順位と各 face のメタ情報を編集したい時。 編集結果を取り戻して別途 FFont::LoadFromFile 等を呼ぶ (panel は設定エディタ、loader は外部)。

使用例

namespace fe = acs::game::fontedit;
fe::AFontEditorPanel panel;
panel.Init();
workspace.RegisterPanel(&panel);

fe::FFontFaceInfo primary {};
primary.file_path   = L"assets/fonts/NotoSansJP-Regular.otf";
primary.family_name = "Noto Sans JP";
panel.AddFontFace(primary);
panel.SetPreviewText("Hello, ACS! 日本語");
panel.SetPreviewFontSize(28.0f);
panel.Shutdown();
