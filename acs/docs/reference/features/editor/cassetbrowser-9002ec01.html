CAssetBrowser

assets/ ディレクトリツリーを Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 で参照し、Drag & Drop で他 panel にゲームで使う画像・音・モデル・データなどの素材ファイル。パスを供給する panel。 左ペインに tree、右ペインに current directory 一覧を表示。 各エントリは "Ax86 CPU のSIMD命令セットの一系統。 SSE2 は 64bit で常に使える。T_PATH" ImGui のドラッグ & ドロップで運ばれるデータ本体。 ACS の CAssetBrowser では "ASSET_PATH" id で wchar_t* を渡す。(const wchar_t* 直渡し)の ImGui のドラッグ & ドロップで、つかんで運ばれる側(payload を提供する元)。 受け側は BeginDragDropTarget で受け取る。。 拡張子から EAssetKind を判定。 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。 / 非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。、全 noexcept、文字列は内部 pool 管理。

クラス(panel)
対応するAPI: acs::game::editor_core::CAssetBrowser

使う場面

エディタにゲームで使う画像・音・モデル・データなどの素材ファイル。ブラウザを組み込み、ファイルを panel へドラッグ供給したい時。
