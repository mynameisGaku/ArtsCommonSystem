FMeshSummary

model 全体の集計情報を 1 インスタンスにまとめた値型。 model load を担当するcallerが集計し、AModelInspectorPanel::UpdateFromModel に渡す。 全フィールド値型なので Mesh / Skeleton 側のリソース解放と panel 表示が完全に decouple される。

構造体(POD)
対応するAPI: acs::game::modelview::FMeshSummary

使う場面

Inspector ImGui で作る、デバッグや編集用の小さな子ウィンドウ(調整画面)。に「メッシュを構成する点。 位置・法線・UV などの属性を持つ。数 / 三角形数 / submesh / material slot / スキンメッシュを動かす骨。 階層を組み、頂点がこれに追従して変形する。 / クリップ数 / バウンディング球」を渡す時に組み立てる。

API項目

API項目 1

u32 vertex_count = 0
説明
全 vertex 数(submesh 跨ぎ合算後)。
対応API
acs::game::modelview::FMeshSummary::vertex_count メンバー変数

API項目 2

u32 triangle_count = 0
説明
全 triangle 数(index_count / 3 合算)。
対応API
acs::game::modelview::FMeshSummary::triangle_count メンバー変数

API項目 3

u32 submesh_count = 0
説明
submesh セクション数。
対応API
acs::game::modelview::FMeshSummary::submesh_count メンバー変数

API項目 4

u32 material_slot_count = 0
説明
material slot 数(= 異なる material の数)。
対応API
acs::game::modelview::FMeshSummary::material_slot_count メンバー変数

API項目 5

u32 bone_count = 0
説明
skeleton 内 bone 数(skeleton 無しなら 0)。
対応API
acs::game::modelview::FMeshSummary::bone_count メンバー変数

API項目 6

u32 animation_clip_count = 0
説明
関連付けられた animation clip 数(0 可)。
対応API
acs::game::modelview::FMeshSummary::animation_clip_count メンバー変数

API項目 7

f32 bounding_radius = 0.0f
説明
model 全体の bounding sphere 半径。
対応API
acs::game::modelview::FMeshSummary::bounding_radius メンバー変数

API項目 8

acs::FVec3 bounding_center = {}
説明
同 bounding sphere の中心(object 空間)。
対応API
acs::game::modelview::FMeshSummary::bounding_center メンバー変数

使用例

FMeshSummary s;
s.vertex_count    = 12000;
s.triangle_count  = 4000;
s.submesh_count   = 3;
s.bone_count      = 52;
s.bounding_radius = 1.8f;
