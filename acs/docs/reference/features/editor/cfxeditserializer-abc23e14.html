CFxeditSerializer

ParticleEditor が編集中の FParticleEmitterDef 群を、人間可読で Git の変更差分を表示するコマンド。 テキスト保存形式はこれで読みやすいと版管理しやすい。 しやすい .fxedit テキスト形式で保存・復元する オブジェクトの中身をファイルに保存できる形へ書き出し、また読み戻す部品。。 バイナリの TSaveSlot と違い、作業中ゲームで使う画像・音・モデル・データなどの素材ファイル。をそのまま版管理に乗せることを優先する。 全メンバ static、生成・中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。・中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。はすべて = delete。

クラス(static ユーティリティ)
対応するAPI: acs::game::fxedit::CFxeditSerializer

使う場面

emitter 定義をテキストでセーブ/ロードしたい時。 1 行 1 key=value なので 1 パラメータ変更が 1 行 diff になる。 ファイル I/O は acs::CFileSystem 経由。

使用例

acs::game::FParticleEmitterDef defs[2] = {};
defs[0].lifetime_sec = 2.0f;
const char* names[] = {"fire", "smoke"};
namespace fx = acs::game::fxedit;
fx::CFxeditSerializer::Save(L"data/fx.fxedit", defs, names, 2);

acs::game::FParticleEmitterDef loaded[16] = {};
char name_buf[16 * 32] = {};
auto r = fx::CFxeditSerializer::Load(L"data/fx.fxedit", loaded, name_buf, sizeof(name_buf), 16);
if (r.IsOk()) { acs::u32 n = r.Value(); (void)n; }
