FAnimationClipInfo

Inspector が表示する 1 つの animation clip のメタ情報(名前 / 長さ / サンプル数 / ループ可否)。 AModelAnimationPanel の 1 つのボーンアニメーション(尺と時刻ごとの姿勢キー)。ClipObservable 同士を結びつけ、片方が変わると相手も自動で更新する MVVM のデータバインド。 双方向版は TwoWayBind。ing とは別物(こちらは read-only 表示用)。

構造体(POD)
対応するAPI: acs::game::modelview::FAnimationClipInfo

使う場面

Inspector の Animations テーブルに clip 行を表示するため、clip ごとに 1 件作って配列で渡す。

API項目

API項目 1

const char* name = nullptr
説明
clip 名(例: "状態機械の「何もしていない/開始前」を表す既定状態。 Idle→Walk のように、ここから他状態へ遷移する。", "Run", "Attack01")。 caller 所有のメモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。。
対応API
acs::game::modelview::FAnimationClipInfo::name メンバー変数

API項目 2

f32 duration_sec = 0.0f
説明
クリップの長さ(秒)。
対応API
acs::game::modelview::FAnimationClipInfo::duration_sec メンバー変数

API項目 3

u32 sample_count = 0
説明
サンプル数(= keyframe 数の合計など)。
対応API
acs::game::modelview::FAnimationClipInfo::sample_count メンバー変数

API項目 4

bool is_looping = false
説明
ループ再生ON/OFF を表す印。 ここでは暗号化/圧縮の有無。(clip metadata)。
対応API
acs::game::modelview::FAnimationClipInfo::is_looping メンバー変数

使用例

FAnimationClipInfo c;
c.name         = "Idle";
c.duration_sec = 2.0f;
c.sample_count = 60;
c.is_looping   = true;
