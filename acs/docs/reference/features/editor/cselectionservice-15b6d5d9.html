CSelectionService

今「選択されている シーン内の ANode を指す index(24bit) + generation(8bit) の packed ハンドル。 stale 検出に使う。」を全 editor panel (AHierarchyPanel / AInspectorPanel / AEditorToolbar / scene view 等) で共有するための選択ハブ。 単一の選択だけを持ち、変化時に登録済み あとで呼んでもらうために登録しておく関数。 ACS では関数ポインタ + void* ユーザーデータの形を取る(STL 不依存方針)。を (from, to) 付きで一斉発火する。 ゲームアプリの基底クラス。 CApplication を継承し、シーン管理・固定タイムステップ・シーン遷移を内蔵する。 / CSceneManager には依存せず、対象 2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。 が生きているかの検証は値や配列の変化を受け取るためにコールバックを登録すること(Subscribe)。 要らなくなったら解除(Unsubscribe)する。側責務。 ACSの基盤コードと公開APIでは、可変長配列、文字列、所有権管理に TArray、FString、TUniquePtr などのACS型を使用する方針です。 (内部は 末尾追加が速く要素は連続メモリに並ぶ。 コピー禁止・ムーブ専用。)、非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。・非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。。

クラス
対応するAPI: acs::game::inspector::CSelectionService

使う場面

editor 起動コードが 1 個だけ所有し、各 panel が選択を読み書き・値や配列の変化を受け取るためにコールバックを登録すること(Subscribe)。 要らなくなったら解除(Unsubscribe)する。する集中点として使う。 クリックで SelectNode、ハイライト判定に IsSelected、選択追従に RegisterCallback。
