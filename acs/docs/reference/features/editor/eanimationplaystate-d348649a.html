API項目

API項目 1

Stopped = 0
説明
未再生(m_CurrentTime = 0、Play で頭から開始)。
対応API
acs::game::modelview::EAnimationPlayState::Stopped 列挙値

API項目 2

Playing = 1
説明
再生中(Tick(dt) で m_CurrentTime += dt * speed)。
対応API
acs::game::modelview::EAnimationPlayState::Playing 列挙値

API項目 3

Paused = 2
説明
一時停止(m_CurrentTime 保持、Play で同位置から再開)。
対応API
acs::game::modelview::EAnimationPlayState::Paused 列挙値

使用例

if (anim.PlayState() == EAnimationPlayState::Playing) {
    anim.Pause();
