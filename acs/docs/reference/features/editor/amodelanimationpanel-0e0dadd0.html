AModelAnimationPanel

ModelViewer 内でロード済みモデルの animation clip 再生制御 + timeline を行うImGui で作る、デバッグや編集用の小さな子ウィンドウ(調整画面)。。 ACS の editor_core が提供するエディタパネルの抽象基底クラス。 Title / DrawUI / OnInit などを override し、CEditorWorkspace に登録して使う。 を継承し、clip dropdown / Play / Pause / Stop / Time slider / Loop checkbox / Speed slider / BlendWeight slider を提供する。 時刻の進行 + clip 選択 + UI control だけを持ち、実 bone palette 計算 / 画像処理に特化した演算装置。 描画はここで行われる。 反映は OnFrameCallback(raw 関数そのものを指し示す値。 あとで fn() のように呼び出せる。 テスト本体を一覧に登録する仕組みに使う。 + void*) 経由で外部 renderer + CAnimationPlayer に委譲する。 時刻進行は Tick(dt) に分離(DrawUI は画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。専任)。 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。 / 非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。・全 noexcept。

クラス(AEditorPanel 派生)
対応するAPI: acs::game::modelview::AModelAnimationPanel

使う場面

モデルのアニメーションを切り替えて再生確認するImGui で作る、デバッグや編集用の小さな子ウィンドウ(調整画面)。として使う。 SetClips で clip 一覧を渡し、ある出来事が起きた時に呼んでもらう関数。 を登録して毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。 Tick(dt) を呼ぶと、終端で外部に時刻が通知される。
