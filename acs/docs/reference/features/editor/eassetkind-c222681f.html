EAssetKind

拡張子から推測されるゲームで使う画像・音・モデル・データなどの素材ファイル。種別。 editor_core のアセットブラウザパネル。 ファイル選択を OnAssetSelected で各パネルに通知し、拡張子で mesh / texture などに分類する。 の kind フィルタ / アイコン表示 / ClassifyByExtension の戻り値に使う。 Unknown は未分類(未知拡張子 or path が nullptr / 空)、Other は既知だがどの分類にも該当しない汎用ファイル(現状未使用 / 利用側拡張用)。

列挙(enum class : u8)
対応するAPI: acs::game::editor_core::EAssetKind

使う場面

ゲームで使う画像・音・モデル・データなどの素材ファイル。の種類で分岐 / フィルタしたい時。
