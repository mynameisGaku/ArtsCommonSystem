AModelViewerPanel

ModelViewer のメイン描画する画面上の矩形領域と深度の出力範囲。ImGui で作る、デバッグや編集用の小さな子ウィンドウ(調整画面)。。 ACS の editor_core が提供するエディタパネルの抽象基底クラス。 Title / DrawUI / OnInit などを override し、CEditorWorkspace に登録して使う。 を継承し、3D モデルの表示領域と「表示パラメータ」(editor_core のエディタ用カメラ。 3D orbit / pan / dolly 操作と ViewMatrix / ProjectionMatrix の取得を提供し、各パネルが値メンバとして所有する。 / ライティング / 背景色 / グリッド / スキンメッシュを動かす骨。 階層を組み、頂点がこれに追従して変形する。表示) を Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 で操作する。 editor_core のアセットブラウザパネル。 ファイル選択を OnAssetSelected で各パネルに通知し、拡張子で mesh / texture などに分類する。 からの選択通知を受けて mesh 拡張子なら自動でモデルを切り替える。 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。 / 非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。・全 noexcept。

AModelViewerPanel viewer;
viewer.Init();

    auto& cam = viewer.Camera();      // renderer が ViewMatrix を取り出す

}
