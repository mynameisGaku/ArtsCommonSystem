ETimelineKeyKind

ACinematicsTimelineEditorPanel の編集 UI 上で扱う 5 種の 演出概念。 runtime 側の CCinematicsDirector::ETimelineTrackKind とは意図的に概念を分離し、オーサリング向けの要素を表現する。 Play 時に ToTrackKind() 相当で director の TrackKind にマップされる。

列挙(enum class : u8)
対応するAPI: acs::game::cinetimeline::ETimelineKeyKind

使う場面

AddKeyframe で新規キーの種別を指定する時、および timeline の 5 トラックの行割り当て。
