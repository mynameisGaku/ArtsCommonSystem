CEditorTheme

全エディタ panel が共通参照する Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 スタイル統一テーマ管理。 色パレット / spacing / font scale / corner radius を 1 ヶ所で管理し、Init() + ApplyPreset で全エディタが統一見た目になる。 acs::4 次元ベクトル(x, y, z, w)。 RGBA 色や同次座標、行列との掛け算に使う。 ベースで ImVec4 変換は .cpp 内のみ(ヘッダから Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 を漏らさない)。 .acstheme 人間可読テキストで永続化。 Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。::CreateContext 後に呼ぶこと。 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。 / 非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。(global 副作用のため複製不可)、全 noexcept。

クラス(サービス)
対応するAPI: acs::game::editor_core::CEditorTheme

使う場面

エディタ起動時に配色 / DPI スケール / 角丸を統一したい時。
