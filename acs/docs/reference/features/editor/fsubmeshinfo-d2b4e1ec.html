ACS 機能 / editor

FSubmeshInfo

1 つの submesh セクションの情報(名前 + index 範囲 + 使用する material slot)。 name は caller 所有のリテラル / 永続文字列を想定(panel 寿命 ≦ name 寿命)。

構造体(POD)
対応するAPI: acs::game::modelview::FSubmeshInfo

使う場面

Inspector に submesh テーブルを表示するため、submesh ごとに 1 件作って配列で渡す。

基本情報

モジュール

構造体(POD)

API項目

API項目 1

const char* name = nullptr
説明
submesh 名(例: "Body", "Hair", "Eyes")。 caller 所有のメモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。。
対応API
acs::game::modelview::FSubmeshInfo::name メンバー変数

API項目 2

u32 index_start = 0
説明
全 index buffer 内の開始 index。
対応API
acs::game::modelview::FSubmeshInfo::index_start メンバー変数

API項目 3

u32 index_count = 0
説明
この submesh の index 数(3 の倍数想定)。
対応API
acs::game::modelview::FSubmeshInfo::index_count メンバー変数

API項目 4

u32 material_slot_index = 0
説明
この submesh が使う material slot 番号。
対応API
acs::game::modelview::FSubmeshInfo::material_slot_index メンバー変数

使用例

FSubmeshInfo sm;
sm.name                = "Body";
sm.index_start         = 0;
sm.index_count         = 3600;   // 3 の倍数想定
sm.material_slot_index = 0;
