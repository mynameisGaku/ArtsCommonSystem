FEditorCameraState

視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。の公開 state。 debug overlay / serializer から position / target 等を直接覗くための可視 struct(editor_core のエディタ用カメラ。 3D orbit / pan / dolly 操作と ViewMatrix / ProjectionMatrix の取得を提供し、各パネルが値メンバとして所有する。::State() が const 参照で返す)。 直接書き換えは SetTarget 等の accessor 経由推奨(smooth_target との 2 重管理が崩れるため)。

構造体(POD)
対応するAPI: acs::game::editor_core::FEditorCameraState
