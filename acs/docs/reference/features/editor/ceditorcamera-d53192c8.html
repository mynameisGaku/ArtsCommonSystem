CEditorCamera

2D / 3D を 1 クラスで扱う editor 視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。コントローラ。 3D は target を yaw + pitch + distance で周回する 3D カメラが注視点(target)を中心に yaw / pitch / distance で周回する操作モデル。、2D は position + zoom_2d の pan/zoom。 HandleMouseキーボード・マウス・ゲームパッドの状態を問い合わせで読む静的クラス。 毎フレーム先頭で Update() を呼んでから状態を読む。 でマウス IO を集約し、Tick が framerate-independent な 1 - exp(-rate*dt) 2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。で smoothing する。 view / projection 複数の変換（移動・回転・拡大）をまとめて表す数値の表。 3D では FMat4(4x4)。 ベクトルに掛けて座標変換する。を生成。 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。 / 非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。、全 noexcept。

ModelViewer / LevelEditor 等の viewport 視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。を動かす時。
