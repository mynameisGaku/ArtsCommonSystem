FAssetEntry

列挙された 1 件のディレクトリ / ファイル。 path / short_name は editor_core のアセットブラウザパネル。 ファイル選択を OnAssetSelected で各パネルに通知し、拡張子で mesh / texture などに分類する。 の内部 pool を指し、寿命は次の Refresh() まで(再列挙で pool がクリアされ pointer 無効化)。 保持したいなら利用側でバッファに退避する。

構造体
対応するAPI: acs::game::editor_core::FAssetEntry

使う場面

editor_core のアセットブラウザパネル。 ファイル選択を OnAssetSelected で各パネルに通知し、拡張子で mesh / texture などに分類する。::GetEntry で current directory のエントリを 1 件ずつ読む時。
