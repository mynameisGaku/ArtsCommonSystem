ManipulateCallback

drag 終了時に外部へ delta を通知する ある出来事が起きた時に呼んでもらう関数。 型。 drag 完了時に 1 度だけ呼ばれ、CUndoStack に AMoveNodeCommand 等を push する適切なタイミングになる。 delta はモード依存(Translate=移動量 / Rotate=euler 差分[radians] / Scale=倍率差分)。 user は SetOnManipulateCallback の第二引数がそのまま戻る。

型エイリアス(関数ポインタ)
対応するAPI: acs::game::editor_core::ManipulateCallback

使う場面

viewport 上で選択 ANode の Transform(移動 / 回転 / 拡縮)を直接ドラッグ操作するハンドル。 ACS では CEditorGizmo が実装する。操作完了を undo stack やエディタの dirty ON/OFF を表す印。 ここでは暗号化/圧縮の有無。に反映したい時。
