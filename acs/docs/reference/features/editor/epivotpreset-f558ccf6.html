EPivotPreset

ASpriteAtlasEditorPanel のツールバー「Pivot toggle」用 決まった選択肢の集合を表す型(列挙)。 例: 上下左右のキー。。 frame の スプライトの基準点 (回転・配置の原点)。 0〜1 の正規化座標で (0.5,0.5)=中央、(0,0)=左上 を表す。 をプリセット切替する。 E-prefix は ACS 規約。

列挙(enum class : u8)
対応するAPI: acs::game::spriteatlas::EPivotPreset

使う場面

Pivot プリセットを選ぶ時。 SetPivotPreset / PivotPreset で読み書き。 Custom 以外を選ぶと selected frame に スプライトの基準点 (回転・配置の原点)。 0〜1 の正規化座標で (0.5,0.5)=中央、(0,0)=左上 を表す。 値が流し込まれる。

API項目 1

Center = 0
説明
Centerはスプライトの基準点 (回転・配置の原点)。 0〜1 の正規化座標で (0.5,0.5)=中央、(0,0)=左上 を表す。を(0.5, 0.5)に設定します。
