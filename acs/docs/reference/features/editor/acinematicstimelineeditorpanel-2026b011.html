ACinematicsTimelineEditorPanel

CCinematicsDirector を対話編集する timeline editor ImGui で作る、デバッグや編集用の小さな子ウィンドウ(調整画面)。。 水平タイムライン + 5 トラック (ETimelineKeyKind ごと) + keyframe marker + 再生制御 (Play/Pause/Stop/Step) + scrub slider を提供。 リッチな FEditorKeyframe を panel 所有で持ち、Play 時に director へベイクする。 director は そのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。 (caller 所有)。 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。・非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。・全 noexcept。

クラス(AEditorPanel 派生)
対応するAPI: acs::game::cinetimeline::ACinematicsTimelineEditorPanel

使う場面

cutscene の keyframe を時間軸上で配置・編集し、再生確認したい時。 SetCinematicsDirector(&dir) でソケットを特定のアドレス/ポートに結び付けて、そこで送受信できるようにすること。する。

使用例

namespace ct = acs::game::cinetimeline;
ct::ACinematicsTimelineEditorPanel panel;
panel.Init();
workspace.RegisterPanel(&panel);
acs::game::CCinematicsDirector director;
panel.SetCinematicsDirector(&director);
panel.AddKeyframe(ct::ETimelineKeyKind::CameraCut, 0.0f);
panel.AddKeyframe(ct::ETimelineKeyKind::FadeColor, 2.0f);
panel.Play();
panel.Step(0.016f);
panel.Shutdown();
