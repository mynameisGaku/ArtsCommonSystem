FEditorThemeColors

テーマの色 / spacing / corner をまとめた既定スナップショット。 ACS では EEditorThemePreset(Dark / DarkBlue / Light など)。 1 個分のカラーパレット。 各メンバは RGBA [0,1] の acs::4 次元ベクトル(x, y, z, w)。 RGBA 色や同次座標、行列との掛け算に使う。(Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 の ImVec4 と同じ意味論)。 window 背景 / タイトルバー / ボタン各オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。 / frame / text / border / separator / UI の強調色(CheckMark / SliderGrab / TabActive など)。 ACS のブランド色相当。(強調色 = ACS ブランド色相当) / warning / error をまとめる。

構造体(POD)
対応するAPI: acs::game::editor_core::FEditorThemeColors

使う場面

SetCustomColors で独自配色を渡す / Colors() で現パレットを読む時。
