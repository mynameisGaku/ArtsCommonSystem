CMeshCollider

3D の三角形メッシュから当たり判定を作るクラス。 内部で 図形を空間的にまとめて階層の木にした構造(Bounding Volume Hierarchy)。 レイキャストや重なり判定を高速化する。(三角形を空間で階層分けした木)を組み、ある点からある方向へ光線 (ray) を飛ばし、最初に当たる形状と交点を求める処理。 視線判定や射撃に使う。や Axis-Aligned Bounding Box。 軸に平行な直方体の境界ボックス。 当たり判定の粗い包囲に使う。 との重なり判定を高速に行う。

クラス
対応するAPI: acs::CMeshCollider

使う場面

床・壁・地形などのメッシュに対して、視線・弾・マウスのレイがどこに当たるかを調べたい時。 レンダリング用メッシュをそのまま当たり判定に流用できる。
