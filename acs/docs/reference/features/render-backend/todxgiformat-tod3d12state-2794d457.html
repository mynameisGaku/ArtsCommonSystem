API項目

API項目 1

DXGI_FORMAT ToDxgiFormat(EFormat f) noexcept
説明
ピクセルフォーマット(1 ピクセルのビット配置)を表す論理的なenum。 DX12 / Vulkan で共通の名前で扱える。 を DXGI_FORMAT へ変換。 未対応値は DXGI_FORMAT_UNKNOWN。
戻り値
DXGI 1 ピクセル/要素のビット配置と型(RGBA8、HDR float、深度など)。 ACS では EFormat。
対応API
acs::ToDxgiFormat 関数

API項目 2

D3D12_RESOURCE_STATES ToD3D12State(EResourceState s) noexcept
説明
EResourceState を D3D12_RESOURCE_STATES へ変換。 未対応値は D3D12_RESOURCE_STATE_COMMON。
戻り値
D3D12 GPU リソースが今どう使われているか(レンダーターゲット / シェーダ読取 / 提示 等)。 切り替えにはバリアが要る。
対応API
acs::ToD3D12State 関数

使用例

DXGI_FORMAT fmt   = ToDxgiFormat(EFormat::R8G8B8A8_UNorm);
