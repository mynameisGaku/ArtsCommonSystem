FDiligentPipeline

Diligent Engine。 1 つの API で D3D12 / Vulkan 等を扱えるクロスバックエンド層。 ACS の Diligent* 系が利用する。 のグラフィックス1 回の描画方式(VS+PS・頂点レイアウト・ブレンド・深度等)を丸ごと固めたオブジェクト。 PSO とも。(IRhiPipeline 派生)。 IPipelineState と Shader Resource Binding。 Diligent でシェーダにリソースを結び付ける仕組み。 名前ベースで lookup する。(GPU 上で頂点やピクセルを計算する小さなプログラム。 ACS では HLSL で書く。リソーススクリプト言語と C++ の機能を結びつける橋渡し (関数や値の登録)。)を作ります。 Diligent Engine。 1 つの API で D3D12 / Vulkan 等を扱えるクロスバックエンド層。 ACS の Diligent* 系が利用する。 は名前でリソースを引くため、FPipelineDesc の DirectX 系のシェーダ言語(High-Level Shading Language)。 リソース名(cbuffer_names/texture_names)を保持します。
