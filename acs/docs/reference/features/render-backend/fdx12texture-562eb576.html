FDx12Texture

Direct3D 12。 Windows の低レベル GPU API。 ACS の Dx12* 系がネイティブ実装。 のテクスチャ(IRhiTexture 派生)。 通常の 2D 画像のほか、レンダーターゲット・深度バッファ・cubemap・テクスチャ配列を扱い、Shader Resource View。 テクスチャ等をシェーダから読むためのビュー。/RTV/DSV のテクスチャやバッファを GPU から参照するための小さな「住所メモ」。 ディスクリプタヒープに並べて使う。を必要に応じて持ちます。

使用例

FTextureDesc d;
d.width = 256; d.height = 256;
d.format = EFormat::R8G8B8A8_UNorm;
d.initial_data = pixels; d.initial_data_size = 256*256*4;
auto tex = CreateRhiTexture(*dev, d).Value();
cmd->SetTexture(0, *tex);   // パイプラインで texture_slots>=1 が必要
