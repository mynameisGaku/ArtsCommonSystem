CDiligentDevice

Diligent Engine。 1 つの API で D3D12 / Vulkan 等を扱えるクロスバックエンド層。 ACS の Diligent* 系が利用する。 Engine 経由のRHI の入口となる GPU 抽象。 バッファ・テクスチャ・パイプライン等を作る親。(GPU そのものを表す RHI の中心インターフェース。 あらゆる GPU リソースをここから作る。 派生)。 内部に IRenderDevice・IDeviceContext・EngineFactory を持ち、D3D12 と(ビルド次第で)Vulkanを 1 つの ライブラリの機能を外から使うための窓口(関数や型の取り決め)。 例: ネットワークは WinSock をくるんだ薄い API として提供される。 で扱えます。 ヘッダは Diligent Engine。 1 つの API で D3D12 / Vulkan 等を扱えるクロスバックエンド層。 ACS の Diligent* 系が利用する。 依存を漏らさず前方宣言だけで完結します。
