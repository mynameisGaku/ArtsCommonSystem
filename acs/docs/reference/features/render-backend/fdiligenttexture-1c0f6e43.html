FDiligentTexture

Diligent Engine。 1 つの API で D3D12 / Vulkan 等を扱えるクロスバックエンド層。 ACS の Diligent* 系が利用する。 のテクスチャ(IRhiTexture 派生)。 ITexture と、その Shader Resource View。 テクスチャ等をシェーダから読むためのビュー。/RTV/DSV 同じリソースを「どう解釈して読むか」を表す窓。 1 つのテクスチャに SRV / RTV / DSV など複数のビューを作れる。を持ちます。 cubemap・テクスチャ配列・per-slice RTV にも対応します。
