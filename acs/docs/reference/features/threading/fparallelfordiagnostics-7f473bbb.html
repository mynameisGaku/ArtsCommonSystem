FParallelForDiagnostics

タスクを並列実行するスレッドプール(ワークスチール方式)。::ParallelFor が一時 context をどこへ置いたかと、固定 block の同時使用量を返す 40 byte の値 ある時刻の世界全体の状態を 1 つに固めたもの。 server がこれを配信し、client は受信した複数 snapshot を補間して表示する (FPS/MMO 系で標準)。。

構造体
対応するAPI: acs::FParallelForDiagnostics

使う場面

分割数や同時 ParallelFor 数に対して固定 pool が足りているか、heap 退避が起きていないかを profiler や性能 test で確認する時。
