FMutex

守りたいデータを触る前に Lock し、終わったら Unlock する。 Win32 SRWLOCK ベースで軽量。 中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。不可。

クラス
対応するAPI: acs::FMutex

使う場面

複数の値をまとめて更新する等、ロックなしで安全に共有できる小さな値。 1 個では守れない『データのかたまり』を保護したい時。

API項目 1

void Lock()
説明
あるデータを一度に 1 スレッドだけが触れるように制限すること。 FMutex やロックで実現する。データを守るための『鍵』。 取った人だけが対象を触れ、他は解放されるまで待つ。を取る。 他が持っていれば取れるまで待つ(ブロッキング)。

void Unlock()
説明
データを守るための『鍵』。 取った人だけが対象を触れ、他は解放されるまで待つ。を手放す。 Lock と必ず対で呼ぶ。

使用例

FMutex m;
m.Lock();
// ここは同時に1スレッドだけ
list.Add(x);
m.Unlock();
// 実際は手で Unlock せず FScopedLock を使うのが安全
