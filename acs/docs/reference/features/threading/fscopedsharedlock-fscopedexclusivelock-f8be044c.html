FScopedSharedLock / FScopedExclusiveLock

複数の読み取りを同時に許可し、書き込みは1つのスレッドだけに限定する読み書きロックです。 用の オブジェクトの寿命に資源の確保/解放を結びつける手法。 スコープを抜けると自動で後始末される。 ガード。 Shared=共有(読み取り)を自動データを守るための『鍵』。 取った人だけが対象を触れ、他は解放されるまで待つ。/解除、Exclusive=あるデータを一度に 1 スレッドだけが触れるように制限すること。 FMutex やロックで実現する。(書き込み)を自動データを守るための『鍵』。 取った人だけが対象を触れ、他は解放されるまで待つ。/解除。

クラス

対応するAPI候補

  • acs::FScopedSharedLockclass FScopedSharedLock;
  • acs::FScopedExclusiveLockclass FScopedExclusiveLock;

使う場面

複数の読み取りを同時に許可し、書き込みは1つのスレッドだけに限定する読み書きロックです。 を使う時は手動の Lock/Unlock ではなくこれで包む。

API項目

API項目 1

explicit FScopedSharedLock(FRwLock& r) noexcept
説明
構築時に r.LockShared()、オブジェクトが破棄される時に自動で呼ばれる後始末の関数(~ClassName)。で r.UnlockShared()(読み取り、複数同時可)。
対応API
acs::FScopedSharedLock::FScopedSharedLock メンバー関数

API項目 2

explicit FScopedExclusiveLock(FRwLock& r) noexcept
説明
構築時に r.LockExclusive()、オブジェクトが破棄される時に自動で呼ばれる後始末の関数(~ClassName)。で r.UnlockExclusive()(書き込み、独占)。
対応API
acs::FScopedExclusiveLock::FScopedExclusiveLock メンバー関数

使用例

FRwLock rw;
{
    FScopedSharedLock lk(rw);     // 読み取りで保持
    Read(config);
}
{
    FScopedExclusiveLock lk(rw);  // 書き込みで独占
    Write(config);
}
