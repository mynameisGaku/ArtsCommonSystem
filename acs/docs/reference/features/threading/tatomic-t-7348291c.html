API項目 4

bool CompareExchange(T& expected, T desired)
説明
現在値が expected と一致すれば desired に書き換え true。 失敗時は expected に実際の値が入り false。 Compare-And-Swap。 『今の値が期待通りなら新しい値に書き換える』をアトミックに行う基本操作。。
戻り値
成功したか
使う場面
『今が X なら Y にする』というデータを守るための『鍵』。 取った人だけが対象を触れ、他は解放されるまで待つ。フリーな更新ループを書く時。
使用例
u32 cur = a.Load();
while (!a.CompareExchange(cur, cur + 1)) { /* cur は実値に更新済 */ }

API項目 7

T operator++() / operator--()
説明
複数スレッドから同時に触っても途中状態が見えず、分割されずに完了する操作。 TAtomic が代表。なインクリメント/デクリメント。 前置は演算後、後置(++(int))は演算前の値を返す。
overload候補
operator++ は複数の宣言に対応します。
  • acs::TAtomic::operator++ACS_FORCEINLINE T operator++() noexcept;
  • acs::TAtomic::operator++ACS_FORCEINLINE T operator++(int) noexcept;
overload候補
operator-- は複数の宣言に対応します。
  • acs::TAtomic::operator--ACS_FORCEINLINE T operator--() noexcept;
  • acs::TAtomic::operator--ACS_FORCEINLINE T operator--(int) noexcept;

使用例

TAtomic<u32> counter{0};
counter.FetchAdd(1);              // どのスレッドから呼んでも正しく +1
u32 now = counter.Load();        // 現在値を読む
TAtomic<bool> ready{false};
ready.Store(true, EMemoryOrder::Release); // 公開
