FTask / TaskFn

タスクを並列実行するスレッドプール(ワークスチール方式)。 に投げる 1 件の仕事。 TaskFn=タスク本体の関数型 void(*)(void* user, u32 worker_index)。 FTask=その関数・ユーザーデータ・完了通知先をまとめた Plain Old Data。 コンストラクタ等の特別な振る舞いを持たない単純な構造体。 コピーが速く扱いやすい。。

構造体 / 型エイリアス

対応するAPI候補

  • acs::FTaskstruct FTask;
  • acs::TaskFnusing TaskFn = void (*)(void* user, u32 worker_index);

使う場面

タスクを並列実行するスレッドプール(ワークスチール方式)。::Submit に渡すために組み立てる。 counter を付けると Wait で完了を待てる。

API項目 4

説明
完了通知先(任意・null 可)。 Submit 時に自動で 1 加算され、タスク終了時に減算される。
overload候補
FCompletionCounter は複数の宣言に対応します。

使用例

void MyTask(void* user, u32 worker) { /* 実処理 */ }
FCompletionCounter done;
FTask t;
t.fn      = &MyTask;
t.user    = &ctx;
t.counter = &done;   // 任意(null 可)
FThreadPool::Submit(t);
