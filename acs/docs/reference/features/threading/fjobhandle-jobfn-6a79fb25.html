FJobHandle / JobFn

FJobHandle=依存関係付きのジョブを並列実行するスケジューラ。 に追加した並列実行する小さな仕事の単位。 依存関係を付けて CJobGraph で順序立てて走らせられる。を指す軽い参照で、これ越しに依存関係を張る。 JobFn=並列実行する小さな仕事の単位。 依存関係を付けて CJobGraph で順序立てて走らせられる。本体の関数型 void(*)(void* user, u32 worker_index)(TaskFn と同形式)。

構造体 / 型エイリアス

対応するAPI候補

  • acs::FJobHandlestruct FJobHandle;
  • acs::JobFnusing JobFn = void (*)(void* user, u32 worker_index);

使う場面

依存関係付きのジョブを並列実行するスケジューラ。::Add の戻り値として受け取り、DependOn で順序を組む時。

使用例

auto build  = g.Add(&Build,  &ctx);
auto upload = g.Add(&Upload, &ctx);
upload.DependOn(build);   // build → upload の順
if (build.IsValid()) { /* 追加成功 */ }
