ThreadEntry / FThreadConfig

ThreadEntry=1 つのプログラム内で同時に進む実行の流れ。 複数あると処理を並列にできる。の入口関数の型 void(*)(void* user)。 FThreadConfig=1 つのプログラム内で同時に進む実行の流れ。 複数あると処理を並列にできる。起動時の設定(名前・関数の呼び出しに沿って自動で確保/解放される高速なメモリ。 寿命はスコープに縛られる。サイズ・優先度・中央演算装置。 対応するSIMD命令により計算速度が変わる。 アフィニティ)。

型エイリアス / 構造体

対応するAPI候補

  • acs::ThreadEntryusing ThreadEntry = void (*)(void* user);
  • acs::FThreadConfigstruct FThreadConfig;

使う場面

FThread::Spawn に渡す。 名前を付けるとデバッガで識別しやすい。

API項目

API項目 1

using ThreadEntry = void (*)(void* user)
説明
1 つのプログラム内で同時に進む実行の流れ。 複数あると処理を並列にできる。で呼ばれる関数。 user は Spawn 時に渡した任意メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。。
対応API
acs::ThreadEntry 型alias

API項目 2

const wchar_t* name
説明
デバッガ表示用の名前(null 可)。
対応API
acs::FThreadConfig::name メンバー変数

API項目 3

u32 stack_bytes
説明
関数の呼び出しに沿って自動で確保/解放される高速なメモリ。 寿命はスコープに縛られる。サイズ。 0 で OS 既定。
対応API
acs::FThreadConfig::stack_bytes メンバー変数

API項目 4

i32 priority
説明
優先度 -2..+2(THREAD_PRIORITY_* に対応)。
対応API
acs::FThreadConfig::priority メンバー変数

API項目 5

u64 affinity
説明
中央演算装置。 対応するSIMD命令により計算速度が変わる。 アフィニティどのレイヤに反応するかをビットで指定する絞り込み。 立っているビットの相手だけが対象になる。。 0 でピン留めなし。
対応API
acs::FThreadConfig::affinity メンバー変数

使用例

FThreadConfig cfg;
cfg.name        = L"AssetLoader";  // デバッガ表示名
cfg.stack_bytes = 0;               // 0 = OS 既定
cfg.priority    = 0;               // -2..+2
FThread::Spawn(&Work, &ctx, cfg);
