FCompletionCounter

投げたタスク群が『あと何個残っているか』を数える複数スレッドから同時に触っても途中状態が見えず、分割されずに完了する操作。 TAtomic が代表。カウンタ。 0 になったら全完了。 Done は 0 で飽和し、呼びすぎても下にあふれない(待ちがハングしない)。 中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。不可。

クラス
対応するAPI: acs::FCompletionCounter

使う場面

複数タスクをまとめて投入し、全部終わるのを タスクを並列実行するスレッドプール(ワークスチール方式)。::Wait で待ちたい時の合図役。

使用例

FCompletionCounter c;
for (auto& job : jobs)
    CThreadPool::Submit(FTask{ job.fn, job.user, &c }); // 自動 Add
FThreadPool::Wait(c);  // 全部終わるまで(自分も手伝いつつ)待つ
