CompilerBarrier / HardwareFence / SpinHint

順序やスピン待ちを細かく制御する低レベル関数群。 CompilerBarrier=コンパイラの命令並び替えだけ禁止(中央演算装置。 対応するSIMD命令により計算速度が変わる。 命令は出さない)。 HardwareFence=中央演算装置。 対応するSIMD命令により計算速度が変わる。 レベルの完全メモリ操作の順序を区切る境界。 これを跨いで読み書きが並び替えられないよう保証する。。 SpinHint=忙しく待つループで 中央演算装置。 対応するSIMD命令により計算速度が変わる。 を一瞬譲るヒント命令。

使う場面

データを守るための『鍵』。 取った人だけが対象を触れ、他は解放されるまで待つ。フリーな自作データ構造の最終調整など、めったに使わない上級用途。 普段は ロックなしで安全に共有できる小さな値。 + EMemoryOrder で足りる。

API項目 2

void HardwareFence()
説明
中央演算装置。 対応するSIMD命令により計算速度が変わる。 + コンパイラ両方のメモリ操作の順序を区切る境界。 これを跨いで読み書きが並び替えられないよう保証する。(x64 では mfence)。
対応API
acs::HardwareFence 関数

API項目 3

void SpinHint()
説明
busy-wait ループ内に 1 回入れて消費電力と発熱を抑える(x86 PAUSE)。
対応API
acs::SpinHint 関数

使用例

while (!flag.Load(EMemoryOrder::Acquire)) {
    SpinHint();   // ハイパースレッディングの相方に CPU を譲る
}
