CJobGraph

依存関係のあるタスク(並列実行する小さな仕事の単位。 依存関係を付けて CJobGraph で順序立てて走らせられる。)を並べて並列実行するスケジューラ。 『B は A の後』のような順序を指定すると、依存が解けた並列実行する小さな仕事の単位。 依存関係を付けて CJobGraph で順序立てて走らせられる。から自動的に タスクを並列実行するスレッドプール(ワークスチール方式)。 上で走り出す。 Submit 冒頭で全 job の完了数を 1 回だけ予約し、依存解決ごとの加算を避ける。

クラス
対応するAPI: acs::CJobGraph

使う場面

読み込み→構築→画像処理に特化した演算装置。 描画はここで行われる。 アップロードのように、一部は並列・一部は順序ありの処理1 回の描画方式(VS+PS・頂点レイアウト・ブレンド・深度等)を丸ごと固めたオブジェクト。 PSO とも。を組みたい時。

使用例

CJobGraph g;
auto loadA = g.Add(&LoadA, &ctx);
auto loadB = g.Add(&LoadB, &ctx);
auto build = g.Add(&Build, &ctx);
build.DependOn(loadA);   // loadA,loadB 完了後に build
build.DependOn(loadB);
g.Submit();              // 依存0のジョブから開始
g.Wait();                // 全完了まで待つ
