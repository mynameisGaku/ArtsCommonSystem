FConditionVar

必ず 一度に1つのスレッドだけが保護区間へ入れる、ACSの排他ロックです。 と組で使う。 中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。不可。

クラス
対応するAPI: acs::FConditionVar

使う場面

生産者・消費者のように『キューが空なら待ち、要素が来たら起きる』待ち合わせを 中央演算装置。 対応するSIMD命令により計算速度が変わる。 を無駄に使わず実現したい時。

API項目

API項目 1

void Wait(FMutex& m)
説明
起こされるまで眠る。 呼ぶ前に m を Lock しておくこと。 眠る間は内部で一時的に Unlock し、起きたら再 Lock してから返る。
使う場面
条件が未成立の間 while ループで囲んで待つ。
対応API
acs::FConditionVar::Wait メンバー関数

API項目 2

bool WaitFor(FMutex& m, u32 timeout_ms)
説明
最大 timeout_ms ミリ秒待つ。 起こされたら true、時間切れなら false。
戻り値
起こされたか
対応API
acs::FConditionVar::WaitFor メンバー関数

API項目 3

void NotifyOne()
説明
待機中の1 つのプログラム内で同時に進む実行の流れ。 複数あると処理を並列にできる。を 1 つだけ起こす。
対応API
acs::FConditionVar::NotifyOne メンバー関数

API項目 4

void NotifyAll()
説明
待機中の全1 つのプログラム内で同時に進む実行の流れ。 複数あると処理を並列にできる。を起こす。
対応API
acs::FConditionVar::NotifyAll メンバー関数

使用例

FMutex m; FConditionVar cv;
// 消費者側
{
    FScopedLock lk(m);
    while (queue.IsEmpty()) cv.Wait(m); // 空なら眠る
    auto item = queue.Pop();
}
// 生産者側: queue.Push(x); cv.NotifyOne();
