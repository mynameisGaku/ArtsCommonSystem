MakeBind / MakeTwoWayBind / MakeBindConvert

バインダを コピー不可・ムーブのみで、スコープを抜けると自動解放。 で返す版。 バインダ自体は中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。/中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。不可なので、クラスのメンバとして持ちたい時はこちらを使う。 オブジェクトが破棄される時に自動で呼ばれる後始末の関数(~ClassName)。で自動的に Unsubscribe される。

使う場面

結合をオブジェクトの寿命に紐づけてメンバ変数に格納したい時(Observable 同士を結びつけ、片方が変わると相手も自動で更新する MVVM のデータバインド。 双方向版は TwoWayBind。 の生の返り値はメンバに置けない)。
