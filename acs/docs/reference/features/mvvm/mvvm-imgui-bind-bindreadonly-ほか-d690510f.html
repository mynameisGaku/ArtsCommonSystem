mvvm::imgui::Bind / BindReadOnly ほか

T監視できる 1 個の値。 Set で変えると購読者へ通知が飛ぶ。 MVVM の中核。<T> を Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 ボタンやラベルなど画面上の UI 部品 1 つ 1 つのこと。 AWidget を継承して作る。に毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。結ぶヘルパ群。 現在値を読んで画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。し、ユーザー操作があれば Set で書き戻す。 即時 mode 前提なので毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。呼ぶ。

使う場面

デバッグ UI を素早く作りたい時(本番 UI は src/ui/ 推奨)。 スライダ・チェックボックス・カラーピッカー・コンボ・文字列キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。・ボタン・読み取り専用表示が揃う。
