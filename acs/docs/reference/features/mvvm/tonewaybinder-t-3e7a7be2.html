TOneWayBinder<T>

片方向処理が終わるまでその場で待つやり方。 結果がすぐ手に入る代わりに止まる。(src → dst のみ)。 src が変わると dst へ流れるが、逆は流れない。 生成時に src の値を dst へ初期反映。

クラステンプレート
対応するAPI: acs::TOneWayBinder

使う場面

Model → View のように一方通行で十分な時。 View → Virtual Machine。 スクリプトを読み込んで実行する仮想機械。 CLuaVm は Lua の VM。 方向にしたいなら Observable 同士を片方向(src→dst)で同期させる小さなクラス。(view, vm) と引数の順で表す(別名は提供しない)。

使用例
