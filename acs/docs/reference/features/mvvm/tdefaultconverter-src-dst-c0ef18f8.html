TDefaultConverter<Src, Dst>

Observable 同士を結びつけ、片方が変わると相手も自動で更新する MVVM のデータバインド。 双方向版は TwoWayBind。 が使う組込みの型変換テーブル。 i32/u32/32bit の浮動小数(float 相当)。 座標・時間・係数など小数値に使う基本型。/f64/bool/短い文字列はヒープ無しで持つ最適化付き。 の主要ペアを Convert 静的メソッドで提供する。 対応の無いペアを使うと static_assert で「既定変換が無い」と教えてくれる。

クラステンプレート
対応するAPI: acs::mvvm::TDefaultConverter

使う場面

通常は Observable 同士を結びつけ、片方が変わると相手も自動で更新する MVVM のデータバインド。 双方向版は TwoWayBind。(src, dst) 経由で間接的に使われる。 直接呼ぶことは少ないが、変換の挙動を知りたい時の参照になる。

使用例

// 数値↔数値は static_cast、FString 絡みは .cpp 実装でパース/整形
