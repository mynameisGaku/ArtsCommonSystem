EArrayChange

要素の追加・削除・変更を通知する配列。 リスト UI の差分更新向け。 の変更の種類を表す列挙。 通知あとで呼んでもらうために登録しておく関数。 ACS では関数ポインタ + void* ユーザーデータの形を取る(STL 不依存方針)。の中でこれを switch して処理を分ける。

列挙(enum)
対応するAPI: acs::EArrayChange

使う場面

配列の変更通知を受け取った時、何が起きたか(追加/削除/書換/全消去)を判別する。

基本情報

モジュール
mvvm
分類
列挙(enum)
ヘッダー
mvvm/ObservableArray.h

API項目

API項目 1

Inserted
説明
index に value を挿入した。
対応API
acs::EArrayChange::Inserted 列挙値

API項目 2

Removed
説明
index の要素を削除した(value はもう無いので nullptr)。
対応API
acs::EArrayChange::Removed 列挙値

API項目 3

Changed
説明
index の要素を別の値に書き換えた(value = 新値)。
対応API
acs::EArrayChange::Changed 列挙値

API項目 4

Cleared
説明
全要素を削除した(index=0, value=nullptr)。
対応API
acs::EArrayChange::Cleared 列挙値

使用例

switch (kind) {
    case EArrayChange::Inserted: /* idx に value を追加 */ break;
    case EArrayChange::Removed:  /* idx を削除 (value=nullptr) */ break;
    case EArrayChange::Changed:  /* idx を value に書換 */ break;
    case EArrayChange::Cleared:  /* 全削除 (value=nullptr) */ break;
}
