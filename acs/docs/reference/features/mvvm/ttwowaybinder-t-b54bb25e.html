TTwoWayBinder(TObservable<T>& a, TObservable<T>& b)
説明
2 つを双方向に結ぶ。 a の値を b へ初期中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。してから両方を値や配列の変化を受け取るためにコールバックを登録すること(Subscribe)。 要らなくなったら解除(Unsubscribe)する。する。 伝播中に処理が終わるまでその場で待つやり方。 結果がすぐ手に入る代わりに止まる。破棄された ある出来事が起きた時に呼んでもらう関数。 は guard だけを確認して直ちに終了する。

使用例

TObservable<f32> view_hp;
TObservable<f32> model_hp { 100.0f };
TTwoWayBinder<f32> bind(view_hp, model_hp); // 双方向
model_hp.Set(50.0f);   // → view_hp も 50
view_hp.Set(0.0f);     // → model_hp も 0
