FArrayObserverHandle

要素の追加・削除・変更を通知する配列。 リスト UI の差分更新向け。 の Subscribe が返す値や配列の変化を受け取るためにコールバックを登録すること(Subscribe)。 要らなくなったら解除(Unsubscribe)する。チケット。 仕様は F監視できる 1 個の値。 Set で変えると購読者へ通知が飛ぶ。 MVVM の中核。Handle と同じく id+generation 方式。

構造体
対応するAPI: acs::FArrayObserverHandle

使う場面

配列の監視を後で解除するために保持しておく。
