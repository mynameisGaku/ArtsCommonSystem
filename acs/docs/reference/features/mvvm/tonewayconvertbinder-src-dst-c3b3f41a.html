TOneWayConvertBinder<Src, Dst>

型を変換しながら片方向処理が終わるまでその場で待つやり方。 結果がすぐ手に入る代わりに止まる。する。 src が変わるたび変換関数 fn を通して dst へ書き込む。 Src と Dst が別の型でもよい。
