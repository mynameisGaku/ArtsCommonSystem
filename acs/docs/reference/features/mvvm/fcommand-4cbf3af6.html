FCommand

Virtual Machine。 スクリプトを読み込んで実行する仮想機械。 CLuaVm は Lua の VM。 側に置くアクション(ボタン押下などの処理)。 実行関数と任意の can_execute 条件を持つ。 条件が false の間は Execute が何もしない。

クラス
対応するAPI: acs::FCommand

使う場面

「攻撃」「リスポーン」などのボタン動作を Virtual Machine。 スクリプトを読み込んで実行する仮想機械。 CLuaVm は Lua の VM。 に持たせ、UI からは押すだけにしたい時。 Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 の Observable 同士を結びつけ、片方が変わると相手も自動で更新する MVVM のデータバインド。 双方向版は TwoWayBind。Command でボタン化+自動グレーアウトできる。

API項目

API項目 1

FCommand(ExecFn fn, void* user)
説明
常時実行可能なコマンドを作る。 fn は void(void*) の関数そのものを指し示す値。 あとで fn() のように呼び出せる。 テスト本体を一覧に登録する仕組みに使う。。
overload候補
FCommand は複数の宣言に対応します。
  • acs::FCommandclass FCommand;
  • acs::FCommand::FCommandFCommand(ExecFn fn, void* user) noexcept;
  • acs::FCommand::FCommandFCommand(ExecFn fn, void* user, TObservable<bool>* can_execute) noexcept;
対応API

説明
can_execute が true の間だけ実行できる条件付きコマンドを作る。 T監視できる 1 個の値。 Set で変えると購読者へ通知が飛ぶ。 MVVM の中核。<bool> の生存期間は呼び出し側の責任。
