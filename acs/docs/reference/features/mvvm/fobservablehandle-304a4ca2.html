FObservableHandle

Subscribe が返す値や配列の変化を受け取るためにコールバックを登録すること(Subscribe)。 要らなくなったら解除(Unsubscribe)する。チケット。 これを Unsubscribe に渡すと監視を外せる。 id と generation で「同じ枠の使い回し」を誤判定しないようになっている。

構造体
対応するAPI: acs::FObservableHandle

使う場面

登録した監視を後で解除するために保持しておく。
