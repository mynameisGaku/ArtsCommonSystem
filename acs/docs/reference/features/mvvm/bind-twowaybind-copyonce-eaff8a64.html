Bind / TwoWayBind / CopyOnce

API項目 4

void CopyOnce(const TObservable<T>& src, TObservable<T>& dst)
説明
1 回だけ src の値を dst へ中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。する。 継続的な結合ではなく初期化用。
対応API
acs::CopyOnce 関数

使用例

TObservable<f32> hp { 100 };
TObservable<FString> hp_text;
auto b = Bind(hp, hp_text);     // f32 → FString 自動変換
TObservable<i32> a, c;
auto b2 = Bind(a, c);           // 同型 → TOneWayBinder<i32>
auto b3 = TwoWayBind(a, c);     // 双方向
