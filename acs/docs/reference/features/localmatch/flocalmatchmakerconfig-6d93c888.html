FLocalMatchmakerConfig

サーバ無しで同一プロセス内のプレイヤーを組ませる IMatchmaker 実装。 の設定。 今は『どれだけプレイヤーの腕前を表す数値(Elo / Glicko-2 等)。 値が近い者同士を組ませると公平な対戦になりやすい。が離れていてもマッチさせてよいか』の上限値だけを持ちます。

構造体
対応するAPI: acs::localmatch::FLocalMatchmakerConfig

使う場面

腕前の差が大きくても組ませたい(値を大きく)、近い相手だけ組ませたい(値を小さく)を調整したい時。

API項目

API項目 1

acs::u32 MaxRatingDelta = 150
説明
2 人のプレイヤーの腕前を表す数値(Elo / Glicko-2 等)。 値が近い者同士を組ませると公平な対戦になりやすい。差がこの値以内なら互換と見なしてマッチさせる。 既定は 150。
戻り値
許容レート差
対応API
acs::localmatch::FLocalMatchmakerConfig::MaxRatingDelta メンバー変数

使用例

FLocalMatchmakerConfig cfg;
cfg.MaxRatingDelta = 50;          // ±50 まで離れた相手のみ許可
FLocalMatchmaker mm(cfg);
