CLocalMatchmaker

対戦/協力するプレイヤー同士を、腕前(レーティング)やモードを見て組み合わせる仕組み。の本体。 acs::game::オンライン対戦の相手を探すマッチメイキングのインターフェース。 検索開始→状態確認→受諾/取消の流れで使う。 を実装し、同じプロセス内で出された検索同士をレートが近い順に組ませる同じ入力なら必ず同じ結果になる性質。 乱数や時刻に依存せず、テストや再現がしやすい。な実装です。 最大 32 件の検索を同時に扱えます。 中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。/中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。は禁止。

クラス
対応するAPI: acs::localmatch::CLocalMatchmaker

使う場面

オンラインサーバ無しでマッチング処理を動かしたい時(自動テスト・オフライン開発・ローカル対戦のロジック確認)。 通常は直接生成せず ローカル matchmaker を既定 provider として登録する関数。 以降 GetDefaultMatchmaker() がこの実装を返す。 経由で使う。

API項目 2

TResult<MatchTicket> StartSearch(const char* Mode, acs::u32 EloHint)
説明
Mode("ranked_1v1" 等のキー)と自分のプレイヤーの腕前を表す数値(Elo / Glicko-2 等)。 値が近い者同士を組ませると公平な対戦になりやすい。推定値で検索を開始し、検索 1 件分を表す不透明な ID(u64)。 0 は無効。 StartSearch で発行され、PollStatus / AcceptMatch / CancelSearch に渡す。 を発行する。 同じ Mode でレートが近い待機者がいれば即座に双方を Matched にする。 空きが無い時は 成功なら値、失敗なら理由を入れて返す型 Result<T,E>。 例外の代わり。 がエラー。
戻り値
発行された ticket
使う場面
プ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ーが『対戦相手を探す』ボタンを押した時。
使用例
auto t = mm.StartSearch("casual", 1500);
if (t.IsOk()) { /* t.Value() を保持して PollStatus で監視 */ }

    mm.AcceptMatch(a.Value());                 // 双方が Accept で確定
}
