FWindowsCrashReporterConfig

Windows 専用のクラッシュ報告 backend。 DbgHelp でミニダンプと人間が読めるテキスト報告書を書き出す。 の初期設定。 今はダンプ／報告書の出力先フォルダを 1 つ指定するだけのシンプルな設定です。

構造体
対応するAPI: acs::crashwin::FWindowsCrashReporterConfig

使う場面

クラッシュ報告ファイルの保存先を既定の "crash_dumps" 以外にしたい時。

API項目

API項目 1

const char* DumpDirectory = "crash_dumps"
説明
ダンプ（.dmp）とテキスト報告書（.txt）を書き出すフォルダ。 呼出側が寿命を保証する文字列（static / リテラル推奨）。
戻り値
出力フォルダ名
対応API
acs::crashwin::FWindowsCrashReporterConfig::DumpDirectory メンバー変数

使用例

FWindowsCrashReporterConfig cfg;
cfg.DumpDirectory = "Saved/Crashes";   // 出力先を変更
FWindowsCrashReporter reporter(cfg);
