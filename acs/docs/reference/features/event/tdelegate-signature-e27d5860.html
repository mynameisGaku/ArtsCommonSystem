TDelegate<Signature>

関数形式を型引数に取り、静的関数またはメンバー関数と任意メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。ーをプログラムが使う記憶領域。 確保と解放の管理が性能と安全性を左右する。確保なしで一組だけ保持する。

クラステンプレート
対応するAPI: acs::TDelegate

使う場面

引数や戻り値を持つ処理を、対象と一緒に軽量な値として保持したい時。
