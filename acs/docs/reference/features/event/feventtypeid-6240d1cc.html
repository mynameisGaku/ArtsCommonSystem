FEventTypeId

型ごとにイベントを同期配信するpub/subバス。 1 スレッド内で使う。 がメッセージ型ごとの通路を識別する番号。

型エイリアス
対応するAPI: acs::FEventTypeId

使う場面

値や配列の変化を受け取るためにコールバックを登録すること(Subscribe)。 要らなくなったら解除(Unsubscribe)する。数の確認など、型から得た通路番号を明示的に保持する時。

API項目 2

using EventTypeId = FEventTypeId
説明
旧名を使う既存コード向けの互換別名。 新しいコードでは Fウィンドウや入力で起きた『出来事』1 つ分を表す構造体。 種別に応じて中のunionの対応フィールドだけが有効になる。TypeId を使う。

API項目 4

bool IsValidEventTypeId(FEventTypeId channel)
説明
通路番号が256未満ならtrue。 仲介器は範囲外の通路を作成しない。
戻り値
範囲内か

対応API
