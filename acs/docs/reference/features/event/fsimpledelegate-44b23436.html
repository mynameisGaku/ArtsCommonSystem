FSimpleDelegate

引数なしの関数またはメンバー関数と任意メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。ーを、プログラムが使う記憶領域。 確保と解放の管理が性能と安全性を左右する。確保なしで一組だけ保持する TDelegate<void()>。

型エイリアス
対応するAPI: acs::FSimpleDelegate

使う場面

処理を後から一度だけ呼ぶ場所や、時間を計る仕組み。 ACS では CClock（経過時間）と FFrameTimer（フレーム間 dt）。ーへ関数と対象をまとめて渡す時。
