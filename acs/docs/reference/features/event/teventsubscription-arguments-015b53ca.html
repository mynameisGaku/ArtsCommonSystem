ACS 機能 / event

TEventSubscription<Arguments...>

破棄時に値や配列の変化を受け取るためにコールバックを登録すること(Subscribe)。 要らなくなったら解除(Unsubscribe)する。を自動解除する中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。専用値。 『× ボタンが押された』『キーが押された』のような、その瞬間に起きた出来事の通知。 ACS では FEvent として届く。本体より長く生存しても対象を所有せず(寿命を延ばさず)、生きているかだけを見られる参照。 循環参照を断ち切るのに使う。が失効するため安全に終了する。

クラステンプレート
対応するAPI: acs::TEventSubscription

使う場面

スコープや所有オブジェクトの寿命と値や配列の変化を受け取るためにコールバックを登録すること(Subscribe)。 要らなくなったら解除(Unsubscribe)する。期間を一致させたい時。
