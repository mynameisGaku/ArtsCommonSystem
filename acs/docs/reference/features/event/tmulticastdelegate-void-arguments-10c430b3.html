TMulticastDelegate<void(Arguments...)>

Tウィンドウや入力で起きた『出来事』1 つ分を表す構造体。 種別に応じて中のunionの対応フィールドだけが有効になる。を使い、静的関数やメンバー関数を複数登録して型付き引数を一斉通知する。

クラステンプレート
対応するAPI: acs::TMulticastDelegate

使う場面

関数を直接登録するデリゲート形式で、複数の受信先へ同じ値を通知したい時。
