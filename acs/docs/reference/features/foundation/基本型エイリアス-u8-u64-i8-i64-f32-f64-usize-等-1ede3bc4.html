基本型エイリアス (u8〜u64 / i8〜i64 / f32 / f64 / usize 等)

ビット幅が一目で分かる短い数値型名。 unsigned int ではなく u32、float ではなく 32bit の浮動小数(float 相当)。 座標・時間・係数など小数値に使う基本型。 と書く。 どの対象とする機種/環境の種別。 ここでは Meta Quest や Valve Index など XR 機器の系統。でも幅が固定（u32 は必ず 4 バイト）なので移植で困らない。

型エイリアス

対応するAPI候補

  • acs::u8using u8 = ::uint8_t;
  • acs::u64using u64 = ::uint64_t;
  • acs::i8using i8 = ::int8_t;
  • acs::i64using i64 = ::int64_t;
  • acs::f32using f32 = float;
  • acs::f64using f64 = double;
  • acs::usizeusing usize = ::size_t;

使う場面

ACS では int や long の代わりに常にこれらを使う。 サイズが重要な構造体やファイル I/O で特に効く。

使用例

acs::u32 count = 0;        // 32bit 符号なし
acs::i64 offset = -100;    // 64bit 符号付き
acs::f32 x = 1.5f;         // 単精度浮動小数
acs::usize n = sizeof(T);  // サイズ・添字用(ポインタ幅と同一)
acs::byte raw[16];         // 生バイト列
