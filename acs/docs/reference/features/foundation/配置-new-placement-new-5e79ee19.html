配置 new (placement new)

すでに確保済みのプログラムが使う記憶領域。 確保と解放の管理が性能と安全性を左右する。上にオブジェクトを構築するための ::new (ptr) T(...) 構文を有効にする宣言。 ACS はビルド時間や予測しやすさのため使わず独自コンテナを用いる。（<new>）を取り込まずに自前で用意している。

演算子

使う場面

メモリの確保/解放のやり方を担当する部品。 用途に応じて差し替えられる。や 成功値かエラー値のどちらか一方を持つ型。 例外を使わずに失敗を戻り値で伝える（既定のエラー型は FErrorCode）。 など、確保と構築を分けて扱う低レベルコードで使う。 通常のゲームコードで直接書くことは稀。

使用例

void* mem = alloc.Alloc(sizeof(T), alignof(T), FSourceLoc::Current());

obj->~T();                          // 破棄は手動
