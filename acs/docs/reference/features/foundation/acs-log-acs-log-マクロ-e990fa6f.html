ACS_LOG / ACS_LOG_* マクロ

非同期でスレッド安全なログ出力クラス。 ACS_LOG_* マクロ経由で使う。 に 1 行書くための入口。 レベル別のショートカットがあり、無効レベルなら書式評価ごと省くので軽い。 問題が起きたソース上の場所（ファイル名・行・関数名）。 FSourceLoc が表す。は自動で付く。

マクロ
対応するAPI: ACS_LOG

使う場面

コードのあちこちでログを出す時。 普段はこのコンパイル前に決まった形へ展開される短い記述(#define)。 定型コードを一行で書ける。だけ使えばよい。
