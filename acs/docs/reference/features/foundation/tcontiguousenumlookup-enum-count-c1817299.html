TContiguousEnumLookup<Enum, Count>

0 始まりで欠番のない列挙値の妥当性判定と名前取得を、constexpr 名前表から生成する。

クラステンプレート
対応するAPI: acs::TContiguousEnumLookup

使う場面

wire 値の検証や診断名で同じ switch/比較列を重複させず、compile-time に範囲を固定したい時。

使用例

constexpr const char* names[]{"A", "B"};
constexpr TContiguousEnumLookup<EMode, 2> lookup(names);
if (lookup.Contains(mode)) Log(lookup.Name(mode));
