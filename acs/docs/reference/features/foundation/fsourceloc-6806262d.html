FSourceLoc

コンパイラ組み込みで取得する。

クラス
対応するAPI: acs::FSourceLoc

使う場面

「どこで呼ばれたか / どこで失敗したか」を記録したい時。 引数の既定値に ソース上の位置(ファイル名・関数名・行・列)を持つ軽い型。::Current() を置くと、呼び出し側の位置を自動取得できる。

使用例

void LogHere(FSourceLoc loc = FSourceLoc::Current()) {
    ACS_LOG_INFO("%s:%u (%s)",
        loc.File(), loc.Line(), loc.Function());
}
LogHere();  // ← この行の位置が記録される
