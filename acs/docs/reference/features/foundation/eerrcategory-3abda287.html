ACS 機能 / foundation

EErrCategory

エラーの大分類を表す 決まった選択肢の集合を表す型(列挙)。 例: 上下左右のキー。 class（基底は u16）。 ロガーでのフィルタや、原因の大まかな切り分けに使う。

列挙(enum)
対応するAPI: acs::EErrCategory

使う場面

ACS_ERR の第 1 引数に渡す。 受け取り側はこの値で switch したり ToString でログに出したりする。

使用例

    case EErrCategory::IO:     /* 入出力 */ break;
    case EErrCategory::Memory: /* 確保失敗 */ break;
    default: break;
}
