ACS_TRY / ACS_TRY_ASSIGN

成功値かエラー値のどちらか一方を持つ型。 例外を使わずに失敗を戻り値で伝える（既定のエラー型は FErrorCode）。 を返す処理を呼び、エラーならその場で関数から抜ける。 エラー処理の if 連打を消せる。

マクロ

対応するAPI候補

  • ACS_TRY#define ACS_TRY(expr) \ do { \ auto m_AcsTryR = (expr); \ if (m_AcsTryR.IsErr()) return ::acs::Err(m_AcsTryR.Error()); \ } while (0)
  • ACS_TRY_ASSIGN#define ACS_TRY_ASSIGN(name, expr) \ auto ACS_CONCAT(m_AcsTmp, __LINE__) = (expr); \ if (ACS_CONCAT(m_AcsTmp, __LINE__).IsErr()) \ return ::acs::Err(ACS_CONCAT(m_AcsTmp, __LINE__).Error()); \ auto&& name = ACS_CONCAT(m_AcsTmp, __LINE__).Value()

使う場面

ある関数の中で、失敗し得る別関数を次々呼びたい時。 途中で失敗したら呼び出し元へエラーを素通しできる。

API項目

API項目 1

ACS_TRY(expr)
説明
expr を評価し、エラーなら TResult が失敗を表す側。 err.subcode で原因を見分ける。 成功側は Ok。(...) を return。 値は捨てる（成功値かエラー値のどちらか一方を持つ型。 例外を使わずに失敗を戻り値で伝える（既定のエラー型は FErrorCode）。<void> 向け）。
対応API
ACS_TRY マクロ

API項目 2

ACS_TRY_ASSIGN(name, expr)
説明
expr がエラーなら return、成功なら値を name という名前に束縛する。
対応API
ACS_TRY_ASSIGN マクロ

使用例

TResult<void> Load() {
    ACS_TRY(OpenFile());              // 失敗なら return Err(...)
    ACS_TRY_ASSIGN(data, ReadAll()); // 成功なら data に束縛
    Process(data);
    return Ok();
}
