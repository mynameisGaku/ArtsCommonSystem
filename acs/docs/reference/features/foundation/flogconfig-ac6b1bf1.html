FLogConfig

非同期でスレッド安全なログ出力クラス。 ACS_LOG_* マクロ経由で使う。 の初期設定。 出力先（ファイル/コンソール/デバッグ出力）と最小レベル、内部リングの長さを指定する。

構造体
対応するAPI: acs::FLogConfig

使う場面

非同期でスレッド安全なログ出力クラス。 ACS_LOG_* マクロ経由で使う。::Init に渡す。 ゲーム起動時に一度だけ作る。

API項目

API項目 1

const wchar_t* file_path
説明
出力ファイルのパス。 nullptr ならファイル出力なし。
対応API
acs::FLogConfig::file_path メンバー変数

API項目 2

ELogSeverity min_severity
説明
これ未満のレベルは出力しない（既定 Info）。
対応API
acs::ELogSeverity 列挙型
対応API
acs::FLogConfig::min_severity メンバー変数

API項目 3

u32 ring_capacity
説明
内部リングの長さ（2 のべき乗、最小 16）。 負荷時の取りこぼしに影響。
対応API
acs::FLogConfig::ring_capacity メンバー変数

API項目 4

bool console / bool debug_output
説明
標準出力に出すか / OutputDebugString に出すか。
対応API
acs::FLogConfig::console メンバー変数
対応API
acs::FLogConfig::debug_output メンバー変数

使用例

FLogConfig cfg;
cfg.file_path = L"game.log";       // nullptr ならファイル無効
cfg.min_severity = ELogSeverity::Info;
cfg.console = true;
FLogger::Init(cfg);
