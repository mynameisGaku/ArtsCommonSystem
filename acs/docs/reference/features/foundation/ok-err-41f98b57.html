Ok / Err

成功値かエラー値のどちらか一方を持つ型。 例外を使わずに失敗を戻り値で伝える（既定のエラー型は FErrorCode）。 を簡潔に作る入口。 Ok(v) で成功側、TResult が失敗を表す側。 err.subcode で原因を見分ける。 成功側は Ok。(e) でエラー側を生成する。 Ok()（引数なし）は 成功値かエラー値のどちらか一方を持つ型。 例外を使わずに失敗を戻り値で伝える（既定のエラー型は FErrorCode）。<void> の成功。

ヘルパー関数

対応するAPI候補

  • acs::Oktemplate<typename T> TResult<T> Ok(T v) noexcept;
  • acs::Okinline TResult<void> Ok() noexcept;
  • acs::Errtemplate<typename T = void> TResult<T> Err(FErrorCode e) noexcept;

使う場面

関数の中で結果を返す時。 成功なら Ok(...)、失敗なら TResult が失敗を表す側。 err.subcode で原因を見分ける。 成功側は Ok。(...) または ACS_ERR(...) をそのまま return する。
