アサートマクロ (ACS_ASSERT 系)

条件が偽なら 回復不能な状況でログとスタックトレースを出してプロセスを終了させる最終経路。 通常はアサートから呼ばれる。 を呼んでその場で止めるチェック群。 バグを早期に・確実に検出する。 デバッグ専用（リリースで消える）と常時有効の 2 系統がある。

マクロ
対応するAPI: ACS_ASSERT

使う場面

事前条件・不変条件・到達しないはずの分岐を主張する時。 安いチェックは ACS_Ax86 CPU のSIMD命令セットの一系統。 SSE2 は 64bit で常に使える。RT、リリースでも守りたい不変条件は ACS_CHECK。

API項目

API項目 1

ACS_ASSERT(expr)
説明
デバッグ専用。 偽なら停止。 リリース（-DACS_ENABLE_Ax86 CPU のSIMD命令セットの一系統。 SSE2 は 64bit で常に使える。RTS=OFF）では除去。
使う場面
安価な事前条件・範囲チェック。
対応API
ACS_ASSERT マクロ

API項目 2

ACS_ASSERTF(expr, fmt, ...)
説明
ACS_Ax86 CPU のSIMD命令セットの一系統。 SSE2 は 64bit で常に使える。RT に printf 風メッセージを付けた版。
対応API
ACS_ASSERTF マクロ

API項目 3

ACS_VERIFY(expr)
説明
デバッグ専用だが expr は常に評価される。 副作用のある式のチェックに使う。
対応API
ACS_VERIFY マクロ

API項目 4

ACS_CHECK(expr) / ACS_CHECKF(...)
説明
常に有効。 リリースでも偽なら停止。 範囲外・null・セキュリティ前提など倒れた方が安全な不変条件に。
対応API
ACS_CHECK マクロ
対応API
ACS_CHECKF マクロ

API項目 5

ACS_NOTREACHED()
説明
到達したら必ず停止する防御マーカー（リリースでも有効）。
対応API
ACS_NOTREACHED マクロ

API項目 6

ACS_NOT_IMPLEMENTED()
説明
未実装の分岐に置く。 リリースでもパニックする。
対応API
ACS_NOT_IMPLEMENTED マクロ

API項目 7

ACS_UNREACHABLE()
説明
「絶対に来ない」と最適化器に教える。 デバッグでは停止、リリースでは最適化ヒント（来るとC++ 規格が結果を保証しない操作(配列外アクセス・寿命切れポインタ等)。 最適化で表面化しやすい。）。
対応API
ACS_UNREACHABLE マクロ

使用例

ACS_ASSERT(idx < size);                         // デバッグのみ
ACS_ASSERTF(p != nullptr, "id=%u", id);          // メッセージ付き
ACS_CHECK(buffer != nullptr);                    // リリースでも検査
if (kind == 0) { /*...*/ } else { ACS_NOTREACHED(); }
