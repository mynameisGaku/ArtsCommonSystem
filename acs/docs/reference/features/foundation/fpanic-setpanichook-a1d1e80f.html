FPanic / SetPanicHook

最終エラー経路。 場所・失敗式・メッセージ・ある時点でどの関数からどの関数が呼ばれてきたか、という呼び出し履歴。 クラッシュ原因の追跡に使う。を出力した後、プロセスを終了させる（戻らない）。 通常は直接呼ばず 条件が偽ならその場でプログラムを止めてバグを知らせる仕組み（ACS_ASSERT 等）。経由で呼ばれる。

使う場面

致命的でこれ以上続行できない時。 SetPanicHook でパニック直前の処理（ログのフラッシュ、クラッシュレポート保存）を差し込める。
