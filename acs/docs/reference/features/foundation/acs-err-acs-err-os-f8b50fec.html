ACS_ERR / ACS_ERR_OS

ACS の標準エラー型。 カテゴリ・サブコード・OS エラー値・メッセージ・発生位置をまとめて持つ POD。 を 1 行で作るコンパイル前に決まった形へ展開される短い記述(#define)。 定型コードを一行で書ける。。 問題が起きたソース上の場所（ファイル名・行・関数名）。 FSourceLoc が表す。を自動でキャプチャするので、どこで失敗したかが常に残る。

マクロ

対応するAPI候補

  • ACS_ERR#define ACS_ERR(cat, sub, msg) \ ::acs::FErrorCode(::acs::EErrCategory::cat, static_cast<::acs::u16>(sub), (msg), ::acs::FSourceLoc::Current())
  • ACS_ERR_OS#define ACS_ERR_OS(cat, sub, msg, os_err) \ ::acs::FErrorCode(::acs::EErrCategory::cat, static_cast<::acs::u16>(sub), (msg), ::acs::FSourceLoc::Current(), (os_err))

使う場面

失敗を返したい箇所すべて。 手で ソース上の位置(ファイル名・関数名・行・列)を持つ軽い型。 を埋める必要がない。

API項目

API項目 1

ACS_ERR(cat, sub, msg)
説明
カテゴリ cat・サブコード sub・メッセージ msg でエラーを生成。 位置は自動。

ACS_ERR マクロ

API項目 2

ACS_ERR_OS(cat, sub, msg, os_err)
説明
上記に加え OS エラー値 os_err も格納する。
対応API
ACS_ERR_OS マクロ

使用例

return ACS_ERR(IO, 1, "開けません");
// OS のエラー値も一緒に運ぶ:
return ACS_ERR_OS(OS, 5, "CreateFile 失敗", GetLastError());
