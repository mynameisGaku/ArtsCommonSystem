ACS 機能 / foundation

Move / Forward / Swap / Min / Max / Clamp

<utility> / <algorithm> の代替となる超基本ユーティリティ。 Move=中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。へのキャスト、Forward=テンプレート関数が受け取った引数を、lvalue/rvalue の区別を保ったまま別の関数に渡すこと（Forward）。、Swap=入れ替え、Min/Max/Clamp=比較。 すべて constexpr で最適化時に消える。

関数テンプレート

対応するAPI候補

  • acs::Movetemplate<typename T> ACS_FORCEINLINE constexpr RemoveRefT<T>&& Move(T&& v) noexcept;
  • acs::Forwardtemplate<typename T> ACS_FORCEINLINE constexpr T&& Forward(RemoveRefT<T>& v) noexcept;
  • acs::Forwardtemplate<typename T> ACS_FORCEINLINE constexpr T&& Forward(RemoveRefT<T>&& v) noexcept;
  • acs::Swaptemplate<typename T> ACS_FORCEINLINE constexpr void Swap(T& a, T& b) noexcept;
  • acs::Mintemplate<typename T> ACS_FORCEINLINE constexpr T Min(T a, T b) noexcept;
  • acs::Maxtemplate<typename T> ACS_FORCEINLINE constexpr T Max(T a, T b) noexcept;
  • acs::Clamptemplate<typename T> ACS_FORCEINLINE constexpr T Clamp(T v, T lo, T hi) noexcept;

使う場面

そのメモリ/資源を『誰が解放する責任を持つか』。 はっきりさせると安全。を移したい（Move）、型を後から指定できる部品。 TArray<int> は『int の配列』というように中身の型を差し替えられる。で受けた引数をそのまま渡したい（Forward）、値を範囲内に収めたい（Clamp）時など、日常的に使う。

API項目

API項目 1

RemoveRefT<T>&& Move(T&& v)
説明
vをRemoveRefT<T>&&へcastし、所有内容を移動できる形で返します。
対応API
acs::Move 関数

API項目 2

T&& Forward<T>(...)
説明
受け取った値のlvalue/rvalue区分を保ったままT&&として転送します。
overload候補
Forward は複数の宣言に対応します。
  • acs::Forwardtemplate<typename T> ACS_FORCEINLINE constexpr T&& Forward(RemoveRefT<T>& v) noexcept;
  • acs::Forwardtemplate<typename T> ACS_FORCEINLINE constexpr T&& Forward(RemoveRefT<T>&& v) noexcept;

API項目 3

void Swap(T& a, T& b)
説明
2 つの値を中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。で入れ替える。
対応API
acs::Swap 関数

API項目 4

T Min(T,T) / T Max(T,T) / T Clamp(T v, T lo, T hi)
説明
最小 / 最大 / 範囲内へ値を指定範囲内に収めること。 Saturate は 0〜1 に収める。。 整数・float / double など小数を表す数値型。 丸め誤差があるため == ではなく EXPECT_NEAR で許容誤差つきで比べる。どちらも可。
対応API
acs::Min 関数
対応API
acs::Max 関数
対応API
acs::Clamp 関数

使用例

TUniquePtr<T> b = Move(a);          // a の中身を b へ移譲
f32 v = Clamp(x, 0.0f, 1.0f);        // 0〜1 に丸める
Min(hp, maxHp);  Max(0, dmg);        // 比較
Swap(lhs, rhs);                       // 入れ替え
