FStackTrace / FStackFrame

呼び出し履歴（コール関数の呼び出しに沿って自動で確保/解放される高速なメモリ。 寿命はスコープに縛られる。）を取得し、関数名・ファイル・行に解決する。 パニック時の診断に使われる。 FStackFrame は 1 段分の情報。

クラス / 構造体

対応するAPI候補

  • acs::FStackTraceclass FStackTrace;
  • acs::FStackFramestruct FStackFrame;

使う場面

クラッシュや条件が偽ならその場でプログラムを止めてバグを知らせる仕組み（ACS_ASSERT 等）。失敗の原因を「どの関数から来たか」で追いたい時。 普通は 回復不能な状況でログとスタックトレースを出してプロセスを終了させる最終経路。 通常はアサートから呼ばれる。 が裏で使う。

使用例

FStackTrace st;
st.Capture();    // 現在のスタックを取得
st.Resolve();    // シンボル/ファイル/行に解決
st.Print([](void*, const char* line, acs::usize) {
    ACS_LOG_INFO("%s", line);
}, nullptr);
