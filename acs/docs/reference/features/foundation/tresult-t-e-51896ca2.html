TResult<T, E>

ACS はC++ の throw/catch による失敗伝搬。 ACS は性能と単純さのため使わず TResult を選ぶ。を使わず、失敗をこの戻り値で伝える。 E の既定は ACS の標準エラー型。 カテゴリ・サブコード・OS エラー値・メッセージ・発生位置をまとめて持つ POD。。 [[nodiscard]] 付きなので戻り値を捨てると警告。

クラステンプレート
対応するAPI: acs::TResult

使う場面

失敗し得る関数（ファイルを開く・確保する・パースする等）の戻り型に使う。 呼ぶ側は if (r) や IsOk() でまず成否を確認する。

API項目 5

T ValueOr(T fallback) const
説明
成功なら値、失敗なら渡した fallback を返す。 分岐を書かずに既定値で済ませたい時に便利。
戻り値
値 または 既定
使用例
u32 size = ReadSize().ValueOr(0u);
対応API
acs::TResult::ValueOr メンバー関数

使用例

TResult<FFile> r = OpenFile("foo");
if (!r) {                              // エラーなら
    ACS_LOG_ERROR("開けません: %s", r.Error().message);
    return;
}
FFile& f = r.Value();                  // 成功 → 値を取り出す
int n = r.ValueOr(0);                  // ※ T=int の例: 失敗なら 0
