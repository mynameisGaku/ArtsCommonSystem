FErrorCode

成功値かエラー値のどちらか一方を持つ型。 例外を使わずに失敗を戻り値で伝える（既定のエラー型は FErrorCode）。 の既定エラー型。 カテゴリ + サブコード + OS エラー値 + メッセージ + 問題が起きたソース上の場所（ファイル名・行・関数名）。 FSourceLoc が表す。をまとめた軽い Plain Old Data。 コンストラクタ等の特別な振る舞いを持たない単純な構造体。 コピーが速く扱いやすい。。 C++ の throw/catch による失敗伝搬。 ACS は性能と単純さのため使わず TResult を選ぶ。の代わりに「何がどこで失敗したか」を運ぶ。

構造体
対応するAPI: acs::FErrorCode

使う場面

失敗を表現する時の標準の入れ物。 普段は手書きせず ACS_ERR コンパイル前に決まった形へ展開される短い記述(#define)。 定型コードを一行で書ける。で作る。 受け取った側はカテゴリで分類したり message を出力したりする。

使用例

FErrorCode e = ACS_ERR(IO, 42, "ファイルが見つかりません");
if (e) {                                  // bool 変換: エラーあり
    ACS_LOG_ERROR("[%s] %s (%s:%u)",
        ToString(e.category), e.message,
        e.loc.File(), e.loc.Line());
}
