Platform.h (OS ヘッダ集約)

<windows.h> など重い OS ヘッダを 1 箇所に閉じ込める窓口。 不要な所有元の寿命に従い、共有機能の開始、更新、終了を管理する部品です。を除外し、min/max や CreateFile など ACS の名前と衝突する Win32 コンパイル前に決まった形へ展開される短い記述(#define)。 定型コードを一行で書ける。を #undef して安全にする。

ヘッダ

使う場面

OS ライブラリの機能を外から使うための窓口(関数や型の取り決め)。 例: ネットワークは WinSock をくるんだ薄い API として提供される。 を直接呼ぶ実装ファイル（.cpp）で <windows.h> の代わりにこれを include する。 これにより他のヘッダを軽量に保てる。
