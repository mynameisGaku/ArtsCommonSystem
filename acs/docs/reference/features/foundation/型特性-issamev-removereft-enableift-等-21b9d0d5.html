型特性 (IsSameV / RemoveRefT / EnableIfT 等)

<type_traits> の最小代替。 型を調べる（整数か・メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。か・同じ型か）／変形する（参照や const を外す）／型を後から指定できる部品。 TArray<int> は『int の配列』というように中身の型を差し替えられる。を条件付きで有効化する道具一式。 主に型を後から指定できる部品。 TArray<int> は『int の配列』というように中身の型を差し替えられる。を書く時の部品。

対応するAPI候補

  • acs::IsSameVtemplate<typename A, typename B> inline constexpr bool IsSameV = TIsSame<A,B>::Value;

  • acs::EnableIfTtemplate<bool C, typename T = void> using EnableIfT = typename TEnableIf<C,T>::Type;

汎用値をまとめて入れておく入れ物(TArray や THashMap など)。 ACS は STL の代わりに独自のものを使う。やメモリの確保/解放のやり方を担当する部品。 用途に応じて差し替えられる。、成功値かエラー値のどちらか一方を持つ型。 例外を使わずに失敗を戻り値で伝える（既定のエラー型は FErrorCode）。 のような型を後から指定できる部品。 TArray<int> は『int の配列』というように中身の型を差し替えられる。を自作・拡張する時。 普通のゲームロジックでは表に出ない。
