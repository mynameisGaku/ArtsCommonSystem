FLogSinkHandle / FLogSinkSubscription

複数利用者向けログ通知先の再利用される番号(ID)に付ける通し番号。 古いハンドルと新しい中身を取り違えないための目印。付き識別子と、破棄時に解除する移動専用そのメモリ/資源を『誰が解放する責任を持つか』。 はっきりさせると安全。。

構造体 / クラス

対応するAPI候補

  • acs::FLogSinkHandlestruct FLogSinkHandle;
  • acs::FLogSinkSubscriptionclass FLogSinkSubscription;

使う場面

エディタ、開発用表示、外部診断など複数の利用者が同じ 非同期でスレッド安全なログ出力クラス。 ACS_LOG_* マクロ経由で使う。 のログを受け取る時。
