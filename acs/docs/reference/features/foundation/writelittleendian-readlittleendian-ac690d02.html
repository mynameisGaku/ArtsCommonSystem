WriteLittleEndian / ReadLittleEndian

1/2/4/8 byte の整数・float / double など小数を表す数値型。 丸め誤差があるため == ではなく EXPECT_NEAR で許容誤差つきで比べる。・列挙値を、host 中央演算装置。 対応するSIMD命令により計算速度が変わる。 に依存しない little endian byte 列へ書き出し・読み戻す。 無効表現を持つ bool は compile-time に拒否する。

使う場面

AssetPack や保存データなど、中央演算装置。 対応するSIMD命令により計算速度が変わる。 endian に左右されない固定 wire 形式を実装する時。
