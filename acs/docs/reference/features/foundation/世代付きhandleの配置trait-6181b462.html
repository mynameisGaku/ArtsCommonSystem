世代付きhandleの配置trait

オブジェクトを直接ポインタで指す代わりに「配列の index + 世代カウンタ」で指す仕組み。 slot が再利用されても世代が食い違うので、破棄済みの古いハンドルを安全に検出できる。の物理配置だけを公開する ABI 監査用 trait。 identity・generation の位置と幅、domain prefix、型全体の size/alignment を compile time で取得できる。

機能
対応するAPI: acs::TPoolRef::handle

使う場面

異種実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。の serialize・ABI 検査・静的契約テストで、field 配置の意図しない変更を検出したい時。 無効値、生存判定、generation 更新規則の共通化には使わない。
