コンパイラ / プラットフォーム検出マクロ

どのコンパイラ・OS・アーキテクチャ・ビルド種別かを判定するコンパイル前に決まった形へ展開される短い記述(#define)。 定型コードを一行で書ける。と、方言差を吸収した関数属性ラッパ（強制インライン化・到達ヒント等）をまとめたもの。 依存なしでどこからでも include できる。

マクロ

使う場面

コンパイラごとに分岐したい、特定関数を強制インライン化したい、ホットパスに分岐予測ヒントを付けたい時。

API項目 9

ACS_RESTRICT
説明
restrict 修飾子のラッパ（MSVC は __restrict、それ以外は __restrict__）。 メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。が指す領域が他とエイリアスしないと最適化器に伝える。
対応API
ACS_RESTRICT マクロ

API項目 10

ACS_DLLEXPORT / ACS_DLLIMPORT
説明
実行時に読み込む共有ライブラリ(Windows の動的リンクライブラリ)。 例: ONNX Runtime の本体を DLL として読み込む。 シンボルのエクスポート / インポート指定（MSVC は __declspec(dllexport/dllimport)、Garbage Collection(ガベージコレクション)。 不要になったメモリを自動回収する仕組み。 Lua が内部で行う。C/Clang は visibility("default") 相当）。
対応API
ACS_DLLEXPORT マクロ
対応API
ACS_DLLIMPORT マクロ

その関数だけ SSE の後継のSIMD命令セット。 AVX2 などより広い幅で計算できる。 / SSE の後継のSIMD命令セット。 AVX2 などより広い幅で計算できる。2(+FMA) を有効化する関数属性。 Clang/Garbage Collection(ガベージコレクション)。 不要になったメモリを自動回収する仕組み。 Lua が内部で行う。C は target(...) を付与、MSVC は空。 ランタイム 中央演算装置。 対応するSIMD命令により計算速度が変わる。 判定で SSE の後継のSIMD命令セット。 AVX2 などより広い幅で計算できる。 経路を選ぶ関数に付ける。
