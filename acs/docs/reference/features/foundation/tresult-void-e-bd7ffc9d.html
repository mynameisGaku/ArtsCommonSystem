ACS 機能 / foundation

TResult<void, E>

返す値が無い処理用の 成功値かエラー値のどちらか一方を持つ型。 例外を使わずに失敗を戻り値で伝える（既定のエラー型は FErrorCode）。。 「成功したか、失敗したか」だけを表す。

クラステンプレート(特殊化)
対応するAPI: acs::TResult

使う場面

保存・初期化・送信など、結果の成否だけ知りたい関数の戻り型に使う。

使用例

TResult<void> Save() {
    ACS_TRY(WriteHeader());   // 失敗なら即 return
    return Ok();              // 成功
}

if (auto r = Save(); !r)
    ACS_LOG_ERROR("save failed");
