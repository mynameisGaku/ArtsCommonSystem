ELogSeverity

ログの重要度レベル（基底 u8）。 数値が小さいほど詳細。 最小レベル以上のものだけが出力される。

列挙(enum)
対応するAPI: acs::ELogSeverity

使う場面

FLogConfig::min_severity や SetMinSeverity でしきい値を決める時。
