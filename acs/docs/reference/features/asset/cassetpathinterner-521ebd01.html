CAssetPathInterner

ゲームで使う画像・音・モデル・データなどの素材ファイル。パスを正規化して一度だけ保持し、同じパスへ同じ FInternedAssetPath を返す共有テーブル。

クラス
対応するAPI: acs::CAssetPathInterner

使う場面

パス文字列の重複確保と繰り返し文字列やデータを決まった大きさの数値へ変換すること。 同じ入力からは常に同じ値が出る。を抑えたい時。
