ABinaryAsset

バイト列をそのまま保持する最小ゲームで使う画像・音・モデル・データなどの素材ファイル。。 専用特定のファイル形式を解析してアセットを作る部品。 IAssetLoader を実装しレジストリへ登録する。がない拡張子の本命が使えない時の代替経路。 XR では HMD 未接続時に通常の 2D 画面描画へ切り替えること。や、テストデータ用。

クラス(AAsset 派生)
対応するAPI: acs::ABinaryAsset

使う場面

形式不問で生バイトを読みたい時。 専用型がない拡張子はこれで読まれる。
