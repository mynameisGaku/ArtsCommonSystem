AMeshAsset

単一メッシュ。 メッシュを構成する点。 位置・法線・UV などの属性を持つ。配列 + 頂点配列のどの点で三角形を作るかを示す番号の列。 同じ頂点を使い回せる。配列 + サブメッシュ範囲を持つ。 メッシュを構成する点。 位置・法線・UV などの属性を持つ。は「位置 + 面や線に垂直な向きのベクトル。 当たった面の向きやライティングの計算に使う。 + UV」固定(v1)。 gltf/glb/obj/fbx に対応。

クラス(AAsset 派生)
対応するAPI: acs::AMeshAsset

使う場面

3D モデルを読み込んで 画像処理に特化した演算装置。 描画はここで行われる。 メッシュにアップロードする時。
