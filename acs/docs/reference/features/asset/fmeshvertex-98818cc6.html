FMeshVertex

標準メッシュを構成する点。 位置・法線・UV などの属性を持つ。1 ピクセル/要素のビット配置と型(RGBA8、HDR float、深度など)。 ACS では EFormat。。 位置 3 次元ベクトル(x, y, z)。 3D の位置・方向・色などに使う最重要型で、SIMD演算に最適化されている。 + 面や線に垂直な向きのベクトル。 当たった面の向きやライティングの計算に使う。 3 次元ベクトル(x, y, z)。 3D の位置・方向・色などに使う最重要型で、SIMD演算に最適化されている。 + UV(u, v)。 3 次元ベクトル(x, y, z)。 3D の位置・方向・色などに使う最重要型で、SIMD演算に最適化されている。 が alignas(16) のため sizeof は 48 バイト(末尾 8B パディング込み)。 ※ ヘッダ MeshAsset.h:19 のコメント「32 bytes」は 3 次元ベクトル(x, y, z)。 3D の位置・方向・色などに使う最重要型で、SIMD演算に最適化されている。 が 12B だった頃の古い記述。
