AAsset

すべてのゲームで使う画像・音・モデル・データなどの素材ファイル。(画像・音声・メッシュ・テキスト等)が継承する共通の基底。 実行時のアセットやローダの種類を表す数値(AssetType)。 文字列名のハッシュから作られる。(Type())・パス文字列をハッシュした 64-bit のアセット識別子。 同じパスなら必ず同じ ID。・アセットが今どの段階か(未ロード/ロード中/利用可/失敗)。 EAssetState で表す。を持つ。

対応するAPI: acs::AAsset

特定のファイル形式を解析してアセットを作る部品。 IAssetLoader を実装しレジストリへ登録する。や読み込んだアセットをキー(FAssetId)で保持・共有し、再利用する管理表。 ACS では CAssetRegistry。がゲームで使う画像・音・モデル・データなどの素材ファイル。を型を問わず受け渡す時の共通の入れ物。 読み込んだ 複数で共有するスマートポインタ。 参照カウントが 0 で自動解放。<AAsset> を具体型に判別したい時にも使う。
