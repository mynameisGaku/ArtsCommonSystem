FAssetFuture

処理の完了を待たずに先へ進み、結果は後で受け取るやり方。 重い読み込みなどで画面を止めない。ロードの結果実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。(「あとで完了する処理の結果」を表すハンドル。 完了を待つ/確認することができる。)。 LoadAsync が返す。 完了を受信や接続待ちの関数が、結果が無くても待たずにすぐ返る動作モード。 ゲームループを止めずに通信できる。で確認したり、待って結果を取り出したりできる。

クラス
対応するAPI: acs::FAssetFuture

使う場面

パスからアセットを読み込み、TSharedPtr でキャッシュ共有する中心クラス。::LoadAsync の戻り値を保持し、後で完了を確認・取得する時。
