FAssetRegistryDiagnostics

ゲームで使う画像・音・モデル・データなどの素材ファイル。読み込んだアセットをキー(FAssetId)で保持・共有し、再利用する管理表。 ACS では CAssetRegistry。の検索、登録、intern 再利用経路を観測する診断 ある時刻の世界全体の状態を 1 つに固めたもの。 server がこれを配信し、client は受信した複数 snapshot を補間して表示する (FPS/MMO 系で標準)。。

構造体
対応するAPI: acs::FAssetRegistryDiagnostics

使う場面

ゲームで使う画像・音・モデル・データなどの素材ファイル。検索 hot path の退行を同じ入力なら必ず同じ結果になる性質。 乱数や時刻に依存せず、テストや再現がしやすい。カウンタで確認する時。
