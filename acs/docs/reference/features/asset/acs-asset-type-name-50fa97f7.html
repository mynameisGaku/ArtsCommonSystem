ACS_ASSET_TYPE(name)

派生ゲームで使う画像・音・モデル・データなどの素材ファイル。クラスにアセットやローダの種類を表す数値(AssetType)。 文字列名のハッシュから作られる。 を一行で宣言するコンパイル前に決まった形へ展開される短い記述(#define)。 定型コードを一行で書ける。。 文字列リテラルから文字列やデータを決まった大きさの数値へ変換すること。 同じ入力からは常に同じ値が出る。で StaticType() を作り、Type() を override する。

マクロ
対応するAPI: ACS_ASSET_TYPE

使う場面

自前のゲームで使う画像・音・モデル・データなどの素材ファイル。型を AAsset から派生させる時、クラス先頭に置くだけ。

class FMyAsset : public AAsset {
public:

};
