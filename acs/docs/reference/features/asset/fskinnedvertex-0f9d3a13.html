FSkinnedVertex

スキンメッシュの1 メッシュを構成する点。 位置・法線・UV などの属性を持つ。(64 バイト固定)。 位置・面や線に垂直な向きのベクトル。 当たった面の向きやライティングの計算に使う。・UV に加え、影響するスキンメッシュを動かす骨。 階層を組み、頂点がこれに追従して変形する。番号 4 つとウェイト 4 つを持つ。

構造体
対応するAPI: acs::FSkinnedVertex

使う場面

スキンメッシュのメッシュを構成する点。 位置・法線・UV などの属性を持つ。を組み立てる時。

API項目

API項目 1

FVec3 position / FVec3 normal
説明
座標と面や線に垂直な向きのベクトル。 当たった面の向きやライティングの計算に使う。。
対応API

対応API

API項目 2

f32 u, v
説明
テクスチャ UV。
対応API

対応API
acs::FSkinnedVertex::v メンバー変数

API項目 3

u8 bones[4]
説明
影響する最大 4 スキンメッシュを動かす骨。 階層を組み、頂点がこれに追従して変形する。の番号(未使用は 0)。
対応API
acs::FSkinnedVertex::bones メンバー変数

API項目 4

f32 weights[4]
説明
各スキンメッシュを動かす骨。 階層を組み、頂点がこれに追従して変形する。の重み(合計 1.0、未使用は 0)。
対応API
acs::FSkinnedVertex::weights メンバー変数

使用例

FSkinnedVertex v;
v.position = FVec3{0,0,0};
v.bones[0] = 3; v.weights[0] = 1.0f;  // ボーン3 に100%追従
