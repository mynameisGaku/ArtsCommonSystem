FAsyncLoadState

非同期ロードの結果を後で受け取るためのハンドル(フューチャ)。 とワーカーが共有する内部オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。。 残タスク数を数える値。 0 になったら処理完了とみなす同期用カウンタ。・結果・エラーを保持する。 通常ユーザが直接触ることはない。
