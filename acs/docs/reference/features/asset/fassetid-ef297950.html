FAssetId

ゲームで使う画像・音・モデル・データなどの素材ファイル。の識別子。 パス文字列を文字列やデータを決まった大きさの数値へ変換すること。 同じ入力からは常に同じ値が出る。した 64-bit 値で、同じパスからは常に同じ ID が得られる。 読み込んだアセットをキー(FAssetId)で保持・共有し、再利用する管理表。 ACS では CAssetRegistry。のキャッシュキーになる。
