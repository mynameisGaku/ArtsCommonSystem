Primitive::MakeCube / MakeSphere / MakePlane

ゲームで使う画像・音・モデル・データなどの素材ファイル。ファイル不要で立方体・球・平面を生成する便利関数。 頂点+インデックス+サブメッシュからなる単一メッシュのアセット。 を 複数で共有するスマートポインタ。 参照カウントが 0 で自動解放。 で返す。 プロトタイピングやサンプルに便利。

関数(名前空間 Primitive)

  • acs::Primitive::MakeCubeTSharedPtr<AMeshAsset> MakeCube(f32 size = 1.0f) noexcept;
  • acs::Primitive::MakeSphereTSharedPtr<AMeshAsset> MakeSphere(f32 radius = 0.5f, u32 segments = 32, u32 rings = 16) noexcept;
  • acs::Primitive::MakePlaneTSharedPtr<AMeshAsset> MakePlane(f32 width = 1.0f, f32 depth = 1.0f) noexcept;
