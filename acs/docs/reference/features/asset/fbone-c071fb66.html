FBone

スキンメッシュを動かす骨。 階層を組み、頂点がこれに追従して変形する。 1 本。 名前・親番号・ソケットを特定のアドレス/ポートに結び付けて、そこで送受信できるようにすること。姿勢(平行移動/回転/スケール)と、計算済みの逆ソケットを特定のアドレス/ポートに結び付けて、そこで送受信できるようにすること。複数の変換（移動・回転・拡大）をまとめて表す数値の表。 3D では FMat4(4x4)。 ベクトルに掛けて座標変換する。を持つ。
