ACS 機能 / asset

CWavAssetLoader / CMp3AssetLoader / CFlacAssetLoader / COggAssetLoader

音声1 ピクセル/要素のビット配置と型(RGBA8、HDR float、深度など)。 ACS では EFormat。別の特定のファイル形式を解析してアセットを作る部品。 IAssetLoader を実装しレジストリへ登録する。。 それぞれ wav / mp3 / flac / ogg を担当し、エンコードされたデータを元の形(ここでは int16 PCM)に戻すこと。結果はすべて wav/mp3/flac/ogg を統一 PCM として読み込んだ音声アセット(asset モジュール)。 CAudioEngine に渡して再生する。(統一 音声を一定間隔で数値化した生波形データ。 圧縮なしでそのまま再生できる形式。)になる。

クラス(IAssetLoader 派生)

対応するAPI候補

  • acs::CWavAssetLoaderclass CWavAssetLoader final : public IAssetLoader;
  • acs::CMp3AssetLoaderclass CMp3AssetLoader final : public IAssetLoader;
  • acs::CFlacAssetLoaderclass CFlacAssetLoader final : public IAssetLoader;
  • acs::COggAssetLoaderclass COggAssetLoader final : public IAssetLoader;

使う場面

標準特定のファイル形式を解析してアセットを作る部品。 IAssetLoader を実装しレジストリへ登録する。登録で自動使用。 特定形式だけ手動で足したい時に個別登録。
