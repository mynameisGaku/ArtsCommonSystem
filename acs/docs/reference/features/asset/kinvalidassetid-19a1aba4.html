kInvalidAssetId

無効な パス文字列をハッシュした 64-bit のアセット識別子。 同じパスなら必ず同じ ID。 を表す定数(パス文字列をハッシュした 64-bit のアセット識別子。 同じパスなら必ず同じ ID。{0})。 value == 0 は「無効」として予約されており、MakeAssetId は結果が 0 になった場合 1 に補正してこの値と衝突しないようにする。

定数
対応するAPI: acs::kInvalidAssetId

使う場面

未設定/失敗の ID を初期値として置く時や、id != kInvalidAssetId で有効性を判定したい時(id.IsValid() と同義)。
