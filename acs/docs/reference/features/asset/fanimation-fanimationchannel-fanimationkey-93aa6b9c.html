FAnimation / FAnimationChannel / FAnimationKey

アニメーションのデータ構造。 1 つのボーンアニメーション(尺と時刻ごとの姿勢キー)。(名前+尺+チャネル群) → 1 つのボーンアニメーション(尺と時刻ごとの姿勢キー)。Channel(対象スキンメッシュを動かす骨。 階層を組み、頂点がこれに追従して変形する。+キー列) → 1 つのボーンアニメーション(尺と時刻ごとの姿勢キー)。Key(時刻ごとの TRS)。

構造体

対応するAPI候補

  • acs::FAnimationstruct FAnimation;
  • acs::FAnimationChannelstruct FAnimationChannel;
  • acs::FAnimationKeystruct FAnimationKey;

使う場面

スキンメッシュを動かす骨。 階層を組み、頂点がこれに追従して変形する。アニメをプログラム的に作る時。

使用例

anim.name = "walk"; anim.duration = 1.0f;
FAnimationChannel ch; ch.bone_index = 0;

anim.channels.Add(Move(ch));
