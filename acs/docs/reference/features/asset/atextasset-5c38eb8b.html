ATextAsset

テキスト(UTF-8 文字列)を保持するゲームで使う画像・音・モデル・データなどの素材ファイル。。 末尾 NUL 付きで C 文字列として取り出せる。 txt/json/xml/yaml/csv/md/hlsl/glsl/lua 等に対応。

クラス(AAsset 派生)
対応するAPI: acs::ATextAsset

使う場面

設定ファイル・スクリプト・GPU 上で頂点やピクセルを計算する小さなプログラム。 ACS では HLSL で書く。ソースなどテキストを読み込む時。
