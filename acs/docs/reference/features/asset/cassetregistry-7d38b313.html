CAssetRegistry

ゲームで使う画像・音・モデル・データなどの素材ファイル。読み込みの中心。 パスを渡すと拡張子に合う特定のファイル形式を解析してアセットを作る部品。 IAssetLoader を実装しレジストリへ登録する。でファイルを読み、結果を 複数で共有するスマートポインタ。 参照カウントが 0 で自動解放。 でキャッシュ共有する。 処理が終わるまでその場で待つやり方。 結果がすぐ手に入る代わりに止まる。/処理の完了を待たずに先へ進み、結果は後で受け取るやり方。 重い読み込みなどで画面を止めない。どちらも対応。 中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。不可。

説明
処理の完了を待たずに先へ進み、結果は後で受け取るやり方。 重い読み込みなどで画面を止めない。で タスクを並列実行するスレッドプール(ワークスチール方式)。 ワーカーに読み込みを投げ、非同期ロードの結果を後で受け取るためのハンドル(フューチャ)。 を返す。 キャッシュ済みなら即完了オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。の future。
