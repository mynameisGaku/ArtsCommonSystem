FAssetPathInternerDiagnostics

パス interner の登録数、再利用数、保持 byte 数を観測する診断 ある時刻の世界全体の状態を 1 つに固めたもの。 server がこれを配信し、client は受信した複数 snapshot を補間して表示する (FPS/MMO 系で標準)。。

構造体
対応するAPI: acs::FAssetPathInternerDiagnostics

使う場面

パス共有の効果とプログラムが使う記憶領域。 確保と解放の管理が性能と安全性を左右する。使用量をプロファイルする時。
