CImageAssetLoader

画像ファイルの特定のファイル形式を解析してアセットを作る部品。 IAssetLoader を実装しレジストリへ登録する。(stb_image)。 バイト列を 画像 1 枚分の CPU 側ピクセルデータを持つアセット。 にエンコードされたデータを元の形(ここでは int16 PCM)に戻すこと。する。 RegisterDefaultLoaders() で登録される。

クラス(IAssetLoader 派生)
対応するAPI: acs::CImageAssetLoader

使う場面

通常は標準特定のファイル形式を解析してアセットを作る部品。 IAssetLoader を実装しレジストリへ登録する。登録で自動的に使われる。 個別に追加したい時のみ手動登録。
