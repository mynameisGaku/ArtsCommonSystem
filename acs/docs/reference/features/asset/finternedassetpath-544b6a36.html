FInternedAssetPath

正規化済みゲームで使う画像・音・モデル・データなどの素材ファイル。パスを共有テーブルの ID として保持する軽量キー。 比較と中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。で文字列全体を走査しない。

クラス
対応するAPI: acs::FInternedAssetPath

使う場面

読み込んだアセットをキー(FAssetId)で保持・共有し、再利用する管理表。 ACS では CAssetRegistry。やキャッシュで同じゲームで使う画像・音・モデル・データなどの素材ファイル。パスを高頻度に比較する時。
