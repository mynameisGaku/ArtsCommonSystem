ACS 機能 / easy

Rgb / Rgba / Fade

0〜255 の整数から FColor を作るヘルパと、不透明度だけ変える Fade。

関数

対応するAPI候補

  • acs::easy::RgbFColor Rgb (u8 r, u8 g, u8 b) noexcept;
  • acs::easy::RgbaFColor Rgba(u8 r, u8 g, u8 b, u8 a) noexcept;
  • acs::easy::FadeFColor Fade(FColor color, f32 alpha) noexcept;

使う場面

0〜255の整数で色を作るときに使用します。 フェードイン/アウトや半透明画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。に Fade。

使用例

FColor c2 = Rgba(0, 0, 0, 128);        // 半透明の黒
FColor c3 = Fade(FColor::White, 0.3f); // 30% の白
