ポストプロセス（SetBloom ほか）

明るい部分を周囲ににじませて発光感を出すポストプロセス効果。（発光）・ビネット・カラーグレーディング等、画面全体にかかる効果。 Diligent Engine。 1 つの API で D3D12 / Vulkan 等を扱えるクロスバックエンド層。 ACS の Diligent* 系が利用する。 抽象的な機能呼び出しを、実際のライブラリや OS API につなぐ実装側のこと。 差し替え可能。でビルドした時だけ有効（Direct3D 12。 Windows の低レベル GPU API。 ACS の Dx12* 系がネイティブ実装。 raw では無視）。 IsPostProcessAvailable() で可否を確認。 既定はすべて無効。

関数
対応するAPI: acs::easy::SetBloom

使う場面

ネオン調の発光、シネマ高精度タイマ（QPC）が刻む最小単位の時間。 TicksPerSecond() で秒に換算する。な色味、画面端の暗化などで見た目を底上げしたい時。 文字も含め画面全体にかかる点に注意。

使用例

if (IsPostProcessAvailable()) {
    SetBloom(0.6f);                       // 発光
    SetVignette(0.4f);                    // 画面端を暗く
    SetColorGrading(1.1f, 1.0f, 0.2f);    // 彩度↑・暖色寄り
    SetTonemap(0);                        // ACES
}
