LoadSprite / LoadSound

画像・音を読み込んで実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。を返す。 同じパスは読み直さず同じ実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。を返す。 失敗しても落ちず、無効実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。（id==0）を返す。

関数

対応するAPI候補

  • acs::easy::LoadSpriteFSprite LoadSprite(const char* path) noexcept;
  • acs::easy::LoadSoundFSound LoadSound (const char* path) noexcept;

使う場面

ゲーム開始時にまとめて読む（ループ内で毎回呼んでも再読込はされないが、開始時が分かりやすい）。 OpenWindow の後で呼ぶ。
