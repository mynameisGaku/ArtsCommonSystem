ACS 機能 / easy

画像を描く（DrawSprite ほか）

LoadSprite で読んだ画像を描く関数群。 元サイズ・伸縮・回転・色掛け（画像に色を掛け合わせて見た目の色を変えること。 点滅やダメージ表現に使う。）・反転・一部切り出し（2D の 1 枚絵(キャラ・アイコン等)。 矩形にテクスチャを貼って描く。シート）に対応。 位置 (x,y) は画像の左上。

関数

対応するAPI候補

  • acs::easy::DrawSpritevoid DrawSprite(FSprite sprite, f32 x, f32 y) noexcept;
  • acs::easy::DrawSpritevoid DrawSprite(FSprite sprite, f32 x, f32 y, f32 width, f32 height) noexcept;

使う場面

キャラやタイルの画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。。 アニメーションは DrawSpritePart でシートのコマを切り替える。

使用例

FSprite p = LoadSprite("hero.png");
DrawSprite(p, 100, 100);                       // 元サイズ
DrawSprite(p, 100, 100, 64, 64);               // 伸縮
DrawSpriteRotated(p, 200, 200, 30);            // 回転
DrawSpriteFlipped(p, 300, 200, true, false);   // 左右反転
// シートの (0,0) から 32x32 のコマだけ切り出す
DrawSpritePart(p, 400, 200, 32, 32, 0, 0, 32, 32);
