ACS 機能 / easy

SetFullscreen / ToggleFullscreen / IsFullscreen

全画面表示（ボーダーレス）の ON/OFF。 次のゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。から反映されます。

関数

対応するAPI候補

  • acs::easy::SetFullscreenvoid SetFullscreen(bool on) noexcept;
  • acs::easy::ToggleFullscreenvoid ToggleFullscreen() noexcept;
  • acs::easy::IsFullscreenbool IsFullscreen() noexcept;

使う場面

設定画面の全画面トグルや、Alt+Enter 相当の切替に。

使用例
