WorkerCount / IsWorker

並列ワーカ数と、今のコードがワーカ1 つのプログラム内で同時に進む実行の流れ。 複数あると処理を並列にできる。上で動いているかを返す。

関数

対応するAPI候補

  • acs::easy::WorkerCounti32 WorkerCount() noexcept;
  • acs::easy::IsWorkerbool IsWorker() noexcept;

使う場面

分割数の目安にしたり、並列実行する小さな仕事の単位。 依存関係を付けて CJobGraph で順序立てて走らせられる。の中（ワーカ上）で誤って画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。関数を呼んでいないか確認したりする時。
