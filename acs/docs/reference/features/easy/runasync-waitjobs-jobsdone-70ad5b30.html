ACS 機能 / easy

RunAsync / WaitJobs / JobsDone

1 つの処理を処理の完了を待たずに先へ進み、結果は後で受け取るやり方。 重い読み込みなどで画面を止めない。に走らせて即座に戻り、FJobBatch を返す。 後で WaitJobs で完了を待つか JobsDone で待たずに確認する。 同じ batch に追加投入もできる。

関数

対応するAPI候補

  • acs::easy::RunAsynctemplate<typename Fn> inline FJobBatch RunAsync(Fn fn) noexcept;
  • acs::easy::RunAsynctemplate<typename Fn> inline void RunAsync(FJobBatch batch, Fn fn) noexcept;
  • acs::easy::WaitJobsvoid WaitJobs(FJobBatch batch) noexcept;
  • acs::easy::JobsDonebool JobsDone(FJobBatch batch) noexcept;

使う場面

重い読み込みや計算を裏で進めつつ、ローディング画面を回したい時。 中では計算だけして結果は捕捉変数に書き、画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。はしないこと。

API項目 1

FJobBatch RunAsync<Fn>(Fn fn)
説明
fn を処理の完了を待たずに先へ進み、結果は後で受け取るやり方。 重い読み込みなどで画面を止めない。で 1 つ走らせ、すぐ戻る。
戻り値
並列実行する小さな仕事の単位。 依存関係を付けて CJobGraph で順序立てて走らせられる。実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。

API項目 3

void WaitJobs(FJobBatch batch)
説明
batch の全並列実行する小さな仕事の単位。 依存関係を付けて CJobGraph で順序立てて走らせられる。完了まで待つ。 待ち終えた batch は無効化される。
対応API
acs::easy::WaitJobs 関数
対応API
acs::easy::FJobBatch 構造体

API項目 4

bool JobsDone(FJobBatch batch)
説明
待たずに完了オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。を確認する。 ローディング表示の継続判定に。
戻り値
完了したか
対応API
acs::easy::JobsDone 関数
対応API
acs::easy::FJobBatch 構造体

使用例

FJobBatch jobs = RunAsync([&]{ loadLevel(); });
RunAsync(jobs, [&]{ buildNav(); });   // 同じ batch に追加
while (NextFrame()) {
    if (JobsDone(jobs)) break;        // 待たずに確認
    DrawString(20, 20, "Loading...", FColor::White);
}
WaitJobs(jobs);                       // 念のため完了を保証
