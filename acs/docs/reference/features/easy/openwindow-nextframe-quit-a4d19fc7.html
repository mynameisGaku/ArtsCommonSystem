OpenWindow / NextFrame / Quit

ゲームの開始・1 ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。進行・終了。 OpenWindow を最初に 1 回だけ呼び、while (NextFrame()) でループします。

API項目

API項目 1

void OpenWindow(i32 width=1280, i32 height=720, const char* title="ACS Game")
説明
OS が画面に出す四角い領域。 タイトルバーや × ボタンを持ち、ゲームの描画先になる。 ACS では FWindow。を開いて初期化。 失敗時はコンソールにエラーを出し、最初の NextFrame() が false を返す（静かに終了）。
対応API
acs::easy::OpenWindow 関数

API項目 2

bool NextFrame()
説明
直前のゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。を画面に出し、次の準備をして true。 閉じられたら後始末して false。 while の条件に使う。
戻り値
続行するか
対応API
acs::easy::NextFrame 関数

API項目 3

void Quit()
説明
ゲームを終了する。 以後 NextFrame() が false を返すようになる。
対応API
acs::easy::Quit 関数

使用例

OpenWindow(1280, 720, "My Game");
while (NextFrame()) {
    if (IsKeyPressed(EKey::Escape)) Quit();
    DrawString(20, 20, "Hello", FColor::White);
}
