ACS 機能 / easy

セーブ／ロード（SaveInt ほか）

実行ファイルの場所の save.dat に key-value で永続化する。 整数・小数・文字列を保存／読み出し。 Load 系は未保存ならデフォルト値を返す。 OpenWindow の前でも後でも呼べる。

関数
対応するAPI: acs::easy::SaveInt

使う場面

ハイスコア・設定・進行状況の保存。 文字列の値に改行（\n）は使えない。
