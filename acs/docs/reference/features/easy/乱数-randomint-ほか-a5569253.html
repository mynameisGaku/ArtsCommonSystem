乱数（RandomInt ほか）

整数・小数・真偽値の規則性のない数値。 敵の出現位置やドロップ抽選などに使う。。 RandomSeed で種を固定すると、毎回同じ並びになる（再現性が必要なテストやプレイの入力や状態を記録し、後で同じ進行を再生する仕組み。 決定論的な乱数と相性が良い。に）。

関数
対応するAPI: acs::easy::RandomInt

使う場面

敵の出現位置、ドロップ判定、ランダム挙動。 デバッグで毎回同じ展開にしたい時は種を固定。
