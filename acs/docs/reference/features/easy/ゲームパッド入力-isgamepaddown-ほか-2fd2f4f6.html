ゲームパッド入力（IsGamepadDown ほか）

最大 4 台（player 0〜3、省略時 0）のコントローラ。 ACS は XInput 互換でボタンやスティック（軸）を読む。を読む。 ボタンは EGamepadButton、ス高精度タイマ（QPC）が刻む最小単位の時間。 TicksPerSecond() で秒に換算する。は -1.0〜+1.0、重なりだけを検出する当たり判定。 物理の押し戻しはせず「触れたか」だけを通知する。 関連語は トリガワールド。ーは 0.0〜1.0。
