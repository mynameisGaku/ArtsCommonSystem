Job / Then / RunJobs

依存つきの並列実行。 Job でゲーム世界に置く部品の単位。 位置やコンポーネントを持ち、親子のツリーで並ぶ。を作り、Then で「A の後に B」と順序を張り、RunJobs で全ゲーム世界に置く部品の単位。 位置やコンポーネントを持ち、親子のツリーで並ぶ。を依存順に実行して全完了まで待つ。 内部は依存グラフ。

関数

対応するAPI候補

  • acs::easy::Jobtemplate<typename Fn> inline FJobNode Job(Fn fn) noexcept;
  • acs::easy::Thenvoid Then(FJobNode before, FJobNode after) noexcept;
  • acs::easy::RunJobsvoid RunJobs() noexcept;

使う場面

処理に前後関係がある時（『地形生成 → ナビ構築 → 敵配置』など）。 順序を Then で表現すれば、独立な部分は自動で並列化される。

使用例

FJobNode gen  = Job([]{ generateTerrain(); });
FJobNode nav  = Job([]{ buildNavmesh(); });
FJobNode spawn= Job([]{ spawnEnemies(); });
Then(gen, nav);    // 地形 → ナビ
Then(nav, spawn);  // ナビ → 敵
RunJobs();         // 依存順に実行し、全完了まで待つ
