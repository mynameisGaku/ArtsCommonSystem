カメラ（SetCamera ほか）

ワールド座標と画面を分ける仕組み。 SetCamera 後に描く図形はワールド座標として扱われ、視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。の位置・ズームに応じて画面に映る。 視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。設定は毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。呼ぶ（呼ばなければ視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。無し）。

API項目

API項目 1

void SetCamera(f32 x, f32 y)
説明
(x,y) のワールド座標が画面中央に映るよう視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。を置く。
対応API
acs::easy::SetCamera 関数

API項目 2

void SetCameraZoom(f32 zoom)
説明
ズーム倍率（1.0 等倍、2.0 で 2 倍に拡大）。
対応API
acs::easy::SetCameraZoom 関数

API項目 3

void ResetCamera()
説明
スクロール無し・ズーム 1.0 に戻す。 HUD を描く前に。
対応API
acs::easy::ResetCamera 関数

API項目 4

f32 CameraX() / f32 CameraY()
説明
現在の視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。中心のワールド座標。
戻り値
視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。中心
対応API
acs::easy::CameraX 関数
対応API
acs::easy::CameraY 関数

API項目 5

f32 MouseWorldX() / f32 MouseWorldY()
説明
スクロール・ズームを反映したマウス位置。 クリックでワールド上のものを掴む時に。
戻り値
マウスのワールド座標
対応API
acs::easy::MouseWorldX 関数
対応API
acs::easy::MouseWorldY 関数

使用例

SetCamera(playerX, playerY);   // プレイヤーを画面中央に
SetCameraZoom(2.0f);            // 2 倍ズーム
DrawSprite(map, 0, 0);         // ワールドに描く
ResetCamera();                 // 以降は画面固定（HUD 用）
DrawString(10, 10, "HUD", FColor::White);
