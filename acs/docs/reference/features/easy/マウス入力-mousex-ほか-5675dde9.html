ACS 機能 / easy

マウス入力（MouseX ほか）

マウス座標（OS が画面に出す四角い領域。 タイトルバーや × ボタンを持ち、ゲームの描画先になる。 ACS では FWindow。内ピクセル＝画面座標）・ボタンオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。・ホイール。 ボタンは EMouseButton（省略時は左）。 Down/Pressed/Released の違いはキーボードと同じ。

関数
対応するAPI: acs::easy::MouseX

使う場面

クリックで撃つ・ボタンを押す、ドラッグ、ホイールでズーム/スクロール。 ワールド上の対象を掴むなら MouseWorldX/Y（視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。節）。
