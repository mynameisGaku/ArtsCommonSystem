ACS 機能 / easy

図形を描く（DrawRect ほか）

四角・円・線・三角・点を描く関数群。 (x,y) は図形の左上（円だけは中心）、回転は図形の中心まわりで角度は度。 Outline 版は枠線だけ、thickness で太さを指定。

関数
対応するAPI: acs::easy::DrawRect

使う場面

画像を使わずに当たり判定の可視化やシンプルなゲームを作る時。 NextFrame() の後で呼ぶ。

使用例

DrawRect(100, 100, 80, 40, FColor::Sky);            // 塗り四角

DrawLine(0, 0, 200, 200, FColor::Red, 3.0f);
DrawRectRotated(300, 200, 60, 60, 45, FColor::Green);
