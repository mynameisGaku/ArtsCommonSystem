ACS 機能 / easy

FSprite / FSound

LoadSprite / LoadSound が返す、中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。可能な軽い素材実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。（中身は番号 id だけ）。 id==0 は無効。

構造体

対応するAPI候補

  • acs::easy::FSpritestruct FSprite;
  • acs::easy::FSoundstruct FSound;

使う場面

読み込んだ画像・音を持ち回って画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。/再生に渡す時。 失敗しても落ちず、無効実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。が返る（画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。/再生は無視される）。

API項目

API項目 1

u32 id
説明
素材を指す内部番号。 0 は無効（読み込み失敗など）。
overload候補
id は複数の宣言に対応します。
  • acs::easy::FSprite::idu32 id = 0;
  • acs::easy::FSound::idu32 id = 0;
  • acs::easy::FJobBatch::idu32 id = 0;
  • acs::easy::FJobNode::idu32 id = 0;

使用例

FSprite player = LoadSprite("player.png");
FSound  jump   = LoadSound("jump.wav");
if (player.id != 0) DrawSprite(player, 100, 100);
