ACS 機能 / easy

音（Play ほか）

効果音の 1 回再生・バックグラウンドミュージック。 場面の間ずっとループで流す音楽。 のループ再生・停止・音量制御。 音量はすべて 0.0〜1.0。

関数

対応するAPI候補

  • acs::easy::Playvoid Play(FSound sound) noexcept;
  • acs::easy::Playvoid Play(FSound sound, f32 volume) noexcept;

使う場面

ジャンプ音や爆発音は Play、バックグラウンドミュージック。 場面の間ずっとループで流す音楽。 は PlayLoop。 設定画面の音量スライダーには SetMasterVolume。

API項目

API項目 1

void Play(FSound s) / void Play(FSound s, f32 volume)
説明
効果音を 1 回鳴らす。 音量は 0.0〜1.0。
overload候補
Play は複数の宣言に対応します。

  • acs::easy::Playvoid Play(FSound sound, f32 volume) noexcept;

使用例

Play(jumpSe);                 // 効果音 1 回
Play(hitSe, 0.5f);            // 音量半分
PlayLoop(bgm, 0.8f);          // BGM ループ
StopSound(bgm);               // その音を止める
SetMasterVolume(0.3f);        // 全体音量
