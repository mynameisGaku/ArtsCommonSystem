ACS 機能 / easy

当たり判定（RectsOverlap ほか）

矩形どうし・円どうしの重なり、点が矩形/円の中にあるかを判定する。 重なっていれば true。

関数
対応するAPI: acs::easy::RectsOverlap

使う場面

敵と弾の衝突、プ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ーとアイテムの接触、ボタンのクリック判定（点 vs 矩形）。

bool RectsOverlap(f32 x1,f32 y1,f32 w1,f32 h1, f32 x2,f32 y2,f32 w2,f32 h2)
