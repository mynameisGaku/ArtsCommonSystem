FColor

色を表す値。 各成分 r,g,b,a は 0.0〜1.0。 a は不透明度（0=透明, 1=不透明）。 FColor::Red などの定数を使うか、Rgb(255,0,0) で作ります。

構造体
対応するAPI: acs::easy::FColor

使う場面

すべての画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。関数に色として渡す。 半透明にしたい時は a を下げるか Fade() を使う。

使用例
