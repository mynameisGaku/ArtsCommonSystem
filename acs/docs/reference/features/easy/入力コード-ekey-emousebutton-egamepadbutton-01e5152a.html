ACS 機能 / easy

入力コード（EKey / EMouseButton / EGamepadButton）

easy が再公開しているキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。用の列挙。 using acs::EKey; 等で acs::easy 名前の衝突を防ぐ入れ物。 acs::easy::OpenWindow の acs::easy の部分。からそのまま EKey::Space のように書ける。 実体は OS ごとのウィンドウ・入力・時間などを抽象化する低レベルモジュール。 easy の入力コード列挙 EKey 等もここで定義される。 モジュールの キーボード・マウス・ゲームパッドの状態を問い合わせで読む静的クラス。 毎フレーム先頭で Update() を呼んでから状態を読む。Codes.h で定義され、easy 側では値一覧が見えないため、よく使う値をここにまとめる。 IsKeyDown / IsMouseDown / IsGamepadDown などに渡す。

列挙

対応するAPI候補

  • acs::EKeyenum class EKey : u16;
  • acs::EMouseButtonenum class EMouseButton : u8;
  • acs::EGamepadButtonenum class EGamepadButton : u8;

使う場面

キーボード・マウス・コントローラ。 ACS は XInput 互換でボタンやスティック（軸）を読む。のキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。関数に「どのキー/ボタンか」を渡す時。 先頭の EKey:: 等を省略せず、列挙の値名で指定する。

使用例

if (IsKeyDown(EKey::Right)) x += 5;          // 矢印キー
if (IsKeyPressed(EKey::Space)) Jump();        // スペース
if (IsMouseDown(EMouseButton::Right)) Pan();  // 右クリック
if (IsGamepadPressed(EGamepadButton::A)) Ok(); // ゲームパッド A
