ACS 機能 / easy

文字を描く（DrawString ほか）

UTF-8 の文字列（日本語可、\n で改行）を描く。 中央そろえ版や、文字の幅・高さを測る関数もある。 size で文字サイズを指定。

関数

対応するAPI候補

  • acs::easy::DrawStringvoid DrawString(f32 x, f32 y, const char* text, FColor color) noexcept;
  • acs::easy::DrawStringvoid DrawString(f32 x, f32 y, const char* text, FColor color, f32 size) noexcept;

使う場面

スコア・メッセージ・メニューの表示。 中央そろえはタイトルやボタンに便利。
