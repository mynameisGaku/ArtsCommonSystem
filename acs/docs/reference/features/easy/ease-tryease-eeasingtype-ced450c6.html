Ease / TryEase / EEasingType

シーン、コンポーネント、各ジャンル用機能、アセット読み書きの抽象 API など、ゲーム構築用の部品を提供する acs::game モジュールです。 と同じトゥイーンの加減速カーブ。 Linear(等速)や InOutSine(ゆっくり始まりゆっくり終わる)など。 catalog の評価可能な全 33 曲線を easy から型付きで利用する入口。 EEasingType は Linear、Quad/Cubic/Quart/Quint/Sine/Expo/Circ/Back/Elastic/Bounce の In/Out/InOut と SmoothStep/SmootherStep を列挙する。 Count = 33 は末尾 sentinel で、評価可能な曲線ではない。 Easy は シーン、コンポーネント、各ジャンル用機能、アセット読み書きの抽象 API など、ゲーム構築用の部品を提供する acs::game モジュールです。 へ一方向に依存し、曲線の数式を重複実装しない。
