InstallSteamworksAsDefault()

実 Bridge を acs::game 側の明示指定が無い時に使われる既定の実装を返す登録関数。 後勝ちで差し替えられる。として登録する。 これを呼ぶと、以降ゲームコードは 抽象的な機能呼び出しを、実際のライブラリや OS API につなぐ実装側のこと。 差し替え可能。非依存に acs::game::GetDefaultValve のゲーム配信プラットフォーム。 実績・フレンド・クラウドセーブ等の機能を Steamworks SDK 経由で使える。worksBridge() で実 Bridge を取得できる(未登録なら自動で 本物の代わりに置く最小実装。 依存ゼロでコンパイル・テストできる no-op 版。 が返る)。

関数
対応するAPI: acs::steamworks::InstallSteamworksAsDefault

使う場面

アプリ起動時に一度だけ呼ぶ。 gameframework はこのモジュールに直接依存できない(モジュール A が B を、B が A を必要とし合い、まっすぐ組めなくなる状態。 登録関数などで断ち切る。回避)ため、登録はこの関数経由で行う。
