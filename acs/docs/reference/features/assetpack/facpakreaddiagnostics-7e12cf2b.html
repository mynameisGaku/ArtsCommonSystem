FAcpakReadDiagnostics

pak 読み取りの index 検索、範囲読み込み、暗号化したデータを鍵で元に戻すこと。、展開、失敗経路を集計する診断 ある時刻の世界全体の状態を 1 つに固めたもの。 server がこれを配信し、client は受信した複数 snapshot を補間して表示する (FPS/MMO 系で標準)。。

構造体
対応するAPI: acs::assetpack::FAcpakReadDiagnostics

使う場面

配布 pak の読み込み量と余分な中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。、失敗理由をプロファイルする時。
