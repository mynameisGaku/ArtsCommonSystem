API項目 2

AcpakFlagEncrypted = 1 << 0
説明
各ファイルを 256bit 鍵の共通鍵暗号化方式。 暗号化と同時に改竄検知(認証タグ)も行う AEAD。 鍵を知らないと中身を読めない形にデータを変換すること。する。

API項目 3

AcpakFlagCompressed = 1 << 1
説明
各ファイルを 速度重視の可逆圧縮形式。 そこそこ縮み、展開がとても速い。 データを規則性を使って小さくすること。 ここでは LZ4 を使う。する。
