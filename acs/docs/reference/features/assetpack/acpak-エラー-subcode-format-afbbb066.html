.acpak エラー subcode (format)

.ACS のアセットアーカイブ形式(.acpak)。 出荷時に複数ファイルを 1 つにまとめる。 の .acpak などのアセットを読む側の部品。 pak をマウントして仮想ファイルを取り出す(対になる書き出し側が Writer)。/Writer が ACS_ERR(IO,...) / ACS_ERR(Asset,...) で返すエラーエラーコードの細目番号。 ACS の Result が持つ FErrorCode.subcode で、どの段階・原因の失敗かを区別する。 AssetPack は 1300 番台を使う。(1301〜1318)。 TSaveSlot(1-99)・Valve のゲーム配信プラットフォーム。 実績・フレンド・クラウドセーブ等の機能を Steamworks SDK 経由で使える。works/ユーザー作成コンテンツ(UGC, MOD やマップ等)を配布・購読する Steam の仕組み。(1001-1199)・CAssetPack.acpak などのアセットを読む側の部品。 pak をマウントして仮想ファイルを取り出す(対になる書き出し側が Writer)。本物の代わりに置く最小実装。 依存ゼロでコンパイル・テストできる no-op 版。/CAssetPackWriter本物の代わりに置く最小実装。 依存ゼロでコンパイル・テストできる no-op 版。(1200 番台)と重ならないよう 1300 番台を使う。
