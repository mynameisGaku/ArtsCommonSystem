FAcpakHeader

.ACS のアセットアーカイブ形式(.acpak)。 出荷時に複数ファイルを 1 つにまとめる。 先頭に書かれる固定長のヘッダ(Plain Old Data。 コンストラクタ等の特別な振る舞いを持たない単純な構造体。 コピーが速く扱いやすい。)。 magic・version・flags・ファイル数・アーカイブ内の各ファイルの名前・位置・サイズなどを並べた目次。の位置を持つ。 ディスク上は 36 バイト。

構造体
対応するAPI: acs::assetpack::FAcpakHeader

使う場面

1 ピクセル/要素のビット配置と型(RGBA8、HDR float、深度など)。 ACS では EFormat。を自前で読み書きする時の参照用。 普通は .acpak などのアセットを読む側の部品。 pak をマウントして仮想ファイルを取り出す(対になる書き出し側が Writer)。/Writer が内部で扱うので直接触らない。

API項目 3

u32 flags
説明
鍵を知らないと中身を読めない形にデータを変換すること。/データを規則性を使って小さくすること。 ここでは LZ4 を使う。の有無を表す EAcpakFlags の各 bit に意味を割り当て、OR で複数の状態を 1 個の整数にまとめて持つ手法。 pause 理由や同意カテゴリの複合表現に使う。。
