CAcpakCrypto

256bit 鍵の共通鍵暗号化方式。 暗号化と同時に改竄検知(認証タグ)も行う AEAD。 鍵を知らないと中身を読めない形にデータを変換すること。と パスワードを何千回も繰り返しハッシュして強い鍵を作る鍵導出方式。 総当たり攻撃を遅くする。 によるパスワードなど人間が覚えられる入力から、暗号用の鍵を計算で作ること。をまとめた薄いラッパ。 中身は Windows 標準の Windows 標準の暗号 API(Cryptography Next Generation)。 外部ライブラリ無しで AES などが使える。(BCrypt)で、外部ライブラリに依存しない。 インスタンス化はせず静的関数だけを使う。

クラス(static 関数群)
対応するAPI: acs::assetpack::CAcpakCrypto

使う場面

通常は CAcpakWriter/CAcpak.acpak などのアセットを読む側の部品。 pak をマウントして仮想ファイルを取り出す(対になる書き出し側が Writer)。 が内部で使うので直接触る必要は少ない。 パスワードから鍵を作る時だけ DeriveKey を呼ぶ。
