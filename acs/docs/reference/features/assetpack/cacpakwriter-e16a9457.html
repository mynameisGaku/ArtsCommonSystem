CAcpakWriter

バラバラのファイル(バイト列)を 1 つの .ACS のアセットアーカイブ形式(.acpak)。 出荷時に複数ファイルを 1 つにまとめる。 複数のファイルを 1 つにまとめた書庫ファイル。 .acpak はその一種。にまとめて書き出す梱包係。 キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。は内部へ中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。して所有し、完成品は同一ディレクトリの一時ファイルから出力先へ原子的に置換するため、途中失敗で既存 pak を壊さない。

クラス
対応するAPI: acs::assetpack::CAcpakWriter

使う場面

ゲームの全ゲームで使う画像・音・モデル・データなどの素材ファイル。を 1 ファイルに固めたい時。 データを規則性を使って小さくすること。 ここでは LZ4 を使う。や鍵を知らないと中身を読めない形にデータを変換すること。を有効にして「中身を覗かれにくく」したい時。

API項目 3

TResult<void> AddFile(const wchar_t* virtual_path, const void* data, u64 size)
説明
1 ファイルを追加する。 / 区切りの正規形仮想パスと全バイトを内部配列へ中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。し、path hash を一度保持する。 重複確認は hash 一致候補だけを完全比較し、同名パスや不正な ./.. segment は拒否する。 成功後は呼び出し側がキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。を直ちに再利用・解放してよい。
使う場面
梱包したいファイルを 1 つずつ登録していく時。
使用例
w.AddFile(L"textures/hero.png", pngBytes, pngLen);

TResult<void> Finalize()
説明
一時ファイルへヘッダ→全データ→アーカイブ内の各ファイルの名前・位置・サイズなどを並べた目次。の順で書き出し、元バイトの データから計算する 32bit のチェック値。 破損や改竄の検出に使う。 を記録する。 ヘッダ確定後に FlushFileBuffers し、出力先へ原子的に置換する。 置換が成功するまでは既存の出力先を保ち、書込み・flush・置換の失敗時は Close またはオブジェクトが破棄される時に自動で呼ばれる後始末の関数(~ClassName)。が一時ファイルを削除する。
