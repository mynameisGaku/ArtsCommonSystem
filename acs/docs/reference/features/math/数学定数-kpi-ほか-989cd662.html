ACS 機能 / math

数学定数 (kPi ほか)

kPi（円周率）や度↔ラジアン変換係数、比較用浮動小数の比較に使う非常に小さな許容誤差。 kEpsilon = 1e-6。などの定数。

定数群
対応するAPI: acs::kPi

使う場面

角度計算（ラジアン）やfloat / double など小数を表す数値型。 丸め誤差があるため == ではなく EXPECT_NEAR で許容誤差つきで比べる。の近似比較をする時。

API項目 3

kEpsilon
説明
比較用の微小値 1e-6。 float / double など小数を表す数値型。 丸め誤差があるため == ではなく EXPECT_NEAR で許容誤差つきで比べる。の「ほぼ等しい」判定に。
対応API
acs::kEpsilon 定数

使用例

f32 rad = 90.0f * kDeg2Rad;  // 度 → ラジアン
f32 deg = rad * kRad2Deg;    // ラジアン → 度
if (Abs(x) < kEpsilon) { /* ほぼ 0 */ }
