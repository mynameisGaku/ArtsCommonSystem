2D 衝突関数 (Intersect / Resolve / Raycast)

2D 形状同士の重なり判定（2 形状が重なっているかを bool で返す判定関数。）、めり込みを押し戻す最小並進ベクトル（Minimum Translation Vector）。 重なりを解消する最短の押し戻し方向と距離。（重なった 2 形状を引き離す最小移動量(MTV)を求める関数。 めり込み解消に。）、レイの命中判定（Raycast）。 軸並行の 2D 矩形コライダー（中心+半サイズ）。 最も軽い当たり判定。/2D の円コライダー（中心+半径）。/2D の凸多角形コライダー（最大 16 頂点）。 複雑な形のスプライトに。/回転できる 2D 矩形コライダー（OBB）。 の組み合わせにオーバーロードされている。

使う場面

2D の当たり判定そのもの。 衝突したか（2 形状が重なっているかを bool で返す判定関数。）、どれだけ押し戻すか（重なった 2 形状を引き離す最小移動量(MTV)を求める関数。 めり込み解消に。）、レイが当たった点と面や線に垂直な向きのベクトル。 当たった面の向きやライティングの計算に使う。（Raycast）を得る。

bool Intersect(A, B)
説明
2 形状が重なっていれば true。 Axis-Aligned Bounding Box。 軸に平行な直方体の境界ボックス。 当たり判定の粗い包囲に使う。/円/へこみのない多角形。 どの 2 点を結んでも内部に収まる。 当たり判定が単純で高速。/有向境界ボックス（Oriented Bounding Box）。 回転を持てる矩形/直方体コライダー。 の全組合せ対応。
