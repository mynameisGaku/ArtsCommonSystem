3D 衝突関数 (Intersect / Resolve / Raycast)

3D 形状の重なり判定（2 形状が重なっているかを bool で返す判定関数。）・押し戻し（重なった 2 形状を引き離す最小移動量(MTV)を求める関数。 めり込み解消に。）・ある点からある方向へ光線 (ray) を飛ばし、最初に当たる形状と交点を求める処理。 視線判定や射撃に使う。（Raycast）。 三角形との交差（レイと三角形の交差を高速に計算する定番アルゴリズム。 メッシュのピッキングに使う。）も含む。

自由関数群

対応するAPI候補

  • acs::IntersectACS_FORCEINLINE bool Intersect(const FAabb3& a, const FAabb3& b) noexcept;
  • acs::IntersectACS_FORCEINLINE bool Intersect(const FSphere& a, const FSphere& b) noexcept;
  • acs::IntersectACS_FORCEINLINE bool Intersect(const FAabb3& a, const FSphere& s) noexcept;
  • acs::IntersectACS_FORCEINLINE bool Intersect(const FSphere& s, const FAabb3& a) noexcept;
  • acs::ResolveACS_FORCEINLINE bool Resolve(const FSphere& a, const FSphere& b, FVec3& push) noexcept;
  • acs::ResolveACS_FORCEINLINE bool Resolve(const FSphere& sphere, const FAabb3& bounds, FVec3& push) noexcept;

使う場面

3D の当たり判定。 物体同士の衝突、めり込み解消、マウスピッキングや弾道のレイ、メッシュ三角形との交差を取る時。

API項目 3

bool Resolve(const FSphere& sphere, const FSphere&/const FAabb3&, FVec3& push)
説明
球を球または Axis-Aligned Bounding Box。 軸に平行な直方体の境界ボックス。 当たり判定の粗い包囲に使う。 から離す最小分離移動量を求める。 Axis-Aligned Bounding Box。 軸に平行な直方体の境界ボックス。 当たり判定の粗い包囲に使う。 内部では最寄り面を同じ入力なら必ず同じ結果になる性質。 乱数や時刻に依存せず、テストや再現がしやすい。に選ぶ。
