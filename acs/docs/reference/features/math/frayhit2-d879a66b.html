FRayHit2

2D ある点からある方向へ光線 (ray) を飛ばし、最初に当たる形状と交点を求める処理。 視線判定や射撃に使う。の結果。 当たったか・距離 t・衝突点・表面の面や線に垂直な向きのベクトル。 当たった面の向きやライティングの計算に使う。を持つ。

構造体
対応するAPI: acs::FRayHit2

使う場面

Raycast 系関数の戻り値を受け取り、命中したかと当たった場所を調べる時。

使用例

FRayHit2 h = RaycastCircle(ray, enemy);
if (h.hit) {
    FVec2 p = h.point;     // 衝突座標
    FVec2 n = h.normal;    // 表面法線
    f32   d = h.t;         // origin から t 倍の位置
}
