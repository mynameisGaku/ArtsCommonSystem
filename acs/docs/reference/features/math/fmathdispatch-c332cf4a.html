FMathDispatch

N 個の向きと大きさを持つ量。 2D/3D の位置・速度・方向を FVec2/FVec3 で表す。を一括変換するような同じ設定の描画をまとめて 1 回の命令で送り、描画回数を減らして高速化すること。演算を、起動時に検出した 中央演算装置。 対応するSIMD命令により計算速度が変わる。 機能に応じた最適実装へ振り分ける関数そのものを指し示す値。 あとで fn() のように呼び出せる。 テスト本体を一覧に登録する仕組みに使う。テーブル。

構造体・関数
対応するAPI: acs::FMathDispatch

使う場面

大量の点や方向向きと大きさを持つ量。 2D/3D の位置・速度・方向を FVec2/FVec3 で表す。を 1 つの複数の変換（移動・回転・拡大）をまとめて表す数値の表。 3D では FMat4(4x4)。 ベクトルに掛けて座標変換する。でまとめて変換する時。 1 個ずつ TransformPoint を呼ぶより速い。

API項目

API項目 1

void TransformPoints(const FVec3* in, FVec3* out, usize count, const FMat4& m)
説明
count 個の点をまとめて複数の変換（移動・回転・拡大）をまとめて表す数値の表。 3D では FMat4(4x4)。 ベクトルに掛けて座標変換する。変換する（移動成分も効く）。
対応API
acs::TransformPoints 関数

API項目 2

void TransformVectors(const FVec3* in, FVec3* out, usize count, const FMat4& m)
説明
count 個の方向向きと大きさを持つ量。 2D/3D の位置・速度・方向を FVec2/FVec3 で表す。をまとめて変換する（移動成分は無視）。
対応API
acs::TransformVectors 関数

API項目 3

const FMathDispatch& GetMathDispatch()
説明
選ばれた関数そのものを指し示す値。 あとで fn() のように呼び出せる。 テスト本体を一覧に登録する仕組みに使う。群を取得（初回で初期化）。 通常は上の利便関数で十分。
