FVec3

3 次元向きと大きさを持つ量。 2D/3D の位置・速度・方向を FVec2/FVec3 で表す。（x, y, z）。 16 バイト整列で1 命令で複数のデータをまとめて計算する CPU 機能。 ベクトル計算を高速化する。演算に最適。 3D の位置・方向・色などに使う最重要型。

構造体
対応するAPI: acs::FVec3

使う場面

3D 空間の座標・速度・面や線に垂直な向きのベクトル。 当たった面の向きやライティングの計算に使う。・視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。方向など、立体的な量を扱うほぼ全ての場面。

使用例

FVec3 a{1,0,0}, b{0,1,0};

FVec3 mid = Lerp(a, b, 0.5f); // 中間点
FVec3 up = FVec3::Up();      // {0,1,0}
