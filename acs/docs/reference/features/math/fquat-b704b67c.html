FQuat

4 つの数で 3D の回転を表す方式。 ジンバルロックがなく、回転の補間が滑らか。 ACS では FQuat。（x, y, z, w）。 3D の回転を表す。 オイラー角で回転を表す時、特定の角度で 1 軸ぶんの自由度が失われる現象。 クォータニオンなら起きない。が起きず、回転同士のクォータニオンの回転を一定速度で滑らかに補間する方法（slerp）。 向きのアニメーションに使う。が滑らか。

使用例

FQuat q = FQuat::AxisAngle(FVec3::Up(), kHalfPi); // Y 軸 90 度
FVec3 v = Rotate(q, {1,0,0});      // ベクトルを回す → ほぼ {0,0,1}
FQuat a = FQuat::Identity(), b = q;
FQuat mid = Slerp(a, b, 0.5f);     // 滑らかに 45 度
FMat4 m = ToMatrix(q);             // 行列に変換
