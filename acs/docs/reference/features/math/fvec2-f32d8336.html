FVec2

2 次元向きと大きさを持つ量。 2D/3D の位置・速度・方向を FVec2/FVec3 で表す。（x, y）。 8 バイト。 2D の位置・速度・方向を表す基本型。 小さいので1 命令で複数のデータをまとめて計算する CPU 機能。 ベクトル計算を高速化する。は使わず素直に計算する。

構造体
対応するAPI: acs::FVec2

使う場面

2D ゲームの座標、UI の位置、2D の 1 枚絵(キャラ・アイコン等)。 矩形にテクスチャを貼って描く。の移動量など、平面上の量を扱う時。

API項目 1

API項目 3

operator+ - * (単項 -) += -= *= /=
説明
向きと大きさを持つ量。 2D/3D の位置・速度・方向を FVec2/FVec3 で表す。同士の加減・スカラ倍。 除算は複合 /= のみ(二項 operator/ は無い)。 pos += vel * dt; のように書ける。
overload候補
operator+ は複数の宣言に対応します。
  • acs::operator+inline FVec2 operator+(FVec2 a, FVec2 b) noexcept;
  • acs::operator+inline FVec3 operator+(FVec3 a, FVec3 b) noexcept;
  • acs::operator+inline FVec4 operator+(FVec4 a, FVec4 b) noexcept;

使用例

FVec2 pos{100, 50};
FVec2 vel{0, -9.8f};
pos += vel * dt;            // 位置を更新
f32 dist = Length(pos);     // 原点からの距離
FVec2 dir = Normalize(vel); // 単位ベクトル化
