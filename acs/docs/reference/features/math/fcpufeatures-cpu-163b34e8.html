FCpuFeatures / Cpu()

実行中の 中央演算装置。 対応するSIMD命令により計算速度が変わる。 が対応する命令セット（x86 CPU のSIMD命令セットの一系統。 SSE2 は 64bit で常に使える。/SSE の後継のSIMD命令セット。 AVX2 などより広い幅で計算できる。/FMA など）を CPU 自身に対応命令セットを問い合わせる命令。 Cpu() が起動時に使う。 で 1 度だけ調べてキャッシュする。

使う場面

中央演算装置。 対応するSIMD命令により計算速度が変わる。 機能に応じて最適な実装を選びたい時。 通常は CPU 機能に応じてバッチ演算の最適実装を選ぶ仕組み。 が内部で使うので直接触る必要は少ない。
