FAabb2 / FCircle / FRay2

2D の衝突判定で使う基本形状。 軸並行の 2D 矩形コライダー（中心+半サイズ）。 最も軽い当たり判定。=軸並行の矩形（中心+半サイズ）、2D の円コライダー（中心+半径）。=円、2D のレイ（始点+方向）。 射撃や視線の判定に。=レイ（始点+方向）。

構造体

対応するAPI候補

  • acs::FAabb2struct FAabb2;
  • acs::FCirclestruct FCircle;
  • acs::FRay2struct FRay2;

使う場面

2D ゲームの当たり判定。 プ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ーや壁を矩形・円で表し、レイで射撃や視線を飛ばす。

API項目

API項目 1

FAabb2{ FVec2 center, FVec2 half_size }
説明
中心と半サイズ（幅/2, 高さ/2）で矩形を表す。
overload候補
FAabb2 は複数の宣言に対応します。
  • acs::FAabb2struct FAabb2;
  • acs::FAabb2::FAabb2constexpr FAabb2() noexcept = default;
  • acs::FAabb2::FAabb2constexpr FAabb2(FVec2 c, FVec2 hs) noexcept;
overload候補
center は複数の宣言に対応します。
  • acs::FAabb2::centerFVec2 center;
  • acs::FCircle::centerFVec2 center;
  • acs::FObb2::centerFVec2 center;
overload候補
half_size は複数の宣言に対応します。
  • acs::FAabb2::half_sizeFVec2 half_size;
  • acs::FObb2::half_sizeFVec2 half_size;

API項目 2

説明
左上+右下、または左上+サイズから作る。 2D の 1 枚絵(キャラ・アイコン等)。 矩形にテクスチャを貼って描く。系に便利。
