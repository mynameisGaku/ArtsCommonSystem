FAabb3 / FSphere / FPlane / FRay3

3D の衝突判定で使う形状。 軸並行の 3D ボックスコライダー。=軸並行ボックス、3D の球コライダー（中心+半径）。=球、3D の無限平面（法線+距離）。 地面や壁の近似に。=平面、3D のレイ（始点+方向）。 ピッキングや弾道に。=レイ。

構造体

対応するAPI候補

  • acs::FAabb3struct FAabb3;
  • acs::FSpherestruct FSphere;
  • acs::FPlanestruct FPlane;
  • acs::FRay3struct FRay3;

使う場面

3D ゲームの当たり判定。 キャラを球、地形を箱や平面で近似し、レイで射撃・ピッキングを行う。
