FVec ベクトル関数

2 次元ベクトル(x, y)。 2D の位置・速度・方向を表す基本型で、8 バイトと小さい。/3 次元ベクトル(x, y, z)。 3D の位置・方向・色などに使う最重要型で、SIMD演算に最適化されている。/4 次元ベクトル(x, y, z, w)。 RGBA 色や同次座標、行列との掛け算に使う。 に共通する演算関数。 2 ベクトルの「向きの近さ」を表す値（dot）。 同じ向きで最大、直角で 0。 角度や影の濃さの計算に使う。・2 つの 3D ベクトルの両方に直交するベクトルを作る演算（cross）。 面の法線や回転軸を求める。・長さ・正規化・2 値の間を一定割合 t(0〜1) で混ぜる（lerp）。 t=0 で始点、t=1 で終点。 滑らかな移動・色変化に。など。 型ごとにオーバーロードされている。
