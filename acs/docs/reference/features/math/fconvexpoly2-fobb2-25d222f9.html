FConvexPoly2 / FObb2

2D の凸多角形コライダー（最大 16 頂点）。 複雑な形のスプライトに。=へこみのない多角形。 どの 2 点を結んでも内部に収まる。 当たり判定が単純で高速。コライダー（最大 16 メッシュを構成する点。 位置・法線・UV などの属性を持つ。）。 回転できる 2D 矩形コライダー（OBB）。=回転できる矩形（有向境界ボックス（Oriented Bounding Box）。 回転を持てる矩形/直方体コライダー。、中心+半サイズ+回転角）。 複雑な形の2D の 1 枚絵(キャラ・アイコン等)。 矩形にテクスチャを貼って描く。当たり判定に。

構造体

対応するAPI候補

  • acs::FConvexPoly2struct FConvexPoly2;
  • acs::FObb2struct FObb2;

使う場面

回転する箱や、2D の 1 枚絵(キャラ・アイコン等)。 矩形にテクスチャを貼って描く。の与えた点をすべて包む、へこみのない最小の形(輪ゴムで囲んだような外形)。 当たり判定で扱いやすい。など、軸並行矩形では表せない形の当たり判定が要る時。 判定は内部で 分離軸判定（Separating Axis Theorem）。 凸形状同士の重なりを「どこかの軸で離れているか」で調べる手法。 に委譲される。

FConvexPoly2 tri;
tri.Add({0,0}); tri.Add({10,0}); tri.Add({5,10});
Obb2 box{ {x,y}, {16,8}, 0.5f };  // 中心,半サイズ,回転(rad)
if (Intersect(box, tri)) { /* 衝突 */ }
ConvexPoly2 p = ToPoly(box);      // OBB を多角形に
