ACS 機能 / math

スカラ数学関数

<cmath> をラップした単精度の数学関数群（Sqrt / Sin / Cos など）と、2 値の間を一定割合 t(0〜1) で混ぜる（lerp）。 t=0 で始点、t=1 で終点。 滑らかな移動・色変化に。・値を指定範囲内に収めること。 Saturate は 0〜1 に収める。・近似比較のヘルパ。

自由関数群

使う場面

三角関数や平方根、値の値を指定した下限と上限の内側へ収める処理です。、滑らかな2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。など、1 つの数値（スカラ）に対する計算全般。
