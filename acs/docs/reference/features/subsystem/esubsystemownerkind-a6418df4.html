ESubsystemOwnerKind

subsystemへ渡すownerの責務種別。

列挙
対応するAPI: acs::ESubsystemOwnerKind

使う場面

そのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。pointerをapplication、game、sceneの型へ安全に解釈する時。

API項目

API項目 1

Unknown
説明
旧ライブラリの機能を外から使うための窓口(関数や型の取り決め)。 例: ネットワークは WinSock をくるんだ薄い API として提供される。または責務を保証できないowner。
対応API
acs::ESubsystemOwnerKind::Unknown 列挙値

API項目 2

Application
説明
application寿命を所有する メインループを回すアプリの基底クラス。 継承して OnStart/OnUpdate/OnRender/OnShutdown を実装する。。
対応API
acs::ESubsystemOwnerKind::Application 列挙値

API項目 3

Game
説明
game session寿命を所有する ゲームアプリの基底クラス。 CApplication を継承し、シーン管理・固定タイムステップ・シーン遷移を内蔵する。。
対応API
acs::ESubsystemOwnerKind::Game 列挙値

API項目 4

Scene
説明
world寿命を所有する AScene。
対応API
acs::ESubsystemOwnerKind::Scene 列挙値
