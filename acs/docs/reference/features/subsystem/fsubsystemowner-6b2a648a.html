FSubsystemOwner

subsystemへ渡すそのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。owner pointerと責務種別。

構造体
対応するAPI: acs::FSubsystemOwner

使う場面

共通のsubsystem ライブラリの機能を外から使うための窓口(関数や型の取り決め)。 例: ネットワークは WinSock をくるんだ薄い API として提供される。からowner固有機能を取得する時。
