FAudioListener

聞き手 (プ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ーの耳) の位置と向き。 position / forward / up を持ち、音を左右どちらのスピーカーへ振るか。 -1=左 / 0=中央 / +1=右。の左右基準を決める。

構造体
対応するAPI: acs::game::FAudioListener

使う場面

視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。やキャラの耳位置に処理が終わるまでその場で待つやり方。 結果がすぐ手に入る代わりに止まる。させて CSpatialAudio::SetListener に渡す。

使用例

FAudioListener l;
l.position = cam.pos;
l.forward  = cam.forward;
l.up       = cam.up;
sp.SetListener(l);
