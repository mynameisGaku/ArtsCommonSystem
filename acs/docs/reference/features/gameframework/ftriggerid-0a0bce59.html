FTriggerId

重なりだけを検出する当たり判定。 物理の押し戻しはせず「触れたか」だけを通知する。 関連語は トリガワールド。を識別する 32bit の実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。(下位 24bit が index、上位 8bit が再利用される番号(ID)に付ける通し番号。 古いハンドルと新しい中身を取り違えないための目印。)。 削除→再登録でスロットが再利用されても、古い実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。は無効と判定できます。
