CDebugOverlay

FPS / タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。名 / カスタム watch をテキスト表示するためのオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。保持クラス。 実画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。は呼出側の責務で、本クラスは「何を出すか」と FPS の 60 ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。移動平均だけを保持する。 Headless でも動く。

クラス
対応するAPI: acs::game::CDebugOverlay

使う場面

画面に FPS や任意の数値 (Player.HP 等) をデバッグ表示したい時。

API項目

API項目 1

void Init()
説明
内部バッファを事前確保する (60 frame 履歴)。 再 Init は履歴クリア。
対応API
acs::game::CDebugOverlay::Init メンバー関数

API項目 2

void Tick(f32 dt)
説明
1 ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。進めて FPS の移動平均 / min / max を更新する。 dt<=0 は無視 (発散防止)。
使う場面
毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。呼ぶ。
対応API
acs::game::CDebugOverlay::Tick メンバー関数

API項目 3

f32 CurrentFps() const
説明

対応API
acs::game::CDebugOverlay::CurrentFps メンバー関数

API項目 6

void AddWatch(const char* label, const char* value)
説明
任意のラベル + 値文字列を表示項目に追加する。 同名は同じ登録を複数回行った時、最後に登録した内容が有効になること。上書き。 値バッファは caller が毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。更新する。
使う場面

使用例

CDebugOverlay ov;
ov.Init();
ov.SetSceneName(\"Gameplay\");
ov.AddWatch(\"Player.HP\", hpText);  // 値文字列は caller 所有
void OnUpdate(f32 dt) { ov.Tick(dt); }
// 描画: DrawString(8,8, ov.CurrentFps()...);
