ACS 機能 / gameframework

FInputAxisOptions

1D軸の合算値へデッドゾーン、非負倍率、反転を適用する12byteの値。 デッドゾーン外を連続する0..1へ再正規化してから倍率を掛ける。

構造体
対応するAPI: acs::game::FInputAxisOptions

使う場面

移動や視点キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。へ、物理ソケットを特定のアドレス/ポートに結び付けて、そこで送受信できるようにすること。とは独立した感度・反転設定を適用したい時。 Fキーボード・マウス・ゲームパッドの状態を問い合わせで読む静的クラス。 毎フレーム先頭で Update() を呼んでから状態を読む。Map::AxisValueへ値渡しする。

API項目

API項目 1

説明
絶対値がこの値以下なら0。 有効範囲は0以上1未満。

API項目 5

f32 Apply(f32 value) const noexcept
説明
有限キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。を制限して設定を適用。 不正設定または非有限キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。は0。
戻り値
