FWeaponState

現在装備中武器のランタイムオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。 ある時刻の世界全体の状態を 1 つに固めたもの。 server がこれを配信し、client は受信した複数 snapshot を補間して表示する (FPS/MMO 系で標準)。。 残弾・次発射可能時刻・reload 中ON/OFF を表す印。 ここでは暗号化/圧縮の有無。 / 残り時間を持ち、主に UI / デバッグ表示に使います。

構造体
対応するAPI: acs::game::FWeaponState

使う場面

HUD に残弾やリロードゲージを出す時。
