ESafetyRule

どの安全機能を有効化するかの bit flag。 キーボード・マウス・ゲームパッドの状態を問い合わせで読む静的クラス。 毎フレーム先頭で Update() を呼んでから状態を読む。Validation / JailbreakDetection / PiiRedaction / ContentRating / TokenBudget / RefusalEnforcement と、全 on の Default。

列挙(enum)
対応するAPI: acs::game::ESafetyRule

使う場面

Init や EnableRule で「Personally Identifiable Information (個人を特定できる情報)。 メール・電話・クレカ番号など。 安全フィルタで [REDACTED] 等に伏せる対象。 除去だけ外す」等、タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。別に機能を取捨選択する時。 OR / AND 演算子も定義済み。
