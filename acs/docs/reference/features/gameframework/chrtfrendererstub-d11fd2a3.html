CHrtfRendererStub

モノラルをステレオへ空間化する処理の抽象インターフェース。 の唯一の既定実装。 真の 頭部伝達関数。 耳の形状による音の変化を畳み込んで、ヘッドホンで方向感のある立体音響を作る技術。 畳み込みは無いが、等パワー音を左右どちらのスピーカーへ振るか。 -1=左 / 0=中央 / +1=右。 + 距離減衰は実数学で行う (= ステレオ空間化は本物)。
