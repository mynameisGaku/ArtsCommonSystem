CLapTimer

レースゲームのラップ計測 + 順位算出を一元管理するある種類の状態 (cooldown / チェックポイント / カード等) をまとめて持ち、登録・更新・問い合わせの API を提供する小さなクラス。。 チェックポイント順序検証・ベストラップ更新・フィニッシュ判定・リアルタイム順位ソートをまとめる。

クラス
対応するAPI: acs::game::CLapTimer

使う場面

レーシング系を作る時。 トラックの collider から通過通知を投げ、UI は順位/統計を読むだけで成立する。 ショートカットや逆走は順序検証で弾く。

使用例

lt.Init(/*total_laps=*/3, /*checkpoints_per_lap=*/4);
FRacerId p = lt.AddRacer("Player");
lt.Start();

lt.NotifyLapCompleted(p);
// 順位表示:
