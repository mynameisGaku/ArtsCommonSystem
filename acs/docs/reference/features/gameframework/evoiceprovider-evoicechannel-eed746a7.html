EVoiceProvider / EVoiceChannel

EVoiceProvider はボイスの実装ある機能 (ここではインスペクタ表示) に対してデータや実装を「供給する」側のオブジェクト。 インターフェースを実装して登録する。(None / Valve のゲーム配信プラットフォーム。 実績・フレンド・クラウドセーブ等の機能を Steamworks SDK 経由で使える。Voice / EosVoice / Vivox / Discord / OpusSelf)、EVoiceChannel はチャンネル種別(Party / Team / Global / Custom)を表す列挙です。

列挙(enum)

対応するAPI候補

  • acs::game::EVoiceProviderenum class EVoiceProvider : u8;
  • acs::game::EVoiceChannelenum class EVoiceChannel : u8;

使う場面

Init である機能 (ここではインスペクタ表示) に対してデータや実装を「供給する」側のオブジェクト。 インターフェースを実装して登録する。を選ぶ / JoinChannel でチャンネル種別を指定する時。
