FTransform2D

2D ゲーム世界に置く部品の単位。 位置やコンポーネントを持ち、親子のツリーで並ぶ。の位置 / 回転 / スケールを表す軽量な値型 (20 byte)。 4x4 行列。 平行移動・回転・拡大縮小、ビュー変換、投影変換を 1 つにまとめて表せる。 3D 描画の心臓部。 より小さく合成が速く、親 位置・回転・拡縮をまとめた座標変換。 親子で合成すると階層的な配置になる。 の回転 / スケールを取り出せる (分解可能)。
