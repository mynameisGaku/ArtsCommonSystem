CUiLayer

タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。に数個の UI 部品(ボタン / テキスト)を貼り付けるための薄い層。 Init / Tick / Handleキーボード・マウス・ゲームパッドの状態を問い合わせで読む静的クラス。 毎フレーム先頭で Update() を呼んでから状態を読む。 / Draw / Shutdown というタイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。のオブジェクトが生成→更新→破棄されるまでの一連の段階。 各段階にフック関数が対応する。に合わせて呼ぶだけで、タイトル画面や HUD の最小 UI が作れます。

クラス
対応するAPI: acs::game::CUiLayer

使う場面

本格的な UI ツリーを組むほどではないが、Play ボタンや簡単な HUD を手早く出したい時。

ui.Init();
u32 playBtn = ui.AddButton("Play", {100,200}, {200,48});
ui.AddText("ACS Demo", {100,100});

ui.Tick(dt);
if (ui.IsButtonPressed(playBtn)) { /* 開始 */ }
