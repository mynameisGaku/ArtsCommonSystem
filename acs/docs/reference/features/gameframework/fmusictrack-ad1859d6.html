FMusicTrack

適応 バックグラウンドミュージック。 場面の間ずっとループで流す音楽。 の 1 トラック登録情報。 ゲームで使う画像・音・モデル・データなどの素材ファイル。パス・intensity 範囲・ループ可否。

構造体
対応するAPI: acs::game::FMusicTrack

使う場面

RegisterTrack に渡す。 現在の intensity が range 内のとき候補になる。

API項目 1

const char* asset_path
説明
曲のパス (そのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。、リテラル前提)。
対応API

API項目 2

f32 intensity_min / intensity_max
説明
再生候補になる激しさ範囲 [0,1]。 [0,1] にすれば常時候補。

対応API
