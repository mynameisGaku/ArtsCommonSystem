CPrivacyDirector

EU の一般データ保護規則。 解析データ収集前にユーザー同意 (consent) を要する。 同意が無ければ送信しない。 / CCPA / COPPA 対応で必須となる「ユーザーの同意」を一元管理する director。 解析・広告・ゲーム内の出来事(クリア・購入・離脱など)を記録して集計する計測の仕組み。 改善のヒントを得るために使う。などカテゴリ別に同意の on/off を持ち、初回ダイアログ判定、ポリシー版の追跡、ローカル永続化を提供する。

クラス
対応するAPI: acs::game::CPrivacyDirector

使う場面

解析や広告 SDK を呼ぶ前に「ユーザーが同意したか」を確認する仕組みを作る時。 カテゴリ別の granular consent が法的に求められる場面で使う。

API項目

API項目 1

void Init(u32 current_policy_version = 1)
説明
有効なプライバシーポリシー版を設定。 保存済み版がこれより小さければ IsPolicyOutdated() が true になる。
対応API
acs::game::CPrivacyDirector::Init メンバー関数

API項目 2

void GrantConsent(EConsentCategory cat)
説明
指定カテゴリの同意 bit を立てる (複合可)。 RevokeConsent は落とす。
対応API
acs::game::CPrivacyDirector::GrantConsent メンバー関数
対応API
acs::game::EConsentCategory 列挙型

API項目 3

void GrantAll()
説明
Required を除く全カテゴリを ON (= "Accept All")。 RevokeAll() は全 OFF。
対応API
acs::game::CPrivacyDirector::GrantAll メンバー関数

API項目 4

bool HasConsent(EConsentCategory cat) const
説明
cat の全 bit が立っているか。 Required (=0) は常に true。
対応API
acs::game::CPrivacyDirector::HasConsent メンバー関数
対応API
acs::game::EConsentCategory 列挙型

API項目 5

bool RequiresInitialConsent() const
説明
まだ同意ダイアログを 1 度も提示していなければ true。 MarkInitialConsentShown() で false 化。
対応API
acs::game::CPrivacyDirector::RequiresInitialConsent メンバー関数

API項目 6

bool IsPolicyOutdated() const
説明
ロード済み policy_version が現在より古ければ true (再同意を促す)。
対応API
acs::game::CPrivacyDirector::IsPolicyOutdated メンバー関数

API項目 7

TResult<void> SaveConsent(const wchar_t* file_path)
説明
現在の同意オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。を .acssave バイナリで保存。 LoadConsent は復元 (ファイル無しは初回起動扱いで Ok)。
対応API
acs::game::CPrivacyDirector::SaveConsent メンバー関数

API項目 8

void Reset()
説明
初期化前のオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。に戻す (テスト / デバッグ用)。
対応API
acs::game::CPrivacyDirector::Reset メンバー関数

API項目 9

using FPrivacyDirector = CPrivacyDirector
説明
旧名を使う既存コード向けの互換別名。 新しいコードでは CPrivacyDirector を使う。
overload候補

使用例

CPrivacyDirector privacy;
privacy.Init(/*current_policy_version=*/2);
privacy.LoadConsent(L"user/consent.bin");
if (privacy.RequiresInitialConsent() || privacy.IsPolicyOutdated()) {
    privacy.GrantConsent(EConsentCategory::Analytics);
    privacy.MarkInitialConsentShown();
    privacy.SaveConsent(L"user/consent.bin");
}
if (privacy.HasConsent(EConsentCategory::Analytics)) SendEvent();
