CStreamingDirector

オープンワールド等で視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。周辺のチャンクだけをロードし、範囲外をアンロードする必要な範囲のアセットだけを動的にロード/アンロードして、メモリに収まらない大規模世界を扱う仕組み。管理係。 各チャンク = 1 1 まとまりのアセット集合をロード/アンロードする単位。 チャンクごとのアセットを束ねる。 を実ロードする (registry 未設定時は擬似ロードで動く)。

クラス
対応するAPI: acs::game::CStreamingDirector

使う場面

全ゲームで使う画像・音・モデル・データなどの素材ファイル。を常駐できない広いマップで、視点に応じて読み込み / 解放を自動化したい時。

API項目 6

void Tick(f32 dt)
説明
範囲評価とロード / アンロードのオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。遷移を 1 ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。進める。
使う場面
