EDialogueScriptState

スクリプト全体のオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。。 状態機械の「何もしていない/開始前」を表す既定状態。 Idle→Walk のように、ここから他状態へ遷移する。 (停止) / Playing (進行中) / Awaitingキーボード・マウス・ゲームパッドの状態を問い合わせで読む静的クラス。 毎フレーム先頭で Update() を呼んでから状態を読む。 (Say 後のキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。待ち) / AwaitingChoice (選択待ち) / Finished (終了)。

対応するAPI: acs::game::EDialogueScriptState

使う場面

ノベル/アドベンチャー向けのシーンスクリプト再生機。 セリフ・選択肢・ジャンプを命令列で宣言的に組むステートマシン。::State() の戻り値を見て UI を切り替える時。
