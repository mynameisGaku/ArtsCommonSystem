CPerfBudget

ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。時間 (ms) とプログラムが使う記憶領域。 確保と解放の管理が性能と安全性を左右する。確保量 (bytes) の予算超過を追跡する 描画や入力などの副作用を持たず、「今どういう状態か」だけを保持する型。 実際の描画・音・入力は呼び出し側が状態を見て行う。 テストしやすく結合が薄い。。 カテゴリ単位で予算を決め、毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。実測値を記録 → 集計し、各カテゴリ / ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。全体の超過を問い合わせられる。 実測 (計測) と UI 画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。は呼び出し側責務。

クラス
対応するAPI: acs::game::CPerfBudget

使う場面

「Render は 8ms 以内」「AI は 2ms 以内」のように予算を決めて、超えたら警告を出すパフォーマンス可視化を作りたい時。

API項目

API項目 1

void SetFrameBudget(f32 ms)
説明
目標ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。時間 (60fps→16.67)。 <= 0 でゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。超過判定を無効化。
対応API
acs::game::CPerfBudget::SetFrameBudget メンバー関数

void DefineCategory(const char* category, f32 budget_ms, u32 budget_bytes)
説明
カテゴリを新規定義 / 上書き。 同名があれば予算だけ差し替え、実測値は保持。 名前は呼び出し側所有 (リテラル想定)。

API項目 3

void RecordTimeMs(const char* category, f32 elapsed_ms)
説明
経過時間をカテゴリに加算 (累積)。 未定義 / nullptr / <= 0 は 何もしない処理。 呼んでも安全で副作用が無いこと。。

対応API

説明
プログラムが使う記憶領域。 確保と解放の管理が性能と安全性を左右する。確保量を加算。 RecordMemoryFree() は減算 (0 に clamp)。

API項目 5

void BeginFrame()
説明
全カテゴリの spent_ms を 0 リセット (spent_bytes は累積保持)。
対応API
acs::game::CPerfBudget::BeginFrame メンバー関数

API項目 6

void EndFrame()
説明
全カテゴリの spent_ms 合計を 60 frame 循環バッファに push し、ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。超過判定を更新。
対応API
acs::game::CPerfBudget::EndFrame メンバー関数

使用例

CPerfBudget budget;
budget.SetFrameBudget(16.67f);                  // 60fps
budget.DefineCategory("Render", 8.0f, 64u*1024u*1024u);
// 毎フレーム
budget.BeginFrame();
budget.RecordTimeMs("Render", render_ms);
budget.EndFrame();
if (budget.IsOverBudget("Render")) { /* 警告 */ }
