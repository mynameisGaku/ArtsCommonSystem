CBehaviorTree

AI / 敵挙動 / 演出分岐のための最小構成のAI の意思決定を木構造で表す手法。 葉ノードが具体的な行動や条件判定 (例: 知覚) になる。。 root ゲーム世界に置く部品の単位。 位置やコンポーネントを持ち、親子のツリーで並ぶ。を 1 つ持ち、毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。 Tick(blackboard, dt) で評価する。 オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。は型を持たない void* の ビヘイビアツリーのノード間で共有するデータ置き場。 ACS では型を持たない void* で渡す。に置く。

クラス
対応するAPI: acs::game::CBehaviorTree

使う場面

「敵が見えたら追跡、見えなければパトロール」のような条件分岐 AI を組みたい時。

root->AddChild(acs::Move(chase));
root->AddChild(acs::MakeUnique<ABtAction>(&Patrol));
m_Bt.SetRoot(acs::Move(root));
