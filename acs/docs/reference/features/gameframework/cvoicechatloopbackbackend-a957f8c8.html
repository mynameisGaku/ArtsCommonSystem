CVoiceChatLoopbackBackend

外部 SDK なしで実際に音声ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。を往復させるマイク音声を圧縮して送受信する仕組み(Steam VOIP)。実装。 同一プロセス内で push→データを送受信 / 保存用の形式(ここではフレーム化したバイト列)に変換すること。 逆はデコード。→他参加者キュー→エンコードされたデータを元の形(ここでは int16 PCM)に戻すこと。→音量 / ミュート→N-way ミックス→pump を成立させます。 ネットを使わず同じ入力なら必ず同じ結果になる性質。 乱数や時刻に依存せず、テストや再現がしやすい。なのでユニットテスト可能。

クラス
対応するAPI: acs::game::CVoiceChatLoopbackBackend

使う場面

ボイスのミュート / 音量 / ミックスのロジックを SDK なしで検証したい / ローカルML ランタイムが推論を実行するための作業単位(モデル・実行環境を束ねたもの)。を組みたい時。
