CGame

ゲームアプリの基底クラス。 メインループを回すアプリの基底クラス。 継承して OnStart/OnUpdate/OnRender/OnShutdown を実装する。 を継承し、CSceneManager を駆動する。 利用者は派生クラスで InitialScene() を override して最初のタイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。を返すだけでよい。 固定タイムステップ・time scale・タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。跨ぎの永続オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。 (シーンを跨いで残しておきたい永続状態 (所持金・セーブデータ等) を型消去で 1 個保持する仕組み。)・フェード付きタイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。遷移を内蔵する。

クラス
対応するAPI: acs::game::CGame

使う場面

ゲームの土台を作る時。 ACS_GAME_MAIN コンパイル前に決まった形へ展開される短い記述(#define)。 定型コードを一行で書ける。と組み合わせて起動する。
