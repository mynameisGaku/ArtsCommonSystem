CAnimationCurveArchive

キーを打って『時間 → 値』を補間する編集可能なカーブ。 checked 更新・評価、Clamp/Loop/PingPong、33 種の easing preset に対応する。 を固定幅 little-endian wire record として保存・復元する bounded codec。 CRC、version、exact size、全 key と wrap mode を検証し、失敗時は出力 buffer と復元先曲線を変更しない。

クラス
対応するAPI: acs::game::CAnimationCurveArchive

使う場面

曲線をエディタデータや save file に永続化し、破損・旧 version・過大キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。を明示的に診断したい時。
