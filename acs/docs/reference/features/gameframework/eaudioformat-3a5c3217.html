EAudioFormat

FAudioClipDesc が指す 音声を一定間隔で数値化した生波形データ。 圧縮なしでそのまま再生できる形式。 バッファの形式。 Pcm16(16bit signed 音声を一定間隔で数値化した生波形データ。 圧縮なしでそのまま再生できる形式。) / Pcm32Float(32bit IEEE float) / Wav(RIFF ヘッダ込み)。

列挙(enum)
対応するAPI: acs::game::EAudioFormat

使う場面

再生する clip のサンプル形式を指定する時。

基本情報

モジュール
gameframework
分類
列挙(enum)

API項目

API項目 1

Pcm16 = 0
説明
16bit signed 音声を一定間隔で数値化した生波形データ。 圧縮なしでそのまま再生できる形式。 (典型的な WAV 音声を一定間隔で数値化した生波形データ。 圧縮なしでそのまま再生できる形式。 の raw bytes)。
対応API
acs::game::EAudioFormat::Pcm16 列挙値

API項目 2

Pcm32Float = 1
説明
32bit IEEE float 音声を一定間隔で数値化した生波形データ。 圧縮なしでそのまま再生できる形式。 (高品質・DSP-friendly)。
対応API
acs::game::EAudioFormat::Pcm32Float 列挙値

API項目 3

Wav = 2
説明
ファイルからロード済みの WAV 形式。 解析処理は呼び出し側が用意する。
対応API
acs::game::EAudioFormat::Wav 列挙値

使用例

FAudioClipDesc d; d.format = EAudioFormat::Pcm16;
