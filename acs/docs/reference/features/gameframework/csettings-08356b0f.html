ACS 機能 / gameframework

CSettings

音量・解像度・キー設定など「ゲームをまたいで残したい設定値」を型付き key-valueで持つ小さなストア。 INI 風テキストで Save/Load できる。

クラス
対応するAPI: acs::game::CSettings

使う場面

オプション画面の値を保存/復元したい時。 audio.master のようなドット区切りのキーで管理する。
