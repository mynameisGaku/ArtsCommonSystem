CTutorialFlow

連続するチュートリアルステップを順番に表示・進行させる小さな限られた状態と、その間の遷移ルールで動きを表す仕組み。 ステートマシンとも。。 画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。はせず、現在ステップへのメモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。を公開するだけなので、見た目は UI 側が自由に描けます。

クラス
対応するAPI: acs::game::CTutorialFlow

使う場面

「WASD で移動」「SPACE でジャンプ」のように、ユーザーが操作を達成したら次へ進むガイドを作る時。

API項目 2

void Start()
説明
ステップ 0 から表示開始する。 ステップが無ければ即完了。
対応API
acs::game::CTutorialFlow::Start メンバー関数

API項目 3

void AdvanceStep()
説明
次のステップへ手動で進める。 最終ステップで呼ぶと完了になる。
使う場面
OK ボタンや条件達成後に明示的に進めたい時。
対応API
acs::game::CTutorialFlow::AdvanceStep メンバー関数

API項目 4

void NotifyAction(const char* action_id)
説明
ユーザー操作を通知する。 現在ステップの id と一致しrequire_user_actionなら自動で次へ進む。
対応API
acs::game::CTutorialFlow::NotifyAction メンバー関数

API項目 5

void Reset()
説明
ステップ定義は残したまま進行オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。だけ初期化する。
対応API
acs::game::CTutorialFlow::Reset メンバー関数

API項目 6

void Skip()
説明
チュートリアル全体を飛ばして完了扱いにする(同じ操作を何度行っても結果が変わらない性質。 削除済みを再削除しても成功扱い、など。)。
対応API
acs::game::CTutorialFlow::Skip メンバー関数

使用例

CTutorialFlow tut;
tut.AddStep({"move", "WASD で移動してみよう", "player", true});
tut.AddStep({"jump", "SPACE でジャンプ",     "player", true});
tut.Start();
// 毎フレーム:
tut.Tick(dt);
if (input.JustPressed(EKey::W)) tut.NotifyAction("move");
