IBackendClient

サーバ側 (ゲーム内の出来事(クリア・購入・離脱など)を記録して集計する計測の仕組み。 改善のヒントを得るために使う。送信・設定取得など) への汎用抽象的な機能呼び出しを、実際のライブラリや OS API につなぐ実装側のこと。 差し替え可能。窓口のプラットフォーム固有 SDK との結合点を抽象化した純粋仮想インターフェース。 ゲーム側はこれ越しに呼び、実装をビルド時に差し替える。。 具体的な通信関数の呼び出しに沿って自動で確保/解放される高速なメモリ。 寿命はスコープに縛られる。 (HTTP/gRPC/Valve のゲーム配信プラットフォーム。 実績・フレンド・クラウドセーブ等の機能を Steamworks SDK 経由で使える。) は抱えず interface だけ提供し、実装はプロジェクト側で差し込む。 失敗は 成功なら値、失敗なら理由を入れて返す型 Result<T,E>。 例外の代わり。 で返す。

API項目 4

TResult<void> SendTelemetry(const char* event_name, const char* json_payload)
説明
ゲーム内の出来事(クリア・購入・離脱など)を記録して集計する計測の仕組み。 改善のヒントを得るために使う。『× ボタンが押された』『キーが押された』のような、その瞬間に起きた出来事の通知。 ACS では FEvent として届く。を送信する (内部キュー + 処理の完了を待たずに先へ進み、結果は後で受け取るやり方。 重い読み込みなどで画面を止めない。 flush は実装次第)。
対応API

API項目 5

void Tick(f32 dt)
説明
処理の完了を待たずに先へ進み、結果は後で受け取るやり方。 重い読み込みなどで画面を止めない。 RPC の応答をメイン1 つのプログラム内で同時に進む実行の流れ。 複数あると処理を並列にできる。に引き上げる pump。 毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。呼ぶ。
対応API
acs::game::IBackendClient::Tick メンバー関数

使用例

IBackendClient& be = GetDefaultBackendClient();
if (be.Connect("game-backend").IsOk()) {
    be.SendTelemetry("level_completed", "{\"level\":3}");
}
// 毎フレーム:
be.Tick(dt);
