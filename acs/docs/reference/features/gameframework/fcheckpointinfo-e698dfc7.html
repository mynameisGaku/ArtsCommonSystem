FCheckpointInfo

1 つの checkpoint の定義。 id・復活座標・level_index・sort_order・one_way (戻れなくする) ・requires_unlock (隠し) を持つ。

構造体
対応するAPI: acs::game::FCheckpointInfo

使う場面

Register() に渡す時。

基本情報

モジュール
gameframework
分類
構造体

gameframework/CheckpointSystem.h

使用例

FCheckpointInfo cp{};
cp.id = \"cp.boss\";
cp.spawn_pos = {500, 200};
cp.sort_order = 1;
cp.one_way = true;        // ここまで来たら戻れない
cp.requires_unlock = false;
