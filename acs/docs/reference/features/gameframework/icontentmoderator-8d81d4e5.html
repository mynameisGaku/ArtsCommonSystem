IContentModerator

User Generated Content。 ユーザーが作った MOD / ステージ等のコンテンツ。 Workshop 等で配布される。 (ユーザー生成コンテンツ = チャット文 / 画像 / ユーザー名) を「公開可 / 警告付き / ブデータを守るための『鍵』。 取った人だけが対象を触れ、他は解放されるまで待つ。」の 3 値で判定する差し替え可能な境界面。 実装(backend)を後から入れ替えられるよう、インターフェースだけを切り出した接合点。。

インターフェース
対応するAPI: acs::game::IContentModerator

使う場面

オンライン要素でユーザーがキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。したテキストや画像を公開前にチェックしたい時。
