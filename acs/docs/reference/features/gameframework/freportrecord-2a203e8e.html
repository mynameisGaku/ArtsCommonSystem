FReportRecord

通報 1 件分の情報。 通報対象 / 通報者 / 種別 / 自由記述 / 時刻を持つ。 文字列はすべてそのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。 (寿命は呼び出し側保証)。

構造体
対応するAPI: acs::game::FReportRecord

使う場面

CSocialModeration::SubmitReport に渡す前に組み立てる。
