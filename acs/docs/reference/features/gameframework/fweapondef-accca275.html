FWeaponDef

武器 1 種類の不変定義。 id / 表示名 / 種別と、1 秒あたりの発射回数。 連射間隔 = 1.0 / fire rate で決まる。・リロード時間・マガジン容量・予備上限・ダメージ・拡散・ペレット数・弾種を持ちます。

構造体
対応するAPI: acs::game::FWeaponDef

使う場面

RegisterWeapon に渡す武器スペックを定義する時。

基本情報

モジュール
gameframework
分類
構造体
ヘッダー
gameframework/WeaponSystem.h

API項目

API項目 1

const char* id / const char* display_name
説明
武器キー(Register / Equip のキー) / UI 表示名(そのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。)。
対応API
acs::game::FWeaponDef::id メンバー変数
対応API
acs::game::FWeaponDef::display_name メンバー変数

API項目 2

EWeaponKind kind
説明
武器ジャンル(メタ情報、機械挙動には不使用)。
対応API
acs::game::EWeaponKind 列挙型
対応API
acs::game::FWeaponDef::kind メンバー変数

API項目 3

f32 fire_rate_per_sec / f32 reload_sec
説明
1 秒あたりの発射回数 / リロード秒数。 どちらも<=0 は本命が使えない時の代替経路。 XR では HMD 未接続時に通常の 2D 画面描画へ切り替えること。(1 発/秒 / 即時)。
対応API
acs::game::FWeaponDef::fire_rate_per_sec メンバー変数
対応API
acs::game::FWeaponDef::reload_sec メンバー変数

API項目 4

u32 mag_size / u32 max_reserve
説明
マガジン容量(0 はマガジン非搭載) / 予備上限(0 は無制限)。
対応API
acs::game::FWeaponDef::mag_size メンバー変数
対応API
acs::game::FWeaponDef::max_reserve メンバー変数

API項目 5

f32 base_damage / f32 spread_deg / u32 pellets_per_shot
説明
1 ペレットの基本ダメージ / 拡散角(片側 deg) / 1 発のペレット数(0 は 1)。
対応API
acs::game::FWeaponDef::base_damage メンバー変数
対応API
acs::game::FWeaponDef::spread_deg メンバー変数
対応API
acs::game::FWeaponDef::pellets_per_shot メンバー変数

API項目 6

const char* projectile_id
説明
発射する弾種 id(そのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。、FireCallback へ伝達)。
対応API
acs::game::FWeaponDef::projectile_id メンバー変数

使用例

FWeaponDef shotgun{ "shotgun", "Pump", EWeaponKind::Shotgun,
    1.0f, 2.6f, 6, 24, 12.0f, 6.0f, 8, "proj.pellet" };
