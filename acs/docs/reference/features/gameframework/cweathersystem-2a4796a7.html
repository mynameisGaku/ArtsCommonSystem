CWeatherSystem

天候のオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。を保持し、現在天候→目標天候へ線形遷移しながら、画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。 / ライティング用の修飾係数(環境光倍率 / 粒子密度 / 空の色補正 / 風 / 霧密度)を提供する部品。 実際に画面へ絵を出す描画システム本体。や粒子は毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。これらを pull するだけで天候表現が反映されます。

クラス
対応するAPI: acs::game::CWeatherSystem

使う場面

晴れ / 雨 / 雪 / 嵐などをなめらかに切り替え、見た目と粒子・風を連動させたい時。
