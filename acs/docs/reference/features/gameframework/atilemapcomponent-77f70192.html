ATilemapComponent

2D グリッドにタイル ID を並べるデータ専用のマップ。 のデータを AScene 上に画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。するANode に付ける部品。 1 つの機能 (物理・描画・当たり判定など) を担い、組み合わせて挙動を作る。。 格子多数の小画像(グリフやタイル)を 1 枚にまとめたテクスチャ。 UV で各部分を取り出す。テクスチャを持ち、非空タイルを対応セルの UV で 多数のスプライトをまとめて効率よく描画する仕組み。 に描く。 当たり判定の生成もできる。

クラス
対応するAPI: acs::game::ATilemapComponent

使う場面

タイルマップを実際に画面表示し、必要なら壁として物理ワールドに登録したい時。

使用例

auto& tm = node->AddComponent<ATilemapComponent>();
tm.Map().Init(16, 12, 1, 1.0f);
tm.Map().FillRect(0, 0, 15, 0, FTileId{1});
tm.SetTexture(atlas_tex);
tm.SetAtlasGrid(4, 4);
tm.BuildCollision(world, 0, kWall);
