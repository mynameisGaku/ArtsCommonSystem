CPerception

NPC が複数の target を「視覚」「聴覚」で検知できるか判定するモジュール。 視覚は距離 + 視野角、聴覚は距離のみ (壁ごしも聞こえる)。 AI の意思決定を木構造で表す手法。 葉ノードが具体的な行動や条件判定 (例: 知覚) になる。の葉や blackboard の値ソースとして使う想定。

クラス
対応するAPI: acs::game::CPerception

使う場面

敵 AI に「プ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ーが見えたら追う」「物音がしたら警戒する」といった知覚を持たせたい時。

API項目

API項目 1

void SetConfig(const FSenseConfig& cfg)
説明
感覚パラメータを差し替える。 cos(fov/2) もここで 1 回だけ計算してキャッシュ。
対応API
acs::game::CPerception::SetConfig メンバー関数
対応API
acs::game::FSenseConfig 構造体

API項目 2

void SetEyePos(FVec2 pos, FVec2 forward)
説明
目の位置と前方向 (正規化済み前提) を更新。 forward が長さ 0 なら (1,0) に本命が使えない時の代替経路。 XR では HMD 未接続時に通常の 2D 画面描画へ切り替えること。。
対応API
acs::game::CPerception::SetEyePos メンバー関数
対応API
acs::game::FPerceptionTarget::pos メンバー変数

API項目 3

void AddTarget(u32 id, FVec2 pos)
説明
知覚対象を追加。 同 id が既にあれば位置更新だけ (重複防止)。
対応API
acs::game::CPerception::AddTarget メンバー関数
対応API
acs::game::FPerceptionTarget::id メンバー変数
対応API
acs::game::FPerceptionTarget::pos メンバー変数

API項目 4

void RemoveTarget(u32 id)
説明
指定 id の target を削除。 順序は保持されない (高速削除)。
対応API
acs::game::CPerception::RemoveTarget メンバー関数
対応API
acs::game::FPerceptionTarget::id メンバー変数

API項目 5

void UpdateTarget(u32 id, FVec2 pos)
説明
target の位置を更新。 存在しなければ 何もしない処理。 呼んでも安全で副作用が無いこと。 (Add はしない)。
対応API
acs::game::CPerception::UpdateTarget メンバー関数
対応API
acs::game::FPerceptionTarget::id メンバー変数
対応API
acs::game::FPerceptionTarget::pos メンバー変数

API項目 6

bool IsTargetVisible(u32 id) const
説明
前回 Tick 時点で視認できていたか。 IsTargetAudible() は聴取版。
対応API
acs::game::CPerception::IsTargetVisible メンバー関数
対応API
acs::game::FPerceptionTarget::id メンバー変数

API項目 7

void Tick(f32 dt)
説明
全 target の is_visible / is_audible を現在の eye / forward / config で再計算する。
対応API
acs::game::CPerception::Tick メンバー関数

API項目 8

const FPerceptionTarget* AllTargets(u32& out_count) const
説明
全 target を読み取り用に列挙。 out_count に件数。 次の Add/Remove/Update で無効化される。
戻り値
target 配列
対応API
acs::game::FPerceptionTarget 構造体
対応API
acs::game::CPerception::AllTargets メンバー関数

使用例

CPerception perc;
FSenseConfig cfg;
cfg.sight_range   = 10.0f;
cfg.sight_fov_rad = acs::kPi * 0.5f;   // 90 度
cfg.hearing_range = 5.0f;
perc.SetConfig(cfg);
perc.AddTarget(1, FVec2{3.0f, 0.0f});
perc.SetEyePos(FVec2{0,0}, FVec2{1,0});   // +X 向き
perc.Tick(0.016f);
if (perc.IsTargetVisible(1)) { /* 視認 */ }
