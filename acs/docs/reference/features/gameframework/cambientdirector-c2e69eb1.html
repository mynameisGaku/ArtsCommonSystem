CAmbientDirector

1 日の時刻 (0〜24h) に応じて空の色・環境光・太陽方向を2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。する時刻ドライバ (time-of-day)。 実際に画面へ絵を出す描画システム本体。は 3 つの色/向きと大きさを持つ量。 2D/3D の位置・速度・方向を FVec2/FVec3 で表す。を毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。 pull するだけで朝昼夕夜の表情が出る。

クラス
対応するAPI: acs::game::CAmbientDirector

使う場面

屋外タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。で時間経過の昼夜サイクルを出したい時。

API項目 6

void Tick(f32 dt)
説明
リアル秒 dt をタイムスケール換算してゲーム時間を進める。 毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。呼ぶ。

使用例

CAmbientDirector amb;
amb.SetTimeOfDay(6.5f);      // 朝焼け開始
amb.SetTimeScale(0.1f);      // リアル 1s = 0.1 game-hour
// 毎フレーム:
amb.Tick(dt);
renderer.SetSkyColor(amb.SkyColor());
renderer.SetSunDir (amb.SunDirection());
