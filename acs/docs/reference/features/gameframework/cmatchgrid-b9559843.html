CMatchGrid

FMatchGrid が扱う、同じ種類の要素を縦または横に3個以上並べて消去するパズル規則。パズルの2Dグリッドを管理します。 隣接 swap、3個以上の連続検出、消去、special 効果、重力落下、補充、連鎖を処理します。 隣接 swap → 3 個以上の連続検出 → 消去 (special 効果) → 重力落下 → 補充 → 連鎖、までを内包する。

クラス
対応するAPI: acs::game::CMatchGrid

使う場面

マッチ 3 パズルを作る時。 盤面のオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。とロジックだけを持ち、VFX/SFX/スコアは消去あとで呼んでもらうために登録しておく関数。 ACS では関数ポインタ + void* ユーザーデータの形を取る(STL 不依存方針)。で外に出す。

使用例

CMatchGrid g;
g.Init(8, 8, /*color_count=*/5);
g.FillRandom(0xC0FFEEull); // 初期マッチが残らない決定論埋め
g.SetOnClearCallback(&MyClearFx, &fx);
if (g.TrySwap(3, 4, 4, 4)) {        // 成立すれば自動 resolve
    u32 chains  = g.ChainLevel();
    u32 cleared = g.TotalClearedThisChain();
    g.ResetChain();
}
