FAccessibilityProfile

色覚補正・モーション低減・字幕・片手操作などのアクセシビリティ設定を保持する箱。 値を持つだけで、実際の適用 (LUT 差し替え / 字幕表示など) は実際に画面へ絵を出す描画システム本体。や UI 側が Get() で読んで行う。

クラス
対応するAPI: acs::game::FAccessibilityProfile

使う場面

近代タイトル並みの配慮機能を 1 箇所で管理したい時。 ゲームアプリの基底クラス。 CApplication を継承し、シーン管理・固定タイムステップ・シーン遷移を内蔵する。 に 1 個だけ持たせる想定 (非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。・非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。)。

使用例

FAccessibilityProfile prof;
prof.ApplyPreset(EPreset::Dyslexia);     // 識字困難向け一括設定
prof.SetScreenShakeScale(0.5f);          // 画面振動を半分に
if (prof.AreSubtitlesEnabled()) ShowSubtitles();
