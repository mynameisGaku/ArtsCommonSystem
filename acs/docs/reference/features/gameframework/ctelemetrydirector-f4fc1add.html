CTelemetryDirector

「level_completed」「player_died」などの解析『× ボタンが押された』『キーが押された』のような、その瞬間に起きた出来事の通知。 ACS では FEvent として届く。を集めてサーバへまとめ送りする director。 一定間隔または明示 Flush() で gameframework が定める『サーバ側との窓口』インターフェース。 テレメトリ送信などを抽象化し、実装を差し替えられる。 経由送信。 EU の一般データ保護規則。 解析データ収集前にユーザー同意 (consent) を要する。 同意が無ければ送信しない。 同意が無ければ全 何もしない処理。 呼んでも安全で副作用が無いこと。。

クラス
対応するAPI: acs::game::CTelemetryDirector

使う場面

ゲームのプレイ状況を解析したい時。 インターフェースの裏で実際に仕事をする具象実装。 ここでは OpenXR ローダ等の XR 実装本体。 未接続でもオフラインで貯めておける。
