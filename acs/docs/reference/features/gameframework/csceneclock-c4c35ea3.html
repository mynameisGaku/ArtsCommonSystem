CSceneClock

タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。単位の時間トラッカ。 実時間とは別に、pause / slow-mo / 倍速を反映した「タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。が感じる論理時間」を刻む。 時間の流れる倍率。 1=通常、0=停止、>1=早送り、<1=スロー。 CSceneClock がこれを掛けて scaled な時間を作る。 を変えるだけでスローモーや早送りが作れる。

クラス
対応するAPI: acs::game::CSceneClock

使う場面

位置と向きをまとめた姿勢情報。 XR では頭や手の ポーズ を追跡する。可能なゲームや、スローモー演出・スピードラン倍速モードで、値を時間で滑らかに補間する仕組み。 UI・カメラ・演出・シーン遷移に使う。 や時間を計る仕組み。 ACS では CClock（経過時間）と FFrameTimer（フレーム間 dt）。ーに渡す時間を一元管理したい時。
