CScriptHost

スクリプト呼び出しの単一窓口。 スクリプト VM の純粋仮想インターフェース。 Lua/Wren/Python 等を差し替えるための seam。 CLuaVm がこれを実装する。 を 1 個保持し、ファイル読み込み・グローバル関数呼び出し・スクリプトから呼べるよう登録した C++ 側の関数。登録をまとめる。 Mod や UI ロジックの動的拡張に使う。

クラス
対応するAPI: acs::game::CScriptHost

使う場面

ゲーム組み込みで広く使われる軽量スクリプト言語。 C++ を再ビルドせずにロジックを差し替えられる。 などのスクリプトでゲームを拡張したい時。 Virtual Machine。 スクリプトを読み込んで実行する仮想機械。 CLuaVm は Lua の VM。 本体は別モジュールが提供し、ここはその窓口。
