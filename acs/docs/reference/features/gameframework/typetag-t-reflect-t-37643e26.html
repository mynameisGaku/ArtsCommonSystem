TypeTag<T>() / Reflect<T>()

TypeTag<T>() は Run-Time Type Information。 C++ 標準の実行時型情報。 ACS では使わず、軽量な型 ID / リフレクションで代替する。 を使わず型 T の一意な ID(static 変数のアドレス)を返します。 Reflect<T>() は TTypeInfo<T>::Get() の短縮形です。
