API項目

API項目 1

void InitGrid(u32 cols, u32 rows, u32 frame_count, f32 fps, EPlayMode mode = EPlayMode::Loop)
説明
テクスチャを格子に等分し、先頭から frame_count 枚を順に再生する。
使う場面
1 枚を等間隔セルに割ったよくあるシートの時。
対応API
