CBuffSystem

オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。異常・バフ・デバフの管理ある種類の状態 (cooldown / チェックポイント / カード等) をまとめて持ち、登録・更新・問い合わせの API を提供する小さなクラス。。 複数の owner (キャラ) に時間制限付きの効果を載せ、毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。進行させて tick (毒ダメージ等) / 期限切れを通知する。 実際のステータス計算は呼出側が AllBuffsOfOwner() で列挙して行う。

クラス
対応するAPI: acs::game::CBuffSystem

使う場面

RPG/アクション/ローグライクで「攻撃力アップ」「毒」「シールド」などの効果を一元管理したい時。

API項目 2

説明
効果を載せる対象 (キャラ) を発行する。 空き slot を再利用するオブジェクトを直接ポインタで指す代わりに「配列の index + 世代カウンタ」で指す仕組み。 slot が再利用されても世代が食い違うので、破棄済みの古いハンドルを安全に検出できる。。
戻り値
owner 実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。

API項目 7

const FBuffInstance* AllBuffsOfOwner(FBuffOwnerId owner, u32& out_count) const
説明
owner の全バフを生バッファで返す。 毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。列挙して効果倍率を計算する用途。

API項目 9

void Tick(f32 dt)
説明
全 owner の全バフを dt 進める。 周期 tick 発火 + 期限切れ除去をまとめて行う。 dt<=0 は 何もしない処理。 呼んでも安全で副作用が無いこと。。

// 毎フレーム:
