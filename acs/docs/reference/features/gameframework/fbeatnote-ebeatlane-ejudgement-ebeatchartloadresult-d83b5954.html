FBeatNote / EBeatLane / EJudgement / EBeatChartLoadResult

FBeatNote=譜面の 1 note (絶対秒 time_sec / lane / is_hold / hold_duration_sec)。 EBeatLane=キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。レーン (Left/Down/Up/Right + Custom1/2)。 EJudgement=判定結果。 EBeatChartLoad成功なら値、失敗なら理由を入れて返す型 Result<T,E>。 例外の代わり。=null、上限超過、非有限値、不正 lane/BPM/hold、OOM を区別する checked load 結果。

リズムゲームの checked 譜面読み込みと timing 判定。 通常 note に加え、PressLane/ReleaseLane で hold の head/tail を 1 回だけ集計する。 に譜面を渡したり、判定結果を受け取ったりする時。
