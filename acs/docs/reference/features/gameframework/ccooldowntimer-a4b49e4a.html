CCooldownTimer

複数のクールダウン (スキル / アビリティ / リロード等) を同時追跡する軽量ある種類の状態 (cooldown / チェックポイント / カード等) をまとめて持ち、登録・更新・問い合わせの API を提供する小さなクラス。。 各 cooldown は label と長さを持ち、Tick で残り時間を減らし、0 で使用可 (charged) になる。 TryUse は charged の時だけ true を返して即リロード開始。

クラス
対応するAPI: acs::game::CCooldownTimer

使う場面

「このスキルは 3 秒に 1 回しか撃てない」のような再使用待ち時間を管理する時。

使用例

CCooldownTimer cd;
FCooldownId fireball = cd.Register(\"fireball\", 3.0f);
cd.ForceReady(fireball);  // 初手は即撃てる
void OnUpdate(f32 dt) {
    cd.Tick(dt);
    if (pressed && cd.TryUse(fireball)) SpawnFireball();
}
