FProjectileDef

弾種ごとの挙動パラメータ。 RegisterDef で『弾の設計図』として登録しておき、Spawn 時に名前で参照する。

構造体
対応するAPI: acs::game::FProjectileDef

使う場面

新しい弾の種類 (速い弾・重力で落ちる手榴弾・貫通弾・追尾弾など) を定義する時。

基本情報

モジュール
gameframework
分類
構造体
ヘッダー
gameframework/ProjectileSystem.h

API項目

API項目 1

const char* id
説明
弾種の名前 (Spawn のキー)。 文字列リテラル推奨。
対応API
acs::game::FProjectileDef::id メンバー変数

API項目 2

EProjectileKind kind
説明
VFX/SE 振り分け用のヒント。 挙動には影響しない。
対応API
acs::game::EProjectileKind 列挙型
対応API
acs::game::FProjectileDef::kind メンバー変数

API項目 3

f32 speed / f32 lifetime_sec / f32 radius
説明
初速の目安・最大寿命(秒)・当たり判定半径。
対応API
acs::game::FProjectileDef::speed メンバー変数
対応API
acs::game::FProjectileDef::lifetime_sec メンバー変数
対応API
acs::game::FProjectileDef::radius メンバー変数

API項目 4

f32 gravity_y
説明
重力 (正で下向き)。 0 で直進、手榴弾や矢は >0。
対応API
acs::game::FProjectileDef::gravity_y メンバー変数

API項目 5

bool pierces / u32 max_pierces
説明
貫通するか、何体まで貫通するか。 max_pierces=2 なら 3 体目で消滅。
対応API
acs::game::FProjectileDef::pierces メンバー変数
対応API
acs::game::FProjectileDef::max_pierces メンバー変数

API項目 6

bool homing / f32 homing_strength
説明
追尾するか、その強さ [0,1]。
対応API
acs::game::FProjectileDef::homing メンバー変数
対応API
acs::game::FProjectileDef::homing_strength メンバー変数

使用例

FProjectileDef d{};
d.id = "arrow";
d.speed = 600.0f;
d.lifetime_sec = 2.0f;
d.gravity_y = 300.0f;      // 弧を描いて落ちる
d.pierces = true; d.max_pierces = 2;  // 3 体目で消える
