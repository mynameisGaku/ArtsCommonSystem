CAssetBundle

タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。が使う複数ゲームで使う画像・音・モデル・データなどの素材ファイル。をまとめて宣言・一括ロードし、集約した進捗を見られる箱。 個別の Future を散らかさず 1 つの bundle で扱える。 タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。破棄で参照が drop し、同じ入力なら必ず同じ結果になる性質。 乱数や時刻に依存せず、テストや再現がしやすい。に解放される。

クラス
対応するAPI: acs::game::CAssetBundle

使う場面

ローディング画面付きで「このタイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。に必要な N 個のゲームで使う画像・音・モデル・データなどの素材ファイル。」をまとめて読み込みたい時。

使用例

CAssetBundle bundle;
bundle.Add("textures/hero.png");
bundle.Add("audio/bgm.ogg");
bundle.BeginLoad(registry);
// 毎フレーム:
if (!bundle.IsLoaded()) ShowLoading(bundle.Progress());
else RunGame();
// 終了時:
bundle.Unload();
