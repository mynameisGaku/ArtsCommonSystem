CNodePool

タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。内の 2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。 を登録して、安定した シーン内の ANode を指す index(24bit) + generation(8bit) の packed ハンドル。 stale 検出に使う。 を発行する読み込んだアセットをキー(FAssetId)で保持・共有し、再利用する管理表。 ACS では CAssetRegistry。。 2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。 本体は親が TObjectPtr<2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。> で所有し続け、この pool は参照だけを持つ (そのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。)。 発行済み ID の「古くなって無効になった」状態。 例えば破棄された ANode を指したままのハンドルが stale。 世代付きハンドルでは世代不一致で検出する。検出も担う。

使用例

CNodePool pool;
pool.Init(512);
FNodeId id = pool.RegisterExistingNode(enemy_ptr);
// 後で stale 検査付きで取り出し
if (ANode* p = pool.Get(id)) {
    p->SetPosition2D(p->Position2D() + FVec2{1, 0});
}
pool.Unregister(id);   // slot 解放 + gen++ で古い ID は無効化
