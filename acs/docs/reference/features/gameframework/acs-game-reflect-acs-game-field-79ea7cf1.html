ACS_GAME_REFLECT / ACS_GAME_FIELD

型を型が自身の構造(フィールド名 / 型 / オフセット)を自己記述する仕組み。 シリアライザやインスペクタの土台になる。対象として登録するコンパイル前に決まった形へ展開される短い記述(#define)。 定型コードを一行で書ける。。 ACS_GAME_FIELD で 1 フィールドを記述し、ACS_GAME_REFLECT でそれらをまとめて型に紐付けます。 グローバル空間で書きます。

マクロ

対応するAPI候補

  • ACS_GAME_REFLECT#define ACS_GAME_REFLECT(T, ...) \ namespace acs::game { \ template<> \ struct TReflectedFields<T> { \ static const ::acs::game::FieldInfo* Fields() noexcept { \ static const ::acs::game::FieldInfo s_fields[] = { __VA_ARGS__ }; \ return s_fields; \ } \ static ::acs::u32 Count() noexcept { \ static const ::acs::game::FieldInfo s_fields[] = { __VA_ARGS__ }; \ return static_cast<::acs::u32>( \ sizeof(s_fields) / sizeof(s_fields[0])); \ } \ }; \ template<> \ struct TTypeInfo<T> { \ static const ::acs::game::FTypeInfoBase& Get() noexcept { \ static const ::acs::game::FTypeInfoBase s_info { \ /* type_name */ #T, \ /* size */ sizeof(T), \ /* alignment */ alignof(T), \ /* fields */ TReflectedFields<T>::Fields(), \ /* field_count */ TReflectedFields<T>::Count(), \ /* type_tag */ ::acs::game::TypeTag<T>(), \ }; \ return s_info; \ } \ }; \ } // namespace acs::game
  • ACS_GAME_FIELD#define ACS_GAME_FIELD(T, field, type_str) \ ::acs::game::FieldInfo{ \ #field, \ (type_str), \ static_cast<::acs::usize>(offsetof(T, field)), \ static_cast<::acs::usize>(sizeof(((T*)0)->field)) \ }

使う場面

自作の構造体をセーブ / インスペクタ対象にしたい時。

API項目

API項目 1

ACS_GAME_FIELD(T, field, type_str)
説明
FFieldInfo の初期化子を作る。 名前・型名文字列・offsetof・sizeof を埋める。
対応API
ACS_GAME_FIELD マクロ

API項目 2

ACS_GAME_REFLECT(T, fields...)
説明
TReflectedFields<T> と TTypeInfo<T> の特殊化を生成し、型 T を反射可能にする。
対応API
ACS_GAME_REFLECT マクロ
対応API
acs::game::FTypeInfoBase::fields メンバー変数

使用例

ACS_GAME_REFLECT(PlayerState,
    ACS_GAME_FIELD(PlayerState, x,  "f32"),
    ACS_GAME_FIELD(PlayerState, y,  "f32"),
    ACS_GAME_FIELD(PlayerState, hp, "i32"))
