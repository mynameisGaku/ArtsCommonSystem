CLocalizationDirector

「言語と地域の設定 (例: 日本語 / 英語)。 どの翻訳を出すかの選択キー。 + 文字列 ID」を「翻訳済みの文字列」に解決するinternationalization (国際化) の略。 多言語対応のこと。 文字列を言語ごとの辞書から引けるようにする。 (多言語化) ストア。 UI ラベル / セリフ / メニュー文言を言語非依存に引ける。

クラス
対応するAPI: acs::game::CLocalizationDirector

使う場面

ゲームを多言語対応させたい時。 現 locale → Default(En) → key 自身、の 3 段本命が使えない時の代替経路。 XR では HMD 未接続時に通常の 2D 画面描画へ切り替えること。で、未翻訳箇所が画面で key として見えるので発見しやすい。

使用例

CLocalizationDirector loc;
loc.RegisterString(ELocale::En, "ui.title", "Adventure");
loc.RegisterString(ELocale::Ja, "ui.title", "クロードの冒険");
loc.SetLocale(ELocale::Ja);
const char* t = loc.Get("ui.title"); // -> "クロードの冒険"
