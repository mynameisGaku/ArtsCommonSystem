FAnimationCurve

編集できる「時間 → 値」の2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。曲線。 キーを打って、任意の 32bit の浮動小数(float 相当)。 座標・時間・係数など小数値に使う基本型。 値を時間で滑らかに変化させる。 Step / Linear / Hermite 2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。と前後の折り返し (Clamp/Loop/PingPong) に対応。

クラス
対応するAPI: acs::game::FAnimationCurve

使う場面

FOV やフェード、体力バー演出など、固定の トゥイーンの加減速カーブ。 Linear(等速)や InOutSine(ゆっくり始まりゆっくり終わる)など。式では表せない自由なカーブが欲しい時。
