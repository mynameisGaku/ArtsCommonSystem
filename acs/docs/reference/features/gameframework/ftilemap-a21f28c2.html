FTilemap

2D グリッドに タイル 1 セルの ID(u16)。 0 を「空(タイル無し)」として予約し、描画側がアトラスの index などとして解釈する。 を並べるデータ専用のタイルマップ。 当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ー対応・tile↔world 座標変換・Fill / FillRect を提供。 Tiled の JSON も読める。

クラス
対応するAPI: acs::game::FTilemap

使う場面

2D マップ (床 / 壁 / 背景) をグリッドで持ちたい時。 画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。は別途 タイルマップを画面に描画するコンポーネント。 等で行う。
