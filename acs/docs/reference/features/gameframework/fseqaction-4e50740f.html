FSeqAction

「待つ→関数を呼ぶ→値を滑らかに変える」を 1 行で連鎖記述する演出ビルダー。 作って CSequenceRunner に渡して再生する。 の中に積まれる「動作 1 つ」を表す Plain Old Data。 コンストラクタ等の特別な振る舞いを持たない単純な構造体。 コピーが速く扱いやすい。。 EKind(Wait / Call / 値を時間で滑らかに補間する仕組み。 UI・カメラ・演出・シーン遷移に使う。F / 値を時間で滑らかに補間する仕組み。 UI・カメラ・演出・シーン遷移に使う。V2 / 値を時間で滑らかに補間する仕組み。 UI・カメラ・演出・シーン遷移に使う。V3) で種類を区別する。

構造体
対応するAPI: acs::game::FSeqAction

使う場面

通常は 「待つ→関数を呼ぶ→値を滑らかに変える」を 1 行で連鎖記述する演出ビルダー。 作って CSequenceRunner に渡して再生する。 のビルダー経由で間接的に作られる。 中身を直接覗いて独自処理したい時だけ触る。
