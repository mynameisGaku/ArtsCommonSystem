CWaterVolume

Axis-Aligned Bounding Box。 軸に平行な直方体の境界ボックス。 当たり判定の粗い包囲に使う。 で定義した 2D の水域を複数登録し、点が水中かの判定と、物体に掛かる水中の物体を上向きに押し上げる力。 ACS では水深 × 強さ × 質量の簡易モデルで近似する。 + 水中で速度に逆らう減速力(-velocity × drag)。 水の粘性的な抵抗を表す。を力向きと大きさを持つ量。 2D/3D の位置・速度・方向を FVec2/FVec3 で表す。で返す部品。 「浮く」「沈む」「水中で減速」をゲームに組み込めます。

クラス
対応するAPI: acs::game::CWaterVolume

使う場面

池・川・海などの水場を作り、入った物体を浮かせたり沈ませたりしたい時。

API項目 6

FVec2 ComputeBuoyancyForce(FVec2 pos, FVec2 velocity, f32 mass) const
説明
水中の物体を上向きに押し上げる力。 ACS では水深 × 強さ × 質量の簡易モデルで近似する。(上向き = -Y) + 水中で速度に逆らう減速力(-velocity × drag)。 水の粘性的な抵抗を表す。(-velocity*drag)の合計を返す。 重なる水域は加算。 水中でなければ (0,0)。
戻り値
合力(world)
使う場面
物理ボディに ApplyForce する力を得る時。

使用例

CWaterVolume water;
FWaterVolumeInfo pond{ {0,50}, {200,50}, 9.8f, 2.0f, 0.0f, {0.1f,0.3f,0.6f} };
auto id = water.AddVolume(pond);
if (water.IsUnderwater(body.position)) {
    FVec2 f = water.ComputeBuoyancyForce(body.position, body.velocity, body.mass);
    body.ApplyForce(f);
}
