CModRegistry

ユーザー Mod (追加コンテンツパック) の登録・有効化・並び順を管理する薄い読み込んだアセットをキー(FAssetId)で保持・共有し、再利用する管理表。 ACS では CAssetRegistry。。 各 Mod は .ACS のアセットアーカイブ形式(.acpak)。 出荷時に複数ファイルを 1 つにまとめる。 を伴い、load_order 順に重ねていく (同じ登録を複数回行った時、最後に登録した内容が有効になること。で同名ゲームで使う画像・音・モデル・データなどの素材ファイル。を上書き) 想定。

クラス
対応するAPI: acs::game::CModRegistry

使う場面

Mod 対応ゲームで、Editor UI から Mod 一覧を出し、有効/無効や読み込み順を管理したい時。 実際の mount は別当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。 (本体は path を保持するだけ)。

使用例

CModRegistry mr;
FModInfo a{}; a.id="core"; a.load_order=0; a.enabled=true;
a.pack_path="mods/core.acpak";
mr.Register(a);
mr.Enable("weapons-ex");
mr.SortByLoadOrder();
for (u32 i=0; i<mr.Count(); ++i)
    if (mr.All()[i].enabled) MountPack(mr.All()[i].pack_path);
