CDungeonGenerator

2D グリッド上に部屋と廊下を配置するBinary Space Partitioning。 空間を再帰的に 2 分割していく手法。 ダンジョン生成では領域を割って各リーフに部屋を置く。 (空間二分割) ダンジョン生成器。 全体を再帰的に 2 分割し各リーフに 1 部屋を置き、隣り合う部屋を L 字廊下で繋ぐ。 乱数生成の初期値。 同じシードからは同じ乱数列が得られる。で結果を再現できる。

クラス
対応するAPI: acs::game::CDungeonGenerator

使う場面

ローグライクの「毎フロア違う各ウィジェットを画面のどこにどの大きさで置くかを決めて配置すること。 Layout で行う。」を自動生成したい時。 地形のみ生成し、モンスターやアイテム配置は呼び出し側で行う。

使用例

FDungeonGenConfig cfg;
cfg.width = 80; cfg.height = 50;
cfg.seed = 0xDEADBEEFu;
FDungeonGenerator gen;
gen.Generate(cfg);
for (u32 y = 0; y < gen.Height(); ++y)
  for (u32 x = 0; x < gen.Width(); ++x)
    if (gen.At(x, y) == ETileKind::Floor) DrawSprite(floor, x, y);
u32 px, py; gen.GetRoomCenter(0, px, py);  // 開始位置 = 最初の部屋の中心
