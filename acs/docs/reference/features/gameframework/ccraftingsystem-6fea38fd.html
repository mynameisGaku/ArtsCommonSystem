CCraftingSystem

サバイバル / クラフト系のレシピ + 素材消費 + 時間経過で成果物生成を扱う production ある種類の状態 (cooldown / チェックポイント / カード等) をまとめて持ち、登録・更新・問い合わせの API を提供する小さなクラス。。 レシピを登録し、StartCraft で素材を消費して Tick で進行、完了すると成果物を付与する。 在庫操作は別システム (ここでは在庫システム) との橋渡しをする差し替え可能な関数群。 これ経由にすることで本体が在庫の実装に依存しない。 ある出来事が起きた時に呼んでもらう関数。 経由なので在庫表現に依存しない。

クラス
対応するAPI: acs::game::CCraftingSystem

使う場面

「木3個 + 鉄2個を4秒かけて斧にする」のようなクラフトを作る時。 同時クラフトは 1 件なので、複数同時なら instance を複数持つ。

使用例

CCraftingSystem cs;
cs.RegisterRecipe({ \"craft.axe\", \"Iron Axe\", \"tool.axe\", 1, 2, ingredients, 4.0f, \"workbench\", 3 });
cs.SetInventoryAdapter(&Query, &Consume, &Grant, &inv);
if (cs.CanCraft(\"craft.axe\", \"workbench\", level))
    cs.StartCraft(\"craft.axe\", \"workbench\", level);
// 毎フレーム: cs.Tick(dt);
