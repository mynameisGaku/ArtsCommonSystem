FDialogueLine

会話 1 行のデータ。 発話者名・本文・タイプ速度を持つ。 文字列は所有しない (リテラルや外部バンドルを参照)。

構造体
対応するAPI: acs::game::FDialogueLine

使う場面

CDialogueSystem::AddLine に渡す 1 行を組み立てる時。

基本情報

モジュール
gameframework
分類
構造体
ヘッダー
gameframework/DialogueSystem.h

API項目

API項目 1

const char* speaker
説明
発話者名 (nullptr 可)。
対応API
acs::game::FDialogueLine::speaker メンバー変数

API項目 2

const char* text
説明
本文 (nullptr は空行)。
対応API
acs::game::FDialogueLine::text メンバー変数

API項目 3

f32 type_speed_cps
説明
タイプ速度 (chars per second)。 <=0 で瞬時表示。
対応API
acs::game::FDialogueLine::type_speed_cps メンバー変数

使用例

FDialogueLine l;
l.speaker        = "アリス";   // nullptr 可
l.text           = "やあ！";    // nullptr は空行扱い
l.type_speed_cps = 30.0f;        // 1 秒あたり 30 文字、<=0 で瞬時表示
