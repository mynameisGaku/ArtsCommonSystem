FTweenHandle

個々のある値を一定時間かけて始点から終点へなめらかに変化させる仕組み。 イージングで変化カーブを指定する。を指す実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。(index + 再利用される番号(ID)に付ける通し番号。 古いハンドルと新しい中身を取り違えないための目印。)。 古い / 完了済みのある値を一定時間かけて始点から終点へなめらかに変化させる仕組み。 イージングで変化カーブを指定する。を誤って操作しないための識別子です。

値を時間で滑らかに補間する仕組み。 UI・カメラ・演出・シーン遷移に使う。 の戻り値を保持して、後で Cancel / IsActive に渡す時。
