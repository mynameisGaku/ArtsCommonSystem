CDebugDraw

1 ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。分の2 つの端点と色からなる 1 本の線。 デバッグ描画の最小単位。を溜めるだけの状態を保持せず、毎フレーム「今出したいもの」をその場で積み上げる API スタイル。 CDebugDraw がこの方式。 デバッグ図形バッファ。 実画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。はしない。 ゲームロジックの任意の場所から線 / Axis-Aligned Bounding Box。 軸に平行な直方体の境界ボックス。 当たり判定の粗い包囲に使う。 / 円 / 十字を積み、画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。側が Lines() を読んでまとめて描く。

クラス
対応するAPI: acs::game::CDebugDraw

使う場面

当たり判定や物理の様子をその場で線で可視化したい時。 テストでは溜まった線配列を直接検査できる。

API項目 14

using FDebugDraw = CDebugDraw
説明
旧名を使う既存コード向けの互換別名。 新しいコードでは 1 フレーム分のデバッグ線分(線/AABB/円/十字)を溜めるだけのimmediate-modeバッファ。 実描画は描画側が行う。 を使う。
overload候補
CDebugDraw は複数の宣言に対応します。

  • acs::game::CDebugDraw::CDebugDrawCDebugDraw() noexcept = default;

使用例

CDebugDraw dd;
dd.Clear();
dd.DrawAabb(playerAabb, FVec4{1,0,0,1});
dd.DrawCircle(enemyCircle, FVec4{1,1,0,1});
for (u32 i = 0; i < dd.LineCount(); ++i) {
    const auto& ln = dd.Lines()[i];
    batch.DrawLine(ln.a, ln.b, ln.color);
}
