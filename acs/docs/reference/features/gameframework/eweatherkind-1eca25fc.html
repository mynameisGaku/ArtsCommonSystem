EWeatherKind

天候種別を表す 8 値の列挙(晴れ / 曇り / 雨 / 豪雨 / 雪 / 嵐 / 霧 / 砂嵐)。 値はセーブに書ける安定値です。

列挙(enum)
対応するAPI: acs::game::EWeatherKind

使う場面

SetWeather で天候を指定する / 現在天候で分岐する時。
