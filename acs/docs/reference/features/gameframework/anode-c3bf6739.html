API項目 1

virtual void OnSpawn/OnUpdate(f32)/OnFixedUpdate(f32)/OnDraw(FRenderContext&)/OnDespawn() noexcept
説明
オブジェクトが生成→更新→破棄されるまでの一連の段階。 各段階にフック関数が対応する。特定のタイミングで自動的に呼ばれる差し込み点となる関数 (OnSpawn / OnUpdate など)。 override して処理を書く。。 必要なものだけ override する (全 noexcept 必須)。 OnFixedUpdate は固定刻みの物理/同じ入力なら必ず同じ結果になる性質。 replay / netcode / record-replay の同期で必須。 ML 推論や浮動小数のドライバ差はこれを壊すので隔離する。ロジック用。

class APlayer : public ANode {
public:
    void OnUpdate(f32 dt) noexcept override {
        SetPosition2D(Position2D() + FVec2{100.0f * dt, 0.0f});
    }
};
ANode& p = root.AddChild(NewObject<APlayer>());
p.SetDrawLayer(1);
p.SetYSortEnabled(true);
p.AddComponent<ASprite2DComponent>();
