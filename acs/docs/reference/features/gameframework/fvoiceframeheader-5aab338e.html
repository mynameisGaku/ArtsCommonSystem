FVoiceFrameHeader

ループバック インターフェースの裏で実際に仕事をする具象実装。 ここでは OpenXR ローダ等の XR 実装本体。 が運ぶ 音声を一定間隔で数値化した生波形データ。 圧縮なしでそのまま再生できる形式。 ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。の固定 16 byte ヘッダ(LE)。 magic / 時間順に処理を並べて演出やイベントを組み立てる仕組み。番号 / サンプル数を持ち、エンコードされたデータを元の形(ここでは int16 PCM)に戻すこと。時に破損検出に使います。

構造体
対応するAPI: acs::game::FVoiceFrameHeader

使う場面

ループバックの音声ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。形式を理解 / 自前で組み立てる時。
