CProjectileSystem

弾・矢・ロケット・魔法弾など『飛んでいって何かに当たる』ものを固定容量のあらかじめ確保した固定数の枠を使い回す仕組み。 確保/解放のコストとフレーム落ちを避けられる。で一括管理するコンポーネントを持つエンティティ群を毎フレーム処理する関数(移動・AI など)。 CSystemScheduler で順に実行する。。 発射 → 飛翔 → 命中/寿命切れ までを毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。の Tick で進める。

クラス
対応するAPI: acs::game::CProjectileSystem

使う場面

シューティングや弾幕、敵の攻撃弾など、大量の投射物を出したい時。 CWeaponSystem と組み合わせて使うのが定番。

使用例

CProjectileSystem ps;
ps.Init(256);                    // 同時 256 発まで
FProjectileDef d{};
d.id = "bullet"; d.speed = 800.0f; d.lifetime_sec = 1.5f;
ps.RegisterDef(d);               // 弾種を登録
ps.Spawn("bullet", pos, FVec2{800,0}, ownerId, /*damage=*/15.0f);
ps.Tick(dt);                     // 毎フレーム進める
