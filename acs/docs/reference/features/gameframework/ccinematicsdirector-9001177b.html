CCinematicsDirector

時間軸に並べたタイムライン上の「この時刻にこれを起こす」を表す 1 点(時刻＋動作)。 並べてカットシーンを組む。を順に発火していくカットタイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。 driver。 「0 秒で バックグラウンドミュージック。 場面の間ずっとループで流す音楽。」「2 秒で視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。移動」「3 秒でセリフ」を 1 本のタイムラインとして宣言的に組める。 自分では画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。も音も出さず、種別ごとの ある出来事が起きた時に呼んでもらう関数。 を呼ぶだけ。

クラス
対応するAPI: acs::game::CCinematicsDirector

使う場面

オープニング・ボス導入・『× ボタンが押された』『キーが押された』のような、その瞬間に起きた出来事の通知。 ACS では FEvent として届く。ムービー等の演出を時系列で組み立てる時。

API項目 1

bool TryAddKeyframe(const FTimelineKeyframe& kf)
説明
有限時刻の keyframe を time_sec 昇順 (同時刻は登録順) で追加する。 再生中・進行後・確保失敗・非有限時刻では追加せず false。 負値は 0 秒へ丸める。
戻り値
追加可否
使う場面
停止オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。の初期設定時。

API項目 7

void Tick(f32 dt)
説明
有限で正の dt だけ時刻を進め、到達した keyframe を時刻順に一度発火する。 再生中でない、非有限、0 以下、または加算結果が非有限なら何もしない。
使う場面
毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。呼ぶ。
対応API
acs::game::CCinematicsDirector::Tick メンバー関数

使用例

CCinematicsDirector cine;
FTimelineKeyframe kf;
kf.time_sec = 2.0f; kf.kind = ETimelineTrackKind::MoveCamera;
kf.payload.camera = { FVec2{100,200}, 1.5f, 3.0f };
cine.AddKeyframe(kf);
cine.SetCameraCallback(&DoMoveCamera, this);
cine.Play();
// 毎フレーム: cine.Tick(dt);
