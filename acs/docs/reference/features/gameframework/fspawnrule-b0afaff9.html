FSpawnRule

1 つのウェーブ内で「どの敵を・何体・どの間隔で・どこに」湧かせるかの 1 設定。 FSpawnRule。。 「どの敵を・何体・どの間隔で・どこに」湧かせるかを定義します。 1 つの wave が任意数のルールを持てます。

構造体
対応するAPI: acs::game::FSpawnRule

使う場面

wave の中身(敵の出し方)を定義する時。

基本情報

モジュール
gameframework
分類
構造体
ヘッダー
gameframework/WaveSpawner.h

API項目

API項目 1

const char* enemy_id
説明
敵種別の識別子(リテラル推奨、そのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。)。
対応API
acs::game::FSpawnRule::enemy_id メンバー変数

API項目 2

u32 count
説明
この rule で湧かせる総数。
対応API
acs::game::FSpawnRule::count メンバー変数

API項目 3

f32 spawn_interval_sec / f32 initial_delay_sec
説明
2 体目以降の間隔(秒) / wave 開始から 1 体目までの必要になるまで計算を先延ばしにする方式(lazy)。 現行 TDerived は生成時と依存通知時に即時評価し、Get の再計算は dirty が残った場合の補完経路。(秒)。
対応API
acs::game::FSpawnRule::spawn_interval_sec メンバー変数
対応API
acs::game::FSpawnRule::initial_delay_sec メンバー変数

API項目 4

FVec2 spawn_position
説明
出現位置(world 座標)。 分散させたいなら別 rule を並べる。
対応API
acs::game::FSpawnRule::spawn_position メンバー変数

使用例

FSpawnRule rule{
    /*enemy_id=*/"goblin", /*count=*/5,
    /*interval=*/0.5f, /*delay=*/1.0f,
    /*pos=*/{100,0} };
