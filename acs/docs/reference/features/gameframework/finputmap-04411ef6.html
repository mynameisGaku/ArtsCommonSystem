FInputMap

物理キー/マウス/コントローラ。 ACS は XInput 互換でボタンやスティック（軸）を読む。を「Jump」「MoveX」のような名前付きアクションに束ねるマッピング層。 ゲームロジックが物理キーから切り離され、キーコンフィグ UI も後付けできる。

クラス
対応するAPI: acs::game::FInputMap

使う場面

「W / 左stick = MoveForward」のように 1 actionへ複数キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。を割り当てたい時。 通常queryはOS ごとのウィンドウ・入力・時間などを抽象化する低レベルモジュール。 easy の入力コード列挙 EKey 等もここで定義される。キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。を読み、replay・AI・testでは明示ある時刻の世界全体の状態を 1 つに固めたもの。 server がこれを配信し、client は受信した複数 snapshot を補間して表示する (FPS/MMO 系で標準)。をEvaluateへ渡す。

使用例

FInputMap im;
im.BindKey    (FActionId("Jump"),  EKey::Space);
im.BindGamepad(FActionId("Jump"),  EGamepadButton::A);
im.BindAxisKeys(FActionId("MoveX"), EKey::A, EKey::D);
if (im.IsPressed(FActionId("Jump"))) DoJump();
f32 mx = im.Axis(FActionId("MoveX")); // -1, 0, +1
