CBeatGrid

リズムゲームのタイミング判定 + 譜面再生。 1 譜面分の note 配列を持ち、再生時刻を進めながらプ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ーの Tap を最近 note と突き合わせ、Perfect / Great / Good / Miss の 4 段階で判定する。 コンボや精度も集計する。

クラス
対応するAPI: acs::game::CBeatGrid

使う場面

音ゲー (DDR/太鼓系) の判定ロジックを組みたい時。 音の再生 (CAudioDirector) とは独立に動く軽量 state machine。

使用例

CBeatGrid grid;
grid.Init();
grid.TrySetTimingWindows(25.0f, 50.0f, 100.0f); // ms
FBeatNote notes[] = {
    { 1.0f, EBeatLane::Left, false, 0.0f },
    { 1.5f, EBeatLane::Down, true, 0.75f },
};
if (grid.TryLoadChart(notes, 2, 120.0f) == EBeatChartLoadResult::Success) grid.Start();
grid.Tick(dt);
grid.PressLane(EBeatLane::Down);
grid.ReleaseLane(EBeatLane::Down);
