FBuffDef / FBuffInstance / FBuffOwnerId

バフ 1 種の定義(id・種別・持続秒・効果量・スタック方針など)。 RegisterBuff で登録する。=バフ 1 種の定義 (id/kind/持続秒/tick 間隔/効果量/StackPolicy/最大 stack/デバフON/OFF を表す印。 ここでは暗号化/圧縮の有無。)。 FBuffInstance=今 owner に掛かっている実体 (残り秒 / 重ねがけ数)。 FBuffOwnerId=効果対象のオブジェクトを直接ポインタで指す代わりに「配列の index + 世代カウンタ」で指す仕組み。 slot が再利用されても世代が食い違うので、破棄済みの古いハンドルを安全に検出できる。 (24bit index + 8bit gen)。

構造体

対応するAPI候補

  • acs::game::FBuffDefstruct FBuffDef;
  • acs::game::FBuffInstancestruct FBuffInstance;
  • acs::game::FBuffOwnerIdstruct FBuffOwnerId;

使う場面

RegisterBuff に Def を渡し、AllBuffsOfOwner で Instance を読む。 owner は CreateOwner が返す。
