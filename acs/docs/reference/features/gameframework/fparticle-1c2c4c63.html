FParticle

個別の粒子データ。 位置 / 速度 / 経過秒 (age) / 寿命 (lifetime) / 色 / サイズ / 重力を自分で持ち回る自分が動くのに必要なデータを全部自分で持っていて、外部の状態に依存しないこと。設計なので、emitter が消えても粒子は正しく動き続ける。

構造体
対応するAPI: acs::game::FParticle

使う場面

画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。側がこの構造体を直接読み、age/lifetime から2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。係数を求めて色・サイズを決める。

API項目

API項目 1

f32 NormalizedAge() const
説明
age / lifetime を 0..1 に clamp して返す。 色・サイズ2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。に使う。
戻り値
0..1 の経過比
対応API
acs::game::FParticle::NormalizedAge メンバー関数

API項目 2

bool IsAlive() const
説明
age < lifetime なら true (まだ生きている)。
対応API
acs::game::FParticle::IsAlive メンバー関数

使用例

u32 n = 0;
const FParticle* p = fx.AllParticles(n);
for (u32 i = 0; i < n; ++i) {
    if (!p[i].IsAlive()) continue;
    f32 t = p[i].NormalizedAge();   // 0..1
    // 描画 (位置 p[i].position、色は補間)
}
