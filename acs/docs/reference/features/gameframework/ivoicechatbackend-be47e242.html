IVoiceChatBackend

パーティ / チーム / 全体チャンネルのマイク音声を圧縮して送受信する仕組み(Steam VOIP)。を抽象化するプラットフォーム固有 SDK との結合点を抽象化した純粋仮想インターフェース。 ゲーム側はこれ越しに呼び、実装をビルド時に差し替える。(純粋仮想実装を差し替えられるようにするための約束事(純粋仮想クラス)。 I で始まる。)。 実体は Valve のゲーム配信プラットフォーム。 実績・フレンド・クラウドセーブ等の機能を Steamworks SDK 経由で使える。 Voice / EOS Voice / Vivox / Discord / 自前 Opus のどれでもよく、ゲーム側はこの I/F 越しに参加者管理・ミュート・音量だけを扱います。

インターフェース
対応するAPI: acs::game::IVoiceChatBackend

使う場面

オンライン対戦 / 協力プレイにマイク音声を圧縮して送受信する仕組み(Steam VOIP)。を載せたいが、使う SDK をビルド時に差し替えたい時。
