CXAudio2Backend

CAudioDirector から見た「実際に音を出す層」の純粋仮想インターフェース。 Windows では XAudio2 実装が差し込まれる。 の Windows 用 concrete 実装 = Win32 Windows 標準の低レベル音声 API。 ACS の音声再生はこの上に実装されている。 を叩いて実音声を出す。 重い <xaudio2.h> は pimpl で .cpp に隠蔽。 固定容量 voice pool + generation 付き handle で すでに解放したメモリを誤って使ってしまうバグ。 世代付きハンドルなどで検出・防止する。 を防ぐ。 COM 初期化も本クラスが責任を持つ。 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。・非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。。

クラス
対応するAPI: acs::game::CXAudio2Backend

使う場面

Windows で CAudioDirector に実音声を鳴らさせたい時。 director.SetBackend(&xaudio2) で差し込む。

使用例

CXAudio2Backend m_Audio;
FAudioDirector  m_Director;
ACS_TRY(m_Audio.Init(64));        // 同時発音 64 voice
m_Director.SetBackend(&m_Audio);
// 終了時:
m_Director.SetBackend(nullptr);  // 先に director を切る
m_Audio.Shutdown();
