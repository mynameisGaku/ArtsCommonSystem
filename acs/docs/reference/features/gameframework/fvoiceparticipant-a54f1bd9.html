FVoiceParticipant

マイク音声を圧縮して送受信する仕組み(Steam VOIP)。参加者 1 人の情報。 GetParticipant が返し、ID / 表示名(そのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。)・発話中か・ローカルミュート・音声レベルを持ちます。

構造体
対応するAPI: acs::game::FVoiceParticipant

使う場面

参加者リストや発話インジケータ・音量メーターを UI に描く時。
