IInspectableProvider

自分 (または管理下のオブジェクト群) をインスペクタに公開する抽象実装を差し替えられるようにするための約束事(純粋仮想クラス)。 I で始まる。。 ゲーム側クラスが継承して実装する。

インターフェース
対応するAPI: acs::game::IInspectableProvider

使う場面

Player や Camera を実行時に覗ける/編集できるようにしたい時。 1 『既定の実装を返す関数』を後から登録する仕組み。 登録するとアプリ全体の既定実装が差し替わる。 が N オブジェクトを公開する Manager 型にもできる。

API項目

API項目 1

virtual u32 ObjectCount() noexcept = 0
説明
公開するオブジェクト数。 0 なら何も描かれない。
対応API
acs::game::IInspectableProvider::ObjectCount メンバー関数

API項目 2

virtual FInspectableObject GetObject(u32 index) noexcept = 0
説明
index 番目のオブジェクト記述を返す。 fields 配列は 『既定の実装を返す関数』を後から登録する仕組み。 登録するとアプリ全体の既定実装が差し替わる。 所有。
対応API
acs::game::FInspectableObject 構造体
対応API
acs::game::IInspectableProvider::GetObject メンバー関数

API項目 3

virtual void OnFieldChanged(u32 obj_index, u32 field_index) noexcept = 0
説明
UI が値を書き換えた直後に呼ばれる。 clamp / 再計算 / dirty ON/OFF を表す印。 ここでは暗号化/圧縮の有無。をここで。
対応API
acs::game::IInspectableProvider::OnFieldChanged メンバー関数

使用例

class FPlayer : public IInspectableProvider {
    u32 ObjectCount() noexcept override { return 1; }
    FInspectableObject GetObject(u32) noexcept override {
        static FInspectableField f[] = {
            { "hp", EFieldKind::I32, &m_Hp, 0, nullptr } };
        return { "Player", "P1", f, 1 };
    }
    void OnFieldChanged(u32, u32) noexcept override {}
};
