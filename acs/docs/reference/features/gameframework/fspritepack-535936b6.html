FSpritePack

「1 枚の 多数の小画像(グリフやタイル)を 1 枚にまとめたテクスチャ。 UV で各部分を取り出す。テクスチャ + その中に並ぶ複数ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。の矩形」を持つデータ層。 名前でゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。を引き、[0,1] の UV を計算する。 Aseprite / TexturePacker の JSON も読める。

クラス
対応するAPI: acs::game::FSpritePack

使う場面

2D の 1 枚絵(キャラ・アイコン等)。 矩形にテクスチャを貼って描く。シートを名前付きゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。で管理したい時。 経過時間から現在のアニメフレーム番号を計算する部品。 と組んでアニメ再生する。

FVec4 ComputeUv(const FSpriteFrame& frame) const
説明

使用例

FSpritePack pack;
FSpritePackInfo info; info.atlas_texture_path = "hero.png";
info.atlas_width = 1024; info.atlas_height = 1024;
pack.Init(info);
if (const FSpriteFrame* f = pack.FindFrame("Idle_00")) {
    FVec4 uv = pack.ComputeUv(*f);
}
