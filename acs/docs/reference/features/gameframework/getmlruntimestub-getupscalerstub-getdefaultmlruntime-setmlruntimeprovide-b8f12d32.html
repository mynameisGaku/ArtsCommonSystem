GetMlRuntimeStub / GetUpscalerStub / GetDefaultMlRuntime / SetMlRuntimeProvider

ML / IUpscaler の窓口アクセサ群。 プロセス内に 1 個だけある stub への参照を返すほか、実 インターフェースの裏で実際に仕事をする具象実装。 ここでは OpenXR ローダ等の XR 実装本体。 を SetMlRuntimeProvider で部品同士をつなぎ込む(実装を既定の口に登録する)こと。 これで上位が下位に直接依存せず使える。して GetDefaultMlRuntime から インターフェースの裏で実際に仕事をする具象実装。 ここでは OpenXR ローダ等の XR 実装本体。 非依存に取得できる。

使う場面

ゲームコードから インターフェースの裏で実際に仕事をする具象実装。 ここでは OpenXR ローダ等の XR 実装本体。 を直接 include せずに既定 ML ランタイムを取りたい時。 『既定の実装を返す関数』を後から登録する仕組み。 登録するとアプリ全体の既定実装が差し替わる。 未登録なら自動で stub を返す。
