FTypeInfoBase

型の型が自身の構造(フィールド名 / 型 / オフセット)を自己記述する仕組み。 シリアライザやインスペクタの土台になる。情報の本体。 Reflect<T>() が返す型で、型名・サイズ・整列・フィールド配列・一意なアセットやローダの種類を表す数値(AssetType)。 文字列名のハッシュから作られる。 を持ちます。

構造体
対応するAPI: acs::game::FTypeInfoBase

使う場面

型が自身の構造(フィールド名 / 型 / オフセット)を自己記述する仕組み。 シリアライザやインスペクタの土台になる。結果を走査してフィールドを列挙する時。
