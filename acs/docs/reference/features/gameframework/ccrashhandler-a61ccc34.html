CCrashHandler

gameframework 側のクラッシュ報告 backend 抽象インターフェース。 crashwin はその Windows 実装。 を 1 つ抱えてタイトル側で使いやすくする薄い wrapper。 インターフェースの裏で実際に仕事をする具象実装。 ここでは OpenXR ローダ等の XR 実装本体。 が未 Install (nullptr) のときは全 ライブラリの機能を外から使うための窓口(関数や型の取り決め)。 例: ネットワークは WinSock をくるんだ薄い API として提供される。 が 何もしない処理。 呼んでも安全で副作用が無いこと。 になる (二次クラッシュ防止)。

クラス
対応するAPI: acs::game::CCrashHandler

使う場面

ホットパスから簡単にクラッシュ通知 / クラッシュ前に何が起きていたかを時系列で残す短いログ。 クラッシュ報告に添付して原因追跡に使う。 を出したい時。
