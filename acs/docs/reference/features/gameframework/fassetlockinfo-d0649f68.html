FAssetLockInfo

文字列は インターフェースの裏で実際に仕事をする具象実装。 ここでは OpenXR ローダ等の XR 実装本体。 が所有せず、寿命は「次の Backend 呼び出しまで」を保証する。

構造体
対応するAPI: acs::game::FAssetLockInfo

使う場面

あるゲームで使う画像・音・モデル・データなどの素材ファイル。が誰にいつデータを守るための『鍵』。 取った人だけが対象を触れ、他は解放されるまで待つ。されているかを問い合わせた結果を読む時。
