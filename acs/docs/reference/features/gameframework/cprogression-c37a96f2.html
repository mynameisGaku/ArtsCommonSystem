CProgression

「累計 XP を加算するとレベルが上がり、所定の XP 閾値で Milestone を達成 → コンテンツが Unlock される」進行コンポーネントを持つエンティティ群を毎フレーム処理する関数(移動・AI など)。 CSystemScheduler で順に実行する。を 1 クラスにまとめた小型ある種類の状態 (cooldown / チェックポイント / カード等) をまとめて持ち、登録・更新・問い合わせの API を提供する小さなクラス。。 レベルは floor(log2(xp + 1)) で典型的な RPG カーブを近似。 Steam や各家庭機が提供する、実績・課金・マッチング等を扱う公式ライブラリ。 非依存。

クラス
対応するAPI: acs::game::CProgression

使う場面

敵撃破やクエスト完了で XP が貯まり、一定値で「Lv.10 到達で新エリア解放」のようなマイルストーンを達成させたい時。 達成時に ある出来事が起きた時に呼んでもらう関数。 でゲーム側へ通知する。

API項目

API項目 1

void RegisterMilestone(const FMilestoneDef& def)
説明
起動時に 1 度ずつ登録。 同 id の 2 重登録 / id==nullptr は 何もしない処理。 呼んでも安全で副作用が無いこと。。
対応API
acs::game::CProgression::RegisterMilestone メンバー関数
対応API
acs::game::FMilestoneDef 構造体

API項目 2

void AwardXp(u32 amount)
説明
累計 XP に加算し、各 milestone の達成判定を行う。 u32 超過は max に値を指定範囲内に収めること。 Saturate は 0〜1 に収める。。 amount=0 は 何もしない処理。 呼んでも安全で副作用が無いこと。。
対応API
acs::game::CProgression::AwardXp メンバー関数

API項目 3

u32 CurrentXp() const
説明
現在の累計 XP。 CurrentLevel() は floor(log2(xp+1)) (xp=1→Lv1, xp=7→Lv3, ...)。
対応API
acs::game::CProgression::CurrentXp メンバー関数
