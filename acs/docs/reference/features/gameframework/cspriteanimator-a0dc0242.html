CSpriteAnimator

「経過時間から現在ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。番号を計算する」ロジックだけを担う部品。 画像 / 画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。 ライブラリの機能を外から使うための窓口(関数や型の取り決め)。 例: ネットワークは WinSock をくるんだ薄い API として提供される。 には触れず、利用者が CurrentFrame() を取り出して自分の絵に適用する。

クラス
対応するAPI: acs::game::CSpriteAnimator

使う場面

コマ送りの時間管理だけ欲しい時。 画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。と切り離してテストしやすい。 指定ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。で『× ボタンが押された』『キーが押された』のような、その瞬間に起きた出来事の通知。 ACS では FEvent として届く。 (足音など) を鳴らせる。

}, this);
