FTurnSideId

ターンの陣営(side)を識別する 32bit の実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。(24bit index + 8bit再利用される番号(ID)に付ける通し番号。 古いハンドルと新しい中身を取り違えないための目印。)。 除外→再追加でスロットが再利用されても、古い ID を無効と検出できます。

構造体
対応するAPI: acs::game::FTurnSideId

使う場面

ターン制ゲームの進行を管理する部品。 複数の陣営を行動順で並べ、各陣営が AP(行動ポイント)予算で行動する。 の各 ライブラリの機能を外から使うための窓口(関数や型の取り決め)。 例: ネットワークは WinSock をくるんだ薄い API として提供される。 で陣営を指す時。
