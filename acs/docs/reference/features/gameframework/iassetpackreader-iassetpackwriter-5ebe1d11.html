IAssetPackReader / IAssetPackWriter

.ACS のアセットアーカイブ形式(.acpak)。 出荷時に複数ファイルを 1 つにまとめる。 鍵を知らないと中身を読めない形にデータを変換すること。複数のファイルを 1 つにまとめた書庫ファイル。 .acpak はその一種。の読み書きプラットフォーム固有 SDK との結合点を抽象化した純粋仮想インターフェース。 ゲーム側はこれ越しに呼び、実装をビルド時に差し替える。。 開発中はバラのファイル、出荷時は 1 つの不透明な pak、をゲームコードを変えずに切り替えられる。 実体 (AES 暗号 + 速度重視の可逆圧縮形式。 そこそこ縮み、展開がとても速い。 データを規則性を使って小さくすること。 ここでは LZ4 を使う。) は別 インターフェースの裏で実際に仕事をする具象実装。 ここでは OpenXR ローダ等の XR 実装本体。 モジュールが実装する。

使う場面

.acpak などのアセットを読む側の部品。 pak をマウントして仮想ファイルを取り出す(対になる書き出し側が Writer)。=ランタイムで pak からファイルを読む時。 Writer=パッキングツールで pak を作る時。
