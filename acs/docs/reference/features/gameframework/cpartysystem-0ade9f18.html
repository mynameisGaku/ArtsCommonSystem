API項目

API項目 1

TResult<void> CreateParty(const char* party_name)
説明
新規パーティ作成 (Solo オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。のみ受理)。 オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。を Joining → InParty へ遷移。
対応API
acs::game::CPartySystem::CreateParty メンバー関数

API項目 2

TResult<void> JoinParty(const char* party_id)
説明
招待で受け取った ID で参加 (Solo のみ)。 Joining に遷移し Tick で timeout 監視。
対応API
acs::game::CPartySystem::JoinParty メンバー関数

API項目 3

TResult<void> LeaveParty()
説明
現在のパーティから離脱 (InParty のみ)。 Leaving に遷移。
対応API
acs::game::CPartySystem::LeaveParty メンバー関数

API項目 4

TResult<void> InviteFriend(const char* friend_id)
説明
フレンドに招待を送る (InParty のみ)。 リーダー権限の判定は呼び出し側責任。
対応API
acs::game::CPartySystem::InviteFriend メンバー関数

API項目 5

bool IsInParty() const
説明
パーティ所属中なら true。 State() で EPartyState も取れる。
対応API
acs::game::CPartySystem::IsInParty メンバー関数

API項目 6

TResult<void> AddMember(const FPartyMember& member)
説明
メンバを 1 件追加。 player_id が nullptr / 既存と重複の場合はエラー。 SDK で accept された相手を流し込む用途。
対応API
acs::game::CPartySystem::AddMember メンバー関数
対応API
acs::game::FPartyMember 構造体

API項目 7

bool RemoveMember(const char* player_id)
説明
一致メンバを削除して true。 順序を保ち前詰め。 見つからなければ false (何もしない処理。 呼んでも安全で副作用が無いこと。)。
対応API
acs::game::CPartySystem::RemoveMember メンバー関数
対応API
acs::game::FPartyMember::player_id メンバー変数

API項目 8

u32 MemberCount() const
説明
パーティ内メンバ数 (自分含む)。 Solo は 0。 Members() で生バッファも取れる。
対応API
acs::game::CPartySystem::MemberCount メンバー関数

API項目 9

u32 FindMember(const char* player_id) const
説明
player_id 一致メンバの index。 GetMember() にそのまま渡せる。
戻り値

対応API
acs::game::CPartySystem::FindMember メンバー関数
対応API
acs::game::FPartyMember::player_id メンバー変数

API項目 10

void Tick(f32 dt)
説明
Joining / Leaving の timeout 監視 + オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。遷移。 呼ばないと Joining のまま停滞する。
対応API
acs::game::CPartySystem::Tick メンバー関数

API項目 11

void AddFriend(const FFriend& f)
説明
フレンドを 1 件登録。 FriendCount() / Friends() で一覧取得。
対応API
acs::game::CPartySystem::AddFriend メンバー関数
対応API
acs::game::FFriend 構造体
