AFire2DComponent

手続き生成の炎を描くANode に付ける部品。 1 つの機能 (物理・描画・当たり判定など) を担い、組み合わせて挙動を作る。。 GPU 上で頂点やピクセルを計算する小さなプログラム。 ACS では HLSL で書く。・ゲームで使う画像・音・モデル・データなどの素材ファイル。不要で、ちらつきと揺らぎを時間で生成する。 強さ (intensity) を動的に変えられる。

クラス (コンポーネント)
対応するAPI: acs::game::AFire2DComponent

使う場面

たいまつ・かがり火・燃え盛る演出を簡単に置きたい時。 近づくと勢いが増す等の連動も可能。

使用例

f.SetSize(0.8f, 1.8f);
f.SetIntensity(1.0f);   // 0 で消火、大きいほど激しく
