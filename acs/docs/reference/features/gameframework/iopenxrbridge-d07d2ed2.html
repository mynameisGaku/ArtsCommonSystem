IOpenXrBridge

VR / AR / MR (XR) ランタイムへの接続を抽象化する差し替え可能な境界面。 実装(backend)を後から入れ替えられるよう、インターフェースだけを切り出した接合点。(差し替え点)。 Head-Mounted Display。 頭に被る VR/AR ディスプレイ(ヘッドセット)。 のヘッド位置と向きをまとめた姿勢情報。 XR では頭や手の ポーズ を追跡する。、左右コントローラのオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。、passthrough の on/off だけを公開する最小の窓口。 実 SDK (Khronos 策定の XR(VR/AR)機器を扱う業界標準 API。 機種差をこの一枚で吸収する。 / Oculus / Valve のゲーム配信プラットフォーム。 実績・フレンド・クラウドセーブ等の機能を Steamworks SDK 経由で使える。VR / PS VR2 等) は別モジュールで差し替える。

インターフェース
対応するAPI: acs::game::IOpenXrBridge

使う場面

VR ゲームを書くが、開発機に Head-Mounted Display。 頭に被る VR/AR ディスプレイ(ヘッドセット)。 が刺さっていなくても動くようにしたい時。 未接続なら stub が「常に未トラッキング」を返すので、通常の 2D 画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。への本命が使えない時の代替経路。 XR では HMD 未接続時に通常の 2D 画面描画へ切り替えること。を最初から書ける。

API項目 6

FXrControllerState LeftController() const
説明
左コントローラの 1 ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。分のキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。 ある時刻の世界全体の状態を 1 つに固めたもの。 server がこれを配信し、client は受信した複数 snapshot を補間して表示する (FPS/MMO 系で標準)。。 RightController() も同様。 未接続側はゼロ state。
対応API
acs::game::FXrControllerState 構造体
対応API
acs::game::IOpenXrBridge::LeftController メンバー関数

位置と向きをまとめた姿勢情報。 XR では頭や手の ポーズ を追跡する。 / キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。の取り込みを進める (『× ボタンが押された』『キーが押された』のような、その瞬間に起きた出来事の通知。 ACS では FEvent として届く。ポンプ相当)。 毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。呼ぶ。
