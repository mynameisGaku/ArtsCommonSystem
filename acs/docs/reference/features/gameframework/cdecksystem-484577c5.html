API項目 3

void Shuffle(u32 seed = 0)
説明
デッキを Fisher-Yates で要素の並びをランダムに入れ替えること。する。 seed==0 はランダム、seed!=0 は同じ入力なら必ず同じ結果になる性質。 replay / netcode / record-replay の同期で必須。 ML 推論や浮動小数のドライバ差はこれを壊すので隔離する。再現。
使う場面
試合開始時やプレイの入力や状態を記録し、後で同じ進行を再生する仕組み。 決定論的な乱数と相性が良い。再現時。
対応API
acs::game::CDeckSystem::Shuffle メンバー関数
