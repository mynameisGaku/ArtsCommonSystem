CWeaponSystem

1 体ぶんの武器ロードアウト + 弾薬 + 連射制御をまとめた小型ある種類の状態 (cooldown / チェックポイント / カード等) をまとめて持ち、登録・更新・問い合わせの API を提供する小さなクラス。。 1 秒あたりの発射回数。 連射間隔 = 1.0 / fire rate で決まる。・リロード時間・マガジン / 予備弾薬・拡散 / ペレット数を一体管理し、発射可否を判定します。 実際の弾生成はあとで呼んでもらうために登録しておく関数。 ACS では関数ポインタ + void* ユーザーデータの形を取る(STL 不依存方針)。で呼び出し側に任せます。

クラス
対応するAPI: acs::game::CWeaponSystem

使う場面

FPS / TPS / シューティングで、複数武器の切替・残弾・連射クールダウンを扱いたい時(1 体につき 1 インスタンス)。

使用例

CWeaponSystem ws;
ws.RegisterWeapon({ "pistol", "9mm", EWeaponKind::Pistol,
                   6.0f, 1.4f, 12, 48, 18.0f, 1.5f, 1, "proj.9mm" });
ws.EquipWeapon("pistol");
ws.SetOnFireCallback(&OnFire, this);
// 毎フレーム:
ws.Tick(dt);
if (input.JustPressed(EKey::Mouse0)) ws.TryFire();
if (input.JustPressed(EKey::R))      ws.StartReload();
