IUpscaler

解像度アップスケーラ (AMD FSR / NVIDependency Injection(依存性注入)。 使う実装を外から差し込み、呼び出し側を具体実装に依存させない設計。 CScriptHost は VM を差し替え可能にする。A DLSS / Intel XeSS) を差し替える抽象実装本体を切り離して差し替え可能にする「継ぎ目」。 インターフェースだけを置き、具象は別モジュールで注入する。 テストや SDK 隔離に使う。。 低解像度で描いた最終バッファをターゲット解像度に拡大する後段ステージ。

インターフェース
対応するAPI: acs::game::IUpscaler

使う場面

アップスケーリングを使いたいが、SDK ライセンスを本体から隔離し、未対応ハードではネイティブ解像度に本命が使えない時の代替経路。 XR では HMD 未接続時に通常の 2D 画面描画へ切り替えること。したい時。
