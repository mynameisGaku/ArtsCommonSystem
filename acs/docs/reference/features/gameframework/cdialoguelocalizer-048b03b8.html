CDialogueLocalizer

会話とゲームのテキストやリソースを言語・地域ごとに切り替えること (多言語化、i18n)。 (多言語化) を疎結合で繋ぐ橋渡し。 本文を持たず「行 → 翻訳キー」だけを保持し、現在の言語と地域の設定 (例: 日本語 / 英語)。 どの翻訳を出すかの選択キー。で翻訳を解決してあとで呼んでもらうために登録しておく関数。 ACS では関数ポインタ + void* ユーザーデータの形を取る(STL 不依存方針)。に渡す。 発話者名も翻訳キー扱い。

クラス
対応するAPI: acs::game::CDialogueLocalizer

使う場面

同じシナリオ行を言語ごとに別文字列で出したい時。 CLocalizationDirector (翻訳辞書) と CDialogueSystem を直結せず繋ぎたい時。

使用例

CDialogueLocalizer dl;
dl.RegisterLine({ "char.alice", "scene1.line0", 30.0f });
dl.SetLocalizer(&loc);   // 翻訳辞書を差し込む
dl.StartFromLine(0, [](void*, const char* sp, const char* tx, f32 cps) noexcept {
    // sp="アリス", tx="こんにちは" のように現ロケールで解決される
}, nullptr);
