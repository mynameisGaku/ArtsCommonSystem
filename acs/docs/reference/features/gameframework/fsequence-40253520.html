FSequence

「待つ → 関数を呼ぶ → 値をなめらかに変える」を 1 行で連鎖記述するビルダー。 作った 「待つ→関数を呼ぶ→値を滑らかに変える」を 1 行で連鎖記述する演出ビルダー。 作って CSequenceRunner に渡して再生する。 は 複数の FSequence を同時に再生・管理する実行係。 Start で所有して走らせ、毎フレーム Tick で進める。 に 中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。で渡して再生する。

クラス
対応するAPI: acs::game::FSequence

使う場面

カットタイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。・出現敵が波状にまとまって出現する単位。 倒しきると次の波へ進む。 CWaveSpawner が管理する。・タイトルのロゴ演出など、時間に沿った一連の動きを台本のように書きたい時。

説明
32bit の浮動小数(float 相当)。 座標・時間・係数など小数値に使う基本型。 変数を from から to へ duration 秒かけて2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。する。 トゥイーンの加減速カーブ。 Linear(等速)や InOutSine(ゆっくり始まりゆっくり終わる)など。で緩急を付けられる。
