FCooldownId

cooldown を指す実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。。 24bit index + 8bit generation の packed u32。 0 は invalid。

構造体
対応するAPI: acs::game::FCooldownId

使う場面

登録した cooldown を後で参照する時。
