CRollbackSession

キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。履歴とある時刻の世界全体の状態を 1 つに固めたもの。 server がこれを配信し、client は受信した複数 snapshot を補間して表示する (FPS/MMO 系で標準)。を使うrollback進行を管理する。

クラス
対応するAPI: acs::game::CRollbackSession

使う場面

同じ入力なら必ず同じ結果になる性質。 replay / netcode / record-replay の同期で必須。 ML 推論や浮動小数のドライバ差はこれを壊すので隔離する。的な対戦オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。を巻き戻して再実行する時。
