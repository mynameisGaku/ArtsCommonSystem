FSpriteFrame

多数の小画像(グリフやタイル)を 1 枚にまとめたテクスチャ。 UV で各部分を取り出す。内の 1 矩形 = 1 ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。。 名前・ピクセル矩形 (x,y,w,h)・スプライトの回転中心 / 配置基準となる点。 0..1 のローカル座標で表す。 (0..1) を持つ。 name はそのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。 (リテラル想定)。

構造体
対応するAPI: acs::game::FSpriteFrame

使う場面

1 枚のアトラスと名前付きフレーム矩形を持つデータ層。::AddFrame で手動登録する時、または FindFrame の戻り値として受け取る時。

使用例

FSpriteFrame f;
f.name = "Run_00";
f.x = 0; f.y = 0; f.w = 64; f.h = 64;
f.pivot_x = 0.5f; f.pivot_y = 1.0f; // 足元基準
pack.AddFrame(f);
