CSequenceRunner

複数の 「待つ→関数を呼ぶ→値を滑らかに変える」を 1 行で連鎖記述する演出ビルダー。 作って CSequenceRunner に渡して再生する。 を同時に再生・管理する実行係。 Start で時間順に処理を並べて演出やイベントを組み立てる仕組み。を所有して走らせ、毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。 Tick(dt) で進める。

クラス
