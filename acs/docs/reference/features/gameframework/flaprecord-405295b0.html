FLapRecord

1 ラップ分の結果ある瞬間の状態をまとめて切り取ったコピー。 ここでは 1 フレーム分の入力値の束。。 ラップ番号・そのラップ単体の秒数・累計秒数・自己ベスト更新ON/OFF を表す印。 ここでは暗号化/圧縮の有無。。

構造体
対応するAPI: acs::game::FLapRecord

使う場面

GetLapRecord でラップ履歴を表示する時。
