CLegacyKitEaseIdCodec

旧 Kit 形式で固定された33個のトゥイーンの加減速カーブ。 Linear(等速)や InOutSine(ゆっくり始まりゆっくり終わる)など。数値 ID と、ACS の Easing::EEasingType を相互変換するオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。なしの移行境界。 曲線の評価実装や正規 決まった選択肢の集合を表す型(列挙)。 例: 上下左右のキー。 の数値は変更しない。

クラス
対応するAPI: acs::game::CLegacyKitEaseIdCodec

使う場面

旧形式の保存データを読み込む時、または互換出力へ旧数値 ID を書き戻す時。 新規データはcanonical名を保存する。
