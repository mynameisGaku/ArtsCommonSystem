CInputRecorder

OS 寄りの生 (raw) キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。 (キー変化 + マウス座標 + ボタン) を 1 tick = 1 サンプルとして録画し、後でそのまま再生できるレコーダ。 .acsr 形式でファイル保存も可能。

クラス
対応するAPI: acs::game::CInputRecorder

使う場面

TAS / 自動テスト / バグ再現で「同じキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。列をピクセル単位で再現」したい時。 ゲーム解釈済みキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。を扱う CLockstep とは別当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。 (こちらは OS 信号寄り)。

API項目 10

using FInputRecorder = CInputRecorder
説明
旧名を使う既存コード向けの互換別名。 新しいコードでは Cキーボード・マウス・ゲームパッドの状態を問い合わせで読む静的クラス。 毎フレーム先頭で Update() を呼んでから状態を読む。Recorder を使う。
overload候補
CInputRecorder は複数の宣言に対応します。
  • acs::game::CInputRecorderclass CInputRecorder;
  • acs::game::CInputRecorder::CInputRecorderCInputRecorder() noexcept = default;
  • acs::game::CInputRecorder::CInputRecorderCInputRecorder(const CInputRecorder&) = delete;
  • acs::game::CInputRecorder::CInputRecorderCInputRecorder(CInputRecorder&&) = delete;

使用例

CInputRecorder rec;
rec.StartRecording(/*tick_rate_hz=*/60);
FInputSample s; s.tick = tick; /* ...詰める... */
rec.Capture(s);
// 後で:
rec.StartReplay();
FInputSample out;
if (rec.ConsumeSample(tick, out)) { /* out を入力の代わりに使う */ }
