API項目 10

virtual void Tick(f32 dt)
説明
完了した一発再生 voice の slot 解放等、内部オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。を進める。 dt は実時間秒。
使う場面
ゲームループから毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。呼ぶ。
対応API
acs::game::IAudioBackend::Tick メンバー関数

使用例

CXAudio2Backend backend;
ACS_TRY(backend.Init(64));
director.SetBackend(&backend);
// 一発再生:
FAudioVoiceHandle v = backend.PlayOneShot(clip, 1.0f, 1.0f);
backend.Tick(dt);   // 毎フレーム: 完了 voice を回収
