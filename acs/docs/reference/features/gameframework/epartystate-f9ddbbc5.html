EPartyState

パーティオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。。 Solo (非所属) / InParty (所属中) / Joining (参加要求中) / Leaving (離脱要求中)。 Joining / Leaving は処理の完了を待たずに先へ進み、結果は後で受け取るやり方。 重い読み込みなどで画面を止めない。 SDK 完了待ちの中間オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。。

列挙(enum)
対応するAPI: acs::game::EPartyState

使う場面

UI で「参加中…」の表示を出したり、オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。によって操作を許可/禁止したい時。
