CParticleEffectSystem

2D 向けの軽量 sprite 炎・煙・火花などを表現する大量の小さな粒子。 1 つ 1 つが位置・速度・寿命を持って動く。コンポーネントを持つエンティティ群を毎フレーム処理する関数(移動・AI など)。 CSystemScheduler で順に実行する。。 emitter (放出口) を複数置いて、炎・煙・スパーク・吹き出しなどの連続演出を出す。 画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。はせず、AllParticles() で粒子データを渡すだけなので画面 (描画) を持たずに動かせること。 テストや CI で見た目なしにロジックだけ検証できる。でも動く。

クラス
対応するAPI: acs::game::CParticleEffectSystem

使う場面

ヒット時の火花、燃えるたいまつ、走った跡の砂煙など「粒子を出し続ける」演出が欲しい時。 単発の Flash / Shake は別の CEffectSystem が担当。

void Tick(f32 dt)
説明
dt 秒進める。 連続放出 → 全粒子の物理更新 → 寿命切れ返却。 dt <= 0 は 何もしない処理。 呼んでも安全で副作用が無いこと。。

使用例

FParticleEmitterDef def{};
def.lifetime_sec      = 0.8f;
def.emit_rate_per_sec = 30.0f;
def.speed_min = 40.0f; def.speed_max = 80.0f;
def.gravity = {0.0f, 60.0f};
FParticleEffectSystem fx;
fx.Init(2048);
auto h = fx.CreateEmitter(def, {200.0f, 300.0f});
fx.Tick(dt);                 // 毎フレーム
fx.Burst(h);                 // 一気に放出 (爆発)
