FTurnSideState

陣営 1 つの表示用 ある時刻の世界全体の状態を 1 つに固めたもの。 server がこれを配信し、client は受信した複数 snapshot を補間して表示する (FPS/MMO 系で標準)。。 GetSideState が返す読み取り専用同じリソースを「どう解釈して読むか」を表す窓。 1 つのテクスチャに SRV / RTV / DSV など複数のビューを作れる。で、UI / AI / セーブで現在の アクションポイント。 ターン制で各陣営が 1 ターンに使える行動予算。 CTurnManager が管理する。 や行動済みかを見るのに使います。

構造体
対応するAPI: acs::game::FTurnSideState

使う場面

ターン UI に各陣営の アクションポイント。 ターン制で各陣営が 1 ターンに使える行動予算。 CTurnManager が管理する。 や名前を出す時。
