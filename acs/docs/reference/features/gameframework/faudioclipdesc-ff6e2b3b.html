FAudioClipDesc

再生する音声バッファの記述子。 1 ピクセル/要素のビット配置と型(RGBA8、HDR float、深度など)。 ACS では EFormat。 + データ参照を持つ。 pcm_data は インターフェースの裏で実際に仕事をする具象実装。 ここでは OpenXR ローダ等の XR 実装本体。 側が必要な間 (一発再生終了 / Stop まで) 内部中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。する。

構造体
対応するAPI: acs::game::FAudioClipDesc

使う場面

PlayOneShot / PlayLooped に渡す clip を組み立てる時。

API項目

API項目 1

const void* pcm_data = nullptr
説明
raw 音声を一定間隔で数値化した生波形データ。 圧縮なしでそのまま再生できる形式。 サンプル列 (Wav 形式の場合は RIFF ヘッダ込み)。
対応API

API項目 3

clip.pcm_data = bytes;
