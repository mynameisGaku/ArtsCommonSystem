TTypeInfo<T>

Run-Time Type Information。 C++ 標準の実行時型情報。 ACS では使わず、軽量な型 ID / リフレクションで代替する。 を使わない最小の型が自身の構造(フィールド名 / 型 / オフセット)を自己記述する仕組み。 シリアライザやインスペクタの土台になる。(型情報の自己記述)。 型の名前・サイズ・各フィールドの名前 / オフセット / サイズをコンパイル時に取り出せます。 オブジェクトの中身をファイルに保存できる形へ書き出し、また読み戻す部品。やインスペクタの土台。

クラステンプレート
対応するAPI: acs::game::TTypeInfo

使う場面

セーブ / ロードやデバッグ表示で「この構造体にはどんなフィールドがあるか」を機械的に知りたい時。
