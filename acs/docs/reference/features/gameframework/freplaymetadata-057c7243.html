ACS 機能 / gameframework

FReplayMetadata

1 録画分のメタデータ。 ゲームバージョン・レベル ID・乱数生成の初期値。 同じシードからは同じ乱数列が得られる。・録画日時・録画時間・プ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ー名・チェックサムを持つ。

構造体
対応するAPI: acs::game::FReplayMetadata

使う場面

プレイの入力や状態を記録し、後で同じ進行を再生する仕組み。 決定論的な乱数と相性が良い。一覧の表示や、バージョン不一致の検出に使う。

API項目

API項目 1

const char* game_version / const char* level_id
説明
ゲームバージョンと録画開始時のタイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。 ID (長寿命な文字列を渡す)。
対応API
acs::game::FReplayMetadata::game_version メンバー変数
対応API
acs::game::FReplayMetadata::level_id メンバー変数

API項目 2

u64 seed
説明
同じ入力なら必ず同じ結果になる性質。 replay / netcode / record-replay の同期で必須。 ML 推論や浮動小数のドライバ差はこれを壊すので隔離する。再生用の RNG 乱数生成の初期値。 同じシードからは同じ乱数列が得られる。。
対応API
acs::game::FReplayMetadata::seed メンバー変数

API項目 3

u64 timestamp / u32 duration_ticks
説明
録画開始時刻 (Unix 秒) と総 tick 数 (停止時に確定)。
対応API
acs::game::FReplayMetadata::timestamp メンバー変数
対応API
acs::game::FReplayMetadata::duration_ticks メンバー変数

API項目 4

const char* player_name / const char* checksum_hex
説明
プ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ー名と全プレイヤーが同じ入力フレームを共有して同期する決定論シミュレーション方式。チェックサムの hex 文字列。
対応API
acs::game::FReplayMetadata::player_name メンバー変数
対応API
acs::game::FReplayMetadata::checksum_hex メンバー変数
