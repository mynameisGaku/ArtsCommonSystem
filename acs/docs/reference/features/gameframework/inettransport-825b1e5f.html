INetTransport

ネットワークの実体を抽象化する実装本体を切り離して差し替え可能にする「継ぎ目」。 インターフェースだけを置き、具象は別モジュールで注入する。 テストや SDK 隔離に使う。。 IBackendClient で送信先(サーバや出力ファイル)を開いて通信を始めること。 終了時は Disconnect。 / Disconnect / Send / Receive 等の最小 ライブラリの機能を外から使うための窓口(関数や型の取り決め)。 例: ネットワークは WinSock をくるんだ薄い API として提供される。 だけを切り、相手と接続を張り、順序どおり・確実にデータを届ける通信方式。 取りこぼしが許されない用途向け。 関連語 UDP。/接続を張らずデータグラムを 1 通ずつ送る通信方式。 速いが到達・順序は保証されない。 関連語 TCP。/Valve のゲーム配信プラットフォーム。 実績・フレンド・クラウドセーブ等の機能を Steamworks SDK 経由で使える。 Datagram/loopback fake を派生で差し込む。

使う場面

CNetSnapshot に socket を差し替えたい時。 Send/Receive は非ブロッキングでメッセージ境界を保持する契約。
