ACS 機能 / gameframework

FWaterVolumeInfo

水域 1 つの幾何 + パラメータ。 中心 / 半サイズ・水中の物体を上向きに押し上げる力。 ACS では水深 × 強さ × 質量の簡易モデルで近似する。強度・水中で速度に逆らう減速力(-velocity × drag)。 水の粘性的な抵抗を表す。・水面 y・水色を持ち、AddVolume / UpdateVolume に値渡しします。

構造体
対応するAPI: acs::game::FWaterVolumeInfo

使う場面

水域を 1 つ定義する時。

API項目

API項目 1

FVec2 center / FVec2 half_size
説明
Axis-Aligned Bounding Box。 軸に平行な直方体の境界ボックス。 当たり判定の粗い包囲に使う。 の中心 / 半サイズ(world)。
対応API
acs::game::FWaterVolumeInfo::center メンバー変数
対応API
acs::game::FWaterVolumeInfo::half_size メンバー変数

API項目 2

f32 buoyancy_strength / f32 drag
説明
水中の物体を上向きに押し上げる力。 ACS では水深 × 強さ × 質量の簡易モデルで近似する。強度(重力相当) / 水中水中で速度に逆らう減速力(-velocity × drag)。 水の粘性的な抵抗を表す。係数。
対応API
acs::game::FWaterVolumeInfo::buoyancy_strength メンバー変数
対応API
acs::game::FWaterVolumeInfo::drag メンバー変数

API項目 3

f32 surface_y
説明
水面 y 座標(+Y=画面下なので水面が最小 y)。 center.y - half_size.y が自然値。
対応API
acs::game::FWaterVolumeInfo::surface_y メンバー変数

API項目 4

FVec3 water_color
説明
実際に画面へ絵を出す描画システム本体。が水面画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。に使う色(linear RGB)。
対応API
acs::game::FWaterVolumeInfo::water_color メンバー変数

使用例

FWaterVolumeInfo info{
    /*center=*/{0,50}, /*half=*/{200,50},
    /*buoyancy=*/9.8f, /*drag=*/2.0f,
    /*surface_y=*/0.0f, /*color=*/{0.1f,0.3f,0.6f} };
