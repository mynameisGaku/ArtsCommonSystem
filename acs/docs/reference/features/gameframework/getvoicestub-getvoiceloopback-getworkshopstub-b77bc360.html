GetVoiceStub / GetVoiceLoopback / GetWorkshopStub

各プラットフォーム固有 SDK との結合点を抽象化した純粋仮想インターフェース。 ゲーム側はこれ越しに呼び、実装をビルド時に差し替える。の既定実装を返す static プロセス内に 1 個だけ存在するインスタンス。 XR ランタイムのように 1 接続前提のものに使う。 アクセサ。 実 SDK を Dependency Injection(依存性注入)。 使う実装を外から差し込み、呼び出し側を具体実装に依存させない設計。 CScriptHost は VM を差し替え可能にする。 する前でも、これらを使うだけでコンパイル / 動作させられます。
