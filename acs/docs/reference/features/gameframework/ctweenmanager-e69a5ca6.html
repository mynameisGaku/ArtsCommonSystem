CTweenManager

変数をなめらかに変化させるある値を一定時間かけて始点から終点へなめらかに変化させる仕組み。 イージングで変化カーブを指定する。管理。 値(32bit の浮動小数(float 相当)。 座標・時間・係数など小数値に使う基本型。 / 2 次元ベクトル(x, y)。 2D の位置・速度・方向を表す基本型で、8 バイトと小さい。 / 3 次元ベクトル(x, y, z)。 3D の位置・方向・色などに使う最重要型で、SIMD演算に最適化されている。)のメモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。を渡すと、毎 Tick で from→to をトゥイーンの加減速カーブ。 Linear(等速)や InOutSine(ゆっくり始まりゆっくり終わる)など。2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。して書き込んでくれます。 あとで呼んでもらうために登録しておく関数。 ACS では関数ポインタ + void* ユーザーデータの形を取る(STL 不依存方針)。不要なのが特徴。

クラス
対応するAPI: acs::game::CTweenManager

使う場面

色・位置・透明度などを一定時間でフワッと変えたい時(フェード、ポップアップ、視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。寄せなど)。

API項目 1

FTweenHandle Tween(f32* target, f32 from, f32 to, f32 duration, Easing::EasingFn ease = Easing::Linear)
説明
32bit の浮動小数(float 相当)。 座標・時間・係数など小数値に使う基本型。 変数を from→to へ duration 秒で2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。する。 duration<=0 は即時設定、target が null は 何もしない処理。 呼んでも安全で副作用が無いこと。。
戻り値
ある値を一定時間かけて始点から終点へなめらかに変化させる仕組み。 イージングで変化カーブを指定する。 実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。
使う場面
1 つのスカラー値を時間2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。したい時。

API項目 4

void Cancel(FTweenHandle h)
説明
進行中のある値を一定時間かけて始点から終点へなめらかに変化させる仕組み。 イージングで変化カーブを指定する。を中止する(target は最後に書いた値で止まる)。 古い実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。は無視。

対応API

API項目 5

void CompleteAll()
説明
全ある値を一定時間かけて始点から終点へなめらかに変化させる仕組み。 イージングで変化カーブを指定する。を即終了させ、target に完了値 to を書く。
使う場面
タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。終了時に確実に最終オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。へ揃えたい時。
対応API

API項目 8

void Tick(f32 dt)
説明
毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。呼ぶ。 全ある値を一定時間かけて始点から終点へなめらかに変化させる仕組み。 イージングで変化カーブを指定する。を dt ぶん進めて target に書き込む。
対応API
acs::game::CTweenManager::Tick メンバー関数

API項目 9

using FTweenManager = CTweenManager
説明
旧名を使う既存コード向けの互換別名。 新しいコードでは C値を時間で滑らかに補間する仕組み。 UI・カメラ・演出・シーン遷移に使う。Manager を使う。
対応API
acs::game::FTweenManager 型alias
overload候補
CTweenManager は複数の宣言に対応します。
  • acs::game::CTweenManagerclass CTweenManager;
  • acs::game::CTweenManager::CTweenManagerCTweenManager() noexcept = default;
  • acs::game::CTweenManager::CTweenManagerCTweenManager(const CTweenManager&) = delete;

使用例

CTweenManager tweens;
FVec3 color{0,0,0};
tweens.Tween(&color, FVec3{0,0,0}, FVec3{1,1,1}, 2.0f, Easing::InOutSine);
// 毎フレーム:
tweens.Tick(dt);
// color が 2 秒かけて白へ補間される
