CWeatherSystem::FKindParams

天候ごとの修飾パラメータ(環境光倍率 / 粒子密度 / 空色 / 風強さ / 霧密度)を 1 つにまとめた表。 各 getter が内部でこの表を参照します。

構造体

対応するAPI候補

  • acs::game::CWeatherSystemclass CWeatherSystem;
  • acs::game::CWeatherSystem::FKindParamsstruct FKindParams;

使う場面

天候パラメータの内部構造を理解する時(通常は getter 経由で十分)。
