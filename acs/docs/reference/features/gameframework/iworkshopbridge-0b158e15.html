IWorkshopBridge

Valve のゲーム配信プラットフォーム。 実績・フレンド・クラウドセーブ等の機能を Steamworks SDK 経由で使える。 ユーザー作成コンテンツ(UGC, MOD やマップ等)を配布・購読する Steam の仕組み。 / EOS User Generated Content。 ユーザーが作った MOD / ステージ等のコンテンツ。 Workshop 等で配布される。 / mod.io などのユーザー生成コンテンツ(User Generated Content。 ユーザーが作った MOD / ステージ等のコンテンツ。 Workshop 等で配布される。)対象とする機種/環境の種別。 ここでは Meta Quest や Valve Index など XR 機器の系統。へ橋渡しするプラットフォーム固有 SDK との結合点を抽象化した純粋仮想インターフェース。 ゲーム側はこれ越しに呼び、実装をビルド時に差し替える。(純粋仮想実装を差し替えられるようにするための約束事(純粋仮想クラス)。 I で始まる。)。 MOD の公開・値や配列の変化を受け取るためにコールバックを登録すること(Subscribe)。 要らなくなったら解除(Unsubscribe)する。・ダウンロードを、使う SDK をビルド時に差し替えながら扱えます。

インターフェース
対応するAPI: acs::game::IWorkshopBridge

使う場面

MOD やステージ共有などの User Generated Content。 ユーザーが作った MOD / ステージ等のコンテンツ。 Workshop 等で配布される。 機能を載せたいが、配信対象とする機種/環境の種別。 ここでは Meta Quest や Valve Index など XR 機器の系統。の SDK を後で差し替えたい時。

API項目 9

説明
ダウンロード進捗を返す。 完了 / 未開始 / 不明は -1。 状態を必要なタイミングで自分から問い合わせる方式。 CInput::IsKeyDown はその瞬間の押下状態を返す。前提。
戻り値

使う場面

API項目 10

virtual void Tick(f32 dt)
説明
毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。呼ぶ。 Valve のゲーム配信プラットフォーム。 実績・フレンド・クラウドセーブ等の機能を Steamworks SDK 経由で使える。ライブラリの機能を外から使うための窓口(関数や型の取り決め)。 例: ネットワークは WinSock をくるんだ薄い API として提供される。_RunCallbacks 相当の『× ボタンが押された』『キーが押された』のような、その瞬間に起きた出来事の通知。 ACS では FEvent として届く。ポンプを回す。
対応API
acs::game::IWorkshopBridge::Tick メンバー関数
