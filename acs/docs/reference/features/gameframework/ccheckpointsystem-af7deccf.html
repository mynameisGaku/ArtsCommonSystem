CCheckpointSystem

プラットフォーマー等のチェックポイント (復活ポイント) を管理するある種類の状態 (cooldown / チェックポイント / カード等) をまとめて持ち、登録・更新・問い合わせの API を提供する小さなクラス。。 配置済み checkpoint を id で識別し、現在 active な 1 つを保持。 死亡時に TriggerRespawn() で復活先の座標と level index を引き出す。

クラス
対応するAPI: acs::game::CCheckpointSystem

使う場面

「死んだら直近のチェックポイントに戻る」を実装する時。 HP コンポーネントを持つエンティティ群を毎フレーム処理する関数(移動・AI など)。 CSystemScheduler で順に実行する。の死亡 ある出来事が起きた時に呼んでもらう関数。 から TriggerRespawn を叩くのが定番。
