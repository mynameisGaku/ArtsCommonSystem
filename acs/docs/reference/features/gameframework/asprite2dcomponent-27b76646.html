ASprite2DComponent

2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。 に付ける2D の 1 枚絵(キャラ・アイコン等)。 矩形にテクスチャを貼って描く。画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。ANode に付ける部品。 1 つの機能 (物理・描画・当たり判定など) を担い、組み合わせて挙動を作る。。 色付き矩形やテクスチャを描く。 サイズはワールド単位で、位置 / 回転 / 拡縮は親の 2D の位置 / 回転 / スケールを表す値型。 が供給する。

クラス
対応するAPI: acs::game::ASprite2DComponent

使う場面

2D のキャラ・背景・UI 部品など、1 枚の四角い絵を表示したい時の基本部品。

API項目 5

void SetUvRect(f32 u0, f32 v0, f32 u1, f32 v1)
説明
テクスチャ内の表示矩形を指定。 2D の 1 枚絵(キャラ・アイコン等)。 矩形にテクスチャを貼って描く。シートの 1 コマを切り出す。
使う場面
アニメ用に スプライトの UV 矩形を毎フレーム書き換えてスプライトシートアニメ(コマ送り)を再生するコンポーネント。 が毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。書き換える。
overload候補
SetUvRect は複数の宣言に対応します。
  • acs::game::ASprite2DComponent::SetUvRectvoid SetUvRect(f32 u0, f32 v0, f32 u1, f32 v1) noexcept;
  • acs::game::ASprite2DComponent::SetUvRectvoid SetUvRect(FVec4 uv) noexcept;
