CInventorySystem

「N 個の固定スロット × 関数の呼び出しに沿って自動で確保/解放される高速なメモリ。 寿命はスコープに縛られる。可能アイテム」モデルのインベントリ管理。 RPG / サバイバル / クラフト系で定番の持ち物画面のロジックを直接提供する。

クラス
対応するAPI: acs::game::CInventorySystem

使う場面

拾った/報酬で得たアイテムをプ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ーが持ち歩くオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。を管理したい時。 即時購入は CEconomyDirector、装着 cosmetic は キャラの見た目(cosmetic)だけを slot 単位で着せ替えするマネージャ。 戦闘性能はいじらない設計。 と役割分担。

void Init(u32 slot_count = 30)
説明
スロット数を設定 (固定長)。 数が変わると内容クリアして resize、同数なら 何もしない処理。 呼んでも安全で副作用が無いこと。。

使用例

CInventorySystem inv;
inv.Init(/*slot_count=*/30);
inv.RegisterItem({ "potion.heal", "Heal Potion",
    EItemCategory::Consumable, 99, "ui/potion.png", true });
inv.AddItem("potion.heal", 5);  // 積み増し優先
inv.MoveSlot(3, 7);             // ドラッグ&ドロップ
inv.DropSlot(7);
