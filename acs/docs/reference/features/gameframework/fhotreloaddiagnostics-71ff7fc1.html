FHotReloadDiagnostics

1 watcher の通知1 回の描画方式(VS+PS・頂点レイアウト・ブレンド・深度等)を丸ごと固めたオブジェクト。 PSO とも。を観測する allocation-free 診断 ある時刻の世界全体の状態を 1 つに固めたもの。 server がこれを配信し、client は受信した複数 snapshot を補間して表示する (FPS/MMO 系で標準)。。 全 counter は 64bit の符号なし整数(0 以上)。 サイズ・ハンドル・大きな個数などに使う基本型。 最大値で飽和し、last_failure と authoritative rescan 要求は ClearDiagnostics まで sticky。

構造体
対応するAPI: acs::game::FHotReloadDiagnostics

使う場面

通知欠落を正常 tick で見失わず、監視ダッシュボード、ログ、復旧処理から rescan 要否を判断する時。 Shipping shell では storage を持たず同じ入力なら必ず同じ結果になる性質。 乱数や時刻に依存せず、テストや再現がしやすい。なゼロ値を返す。

API項目 4

EHotReloadResult last_failure
説明
enqueue・native poll・dispatch で実際に最後に観測した非 Success 結果。 TryTick の代表返却値に使う優先度集約では上書きせず、成功でも消さない。
対応API
acs::game::EHotReloadResult 列挙型
対応API
acs::game::FHotReloadDiagnostics::last_failure メンバー変数

API項目 5

bool authoritative_rescan_required
説明
true ならディスクや asset DB などのほかの表現を照合または再生成する基準データです。から全量再走査が必要。
対応API
acs::game::FHotReloadDiagnostics::authoritative_rescan_required メンバー変数
