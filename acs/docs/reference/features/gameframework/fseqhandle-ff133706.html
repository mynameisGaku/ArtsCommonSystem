FSeqHandle

複数の FSequence を同時に再生・管理する実行係。 Start で所有して走らせ、毎フレーム Tick で進める。 で再生中の 1 本の時間順に処理を並べて演出やイベントを組み立てる仕組み。を指す実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。。 index と generation を持ち、使い回しスロットの取り違えを防ぐ。
