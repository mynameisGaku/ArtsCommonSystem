CCombatStateMachine

タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。全体の戦闘ターン進行の局面(プレイヤーの番 / 敵の番など)。 ETurnPhase で表す。を 6 オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。 (Peaceful / Alert / Engaged / BossFight / Victory / Retreat) の決められた状態のどれか 1 つにいて、入力で別の状態へ遷移する仕組み (state machine)。 戦闘フェーズ管理などに使う。で追跡するディレクタ。 敵検出・戦闘開始・ボス出現などを notify するとオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。が遷移し、連続値の ThreatLevel() [0,1] も出す。
