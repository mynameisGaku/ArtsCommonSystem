EWidgetKind

シーンに数個のボタン/テキストを貼り付けるための薄い UI 層。 シーンのライフサイクルに合わせて呼ぶだけで最小 UI が作れる。 が扱う widget の種類。 現状はボタンとテキストのみ。

列挙(enum)
対応するAPI: acs::game::EWidgetKind

使う場面

FUI 部品の総称。 ACS の実型 AWidget は子を TUniquePtr で所有してツリーを作り、配置・描画・クリック判定・入力の仮想メソッドを持つ。Entry の種別を判定する時。
