CSceneTimer

タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。スコープの必要になるまで計算を先延ばしにする方式(lazy)。 現行 TDerived は生成時と依存通知時に即時評価し、Get の再計算は dirty が残った場合の補完経路。あとで呼んでもらうために登録しておく関数。 ACS では関数ポインタ + void* ユーザーデータの形を取る(STL 不依存方針)。。 SetTimeout/SetInterval で『何秒後に』『何秒ごとに』関数を呼ぶ。 タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。が死ぬと自動で破棄されるのがグローバルな時間を計る仕組み。 ACS では CClock（経過時間）と FFrameTimer（フレーム間 dt）。ーとの違い。

クラス
対応するAPI: acs::game::CSceneTimer

使う場面

敵を一定間隔で湧かせる、数秒後に敵が波状にまとまって出現する単位。 倒しきると次の波へ進む。 CWaveSpawner が管理する。を終わらせる、など時間ベースの処理を書く時。

説明
毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。呼ぶ。 大きい dt では Interval が同ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。で複数回発火し得る。
