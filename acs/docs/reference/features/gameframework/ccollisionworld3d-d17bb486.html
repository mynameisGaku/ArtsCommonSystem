CCollisionWorld3D

world 空間の Axis-Aligned Bounding Box。 軸に平行な直方体の境界ボックス。 当たり判定の粗い包囲に使う。 / sphere を再利用される番号(ID)に付ける通し番号。 古いハンドルと新しい中身を取り違えないための目印。付き handle で明示管理する 画像処理に特化した演算装置。 描画はここで行われる。 非依存の 3D query core。 登録 slot 順の同じ入力なら必ず同じ結果になる性質。 乱数や時刻に依存せず、テストや再現がしやすい。な overlap・raycast・sphere sweep・penetration query を提供し、scene や固定 tick を暗黙には所有しない。

クラス
対応するAPI: acs::game::CCollisionWorld3D

使う場面

3D gameplay の壁・床・trigger 候補を登録し、layer と自己除外を使って処理が終わるまでその場で待つやり方。 結果がすぐ手に入る代わりに止まる。的に問い合わせたい時。
