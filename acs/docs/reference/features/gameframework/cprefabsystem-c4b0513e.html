CPrefabSystem

名前付きの 2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。 ツリー型を後から指定できる部品。 TArray<int> は『int の配列』というように中身の型を差し替えられる。 (Prefab) をオブジェクトを組み立てて返す関数。 Prefab ではこの関数を登録しておき、必要な時に呼んで実体を作る。として登録し、ID か名前から TObjectPtr<2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。> を生成 (spawn) する軽量読み込んだアセットをキー(FAssetId)で保持・共有し、再利用する管理表。 ACS では CAssetRegistry。。 組み立て済みのゲーム世界に置く部品の単位。 位置やコンポーネントを持ち、親子のツリーで並ぶ。構成をファイルではなく関数で表現する。

クラス
対応するAPI: acs::game::CPrefabSystem

使う場面

「敵」「コイン」「弾」などの組み立て済みオブジェクトを 1 度登録しておき、ゲーム中に何度も spawn したい時。

使用例

static TObjectPtr<ANode> SpawnEnemy(void*) noexcept {
    auto n = NewObject<ANode>();
    // 子ノード / コンポーネントを組み立てる
    return n;
}
FPrefabSystem prefabs;
FPrefabId id = prefabs.Register("Enemy", &SpawnEnemy);
auto a = prefabs.Spawn(id);
auto b = prefabs.SpawnByName("Enemy");
