CEntitlementRegistry

プ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ーが DLC・シーズンパス・コスメパック・引換コードなどのプレイヤーがコンテンツを「持っているか」を表す情報 (entitlement)。 DLC・シーズンパス・引換コード等。 (entitlement) を「持っているか」をゲーム側から問い合わせる窓口。 ストアやSteam や各家庭機が提供する、実績・課金・マッチング等を扱う公式ライブラリ。 には依存せず、取得結果を Add() で流し込んでもらう設計。
