CSpatialAudio

3D 音源 (3D 空間内の音源 1 個 (位置 / 音量 / 減衰)。) と聞き手 1 つ (音を聞く側 (プレイヤーの耳) の位置と向き。) から、距離減衰と左右音を左右どちらのスピーカーへ振るか。 -1=左 / 0=中央 / +1=右。を計算する音の空間化当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。。 頭部伝達関数。 耳の形状による音の変化を畳み込んで、ヘッドホンで方向感のある立体音響を作る技術。 本格化は モノラルをステレオへ空間化する処理の抽象インターフェース。 として差し替え可能。

クラス
対応するAPI: acs::game::CSpatialAudio

使う場面

敵や環境音を「位置によって遠近・左右に聞こえる」ようにしたい時。 各ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。に音量と音を左右どちらのスピーカーへ振るか。 -1=左 / 0=中央 / +1=右。を取り出してミキサに渡す。

使用例

CSpatialAudio sp;
sp.SetListener({{0,0,0}, {0,0,1}, {0,1,0}});
u32 src = sp.RegisterSource({5,0,3}, 20.0f, EAttenuationCurve::Linear);
sp.UpdateSource(src, enemy.WorldPos());
f32 vol = sp.ComputeAttenuatedVolume(src);
f32 pan = sp.ComputePan(src);
