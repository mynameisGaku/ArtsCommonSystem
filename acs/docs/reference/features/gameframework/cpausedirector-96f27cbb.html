CPauseDirector

ゲーム全体の pause オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。を一元管理する director。 pause 理由を各 bit に意味を割り当て、OR で複数の状態を 1 個の整数にまとめて持つ手法。 pause 理由や同意カテゴリの複合表現に使う。(EPauseReason) の OR で持ち、「全部の理由が 0 になるまで pause を続ける」関数の呼び出しに沿って自動で確保/解放される高速なメモリ。 寿命はスコープに縛られる。的な挙動にすることで、「メニュー閉じたらフォーカス喪失中なのに動き出した」系のバグを防ぐ。

クラス
対応するAPI: acs::game::CPauseDirector

使う場面

メニュー表示・OS メニュー・フォーカス喪失・カットタイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。など複数の pause 理由が同時に起きうるゲームで、安全に pause/resume したい時。

API項目 1

void Pause(EPauseReason reason)
説明
指定理由の bit を立てる (OR、複合可)。 新たに立った bit ごとに ある出来事が起きた時に呼んでもらう関数。 が paused=true で呼ばれる。

対応API

API項目 2

void Resume(EPauseReason reason)
説明
指定理由の bit を落とす。 実際に落ちた bit ごとに ある出来事が起きた時に呼んでもらう関数。 が paused=false で呼ばれる。
対応API

対応API

void Clear()

説明

pause 解除時に戻る scale。 スローモーション演出 (0.5x など) と pause を直交管理。 負値は 0 に clamp。

使用例

CPauseDirector pause;
pause.Pause(EPauseReason::UserMenu);
game.SetTimeScale(pause.EffectiveTimeScale());   // 0.0f
pause.Pause(EPauseReason::SystemMenu);
pause.Resume(EPauseReason::UserMenu);            // まだ SystemMenu が残る
game.SetTimeScale(pause.EffectiveTimeScale());   // まだ 0.0f
pause.Resume(EPauseReason::SystemMenu);
game.SetTimeScale(pause.EffectiveTimeScale());   // 1.0f に復帰
