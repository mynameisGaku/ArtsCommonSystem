IMlRuntime

ML 学習済みモデルに入力を与えて出力(予測・分類など)を計算すること。 学習(training)ではなく実行(inference)の側。ランタイム (Microsoft 製の、ONNX モデルを実際に実行する推論エンジン。 mlonnx が裏で使う backend。 / DirectML / NNライブラリの機能を外から使うための窓口(関数や型の取り決め)。 例: ネットワークは WinSock をくるんだ薄い API として提供される。 / CoreML / TFLite) を差し替えるための抽象実装本体を切り離して差し替え可能にする「継ぎ目」。 インターフェースだけを置き、具象は別モジュールで注入する。 テストや SDK 隔離に使う。。 全メソッドは同じ入力なら必ず同じ結果になる性質。 replay / netcode / record-replay の同期で必須。 ML 推論や浮動小数のドライバ差はこれを壊すので隔離する。ゾーンの外で呼ばれる前提。

インターフェース
対応するAPI: acs::game::IMlRuntime

使う場面

AI/ML 学習済みモデルに入力を与えて出力(予測・分類など)を計算すること。 学習(training)ではなく実行(inference)の側。をゲームに組み込みたいが、再現性が保証されない計算を sim/物理に混ぜたくない時。 具象 インターフェースの裏で実際に仕事をする具象実装。 ここでは OpenXR ローダ等の XR 実装本体。 は別モジュールで差し込む。

API項目 4

virtual TResult<void> RunInference(FMlModelHandle h, const f32* in, u32 in_n, f32* out, u32 out_n) noexcept = 0
説明
学習済みモデルに入力を与えて出力(予測・分類など)を計算すること。 学習(training)ではなく実行(inference)の側。を 1 回実行 (ブロッキング)。 in/out はcaller確保の 32bit の浮動小数(float 相当)。 座標・時間・係数など小数値に使う基本型。 配列、個数はモデルと一致必須。

使用例

IMlRuntime& ml = GetDefaultMlRuntime();
if (ml.Init().IsOk()) {
    auto h = ml.LoadModel("npc.onnx");
    if (h.IsOk()) ml.RunInference(h.Value(), in, n, out, m);
}
