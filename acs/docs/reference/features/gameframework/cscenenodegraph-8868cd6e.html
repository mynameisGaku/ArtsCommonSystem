CSceneNodeGraph

scene文脈から独立してroot node treeと再利用される番号(ID)に付ける通し番号。 古いハンドルと新しい中身を取り違えないための目印。付きpoolを所有し、構造更新、検索、3D bounds queryを提供するgraph。

クラス
対応するAPI: acs::game::CSceneNodeGraph

使う場面

scene、checked loader、editor stagingで同じnode graph操作を使う時。
