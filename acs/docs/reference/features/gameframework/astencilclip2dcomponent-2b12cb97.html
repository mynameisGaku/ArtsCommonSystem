AStencilClip2DComponent

任意形状のステンシルバッファを使い、任意形状で描画範囲を切り抜く手法。で子ツリーをクリップするANode に付ける部品。 1 つの機能 (物理・描画・当たり判定など) を担い、組み合わせて挙動を作る。。 attach したゲーム世界に置く部品の単位。 位置やコンポーネントを持ち、親子のツリーで並ぶ。の子を、指定形状の内側 (既定) か外側だけに切り抜いて描く。 GPU 上で頂点やピクセルを計算する小さなプログラム。 ACS では HLSL で書く。不要で 多数のスプライトをまとめて効率よく描画する仕組み。 のピクセルごとの整数マスク。 任意形状の描画範囲制限(くり抜き)に使う。モードを使う。

API項目 3

void SetRef(u8 ref)
説明
ネスト用のピクセルごとの整数マスク。 任意形状の描画範囲制限(くり抜き)に使う。参照値 (1..255)。 入れ子どのレイヤに反応するかをビットで指定する絞り込み。 立っているビットの相手だけが対象になる。は別値にする。
