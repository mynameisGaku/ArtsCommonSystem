ALegacyScene3DAdapter

旧scene 3D入口を現行scene lifecycle、固定tick自由cameraキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。、画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。、rollback ある時刻の世界全体の状態を 1 つに固めたもの。 server がこれを配信し、client は受信した複数 snapshot を補間して表示する (FPS/MMO 系で標準)。、任意の障害物回避へ接続する互換object。

クラス
対応するAPI: acs::game::ALegacyScene3DAdapter

使う場面

旧scene実装を段階的に移行する時。
