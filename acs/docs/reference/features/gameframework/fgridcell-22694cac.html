FGridCell

セル 1 個のオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。。 色 (1..color_count、0=空) ・special 種別 (ESpecialKind の u8 値) ・空ON/OFF を表す印。 ここでは暗号化/圧縮の有無。。
