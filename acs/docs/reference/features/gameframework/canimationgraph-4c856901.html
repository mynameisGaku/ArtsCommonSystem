CAnimationGraph

3D スケルトンアニメ向けの「状態」と「状態間の遷移」で動きを記述する仕組み。 Idle→Walk→Jump のようにキャラの挙動管理に使う。型ブレンドグラフ。 「どの clip を / いつから / どの blend 比率で再生するか」を制御する。 実際のスキンメッシュを動かす骨。 階層を組み、頂点がこれに追従して変形する。計算や画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。は呼出側に任せ、本クラスは clip index と blend alpha を提供する。

クラス
対応するAPI: acs::game::CAnimationGraph

使う場面

状態機械の「何もしていない/開始前」を表す既定状態。 Idle→Walk のように、ここから他状態へ遷移する。/Walk/Run/Jump などキャラのオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。に応じてアニメを切り替え、オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。間を滑らかにブレンドしたい時。

使用例

CAnimationGraph g;
g.Init();
u32 idle = g.AddClip({ "Idle", 2.0f, true, 1.0f });
u32 walk = g.AddClip({ "Walk", 1.2f, true, 1.0f });
g.AddStateNode({ "Idle", EAnimationGraphState::Idle, idle, 0.15f, 0.15f });
g.AddStateNode({ "Walk", EAnimationGraphState::Walk, walk, 0.15f, 0.15f });
g.AddTransition({ EAnimationGraphState::Idle, EAnimationGraphState::Walk, 0.1f, "speed", false });
// 毎フレーム:
g.SetParam("speed", current_speed);
g.Tick(dt);
