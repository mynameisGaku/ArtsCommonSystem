FProjectileId

弾 1 発を指す軽量実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。。 24bit の頂点配列のどの点で三角形を作るかを示す番号の列。 同じ頂点を使い回せる。 + 8bit のハンドルに埋め込む小さなカウンタ。 スロット再利用後に古い参照を検出するために使う。を u32 に詰めたもの。 スロット再利用後の対象の破棄や再利用によって無効になった参照です。を検出できる。
