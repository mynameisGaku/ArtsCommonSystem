FEventId

『× ボタンが押された』『キーが押された』のような、その瞬間に起きた出来事の通知。 ACS では FEvent として届く。識別子。 文字列リテラルから文字列をコンパイル時に数値へ変換する手法。 実行時の文字列比較を避けて高速化する。 (FNV-1a) で u32 を生成する。 実行時の文字列比較なしで高速。
