LapCallback / FinishCallback

ラップ完了 / レース完了 (total_laps 到達) の通知あとで呼んでもらうために登録しておく関数。 ACS では関数ポインタ + void* ユーザーデータの形を取る(STL 不依存方針)。型。 どちらも void* user + FRacerId + 詳細を受ける。

関数ポインタ型

対応するAPI候補

  • acs::game::LapCallbackusing LapCallback = void(*)(void* user, FRacerId id, u32 lap, f32 lap_time, bool is_personal_best) noexcept;
  • acs::game::FinishCallbackusing FinishCallback = void(*)(void* user, FRacerId id, f32 final_time, u32 final_position) noexcept;

使う場面

SetOnLapCallback / SetOnFinishCallback に渡す関数の型。
