ACS 機能 / gameframework

FInputSample

1 tick 分の生キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。サンプル (Plain Old Data。 コンストラクタ等の特別な振る舞いを持たない単純な構造体。 コピーが速く扱いやすい。)。 オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。変化したキー (最大 8) + マウス座標 + マウスボタン bitmask を持つ。

構造体
対応するAPI: acs::game::FInputSample

使う場面

OS の raw input / SDL 『× ボタンが押された』『キーが押された』のような、その瞬間に起きた出来事の通知。 ACS では FEvent として届く。を詰めて Capture に渡す時、または再生で受け取る時。

API項目

API項目 1

u32 tick
説明
ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。番号 (0 起点)。
対応API
acs::game::FInputSample::tick メンバー変数

API項目 2

u8 key_codes_changed[8] / u8 key_states[8]
説明
オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。変化したキーコードと、その press(1)/release(0)。 未使用枠は 0。
対応API
acs::game::FInputSample::key_codes_changed メンバー変数
対応API
acs::game::FInputSample::key_states メンバー変数

API項目 3

FVec2 mouse_pos
説明
マウス位置 (window-local px)。
対応API
acs::game::FInputSample::mouse_pos メンバー変数

API項目 4

u8 mouse_button_states
説明
マウスボタン bitmask (L=bit0, R=bit1, M=bit2 ...)。
対応API
acs::game::FInputSample::mouse_button_states メンバー変数

使用例

FInputSample s;
s.tick = m_Tick;
s.mouse_pos = { mx, my };
s.mouse_button_states = mask;
