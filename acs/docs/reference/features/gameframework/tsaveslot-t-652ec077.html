TSaveSlot<T>

1 個の Plain Old Data。 コンストラクタ等の特別な振る舞いを持たない単純な構造体。 コピーが速く扱いやすい。 構造体を 1 ファイルに保存/復元するセーブスロット。 タイトル画面の continue 判定やオプション設定、進捗データの土台。

クラステンプレート
対応するAPI: acs::game::TSaveSlot

使う場面

プ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ープロフィールや設定など、固定各ウィジェットを画面のどこにどの大きさで置くかを決めて配置すること。 Layout で行う。のデータを手軽に保存したい時。

説明

使用例

struct FProfile { acs::u32 hi_score; acs::f32 volume; };
FProfile profile{};
TSaveSlot<FProfile> slot;
slot.Init(L"user/profile.acssave");
if (slot.Exists()) { auto r = slot.Load(); if (r) profile = r.Value(); }
slot.Save(profile);
