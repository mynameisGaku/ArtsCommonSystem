CUdpTransport

INetTransport の実 Winsock2 接続を張らずデータグラムを 1 通ずつ送る通信方式。 速いが到達・順序は保証されない。 関連語 TCP。 実装。 1 Send = 1 sendto = 1 datagram、1 Receive = 1 recvfrom = 1 datagram でメッセージ境界保持の契約を満たす。

クラス
対応するAPI: acs::game::CUdpTransport

使う場面

実際に 接続を張らずデータグラムを 1 通ずつ送る通信方式。 速いが到達・順序は保証されない。 関連語 TCP。 で ある時刻の世界全体の状態を 1 つに固めたもの。 server がこれを配信し、client は受信した複数 snapshot を補間して表示する (FPS/MMO 系で標準)。 を送受信したい時。 loopback round-trip 検証済みの本実装 (stub ではない)。

API項目 2

TResult<void> Connect(const char* address, u16 port) noexcept override
説明
WSAStartup → 接続を張らずデータグラムを 1 通ずつ送る通信方式。 速いが到達・順序は保証されない。 関連語 TCP。 socket 生成 → 非ブロッキング化 → bind → remote endpoint 保持。
