FRacerId

レース参加者の実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。。 24bit index + 8bit ハンドルに付ける版番号。 スロットを再利用しても番号が変わるので、古いハンドルを「もう無効」と確実に弾ける。を packed した u32。 0 が無効。

構造体
対応するAPI: acs::game::FRacerId

使う場面

AddRacer の戻り値を保持し、通知や問い合わせに渡す。 スロット再利用後の古い実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。は再利用される番号(ID)に付ける通し番号。 古いハンドルと新しい中身を取り違えないための目印。不一致で弾かれる。
