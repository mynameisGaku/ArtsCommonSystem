APhysicsBody2D

自分で速度を持って動くが、他の物体から押し返されない物理ボディ。 剛体シミュレーションより軽く、プラットフォーマー等の自機向き。 な 2D 物理ボディのANode に付ける部品。 1 つの機能 (物理・描画・当たり判定など) を担い、組み合わせて挙動を作る。。 velocity + acceleration + gravity を統合し、CCollisionWorld2D に登録された他の形状とぶつかったら止まる / 滑る (壁にぶつかった時、止まるのではなく壁に沿って滑るように動く衝突応答。 キャラ移動の自然さに効く。)。 剛体ソルバではなく「2D プラットフォーマー / トップダウン用の swept 自分で速度を持って動くが、他の物体から押し返されない物理ボディ。 剛体シミュレーションより軽く、プラットフォーマー等の自機向き。」。

クラス (AComponent 派生)
対応するAPI: acs::game::APhysicsBody2D

使う場面

重力で落ちて床で止まる、壁に沿って滑る、といった素朴な 2D キャラ移動を 2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。 に付けたい時。 形状は円 / Axis-Aligned Bounding Box。 軸に平行な直方体の境界ボックス。 当たり判定の粗い包囲に使う。 / 多角形 / 有向境界ボックス（Oriented Bounding Box）。 回転を持てる矩形/直方体コライダー。 から選ぶ。

補足

公開フィールド: 2 次元ベクトル(x, y)。 2D の位置・速度・方向を表す基本型で、8 バイトと小さい。 velocity / acceleration / gravity (動力学)、bool slide (既定 true。 false で旧来の軸独立 block に切替)。

使用例

auto ball = NewObject<ANode>();
ball->SetPosition2D(FVec2{0, 5});
auto& body = ball->AddComponent<APhysicsBody2D>(Services().Physics());
body.SetCircle(0.5f);
body.gravity  = FVec2{0, 10};   // +Y=下
body.velocity = FVec2{1, 0};
root.AddChild(Move(ball));
