CDamageFeedback

プ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ー被弾時の視覚フィードバックを集中管理する純粋な state machine。 赤い被弾オーバーレイ・攻撃源を指す方向矢印・プレイヤーが死んだ瞬間に、致命傷を与えた相手をズームしながら映す演出カメラ。 の 3 要素を扱う。 自分では画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。も視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。操作もせず、画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。 / UI / 視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。層が値を pull する。

クラス

API項目

API項目 1

void TakeDamage(f32 amount, FVec2 source_direction = {})
説明
ダメージを受けたと通知。 赤エッジを累積加算し、source_direction (相手→自分) があれば矢印を更新する。 正規化は内部で行う。
使う場面
プ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ーが被弾した瞬間。
対応API
acs::game::CDamageFeedback::TakeDamage メンバー関数

API項目 2

void Tick(f32 dt)
説明
各エフェクトの decay を進める (赤エッジ・矢印は約 0.5 秒で消える)。 プレイヤーが死んだ瞬間に、致命傷を与えた相手をズームしながら映す演出カメラ。 progress も進める。
使う場面
毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。呼ぶ。
対応API
acs::game::CDamageFeedback::Tick メンバー関数

API項目 3

f32 ScreenEdgeRedIntensity() const
説明
画面端を赤く染める強度。 画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。 overlay が vignette に掛ける。
戻り値
[0,1]
対応API
acs::game::CDamageFeedback::ScreenEdgeRedIntensity メンバー関数

使用例

CDamageFeedback dmg;
void OnHit(f32 amount, FVec2 attackerPos) {
    dmg.TakeDamage(amount, player.Pos() - attackerPos);
    if (player.HP() <= 0) dmg.TriggerDeathCam(killerWorldPos);
}
void OnUpdate(f32 dt) { dmg.Tick(dt); }
// 描画: overlay.Apply(dmg.ScreenEdgeRedIntensity());
