CAudioDirector

タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。を跨いで生きる音声の指揮層。 Master/Bgm/Sfx の 3 段ボリューム、バックグラウンドミュージック。 場面の間ずっとループで流す音楽。 クロスフェード、SFX 連射、ある音を目立たせるため、一時的に別の音 (主に BGM) の音量を下げる手法。、Pause/Resume をまとめて扱う。 CAudioDirector から見た「実際に音を出す層」の純粋仮想インターフェース。 Windows では XAudio2 実装が差し込まれる。 を差すと実音が鳴り、無ければ無音のオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。管理だけ動く。

クラス
対応するAPI: acs::game::CAudioDirector
