ACS 機能 / gameframework

FSafetyResult

1 回の Validate / Filter 呼び出しの結果。 判定・フィルタ済みテキスト・拒否理由・概算トークン数。

構造体
対応するAPI: acs::game::FSafetyResult

使う場面

Validateキーボード・マウス・ゲームパッドの状態を問い合わせで読む静的クラス。 毎フレーム先頭で Update() を呼んでから状態を読む。 / FilterOutput の戻り値を受け取る時。 文字列は内部 static バッファを指すので、次の呼び出し前に中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。 or 消費すること。
