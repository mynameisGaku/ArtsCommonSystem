IBuildFarmBackend

ビルドファームを抽象化するプラットフォーム固有 SDK との結合点を抽象化した純粋仮想インターフェース。 ゲーム側はこれ越しに呼び、実装をビルド時に差し替える。。 「ビルド投入 → 状態を必要なタイミングで自分から問い合わせる方式。 CInput::IsKeyDown はその瞬間の押下状態を返す。で完了確認 → artifact URL 受け取り」のフローを提供する。 ビルド ID は不透明 64bit の符号なし整数(0 以上)。 サイズ・ハンドル・大きな個数などに使う基本型。。

インターフェース
対応するAPI: acs::game::IBuildFarmBackend

使う場面

ナイトリービルドや CI 並列実行する小さな仕事の単位。 依存関係を付けて CJobGraph で順序立てて走らせられる。をプログラムから投入・追跡したい時。
