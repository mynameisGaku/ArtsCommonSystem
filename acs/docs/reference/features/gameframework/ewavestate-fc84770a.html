EWaveState

敵が波状にまとまって出現する単位。 倒しきると次の波へ進む。 CWaveSpawner が管理する。進行のオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。を表す列挙。 値はセーブ / プレイの入力や状態を記録し、後で同じ進行を再生する仕組み。 決定論的な乱数と相性が良い。に書ける安定値です。

列挙(enum)
対応するAPI: acs::game::EWaveState

使う場面

現在 wave がどの段階かで UI / バックグラウンドミュージック。 場面の間ずっとループで流す音楽。 を分岐する時。
