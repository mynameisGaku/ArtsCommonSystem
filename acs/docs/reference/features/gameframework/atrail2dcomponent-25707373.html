ATrail2DComponent

owner ゲーム世界に置く部品の単位。 位置やコンポーネントを持ち、親子のツリーで並ぶ。を追従するモーショントレイル (残像) を描くANode に付ける部品。 1 つの機能 (物理・描画・当たり判定など) を担い、組み合わせて挙動を作る。。 過去の位置を FIFO で保持し、細くなる帯として描く。

クラス (コンポーネント)
対応するAPI: acs::game::ATrail2DComponent

使う場面

高速移動するキャラ・弾・剣閃に残像を付けたい時。

void SetPoints(u32 k)
説明
残像を構成する点数 (2〜48 に値を指定範囲内に収めること。 Saturate は 0〜1 に収める。)。 多いほど長く滑らか。
対応API

使用例

auto& t = node->AddComponent<ATrail2DComponent>();
t.SetColor({0.3f, 0.8f, 1.0f});
t.SetWidth(0.3f);
t.SetPoints(24);   // 残像の節の数 (2..48)
