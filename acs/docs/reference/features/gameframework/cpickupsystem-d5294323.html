CPickupSystem

世界に転がっている「拾える物」(HP オーブ / コイン / ジェム / 弾薬 / パワーアップ / 鍵) を管理する小型ある種類の状態 (cooldown / チェックポイント / カード等) をまとめて持ち、登録・更新・問い合わせの API を提供する小さなクラス。。 プ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ー位置との距離で磁石効果 (引き寄せ)・拾取判定・寿命切れ消滅を 1 つの Tick でまとめて処理する。

使用例

CPickupSystem ps;
ps.Init();
FPickupInfo info{};
info.kind = EPickupKind::Coin;
info.world_pos = {100, 50};
info.radius = 12.0f;
info.magnet_radius = 80.0f;
info.value = 5;
FPickupId id = ps.Spawn(info);
ps.SetOnPickupCallback(&OnPickup, user);
// 毎フレーム
ps.Tick(dt, player_pos, /*magnet_strength=*/200.0f);
