CDialogueScript

ノベル / アドベンチャー向けのタイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。スクリプト再生機。 「セリフ → ポートレート表示 → バックグラウンドミュージック。 場面の間ずっとループで流す音楽。 切替 → 会話などで提示する分岐の候補。 プレイヤーが選ぶと進行が分かれる。 → ジャンプ」を命令列 (FScriptOp[]) とラベルで宣言的に組む「状態」と「状態間の遷移」で動きを記述する仕組み。 Idle→Walk→Jump のようにキャラの挙動管理に使う。。 各命令はあとで呼んでもらうために登録しておく関数。 ACS では関数ポインタ + void* ユーザーデータの形を取る(STL 不依存方針)。で外部へ通知し、実際の画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。・音・キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。は呼び出し側が行う。

クラス
対応するAPI: acs::game::CDialogueScript

使う場面

VN (ビジュアルノベル) や『× ボタンが押された』『キーが押された』のような、その瞬間に起きた出来事の通知。 ACS では FEvent として届く。タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。を、台本のように命令列で書きたい時。

使用例

FScriptOp ops[] = {
  { EScriptOpKind::Background, "bg_room", nullptr },
  { EScriptOpKind::Say,        "アリス", "おかえり。" },
  { EScriptOpKind::EndScene },
};
script.LoadScript(ops, 3, "scene1");
script.SetOnSayCallback(&OnSay, this);
script.Start();
// 毎フレーム:
script.Tick(dt);
if (clicked) script.Advance();   // Say 後の入力待ちを解除
