FWaveDef

1 つの敵が波状にまとまって出現する単位。 倒しきると次の波へ進む。 CWaveSpawner が管理する。の定義。 ウェーブ内で「どの敵を・何体・どの間隔で・どこに」湧かせるかの 1 設定。 FSpawnRule。配列(呼び出し側所有)と、クリア後の小休止時間を持ちます。

構造体
対応するAPI: acs::game::FWaveDef

使う場面

AddWave に渡す 1 波分を組み立てる時。

使用例

waves.AddWave(wave);
