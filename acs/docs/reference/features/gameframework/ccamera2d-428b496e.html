CCamera2D

2D 視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。。 position/zoom/rotation、target 追従 (ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。レート非依存の指数 smoothing)、画面振動 (画面振動 (camera shake) の強さを表す [0,1] の連続値。 被弾などで加算し、毎フレーム減衰させる。 方式)、world↔screen 座標変換、移動範囲の clamp を持つ。 CSceneServices 経由で自動 Tick できる。

クラス
対応するAPI: acs::game::CCamera2D

使う場面

2D ゲームでプ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ー追従・ヒット時の画面振動・座標変換が欲しい時。

void SetTargetPos(FVec2 target_pos, f32 smoothing = 5.0f)
説明
追従先を毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。値で渡す (安定メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。不要)。 smoothing 大ほどキビキビ、0 以下で即スナップ。
使う場面
プ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ー位置に視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。を追わせる時。

使用例

CCamera2D cam;
cam.SetTargetPos(player.Position());  // 追従
if (player.JustHit()) cam.AddShake(0.5f); // 画面振動
// 毎フレーム自動 Tick (Services 経由) or 手動:
cam.Tick(dt);
FVec2 world = cam.ScreenToWorld(mouse, w, h);
