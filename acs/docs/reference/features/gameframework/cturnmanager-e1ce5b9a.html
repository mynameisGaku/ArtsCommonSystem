CTurnManager

ターン制の進行を管理する部品。 複数の陣営(side)を行動順(ターン制での行動順を決める値。 大きいほど先に行動できる。)で並べ、各陣営がアクションポイント。 ターン制で各陣営が 1 ターンに使える行動予算。 CTurnManager が管理する。(行動ポイント)予算で行動する、SRPG / ローグライク / 戦略系の定番ある種類の状態 (cooldown / チェックポイント / カード等) をまとめて持ち、登録・更新・問い合わせの API を提供する小さなクラス。です。

クラス
対応するAPI: acs::game::CTurnManager

使う場面

プ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ー→敵→環境の順に手番を回し、ターン制で全陣営が 1 巡する単位。 1 ラウンドの中に各陣営のターンが並ぶ。ごとに アクションポイント。 ターン制で各陣営が 1 ターンに使える行動予算。 CTurnManager が管理する。 を回復する、ターン制ゲームを作る時。

使用例

CTurnManager tm;
tm.Init();
auto p = tm.AddSide("Player", 3, 100, true);
auto e = tm.AddSide("Enemy",  2, 50,  false);
tm.StartRound();          // 全 side の AP 回復 + 行動順並べ替え
if (tm.TryConsumeAP(1)) { /* 行動した */ }
tm.EndCurrentTurn();      // 次 side へ (最後なら次ラウンド開始)
