CInspectorSeam

ゲーム内オブジェクトが自分のフィールドを公開するある機能 (ここではインスペクタ表示) に対してデータや実装を「供給する」側のオブジェクト。 インターフェースを実装して登録する。を集める「デバッグインスペクタの実装本体を切り離して差し替え可能にする「継ぎ目」。 インターフェースだけを置き、具象は別モジュールで注入する。 テストや SDK 隔離に使う。」。 UI 当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。 (Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 等) はここを回してフィールドを画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。/編集する。

クラス
対応するAPI: acs::game::CInspectorSeam

使う場面

実行中に Player の HP や速度を画面で覗いて書き換えたい時。 本体は読み込んだアセットをキー(FAssetId)で保持・共有し、再利用する管理表。 ACS では CAssetRegistry。だけで、実際の画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。は別当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。。 出荷ビルドでは登録ごと消す前提。
