CEconomyDirector

ゲーム内通貨の残高 + 固定価格のショップアイテム + 購入あとで呼んでもらうために登録しておく関数。 ACS では関数ポインタ + void* ユーザーデータの形を取る(STL 不依存方針)。をまとめた小型ある種類の状態 (cooldown / チェックポイント / カード等) をまとめて持ち、登録・更新・問い合わせの API を提供する小さなクラス。。 通貨は soft (ゲーム内獲得) と premium (課金) を区別でき、商品はゲームの性能に影響しない、見た目だけのアイテム (スキン・装飾)。 pay-to-win を避ける指針。専用ON/OFF を表す印。 ここでは暗号化/圧縮の有無。を持つ。 ガチャ (ランダム報酬) は意図的に非対応、すべて「払えば必ず指定の品が手に入る」固定価格方式。

クラス
対応するAPI: acs::game::CEconomyDirector

使う場面

見た目アイテムのショップやゲーム内通貨を実装したい時。 実際の課金トランザクションは別 (ストア層) で行い、ここはゲーム内売買のみ扱う。

使用例

CEconomyDirector ed;
ed.RegisterCurrency({ "gold", "Gold", false });  // soft 通貨
ed.SetBalance("gold", 1000);
ed.RegisterItem({ "skin.knight_red", "Red Knight", "gold", 500, ~0u, true });
if (ed.PurchaseItem("skin.knight_red")) {
    // 成功 → 残高 500 減、コスメ解放
}
