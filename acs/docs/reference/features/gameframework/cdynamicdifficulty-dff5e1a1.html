CDynamicDifficulty

プ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ーの実プレイ統計 (死亡 / 撃破 / リトライ / クリア時間 / パワーアップ取得) を追跡し、難易度を調整するDynamic Difficulty Adjustment。 プレイヤーの腕前に応じてゲーム難易度を自動で調整する仕組み。 (動的難易度調整)。 Easy/Normal/Hard/VeryHard の固定 4 段と、腕前から自動で寄せる Adaptive を持つ。 敵 HP・ダメージ・速度・プ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ー HP の乗数を返すので、戦闘ロジックが pull して使う。

クラス
対応するAPI: acs::game::CDynamicDifficulty

使う場面

下手なプ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ーには優しく、上手いプ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ーには手応えのある難易度に自動調整したい時。 Adaptive 以外は固定値なのでプレイの入力や状態を記録し、後で同じ進行を再生する仕組み。 決定論的な乱数と相性が良い。処理が終わるまでその場で待つやり方。 結果がすぐ手に入る代わりに止まる。にも使える。

API項目 7

説明
Easy=0.5、Normal=1.0、Hard=1.5、VeryHard=2.0です。 Adaptiveは4値を2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。します。

使用例

CDynamicDifficulty dda;
dda.Init(EDifficultyLevel::Adaptive);
// イベント発生時:
dda.RecordDeath(); dda.RecordRetry();
dda.RecordKill();
dda.RecordLevelComplete(/*time=*/45.0f);
// 毎フレーム:
dda.Tick(dt);
f32 hp_mul  = dda.EnemyHealthMultiplier();
f32 dmg_mul = dda.EnemyDamageMultiplier();
