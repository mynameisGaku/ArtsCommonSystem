CSaveArchive

低レベルなセーブファイル I/O。 任意の Plain Old Data。 コンストラクタ等の特別な振る舞いを持たない単純な構造体。 コピーが速く扱いやすい。 バイト列を .acssave 形式 (24 バイトヘッダ + ImGui のドラッグ & ドロップで運ばれるデータ本体。 ACS の CAssetBrowser では "ASSET_PATH" id で wchar_t* を渡す。 + データから計算する 32bit のチェック値。 破損や改竄の検出に使う。) で読み書きする。 TSaveSlot の土台。

クラス (static のみ)
対応するAPI: acs::game::CSaveArchive

使う場面

可変長データを扱いたい、型を後から指定できる部品。 TArray<int> は『int の配列』というように中身の型を差し替えられる。を介さず生バイトを保存したい時。 普通は TSaveSlot を使えば十分。
