IHrtfRenderer

モノラルキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。をステレオに空間化する処理の抽象実装を差し替えられるようにするための約束事(純粋仮想クラス)。 I で始まる。 (プラットフォーム固有 SDK との結合点を抽象化した純粋仮想インターフェース。 ゲーム側はこれ越しに呼び、実装をビルド時に差し替える。)。 本格的な 頭部伝達関数。 耳の形状による音の変化を畳み込んで、ヘッドホンで方向感のある立体音響を作る技術。 畳み込みを後から差し替えられる。

インターフェース

使う場面
