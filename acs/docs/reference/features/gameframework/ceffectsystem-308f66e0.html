CEffectSystem

画面演出の中央指揮塔。 Flash (全画面色被せ) / HitStop (一瞬の停止) / Camera Shake (画面揺れ) をまとめた純粋な描画や入力などの副作用を持たず、「今どういう状態か」だけを保持する型。 実際の描画・音・入力は呼び出し側が状態を見て行う。 テストしやすく結合が薄い。。 自身は画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。も停止もせず、画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。側・ゲームループ・視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。が「pull する」だけのバスとして働く。

クラス
対応するAPI: acs::game::CEffectSystem

使う場面

被弾時の「白フラッシュ + 一瞬停止 + 画面揺れ」のような手応え演出をまとめて出したい時。

API項目

API項目 1

void Flash(FVec3 color, f32 intensity, f32 duration)
説明
画面全体に色を被せて線形に減衰させる。 再呼出で常に上書き (累積しない)。
対応API
acs::game::CEffectSystem::Flash メンバー関数

API項目 2

void HitStop(f32 duration)
説明
duration 秒の間 IsHitStop() を true に。 重ねがけは長い方を採用。
使う場面
ヒット時の「タメ」を作る時。
対応API
acs::game::CEffectSystem::HitStop メンバー関数

API項目 3

void TriggerShake(f32 trauma, f32 duration_hint = 0.0f)
説明
画面揺れの 画面振動 (camera shake) の強さを表す [0,1] の連続値。 被弾などで加算し、毎フレーム減衰させる。 値を pending に積む。 同ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。複数呼出は最大値を保持。
対応API
acs::game::CEffectSystem::TriggerShake メンバー関数

API項目 4

void Tick(f32 dt)
説明
実時間 dt で全エフェクトの時間を計る仕組み。 ACS では CClock（経過時間）と FFrameTimer（フレーム間 dt）。を進める (hit stop 中も止めない)。
対応API
acs::game::CEffectSystem::Tick メンバー関数

API項目 5

f32 FlashIntensity() / FVec3 FlashColor()
説明
画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。側が overlay を被せるための現在の強度と色。
対応API
acs::game::CEffectSystem::FlashIntensity メンバー関数
対応API
acs::game::CEffectSystem::FlashColor メンバー関数

API項目 6

bool IsHitStop() / f32 HitStopRemain()
説明
停止中か / 残り停止時間。 ゲームループが 時間の流れる倍率。 1=通常、0=停止、>1=早送り、<1=スロー。 CSceneClock がこれを掛けて scaled な時間を作る。=0 を選ぶのに使う。
対応API
acs::game::CEffectSystem::IsHitStop メンバー関数
対応API
acs::game::CEffectSystem::HitStopRemain メンバー関数

API項目 7

f32 PendingShakeTrauma() / void ConsumeShake()
説明
視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。が読む揺れ値 / 読み終えたら 0 に戻す。
対応API
acs::game::CEffectSystem::PendingShakeTrauma メンバー関数
対応API
acs::game::CEffectSystem::ConsumeShake メンバー関数

API項目 8

using FEffectSystem = CEffectSystem
説明
旧名を使う既存コード向けの互換別名。 新しいコードでは CEffectSystem を使う。
対応API

使用例

CEffectSystem fx;
// 被弾時:
fx.Flash({1,1,1}, 0.8f, 0.15f);  // 白フラッシュ 150ms
fx.HitStop(0.08f);               // 80ms 停止
fx.TriggerShake(0.5f);           // 画面揺れ trauma 0.5
// 毎フレーム:
const f32 ts = fx.IsHitStop() ? 0.0f : 1.0f;  // 停止中は time_scale 0
fx.Tick(dt);                     // fx は実時間で進む
if (fx.PendingShakeTrauma() > 0) { cam.AddShake(fx.PendingShakeTrauma()); fx.ConsumeShake(); }
