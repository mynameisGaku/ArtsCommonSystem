ACS 機能 / gameframework

FModInfo

1 Mod 分のメタデータ。 id・表示名・バージョン・load_order・有効ON/OFF を表す印。 ここでは暗号化/圧縮の有無。・.ACS のアセットアーカイブ形式(.acpak)。 出荷時に複数ファイルを 1 つにまとめる。 パス。

構造体
対応するAPI: acs::game::FModInfo

使う場面

Register に渡す。 文字列はすべてそのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。 (manifest loader が組み立て寿命を保証)。
