CCameraStack

Push/Pop で旧 top→新 top を2 値の間を一定割合 t(0〜1) で混ぜる（lerp）。 t=0 で始点、t=1 で終点。 滑らかな移動・色変化に。でブレンドし、画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。側は Effective* で「今どこを写しているか」を読む。

クラス
対応するAPI: acs::game::CCameraStack

使う場面

平常視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。と演出視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。を滑らかに切り替えたい時 (ボス登場の寄りなど)。 最大 4 層。

使用例

CCameraStack stack;
stack.PushCamera(followCam);        // 初期 top
// ボス登場:
stack.PushCamera(cinematicCam, 1.0f); // 1 秒で blend
// 戻る:
stack.PopCamera(0.5f);
// 毎フレーム:
stack.Tick(dt);
rc.SetViewCenter(stack.EffectivePosition());
rc.SetViewZoom(stack.EffectiveZoom());
