FXrControllerState

左右コントローラ 1 ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。分のキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。 ある時刻の世界全体の状態を 1 つに固めたもの。 server がこれを配信し、client は受信した複数 snapshot を補間して表示する (FPS/MMO 系で標準)。。 6DoF 位置と向きをまとめた姿勢情報。 XR では頭や手の ポーズ を追跡する。 + 重なりだけを検出する当たり判定。 物理の押し戻しはせず「触れたか」だけを通知する。 関連語は トリガワールド。 trigger [0,1] + グリップ grip [0,1] + ボタン button_a/b + ス高精度タイマ（QPC）が刻む最小単位の時間。 TicksPerSecond() で秒に換算する。 thumbstick [-1,1]×2 という、各対象とする機種/環境の種別。 ここでは Meta Quest や Valve Index など XR 機器の系統。差を吸収した最小公倍数。

構造体
対応するAPI: acs::game::FXrControllerState

使う場面

VR コントローラのキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。を読む時。 Quest / Index / Vive / PS VR2 のボタン差をこの 1 構造体で統一的に扱える。
