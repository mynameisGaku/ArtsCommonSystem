void RegisterCommand(const char* name, CommandFn fn, void* user, const char* help_text)
説明
コマンドを登録する。 重複は警告して同じ登録を複数回行った時、最後に登録した内容が有効になること。上書き。
使う場面

API項目 2

void Execute(const char* command_line)
説明
キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。行を空白で tokenize → 先頭をコマンド名に照合 → dispatch する。 該当無し / 空行は警告ログ。 最大 8 引数。
使う場面
Enter が押された時。
対応API
acs::game::CDevConsole::Execute メンバー関数

API項目 3

void PushHistory(const char* line)
説明
キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。行を内部バッファに中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。して履歴に追加する (上限 100、最古を drop)。
使う場面
上下キーで再呼び出しできるようにする時。
対応API
acs::game::CDevConsole::PushHistory メンバー関数

使用例

CDevConsole con;
con.RegisterCommand(\"quit\", &App::QuitCmd, this, \"exit\");

    con.PushHistory(input);
    con.Execute(input);  // \"spawn 3\" を tokenize して dispatch
}
