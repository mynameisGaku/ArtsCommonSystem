CLocalFileAssetLocking

アセット排他ロックの抽象シーム (Perforce 等)。 のローカル本実装。 外部 SCM を使わず、<asset>.lock サイドカーファイルを CreateFileW(CREATE_NEW) の原子性で作って協調データを守るための『鍵』。 取った人だけが対象を触れ、他は解放されるまで待つ。する (stub ではなく実動作)。

クラス
対応するAPI: acs::game::CLocalFileAssetLocking

使う場面

Perforce 等のサーバを立てずに、ローカル / 共有フォルダで簡易なあるデータを一度に 1 スレッドだけが触れるように制限すること。 FMutex やロックで実現する。データを守るための『鍵』。 取った人だけが対象を触れ、他は解放されるまで待つ。を使いたい時。
