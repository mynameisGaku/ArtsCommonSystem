AWater2DComponent

波打つ水面を描くANode に付ける部品。 1 つの機能 (物理・描画・当たり判定など) を担い、組み合わせて挙動を作る。。 GPU 上で頂点やピクセルを計算する小さなプログラム。 ACS では HLSL で書く。もゲームで使う画像・音・モデル・データなどの素材ファイル。も不要で、多数のスプライトをまとめて効率よく描画する仕組み。 の三角形を時間で手続き生成して描く。

クラス (コンポーネント)
対応するAPI: acs::game::AWater2DComponent

使う場面

DirectX 系のシェーダ言語(High-Level Shading Language)。 を書かずに海・川・池・水溜まりを置きたい時。 ゲーム世界に置く部品の単位。 位置やコンポーネントを持ち、親子のツリーで並ぶ。に AddComponent するだけで動く。 プ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ーが触れると波紋を立てる等のインタラクションも可能。

使用例

auto& w = node->AddComponent<AWater2DComponent>();
w.SetRect({0, 3}, {16, 2});       // 形 (owner 相対、+Y=下なので水面は下)
w.SetColor({0.1f, 0.35f, 0.6f});
w.SetWaves(0.15f, 1.5f);          // 振幅・速度
w.Disturb(mouse_world, 0.4f);     // 触れた点に波紋
