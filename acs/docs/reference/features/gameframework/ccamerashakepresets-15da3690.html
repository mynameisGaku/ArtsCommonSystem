CCameraShakePresets

「爆発 / 地震 / 着弾」などのジャンル別 shake パラメータを 1 行で流し込む テーマの色 / spacing / corner をまとめた既定スナップショット。 ACS では EEditorThemePreset(Dark / DarkBlue / Light など)。 ライブラリ。 画面振動 (camera shake) の強さを表す [0,1] の連続値。 被弾などで加算し、毎フレーム減衰させる。/amplitude/decay を名前付きで提供し、ゲームコードに magic number を書かずに済む。 画面振動 (camera shake) の強さを表す [0,1] の連続値。 被弾などで加算し、毎フレーム減衰させる。 を吸う側は 画面ゆれ(shake)の trauma を受け取る側の純粋仮想インターフェース。 AddShake など揺れ量の設定 API を持つ。 抽象で受ける。

クラス
対応するAPI: acs::game::CCameraShakePresets

使う場面

2D カメラ。 位置/ズーム/回転、ターゲット追従、画面振動、world↔screen 座標変換を持つ。 等に「爆発っぽい振動」を即座に与えたい時。 カスタム テーマの色 / spacing / corner をまとめた既定スナップショット。 ACS では EEditorThemePreset(Dark / DarkBlue / Light など)。 も名前付きで登録できる。
