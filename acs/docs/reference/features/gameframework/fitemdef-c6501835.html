FItemDef

アイテム 1 種類の定義 (不変)。 id・表示名・分類・最大関数の呼び出しに沿って自動で確保/解放される高速なメモリ。 寿命はスコープに縛られる。数・アイコンパス・落とせるか。

構造体
対応するAPI: acs::game::FItemDef

使う場面

RegisterItem に渡す。 文字列はすべてそのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。 (リテラル想定)。

API項目 1

const char* id / display_name / icon_path
説明
一意キー / UI 表示名 / アイコン画像パス (すべてそのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。)。

API項目 2

EItemCategory category
説明
分類 (UI フィルタ用、Manager は値保存のみ)。
対応API
acs::game::EItemCategory 列挙型
対応API
acs::game::FItemDef::category メンバー変数

API項目 3

u32 max_stack
説明
同スロットに重ねられる最大数。 1=関数の呼び出しに沿って自動で確保/解放される高速なメモリ。 寿命はスコープに縛られる。不可。 0 指定は 1 に値を指定範囲内に収めること。 Saturate は 0〜1 に収める。。
対応API
acs::game::FItemDef::max_stack メンバー変数

API項目 4

bool can_drop
説明
DropSlot で落とせるか。 quest / key 系は false 推奨。
対応API
acs::game::FItemDef::can_drop メンバー変数

使用例

FItemDef d{ "ore.iron", "Iron Ore",
           EItemCategory::Material, 999,
           "ui/ore_iron.png", true };
