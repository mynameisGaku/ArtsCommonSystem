FConsoleArg / CommandFn

FConsoleArg は raw 文字列として保持するコマンド引数 1 つ。 CommandFn はコマンド本体の関数そのものを指し示す値。 あとで fn() のように呼び出せる。 テスト本体を一覧に登録する仕組みに使う。型 void(*)(void* user, u32 argc, const FConsoleArg* args)。 argv[0] はコマンド名でなく最初の引数。
