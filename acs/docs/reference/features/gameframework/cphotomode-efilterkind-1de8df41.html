CPhotoMode::EFilterKind

フォトモードの色フィルタ種別。 None (素通し) / Sepia (セピア) / Grayscale (モノクロ) / Vivid (高彩度) / Vignette (周辺光量落とし)。 実 LUT / GPU 上で頂点やピクセルを計算する小さなプログラム。 ACS では HLSL で書く。解決はシーン描画後に画面全体へかける後処理(Bloom・トーンマップ・色調整など)。パスの責務で、本 決まった選択肢の集合を表す型(列挙)。 例: 上下左右のキー。 は「どれが選ばれているか」だけを持つ。
