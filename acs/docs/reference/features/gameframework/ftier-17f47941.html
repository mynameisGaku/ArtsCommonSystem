ACS 機能 / gameframework

FTier

シーズンの 1 段階。 tier index・解放に必要な XP 閾値・無料報酬 ID・プレミアム報酬 ID を持つ。 報酬 ID は cosmetic を指す前提で、どちらも nullptr 可。

構造体
対応するAPI: acs::game::FTier

使う場面

DefineTier で各段階の到達条件と報酬を定義する時。
