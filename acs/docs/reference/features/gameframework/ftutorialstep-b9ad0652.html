FTutorialStep

チュートリアル 1 ステップ分の定義。 文字列はすべてそのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。(寿命は呼び出し側が保証)で、本クラスは保持するだけです。
