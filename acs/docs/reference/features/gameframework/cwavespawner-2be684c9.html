CWaveSpawner

敵の敵が波状にまとまって出現する単位。 倒しきると次の波へ進む。 CWaveSpawner が管理する。(波状の出現)を管理する部品。 複数 wave をキューに並べ、各 wave のウェーブ内で「どの敵を・何体・どの間隔で・どこに」湧かせるかの 1 設定。 FSpawnRule。を時間軸で順次発火させ、残数→クリア→小休止→次 wave→全完了の限られた状態と、その間の遷移ルールで動きを表す仕組み。 ステートマシンとも。を内蔵します。
