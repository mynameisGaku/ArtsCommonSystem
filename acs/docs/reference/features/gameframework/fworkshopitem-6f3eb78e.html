FWorkshopItem

対象とする機種/環境の種別。 ここでは Meta Quest や Valve Index など XR 機器の系統。共通のUser Generated Content。 ユーザーが作った MOD / ステージ等のコンテンツ。 Workshop 等で配布される。アイテムのメタ情報。 item_id / タイトル / 説明 / 作者(文字列はそのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。)・ファイルサイズ・インストール / 値や配列の変化を受け取るためにコールバックを登録すること(Subscribe)。 要らなくなったら解除(Unsubscribe)する。オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。を持ちます。
