CSceneManager

AScene の関数の呼び出しに沿って自動で確保/解放される高速なメモリ。 寿命はスコープに縛られる。管理。 top のタイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。を毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。更新/画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。し、画面切替 (Change/Push/Pop) をゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。境界まで必要になるまで計算を先延ばしにする方式(lazy)。 現行 TDerived は生成時と依存通知時に即時評価し、Get の再計算は dirty が残った場合の補完経路。して安全に適用する。

クラス
対応するAPI: acs::game::CSceneManager

使う場面

タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。を切り替える時。 普通は AScene::Scenes() 経由でこれを触る。

API項目

API項目 1

void ChangeScene(TUniquePtr<AScene> next)
説明
今の top を pop して next を push (= 画面切替)。 次ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。頭で適用。
overload候補
ChangeScene は複数の宣言に対応します。
  • acs::game::CSceneManager::ChangeScenevoid ChangeScene(TUniquePtr<AScene> next) noexcept;
  • acs::game::CSceneManager::ChangeScenevoid ChangeScene(TUniquePtr<AScene> next, TUniquePtr<CSceneTravelContext> context) noexcept;

API項目 2

void PushScene(TUniquePtr<AScene> next)
説明
今の top を残したまま next を重ねる (= ダイアログ/位置と向きをまとめた姿勢情報。 XR では頭や手の ポーズ を追跡する。)。
overload候補
PushScene は複数の宣言に対応します。
  • acs::game::CSceneManager::PushScenevoid PushScene(TUniquePtr<AScene> next) noexcept;
  • acs::game::CSceneManager::PushScenevoid PushScene(TUniquePtr<AScene> next, TUniquePtr<CSceneTravelContext> context) noexcept;

API項目 3

void PopScene()
説明
top を 1 枚 pop する。 関数の呼び出しに沿って自動で確保/解放される高速なメモリ。 寿命はスコープに縛られる。が 1 枚以下なら何もしない。
overload候補
PopScene は複数の宣言に対応します。
  • acs::game::CSceneManager::PopScenevoid PopScene() noexcept;
  • acs::game::CSceneManager::PopScenevoid PopScene(TUniquePtr<CSceneTravelContext> context) noexcept;

API項目 5

u64 ActiveSceneEpoch() const
説明
active scene境界の再利用される番号(ID)に付ける通し番号。 古いハンドルと新しい中身を取り違えないための目印。。 固定runtime ある時刻の世界全体の状態を 1 つに固めたもの。 server がこれを配信し、client は受信した複数 snapshot を補間して表示する (FPS/MMO 系で標準)。が遷移前のキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。を復元しないために使う。
対応API
