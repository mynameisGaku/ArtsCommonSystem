FNodeId

タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。グラフの 2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。 を一意に指す 32bit のオブジェクトを直接ポインタで指す代わりに「配列の index + 世代カウンタ」で指す仕組み。 slot が再利用されても世代が食い違うので、破棄済みの古いハンドルを安全に検出できる。。 中身は 24bit の index + 8bit の generation を 1 個の u32 に詰めたもの。 packed == 0 が無効値。

構造体
対応するAPI: acs::game::FNodeId

使う場面

2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。 を生メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。で持つと破棄後に破棄済みのメモリを指したままのポインタ。 触ると未定義動作。 これを避けるため ACS は世代付きハンドルを多用する。になる。 代わりにこの ID で持っておき、使う直前に CNodePool::Get() で取り出すと、破棄済みなら安全に nullptr が返る。

API項目

API項目 1

constexpr FNodeId(u32 index, u8 gen)
説明
index(24bit) と generation(8bit) を pack して構築。 index は & 0x00FFFFFF でどのレイヤに反応するかをビットで指定する絞り込み。 立っているビットの相手だけが対象になる。され、24bit を超える上位 bit は黙って捨てられる。
overload候補
FNodeId は複数の宣言に対応します。
  • acs::game::FNodeIdstruct FNodeId;
  • acs::game::FNodeId::FNodeIdconstexpr FNodeId() noexcept = default;
  • acs::game::FNodeId::FNodeIdconstexpr FNodeId(u32 index, u8 gen) noexcept;

API項目 2

constexpr u32 Index() const
説明
あらかじめ確保した固定数の枠を使い回す仕組み。 確保/解放のコストとフレーム落ちを避けられる。 / SoA 配列の index を取り出す。
戻り値
0〜16,777,215
対応API
acs::game::FNodeId::Index メンバー関数

API項目 3

constexpr u8 Generation() const
説明
slot の再利用される番号(ID)に付ける通し番号。 古いハンドルと新しい中身を取り違えないための目印。カウンタ。 「古くなって無効になった」状態。 例えば破棄された ANode を指したままのハンドルが stale。 世代付きハンドルでは世代不一致で検出する。(古い) 実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。検出に使う。
戻り値
0〜255
対応API
acs::game::FNodeId::Generation メンバー関数

API項目 4

constexpr bool IsValid() const
説明
packed != 0 なら true。 ただし「pool に該当 slot が今も生きているか」は別途 CNodePool で検証すること。
戻り値
無効でなければ true
対応API
acs::game::FNodeId::IsValid メンバー関数
