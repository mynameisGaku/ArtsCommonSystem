EChunkState

チャンクのオブジェクトが生成→更新→破棄されるまでの一連の段階。 各段階にフック関数が対応する。オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。。 Unloaded → Queued → Loading → Loaded → Unloading → Unloaded と遷移する。

列挙(enum)
対応するAPI: acs::game::EChunkState

使う場面

GetState の戻り値を見てチャンクの読み込み具合を判断する時。
