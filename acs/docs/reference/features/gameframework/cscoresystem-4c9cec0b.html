CScoreSystem

スコア累積 + コンボ + 倍率 + マイルストン通知を 1 つにまとめたある種類の状態 (cooldown / チェックポイント / カード等) をまとめて持ち、登録・更新・問い合わせの API を提供する小さなクラス。。 NotifyHit でコンボが伸び、AddScore でコンボ由来の倍率を掛けて加算する。 一定時間ヒットが無いとコンボはリセット。

クラス
対応するAPI: acs::game::CScoreSystem

使う場面

アーケード/アクション系で『連鎖でスコア倍率が上がる』仕組みを作る時。

使用例

CScoreSystem ss;
ss.Init();
ss.RegisterMilestone(10000);
ss.SetOnMilestoneCallback(&OnMilestone, user);
// 敵撃破時:
ss.NotifyHit();
ss.AddScore("enemy.normal", 100);  // 100 × 現在倍率
ss.Tick(dt);
