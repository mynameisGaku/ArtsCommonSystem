FScriptValue

インターフェースの裏で実際に仕事をする具象実装。 ここでは OpenXR ローダ等の XR 実装本体。 中立な動的型付け値。 Nil/Bool/Number(f64)/短い文字列はヒープ無しで持つ最適化付き。(そのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。)/Handle(u32) のAES-GCM が出力する 16 バイトの認証データ。 これが合わないとデータが改竄/破損とみなす。付き 同じメモリ領域を複数の型で共用する仕組み。 FEvent は種別ごとに有効なフィールドだけを使う。 風 Plain Old Data。 コンストラクタ等の特別な振る舞いを持たない単純な構造体。 コピーが速く扱いやすい。。 スクリプトと C++ の間で引数・戻り値を受け渡す。
