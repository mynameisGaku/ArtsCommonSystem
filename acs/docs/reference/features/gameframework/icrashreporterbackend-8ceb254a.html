ICrashReporterBackend

本体は具象 HTTP/IPC を抱えず、I/F と 本物の代わりに置く最小実装。 依存ゼロでコンパイル・テストできる no-op 版。 だけを持つ。 失敗は黙って握り潰す (二次クラッシュ防止)。

インターフェース
対応するAPI: acs::game::ICrashReporterBackend

使う場面

クラッシュレポートやエラー報告・クラッシュ前に何が起きていたかを時系列で残す短いログ。 クラッシュ報告に添付して原因追跡に使う。 をシーンが必要に応じて使う共通機能 (時間・補間・入力・カメラ・物理など) の単位。に送りたい時。 実装は各タイトルで差し込む。

API項目

API項目 1

virtual TResult<void> Init(const char* product_id, const char* version)
説明
SDK を初期化する。 product_id / version は集計キー。
使う場面
起動時に 1 度。
対応API
acs::game::ICrashReporterBackend::Init メンバー関数

API項目 2

virtual TResult<void> ReportCrash(const FCrashContext& ctx)
説明
クラッシュ 1 件を送信する (プロセスがまだ生きている前提)。
対応API
acs::game::ICrashReporterBackend::ReportCrash メンバー関数
対応API
acs::game::FCrashContext 構造体

API項目 3

virtual TResult<void> ReportError(const char* category, const char* message)
説明
非致命的エラーを送信する。 category は \"net\" / \"save\" 等の集計キー。
対応API
acs::game::ICrashReporterBackend::ReportError メンバー関数
対応API
acs::game::FCrashContext::message メンバー変数

API項目 4

virtual TResult<void> AddBreadcrumb(const char* category, const char* message)
説明
クラッシュ前の足跡を 1 件追加する (送信せず ReportCrash 時に添付)。
使う場面
重要操作の前後に挟んで後で追跡できるようにする。
対応API
acs::game::ICrashReporterBackend::AddBreadcrumb メンバー関数
対応API
acs::game::FCrashContext::message メンバー変数

API項目 5

virtual void SetUserId(const char* anonymous_id)
説明
匿名ユーザー ID を設定する (生 email でなく UUID 推奨、EU の一般データ保護規則。 解析データ収集前にユーザー同意 (consent) を要する。 同意が無ければ送信しない。/CCPA 配慮)。
対応API
acs::game::ICrashReporterBackend::SetUserId メンバー関数

API項目 6

virtual void Tick(f32 dt)
説明
処理の完了を待たずに先へ進み、結果は後で受け取るやり方。 重い読み込みなどで画面を止めない。送信キューのポンプ。 毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。呼ぶ。
対応API
acs::game::ICrashReporterBackend::Tick メンバー関数

API項目 7

virtual bool IsAvailable() const
説明
Init 済みで送信可能なら true。 本物の代わりに置く最小実装。 依存ゼロでコンパイル・テストできる no-op 版。 は常に false。
対応API
acs::game::ICrashReporterBackend::IsAvailable メンバー関数

使用例

ICrashReporterBackend& cr = acs::game::GetDefaultCrashReporter();
cr.Init(\"com.example.game\", \"1.2.3\");
cr.AddBreadcrumb(\"save\", \"autosave start\");
// 毎フレーム: cr.Tick(dt);
