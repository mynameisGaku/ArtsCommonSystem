CMusicDirector

ゲームプレイオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。 (戦闘/平穏/勝利...) を バックグラウンドミュージック。 場面の間ずっとループで流す音楽。 にマッピングする上位当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。。 state ごとに track を登録し、激しさ (intensity) で曲を選び、クロスフェードや一発もの (stinger) を扱う。 実再生は CAudioDirector に委ねる。

クラス
対応するAPI: acs::game::CMusicDirector

使う場面

状況に応じて バックグラウンドミュージック。 場面の間ずっとループで流す音楽。 を自動で切り替える「適応 バックグラウンドミュージック。 場面の間ずっとループで流す音楽。」を作る時。 CAudioDirector が低当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。の mixer/クロスフェードを担うのに対し、こちらは「どの track をどのゲインで鳴らすか」の state machine。

API項目 8

void SetAudioDirector(CAudioDirector* audio) / CAudioDirector* GetAudioDirector() const
説明
実再生を委ねる低当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。 director を部品同士をつなぎ込む(実装を既定の口に登録する)こと。 これで上位が下位に直接依存せず使える。 (そのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。)。 nullptr で state-only 動作 (無音)。
対応API
acs::game::CMusicDirector::SetAudioDirector メンバー関数
対応API
acs::game::CMusicDirector::GetAudioDirector メンバー関数

API項目 9

void Tick(f32 dt)
説明
毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。呼び、transition / stinger 時間を計る仕組み。 ACS では CClock（経過時間）と FFrameTimer（フレーム間 dt）。を進める。
対応API
acs::game::CMusicDirector::Tick メンバー関数

API項目 10

void Stop()
説明

対応API

使用例

CMusicDirector md;
md.SetAudioDirector(&audio);
md.RegisterTrack(EMusicState::Combat,
    FMusicTrack{ "bgm/combat.ogg", 0.0f, 1.0f, true });
md.SetState(EMusicState::Combat, 2.0f); // 2 秒クロスフェード
md.SetIntensity(0.9f);                  // 高激戦
md.Tick(dt);
