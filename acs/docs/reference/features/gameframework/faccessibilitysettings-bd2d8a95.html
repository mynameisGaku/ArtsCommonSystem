FAccessibilitySettings

アクセシビリティ設定の値オブジェクト (Plain Old Data。 コンストラクタ等の特別な振る舞いを持たない単純な構造体。 コピーが速く扱いやすい。)。 色覚モード・文字サイズの 決まった選択肢の集合を表す型(列挙)。 例: 上下左右のキー。 と、字幕/スクリーンリーダ/片手モード等の bool、振動/フラッシュ係数をまとめて持つ。 中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。可能。

構造体
対応するAPI: acs::game::FAccessibilitySettings

使う場面

UI 画面のキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。をある瞬間の状態をまとめて切り取ったコピー。 ここでは 1 フレーム分の入力値の束。として組み立て、FAccessibilityProfile::Set() に渡す時。
