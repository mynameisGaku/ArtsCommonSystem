API項目 6

u64 ComputeChecksum() const
説明
全 frame の FNV-1a-like 64bit の符号なし整数(0 以上)。 サイズ・ハンドル・大きな個数などに使う基本型。 文字列やデータを決まった大きさの数値へ変換すること。 同じ入力からは常に同じ値が出る。。 同じ入力なら必ず同じ結果になる性質。 replay / netcode / record-replay の同期で必須。 ML 推論や浮動小数のドライバ差はこれを壊すので隔離する。検証 / replay 処理が終わるまでその場で待つやり方。 結果がすぐ手に入る代わりに止まる。ずれ検知に使う。
戻り値
