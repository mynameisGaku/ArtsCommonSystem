CSeasonPass

シーズン (バトルパス) の進行管理。 期間 (開始/終了 timestamp)・累積 XP による tier 進行・各 tier 報酬の請求オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。を 1 クラスで扱う。 報酬は固定 (規則性のない数値。 敵の出現位置やドロップ抽選などに使う。なし)・cosmetic 限定を強く推奨する倫理方針。

クラス
対応するAPI: acs::game::CSeasonPass

使う場面

期間限定シーズンや無料/プレミアムのパス報酬を実装する時。 報酬 ID を吐き出すだけで、実体解放は entitlement 側に橋渡しする。

sp.Tick(dt);
