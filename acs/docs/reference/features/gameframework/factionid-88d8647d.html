FActionId

アクション識別子。 FActionId("Jump") のように文字列リテラルから文字列をコンパイル時に数値へ変換する手法。 実行時の文字列比較を避けて高速化する。 (FNV-1a) で生成され、中身は u32。 実行時の文字列比較が無い。

構造体
対応するAPI: acs::game::FActionId

使う場面

Fキーボード・マウス・ゲームパッドの状態を問い合わせで読む静的クラス。 毎フレーム先頭で Update() を呼んでから状態を読む。Map の bind / query に「アクション名」を渡す時。 同じ文字列なら常に同じ値。
