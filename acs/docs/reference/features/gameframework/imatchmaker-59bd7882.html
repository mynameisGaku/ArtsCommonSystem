IMatchmaker

対戦相手を探すマッチメイキングのプラットフォーム固有 SDK との結合点を抽象化した純粋仮想インターフェース。 ゲーム側はこれ越しに呼び、実装をビルド時に差し替える。 (Glicko-2 / TrueSkill 等の rating ベースを想定)。 StartSearch で検索開始 → PollStatus でオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。確認 → AcceptMatch / CancelSearch で完了、という流れ。

インターフェース
対応するAPI: acs::game::IMatchmaker

使う場面

オンライン対戦のマッチ検索を実装したい時。 実アルゴリズムはプロジェクト側実装に委ねる。

API項目 3

EMatchStatus PollStatus(FMatchTicket t)
説明
現在の検索オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。 (Searching/Matched/Cancelled/Failed) を返す。 副作用なし。
戻り値
検索オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。

API項目 4

TResult<void> AcceptMatch(FMatchTicket t)
説明
Matched オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。のチケットを確定する。 失敗時は再検索に戻る設計を許容。
対応API

対応API
acs::game::FMatchTicket 構造体

使用例

IMatchmaker& mm = GetDefaultMatchmaker();
auto t = mm.StartSearch("ranked_1v1", 1500);
if (t.IsOk()) {
    FMatchTicket ticket = t.Value();
    if (mm.PollStatus(ticket) == EMatchStatus::Matched)
        mm.AcceptMatch(ticket);
}
