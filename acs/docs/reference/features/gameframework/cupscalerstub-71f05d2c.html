CUpscalerStub

Off オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。だけを返す IUpscaler の本実装の代わりに置く「中身が空 / 常に失敗を返す」仮実装。 未統合の backend のフォールバックや、上位層のテストに使う。。 Init(Off) は成功、それ以外は NotImplemented、入出力サイズは常に 0。
