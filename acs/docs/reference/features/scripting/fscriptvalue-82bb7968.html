FScriptValue

C++ と ゲーム組み込みで広く使われる軽量スクリプト言語。 C++ を再ビルドせずにロジックを差し替えられる。 の間で値を受け渡すためのAES-GCM が出力する 16 バイトの認証データ。 これが合わないとデータが改竄/破損とみなす。付き共用体風の Plain Old Data。 コンストラクタ等の特別な振る舞いを持たない単純な構造体。 コピーが速く扱いやすい。。 kind で種類を、v で中身を表す。 種類は Nil / Bool / Number / String / Handle の 5 つ。 Cゲーム組み込みで広く使われる軽量スクリプト言語。 C++ を再ビルドせずにロジックを差し替えられる。Vm の引数 / 戻り値はすべてこの型の配列で表現する。

使用例

acs::game::FScriptValue v;
v.kind = acs::game::EScriptValueKind::Number;
v.v.num = 3.14;          // Number は f64
// 文字列は所有しない(寿命は呼び出し側が保証)
acs::game::FScriptValue s;
s.kind = acs::game::EScriptValueKind::String;
s.v.str = "hello";
