CAudioEngine

音声再生の中心となるエンジン。 wav/mp3/flac/ogg を統一 PCM として読み込んだ音声アセット(asset モジュール)。 CAudioEngine に渡して再生する。 を渡して鳴らし、音量変更・停止・一時停止などを行う。 中身は Windows 標準の低レベル音声 API。 ACS の音声再生はこの上に実装されている。 実装を pimpl で隠している。 中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。不可。

クラス
対応するAPI: acs::CAudioEngine

使う場面

ゲーム中で バックグラウンドミュージック。 場面の間ずっとループで流す音楽。 や効果音を鳴らしたい時。 普通はアプリ全体で 1 個だけ作り、Init() してから使い、終了時に Shutdown() する。

使用例

CAudioEngine engine;
engine.Init();                       // XAudio2 初期化

auto asset = registry.Load(L"sound/bgm.ogg").Value();
auto* audio = static_cast<AAudioAsset*>(asset.Get());

FSoundHandle h = engine.Play(*audio, 1.0f, /*loop=*/true);
engine.SetVolume(h, 0.5f);           // 音量を半分に
engine.Stop(h);                      // 停止
engine.Shutdown();
