FStorage

設定やセーブデータ用の key-value ストア（INI 形式）。 master_volume=0.8 のような人間が読める形でファイルに保存できる。 文字列・整数・小数・真偽を型ごとに出し入れする。

クラス
対応するAPI: acs::FStorage

使う場面

音量・解像度などの設定や、ハイスコア・進行度などのセーブを手軽に永続化したい時。

説明

戻り値

使用例

FStorage cfg;
wchar_t path[260];
FStorage::GetAppDataPath(L"MyGame", L"settings.ini", path, 260);
cfg.Load(path);
f64 vol = cfg.GetFloat("master_volume", 0.8);
cfg.SetInt("high_score", 12345);
cfg.Save(path);
