FLocalization

多言語対応（internationalization (国際化) の略。 多言語対応のこと。 文字列を言語ごとの辞書から引けるようにする。）の仕組み。 各言語を F設定やセーブデータ用の key-value ストア(INI 形式)。 音量・解像度・進行度などを人間が読める形で永続化する。（INI 形式の翻訳辞書）として持ち、キーから現在言語の文字列を引く。 見つからなければ代替言語、それも無ければキー名そのものを返す。

クラス
対応するAPI: acs::FLocalization

使う場面

メニューやセリフを日本語・英語など複数言語で出したい時。 表示文字列をコードに直書きせず、言語ファイルにまとめる。
