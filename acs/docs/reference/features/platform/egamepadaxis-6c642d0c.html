EGamepadAxis

コントローラ。 ACS は XInput 互換でボタンやスティック（軸）を読む。のアナログ軸を表す列挙。 左右ス高精度タイマ（QPC）が刻む最小単位の時間。 TicksPerSecond() で秒に換算する。の X/Y と、左右重なりだけを検出する当たり判定。 物理の押し戻しはせず「触れたか」だけを通知する。 関連語は トリガワールド。ー。

列挙(enum)
対応するAPI: acs::EGamepadAxis

使う場面

Cキーボード・マウス・ゲームパッドの状態を問い合わせで読む静的クラス。 毎フレーム先頭で Update() を呼んでから状態を読む。::GamepadAxisValue に渡す。 ス高精度タイマ（QPC）が刻む最小単位の時間。 TicksPerSecond() で秒に換算する。は -1.0〜+1.0、重なりだけを検出する当たり判定。 物理の押し戻しはせず「触れたか」だけを通知する。 関連語は トリガワールド。ーは 0.0〜1.0 が返る。
