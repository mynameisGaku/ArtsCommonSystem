FFrameTimer

ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。ごとの経過時間（前フレームから今フレームまでの経過秒（dt）。 速度 × dt で動かすとフレームレートに依存しない。）を計る時間を計る仕組み。 ACS では CClock（経過時間）と FFrameTimer（フレーム間 dt）。。 毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。 Tick() を呼ぶと前回からの経過秒を返す。 平均 FPS も取れる。

クラス
対応するAPI: acs::FFrameTimer

使う場面

ゲームループの中で、移動量などを 速度 × dt で計算したい時。 ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。レートに依存しない動きの基本。

説明

使用例

FFrameTimer ft;
while (running) {
    f32 dt = ft.Tick();   // 前フレームからの経過秒
    pos += velocity * dt; // フレームレート非依存
    if (ft.FrameCount() % 60 == 0) ShowFps(ft.SmoothedFPS());
}
