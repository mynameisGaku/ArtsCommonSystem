EKey

キーボードのキーを表す列挙。 A〜Z、数字、ファンクション、修飾キー、矢印、記号、テンキーまで初学者にも分かりやすい名前で揃っている。

列挙(enum)
対応するAPI: acs::EKey

使う場面

Cキーボード・マウス・ゲームパッドの状態を問い合わせで読む静的クラス。 毎フレーム先頭で Update() を呼んでから状態を読む。::IsKeyDown などにキーを指定する時。
