EGamepadButton

コントローラ。 ACS は XInput 互換でボタンやスティック（軸）を読む。のボタンを表す列挙（Xキーボード・マウス・ゲームパッドの状態を問い合わせで読む静的クラス。 毎フレーム先頭で Update() を呼んでから状態を読む。 互換）。 フェイスボタン・十字キー・バンパー・ス高精度タイマ（QPC）が刻む最小単位の時間。 TicksPerSecond() で秒に換算する。押し込み・コンポーネントを持つエンティティ群を毎フレーム処理する関数(移動・AI など)。 CSystemScheduler で順に実行する。ボタン。

列挙(enum)
対応するAPI: acs::EGamepadButton

使う場面

Cキーボード・マウス・ゲームパッドの状態を問い合わせで読む静的クラス。 毎フレーム先頭で Update() を呼んでから状態を読む。::IsGamepadButtonDown / Pressed に渡す。
