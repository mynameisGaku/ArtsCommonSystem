EEventType

Fウィンドウや入力で起きた『出来事』1 つ分を表す構造体。 種別に応じて中のunionの対応フィールドだけが有効になる。 の種別を表す列挙。 OS が画面に出す四角い領域。 タイトルバーや × ボタンを持ち、ゲームの描画先になる。 ACS では FWindow。系（閉じる・サイズ変更・フォーカス）とキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。系（キー・マウス・文字）がある。

列挙(enum)
対応するAPI: acs::EEventType

使う場面

受け取った Fウィンドウや入力で起きた『出来事』1 つ分を表す構造体。 種別に応じて中のunionの対応フィールドだけが有効になる。 の type と比較して分岐する。

API項目

API項目 1

None
説明
未設定（無効な『× ボタンが押された』『キーが押された』のような、その瞬間に起きた出来事の通知。 ACS では FEvent として届く。）。
対応API
acs::EEventType::None 列挙値

API項目 2

WindowClose / WindowResize
説明
× ボタン押下 / OS が画面に出す四角い領域。 タイトルバーや × ボタンを持ち、ゲームの描画先になる。 ACS では FWindow。サイズ変更。
対応API
acs::EEventType::WindowClose 列挙値
対応API

API項目 7

CharInput
説明
文字キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。（日本語などを入力するための変換ソフト。 確定後の文字が TextInput() で取れる。 確定後のテキスト用）。
対応API
acs::EEventType::CharInput 列挙値

switch (e.type) {
    case EEventType::WindowClose:  /* 閉じる */ break;
    case EEventType::KeyPressed:   /* 押下   */ break;
    case EEventType::MouseScrolled:/* ホイール*/ break;
}
