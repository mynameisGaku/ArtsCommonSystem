FWindowConfig

OS が画面に出す四角い領域。 タイトルバーや × ボタンを持ち、ゲームの描画先になる。 ACS では FWindow。を作る時の設定をまとめた小さな箱。 タイトル・サイズ・全画面かどうかなどを指定する。

構造体
対応するAPI: acs::FWindowConfig

使う場面

OS のウィンドウそのものを表すクラス。 四角い領域を開き、閉じる要求や入力などのイベントを受け取る。 ゲームの一番外側のループの中心。::Create に渡す。 必要な項目だけ書き換えれば、残りは無難な既定値が入る。

API項目

API項目 1

対応API
acs::FWindowConfig::title メンバー変数

API項目 2

u32 width / u32 height
説明
OS が画面に出す四角い領域。 タイトルバーや × ボタンを持ち、ゲームの描画先になる。 ACS では FWindow。の中身のサイズ（既定 1280 × 720）。
対応API
acs::FWindowConfig::width メンバー変数
対応API
acs::FWindowConfig::height メンバー変数

API項目 3

bool resizable
説明
ユーザーが端をドラッグしてサイズ変更できるか（既定 true）。
対応API
acs::FWindowConfig::resizable メンバー変数

API項目 4

bool fullscreen
説明
起動時から全画面にするか（既定 false）。
対応API
acs::FWindowConfig::fullscreen メンバー変数

API項目 5

bool vsync_hint
説明
垂直処理が終わるまでその場で待つやり方。 結果がすぐ手に入る代わりに止まる。を使いたい、というヒント（既定 true）。
対応API
acs::FWindowConfig::vsync_hint メンバー変数

使用例

FWindowConfig cfg;
cfg.title      = L"勇者の冒険";
cfg.width      = 1920;
cfg.height     = 1080;
cfg.resizable  = false;   // 固定サイズ窓
cfg.fullscreen = false;
