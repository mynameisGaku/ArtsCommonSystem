FEvent

OS が画面に出す四角い領域。 タイトルバーや × ボタンを持ち、ゲームの描画先になる。 ACS では FWindow。やキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。で起きた『出来事』1 つ分を表す。 種別（type）に応じて、中の同じメモリ領域を複数の型で共用する仕組み。 FEvent は種別ごとに有効なフィールドだけを使う。のうち対応するフィールドだけが有効になる。

構造体
対応するAPI: acs::FEvent

使う場面

Setウィンドウや入力で起きた『出来事』1 つ分を表す構造体。 種別に応じて中のunionの対応フィールドだけが有効になる。Callback で受け取る。 type を見て分岐し、対応するフィールドを読む。

使用例

void OnEvent(void* u, const FEvent& e) {
    if (e.type == EEventType::WindowResize) {
        u32 w = e.resize.width, h = e.resize.height;
    } else if (e.type == EEventType::KeyPressed) {
        EKey k = e.key.key;
    }
}
