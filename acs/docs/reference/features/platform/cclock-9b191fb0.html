CClock

高精度な時間を計る仕組み。 ACS では CClock（経過時間）と FFrameTimer（フレーム間 dt）。。 起動からの経過時間を秒・ミリ秒・高精度タイマ（QPC）が刻む最小単位の時間。 TicksPerSecond() で秒に換算する。で取得できる。 すべて静的関数。

クラス（静的）
対応するAPI: acs::CClock

使う場面

ベンチマークや経過時間の計測。 ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。間の dt が欲しいだけなら Fフレームごとの経過秒(デルタタイム)を計るタイマ。 毎フレーム Tick() を呼ぶと前回からの経過秒を返す。 の方が便利。
