FStorageStringBatchEntry

F設定やセーブデータ用の key-value ストア(INI 形式)。 音量・解像度・進行度などを人間が読める形で永続化する。へ一括設定する終端key/value組。 value == nullptrは空文字列、非nullは終端までのbyte列として扱う。 key/valueの順に二pointerを保持するaggregateで、field offset、standard-layout、trivially-copyableをcompile-timeに固定する。

構造体
対応するAPI: acs::FStorageStringBatchEntry

使う場面

複数の文字列設定を、一部だけ反映されるオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。を作らずまとめて更新したい時。

API項目

API項目 1

const char* key
説明
設定対象のkey。 有効なUTF-8で、空、改行、=、制御文字、INI指示行と衝突する先頭文字は使えない。 LoadFromBytesの境界trimでidentityが変わらないよう、先頭と末尾のASCII space (U+0020)も拒否するが、内部spaceは許可する。
対応API
acs::FStorageStringBatchEntry::key メンバー変数

API項目 2

const char* value
説明
設定する値。 nullは既存のTrySetStringと同じ空文字列。 非nullは終端までのbyte列を追加検査や変換なしで保持し、このwaveで既存valueの制約を強めない。
