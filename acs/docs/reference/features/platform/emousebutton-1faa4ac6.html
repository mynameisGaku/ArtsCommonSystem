EMouseButton

マウスのボタンを表す列挙。 左・右・中（ホイール押し込み）とサイドボタン 2 つ。

列挙(enum)
対応するAPI: acs::EMouseButton

使う場面

Cキーボード・マウス・ゲームパッドの状態を問い合わせで読む静的クラス。 毎フレーム先頭で Update() を呼んでから状態を読む。::IsMouseButtonDown などに渡す。

基本情報

モジュール
platform
分類
列挙(enum)
ヘッダー
platform/InputCodes.h

API項目

API項目 1

Left = 0 / Right = 1 / Middle = 2
説明
左・右・中ボタン（中はホイール押し込み）。 基底型は u8。
対応API
acs::EMouseButton::Left 列挙値
対応API
acs::EMouseButton::Right 列挙値
対応API
acs::EMouseButton::Middle 列挙値

API項目 2

X1 = 3 / X2 = 4
説明
サイドボタン 1・2（戻る/進む等）。 末尾に内部用の番兵 _Count がある。
対応API
acs::EMouseButton::X1 列挙値
対応API
acs::EMouseButton::X2 列挙値

使用例

if (CInput::IsMouseButtonPressed(EMouseButton::Left))   Fire();
if (CInput::IsMouseButtonDown(EMouseButton::Right))     Aim();
