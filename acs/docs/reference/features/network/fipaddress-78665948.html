FIpAddress

192.168.0.1 のような 4 数値で表す主流のネットワークアドレス形式。 アドレス(4 個の数値)とポート番号をまとめた小さな値。 通信相手や自分の待ち受け先を指すのに使う。 v1 では IPv4 を拡張した新しいアドレス形式。 ACS v1 では未対応。 は未対応。

構造体
対応するAPI: acs::FIpAddress

使う場面

接続先・待ち受け先を指定するあらゆる場面。 文字列 \"127.0.0.1\" から作るか、定型の Any() / Loopback() を使う。

API項目 3

説明
全ネットワークインターフェイスを表す。 サーバが待ち受ける時に使う。

対応API

API項目 4

説明
同じ PC 内(自分自身)を指す。 ローカルテストに便利。
戻り値
127.0.0.1
対応API
acs::FIpAddress 構造体
対応API
acs::FIpAddress::Loopback メンバー関数

API項目 5

static FIpAddress FromString(const char* dotted)
説明
\"192.168.0.1\" のような文字列から作る。 書式が不正なら 0.0.0.0 を返す。
戻り値
アドレス
使用例
FIpAddress a = FIpAddress::FromString(\"10.0.0.5\");
対応API
acs::FIpAddress 構造体
対応API
acs::FIpAddress::FromString メンバー関数

使用例

FIpAddress addr = FIpAddress::FromString(\"192.168.0.10\");
addr.port = 8080;             // ポートはフィールドで直接設定
FIpAddress any = FIpAddress::Any();      // 0.0.0.0 (全インターフェイス)
FIpAddress lo  = FIpAddress::Loopback(); // 127.0.0.1 (自分自身)
