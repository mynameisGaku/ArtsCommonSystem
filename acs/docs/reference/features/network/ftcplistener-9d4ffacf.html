FTcpListener

相手と接続を張り、順序どおり・確実にデータを届ける通信方式。 取りこぼしが許されない用途向け。 関連語 UDP。 接続を待ち受ける側(サーバ)。 指定ポートで Listen を始め、Accept() でクライアントの接続を 1 本ずつ受理して F確立済みの TCP 接続 1 本。 順序どおり確実にデータを送受信でき、デストラクタで自動切断する。 コピー不可・ムーブのみ。 に変える。 中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。不可・中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。のみ。

クラス
対応するAPI: acs::FTcpListener

使う場面

自分がサーバになって、複数のクライアントからの接続を受け付けたい時。

説明

戻り値
接続 または エラー
使う場面

使用例

auto lr = FTcpListener::Listen(FIpAddress::Any(), 8080);
if (lr.IsErr()) return;
FTcpListener& l = lr.Value();
while (true) {
    auto cr = l.Accept();           // 1 接続を待つ
    if (cr.IsOk()) HandleClient(Move(cr.Value()));
}
