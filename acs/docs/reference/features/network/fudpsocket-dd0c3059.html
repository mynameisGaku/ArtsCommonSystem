FUdpSocket

接続を張らずデータグラムを 1 通ずつ送る通信方式。 速いが到達・順序は保証されない。 関連語 TCP。 のネットワーク通信の出入口となる OS の口。 ここを通じてデータを送受信する。。 接続を張らずに、宛先を指定して1 通ずつデータ(UDP で送受信する 1 通分のデータの塊。 それ単体で届き、順序は保証されない。)を送受信する。 速いが、到達・順序は保証されない。 中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。不可・中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。のみ。

クラス
対応するAPI: acs::FUdpSocket

使う場面

多少の取りこぼしより速さを優先したい時(対戦中の位置処理が終わるまでその場で待つやり方。 結果がすぐ手に入る代わりに止まる。、簡易ブロードキャストなど)。 確実さが要るなら F確立済みの TCP 接続 1 本。 順序どおり確実にデータを送受信でき、デストラクタで自動切断する。 コピー不可・ムーブのみ。 を選ぶ。

API項目 3

isize RecvFrom(void* buf, usize size, FIpAddress& from)
説明
1 通受け取り、成功時だけ from に送信元を書き込む。 size>0 で null、Windows のソケット通信ライブラリ。 ACS の CNetwork はこれを薄くくるんでいる。 上限超過、OS 失敗時は -1 で from を変えない。 空UDP で送受信する 1 通分のデータの塊。 それ単体で届き、順序は保証されない。も受信する。
戻り値

使う場面
