API項目 5

void Shutdown()
説明
Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 と両 インターフェースの裏で実際に仕事をする具象実装。 ここでは OpenXR ローダ等の XR 実装本体。 を破棄し、確保した GPU 上でテクスチャ(ImGui のフォント等)を参照するための記述子をまとめて置く領域。を解放する。 何度呼んでも安全(二重解放しない)。 オブジェクトが破棄される時に自動で呼ばれる後始末の関数(~ClassName)。からも自動で呼ばれる。

使用例

FImGuiCtx imgui;
imgui.Init(window, renderer);             // 1 回だけ
while (!window.ShouldClose()) {
    renderer.BeginFrame(...);
    imgui.NewFrame();                     // フレーム開始
    ImGui::Begin("Hello");                 // 素の ImGui API
    ImGui::Text("Hello, world!");
    ImGui::End();
    imgui.Render();                       // 描画コマンド発行
    renderer.EndFrame();
}
imgui.Shutdown();                         // 片付け
