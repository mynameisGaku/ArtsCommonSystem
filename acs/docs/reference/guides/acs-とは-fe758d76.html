ACS とは

ACS は日本のインディー開発者向けの軽量な C++ ゲーム作りに必要な土台(描画・入力・音・シーン管理など)をまとめて提供する部品集。 エンジンより薄く、自由度が高い。です。 Windows / Windows の低レベル描画API。 GPU を細かく制御できる代わりに手間も多い。 ACS が裏で使う。 上で動き、ACS はビルド時間や予測しやすさのため使わず独自コンテナを用いる。(標準ライブラリ)を使わず、独自の小さな部品で構成されています。 難しい所は隠しつつ、必要なら中身まで触れる、を狙っています。

とにかく早く動かしたい人は acs::easy(簡単モード)から。 OpenWindow → NextFrame ループで絵が出ます。 慣れてきたら下の層に降りていけます。
