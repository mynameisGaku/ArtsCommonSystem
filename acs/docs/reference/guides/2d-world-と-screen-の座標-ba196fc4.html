2D world と screen の座標

シーン、コンポーネント、各ジャンル用機能、アセット読み書きの抽象 API など、ゲーム構築用の部品を提供する acs::game モジュールです。 の 2D world はscene/camera中心で +Y が下向きです。 HUD、screen、easy のpixel座標は左上が原点で、下に行くほど Y が増えます。 world と screen は AScene::ScreenToWorld で変換します。
