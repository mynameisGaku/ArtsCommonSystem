acs::FStringView

メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。 + バイト長で文字列を参照する軽量値型。 そのメモリ/資源を『誰が解放する責任を持つか』。 はっきりさせると安全。を持たないため、元の文字列の オブジェクトが生まれてから壊れるまでの寿命。 これを過ぎたものを触ると危険。は呼び出し側が保証する。 UTF-8 を前提とし、バイト単位の比較・検索のみを 提供する (コードポイント操作は未対応)。
