acs::game::FFixedStepRuntimeSnapshot

描画frameの長さに左右されず、一定の秒数ずつsimulationを進める方法。時計と未消費キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。を同じ復元境界で保持するprocess内保存値。
