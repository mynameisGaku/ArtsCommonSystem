acs::game::IAssetPackReader::Mount

pak ファイルをマウントし、以降の ライブラリの機能を外から使うための窓口(関数や型の取り決め)。 例: ネットワークは WinSock をくるんだ薄い API として提供される。 呼び出しを有効にする。 多重 Mount は実装依存 (大抵は前の pak を自動 Unmount してから新規 Mount)。 pack_path: マウントする pak ファイルのパス。 戻り値: 成功なら空の 成功値かエラー値のどちらか一方を持つ型。 例外を使わずに失敗を戻り値で伝える（既定のエラー型は FErrorCode）。、失敗ならエラー。
