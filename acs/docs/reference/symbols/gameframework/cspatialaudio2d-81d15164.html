クラス / gameframework

acs::game::CSpatialAudio2D

2D listener + source を集中管理する空間化当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。 (CSpatialAudio の 2D 版)。 AScene 局所 instance としての所有を想定。 1 listener + N source を AoS で保持し、 毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。 distance / volume / pan を pull で取得する。 source_id は単調増加で 再利用しない (「古くなって無効になった」状態。 例えば破棄された ANode を指したままのハンドルが stale。 世代付きハンドルでは世代不一致で検出する。 ID 検出が単純)。 全メソッド inline (header-only)。
