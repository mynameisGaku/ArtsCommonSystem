acs::game::editor_core::FEditorThemeColors

テーマの色 / spacing / corner をまとめた既定スナップショット。 ACS では EEditorThemePreset(Dark / DarkBlue / Light など)。 1 個分のカラーパレット。 各メンバは RGBA `[0, 1]` 範囲の `acs::4 次元ベクトル(x, y, z, w)。 RGBA 色や同次座標、行列との掛け算に使う。`。 Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 の ImVec4 と同じ意味論 (= sRGB 線形値、α は 0 = 完全透明 / 1 = 不透明)。
