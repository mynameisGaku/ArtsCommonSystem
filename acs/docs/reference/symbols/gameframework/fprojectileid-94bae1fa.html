acs::game::FProjectileId

24bit index + 8bit gen を packed した opaque な弾実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。。 m_Packed == 0 を invalid と定義する (gen は常に 1 以上で配る)。 slot 再利用後の 「古くなって無効になった」状態。 例えば破棄された ANode を指したままのハンドルが stale。 世代付きハンドルでは世代不一致で検出する。 参照は IsValid + 内部 gen 一致で検出する。
