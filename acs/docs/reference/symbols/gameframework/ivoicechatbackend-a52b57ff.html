acs::game::IVoiceChatBackend

各 SDK の差を吸収するマイク音声を圧縮して送受信する仕組み(Steam VOIP)。 インターフェースの裏で実際に仕事をする具象実装。 ここでは OpenXR ローダ等の XR 実装本体。 の純粋仮想実装を差し替えられるようにするための約束事(純粋仮想クラス)。 I で始まる。。 Valve のゲーム配信プラットフォーム。 実績・フレンド・クラウドセーブ等の機能を Steamworks SDK 経由で使える。 Voice / EOS Voice / Vivox / Discord / OpusSelf の差を吸収する。 実装は 本体外モジュール (or テスト) で override する。
