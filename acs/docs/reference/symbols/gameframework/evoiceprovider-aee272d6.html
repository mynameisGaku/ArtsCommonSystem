acs::game::EVoiceProvider

マイク音声を圧縮して送受信する仕組み(Steam VOIP)。のある機能 (ここではインスペクタ表示) に対してデータや実装を「供給する」側のオブジェクト。 インターフェースを実装して登録する。種別。 `Init(EVoiceProvider)` で 1 個選んで初期化する。 `OpusSelf` は SDK 非依存の 自前 Opus + 接続を張らずデータグラムを 1 通ずつ送る通信方式。 速いが到達・順序は保証されない。 関連語 TCP。 実装を意図 (専用サーバ運用ケース)。
