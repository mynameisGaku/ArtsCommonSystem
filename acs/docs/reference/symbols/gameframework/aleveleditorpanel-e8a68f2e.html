acs::game::leveledit::ALevelEditorPanel

2D グリッドにタイル ID を並べるデータ専用のマップ。 (multi-layer u16 タイル 1 セルの ID(u16)。 0 を「空(タイル無し)」として予約し、描画側がアトラスの index などとして解釈する。 grid) を対話的に編集する タイルを格子状に敷き詰めて作る 2D マップ。 FTilemap は複数レイヤのタイル ID 配列を持つ。 painter panel。 Paint / Erase / Fill / Pick の 4 ブラシ + アクティブ当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。切替 + tile id picker + grid show/hide + snap-to-grid を提供する。 ACS の editor_core が提供するエディタパネルの抽象基底クラス。 Title / DrawUI / OnInit などを override し、CEditorWorkspace に登録して使う。 基底に載せ、Workspace へ 1 行 で統合できる。 2D グリッドにタイル ID を並べるデータ専用のマップ。 データは caller 所有で raw 参照として受け取り、本 panel は タイルを格子状に敷き詰めて作る 2D マップ。 FTilemap は複数レイヤのタイル ID 配列を持つ。 を生成・破棄しない。 画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。は ImDrawList で色付き矩形を積む placeholder (本物テクスチャ atlas は未対応)。 内部に 2D mode の editor_core のエディタ用カメラ。 3D orbit / pan / dolly 操作と ViewMatrix / ProjectionMatrix の取得を提供し、各パネルが値メンバとして所有する。 を内包し pan/zoom する。
