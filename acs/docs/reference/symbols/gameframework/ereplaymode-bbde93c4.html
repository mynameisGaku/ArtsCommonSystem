acs::game::EReplayMode

CReplayDirector の動作モード。 Cキーボード・マウス・ゲームパッドの状態を問い合わせで読む静的クラス。 毎フレーム先頭で Update() を呼んでから状態を読む。Recorder の ERecorderMode と CLockstep の ENetMode を統合し、UI が要求する Pause/Resume を加えた 4 オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。。 遷移は 状態機械の「何もしていない/開始前」を表す既定状態。 Idle→Walk のように、ここから他状態へ遷移する。→Recording→状態機械の「何もしていない/開始前」を表す既定状態。 Idle→Walk のように、ここから他状態へ遷移する。 / 状態機械の「何もしていない/開始前」を表す既定状態。 Idle→Walk のように、ここから他状態へ遷移する。→Playback→状態機械の「何もしていない/開始前」を表す既定状態。 Idle→Walk のように、ここから他状態へ遷移する。 / Playback↔Paused / Paused→状態機械の「何もしていない/開始前」を表す既定状態。 Idle→Walk のように、ここから他状態へ遷移する。 で、Recording から Playback への直接遷移は禁止 (一旦 Stop を挟む)。
