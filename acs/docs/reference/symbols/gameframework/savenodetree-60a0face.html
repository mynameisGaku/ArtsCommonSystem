acs::game::SaveNodeTree

root とその子孫を骨格バイト列へ直列化する (構造 + 位置・回転・拡縮をまとめた座標変換。 親子で合成すると階層的な配置になる。 + 画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。ON/OFF を表す印。 ここでは暗号化/圧縮の有無。)。 root: 直列化するツリーの根 (この root 自身も含む)。 buf: 出力バッファ。 cap: buf の容量。 戻り値: 書き込んだバイト数。 失敗なら 0。 詳細な失敗理由は TrySaveNodeTree を使う。
