acs::game::FAccessibilitySettings

アクセシビリティ設定値の Plain Old Data。 コンストラクタ等の特別な振る舞いを持たない単純な構造体。 コピーが速く扱いやすい。 オブジェクト。 全フィールド public でデフォルトコンストラクト可能。 UI から渡された ある瞬間の状態をまとめて切り取ったコピー。 ここでは 1 フレーム分の入力値の束。を FAccessibilityProfile::Set() ですべての検証に成功した後だけ変更をまとめて反映する処理です。する用途の中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。可能な値型。
