クラス / gameframework

acs::game::fxedit::CParticleEditorPreview

編集中 emitter の preview canvas + stats を提供する in-game ツール。 外部の CParticleEffectSystem 上に preview emitter を 1 個立て、Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 sub-window で Burst ボタン・active particle 数・pool 使用率・spawn 座標・auto-emit toggle・ frame budget (平均 fps) を表示する。 編集中の FParticleEmitterDef が変わったら RecreatePreviewEmitter で即時再生成し、UI 上の値変更を preview に反映する。 CParticleEffectSystem は所有せず、内部に FEmitterHandle と def ある時刻の世界全体の状態を 1 つに固めたもの。 server がこれを配信し、client は受信した複数 snapshot を補間して表示する (FPS/MMO 系で標準)。、 60-frame の fps 履歴 ring を保持する non-copy / non-move 型。
