クラス / gameframework

acs::game::CWaveSpawner

複数 wave をキュー管理し時間軸上で敵をスポーンさせる state machine。 各 wave に紐づく複数の Fウェーブ内で「どの敵を・何体・どの間隔で・どこに」湧かせるかを定める 1 設定。 スポーンルール。 を並列評価し、残数管理 → wave clear → intermission → 次 wave → 全 wave 完了を線形に進める。 non-copy / non-move で AScene 等に値メンバとして持たせる想定。 Tick(dt) で駆動し、敵撃破は NotifyEnemyKilled で通知する。
