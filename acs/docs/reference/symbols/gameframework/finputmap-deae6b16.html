acs::game::FInputMap

物理キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。を名前付きアクションに束ねるマッピング層。 1 アクションに複数の物理キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。を bind でき、いずれか 1 つでも該当すれば Pressed/Held/Released が true になる (OR セマンティクス)。 オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。は持たず、query 時に acs::Cキーボード・マウス・ゲームパッドの状態を問い合わせで読む静的クラス。 毎フレーム先頭で Update() を呼んでから状態を読む。::* を poll する。
