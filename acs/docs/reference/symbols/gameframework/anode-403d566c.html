acs::game::ANode

タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。の中身を表す唯一の統一ゲーム世界に置く部品の単位。 位置やコンポーネントを持ち、親子のツリーで並ぶ。 (旧 FNode2D / FNode3D を統合)。 親子ツリーで階層的な 位置・回転・拡縮をまとめた座標変換。 親子で合成すると階層的な配置になる。 (FTransform3D) を持ち、各ゲーム世界に置く部品の単位。 位置やコンポーネントを持ち、親子のツリーで並ぶ。が OnSpawn/OnUpdate/OnDraw/OnDespawn を override してロジック・画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。を書く。 `NewObject<MyNode>()` で生成して `AddChild` で所有させ、参照は `TWeakObjectPtr<2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。>` を使う。 画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。順は DrawLayer / DrawPriority / YSort を ゲーム世界に置く部品の単位。 位置やコンポーネントを持ち、親子のツリーで並ぶ。に設定し、タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。が自動で並べる。
