acs::game::FTilemap

2D グリッド上に タイル 1 セルの ID(u16)。 0 を「空(タイル無し)」として予約し、描画側がアトラスの index などとして解釈する。 を並べる data-only 値をまとめて入れておく入れ物(TArray や THashMap など)。 ACS は STL の代わりに独自のものを使う。 (当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ー対応)。 当たり判定や描画の対象を分類するための札。 player/enemy/wall のように仲間分けする。ー数 N に対して N 本の row-major (y * width + x) フラット配列を持ち、 tile↔world 座標変換と Fill / FillRect ユーティリティを提供する。 tile_size は world 単位での 1 tile の辺長 (典型 16.0f / 32.0f)。 タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。所有 / TPool 経由を 想定した non-copy / non-move 型。
