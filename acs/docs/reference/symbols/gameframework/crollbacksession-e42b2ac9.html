acs::game::CRollbackSession

rollback netcode の統合層 (オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。履歴 + キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。台帳 + 予測 + 再シミュレーション制御)。 毎 tick、AdvanceTick が「(必要なら) 巻き戻し再実行 → オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。 ある時刻の世界全体の状態を 1 つに固めたもの。 server がこれを配信し、client は受信した複数 snapshot を補間して表示する (FPS/MMO 系で標準)。 → キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。収集 (確定 or 予測) → sim あとで呼んでもらうために登録しておく関数。 ACS では関数ポインタ + void* ユーザーデータの形を取る(STL 不依存方針)。 → tick 前進」を行う。 確定キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。は Submitキーボード・マウス・ゲームパッドの状態を問い合わせで読む静的クラス。 毎フレーム先頭で Update() を呼んでから状態を読む。 で いつでも (past tick でも) 投入でき、予測と食い違っていた場合のみ次の AdvanceTick 冒頭で自動的に巻き戻して再実行する。 non-copy / non-move 型。
