acs::game::CPrefabSystem

名前付き Prefab 読み込んだアセットをキー(FAssetId)で保持・共有し、再利用する管理表。 ACS では CAssetRegistry。。 型を後から指定できる部品。 TArray<int> は『int の配列』というように中身の型を差し替えられる。 (= factory 関数) を登録し、ID または名前から 2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。 ツリーを spawn する。 1 ML ランタイムが推論を実行するための作業単位(モデル・実行環境を束ねたもの)。内で通常数十〜数百件の登録を想定し、線形走査ベース。 登録された factory メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。の所有移譲を抑止するため non-copy / non-move。
