acs::game::CModRegistry

ユーザー Mod の登録・有効化・並び順を管理する薄い読み込んだアセットをキー(FAssetId)で保持・共有し、再利用する管理表。 ACS では CAssetRegistry。。 各 Mod を FModInfo の内部 末尾追加が速く要素は連続メモリに並ぶ。 コピー禁止・ムーブ専用。 に保持し、load_order 昇順に並べる。 文字列は 所有せず呼び出し側の寿命に依存する。 1 ゲーム寿命に 1 インスタンスのみを想定し non-copy / non-move とする。
