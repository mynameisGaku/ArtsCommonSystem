acs::game::FSequence

時間付きアクションの連鎖を builder パターンで構築する時間順に処理を並べて演出やイベントを組み立てる仕組み。。 Wait / Call / F値を時間で滑らかに補間する仕組み。 UI・カメラ・演出・シーン遷移に使う。 を連鎖して定義し、複数の FSequence を同時に再生・管理する実行係。 Start で所有して走らせ、毎フレーム Tick で進める。::Start に Move して実行する。 non-copy だが move 可能 (Runner がそのメモリ/資源を『誰が解放する責任を持つか』。 はっきりさせると安全。を奪うため)。
