acs::game::FPrefabId

Prefab を識別する packed 32bit handle (generational)。 layout は low24 = index、high8 = generation。 m_Packed == 0 が invalid。 シーン内の ANode を指す index(24bit) + generation(8bit) の packed ハンドル。 stale 検出に使う。 / FShapeId と完全に同じパターン。
