acs::game::CAssetBundle

タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。スコープのゲームで使う画像・音・モデル・データなどの素材ファイル。集合を処理の完了を待たずに先へ進み、結果は後で受け取るやり方。 重い読み込みなどで画面を止めない。ロードし集約進捗を提供する bundle。 オブジェクトが生成→更新→破棄されるまでの一連の段階。 各段階にフック関数が対応する。は Add* → BeginLoad → (poll Progress/IsLoaded) → ... → Unload。 AScene にメンバとして埋め込み、内部 複数で共有するスマートポインタ。 参照カウントが 0 で自動解放。<AAsset> の保持で Unload まで実体の 生存を保証する。 BeginLoad 後の Add はロード開始後の集合変更が未定義になるのを 避けるため無視する。
