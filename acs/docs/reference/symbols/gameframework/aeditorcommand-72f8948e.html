acs::game::editor_core::AEditorCommand

全エディタが共有する undo/redo の原子単位 (純粋抽象)。 Command パターンの GoF 古典に沿い、1 操作 = 1 AEditorCommand 派生インスタンス として表現する。 派生クラスは Execute / Undo / Description を必ず override する。 CanMerge / MergeWith は default で merge 拒否であり、連続 drag をまとめたい派生 のみ override する。 ベース型を `コピー不可・ムーブのみで、スコープを抜けると自動解放。<AEditorCommand>` で CUndoStack に 持たせるため virtual dtor を持ち、複製事故を防ぐため非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。 / 非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。とする。
