クラス / gameframework

acs::game::CSettings

型付き key-value でゲーム設定値を保持する小型ストア。 音量・解像度・キーソケットを特定のアドレス/ポートに結び付けて、そこで送受信できるようにすること。等の「ゲームを跨いで永続化したい設定値」を 32bit の浮動小数(float 相当)。 座標・時間・係数など小数値に使う基本型。 / i32 / bool / const char* の 4 型で持つ。 key は `audio.master` のようなドット階層を文字列で 表現するだけのフラット key-value で、線形検索 + 同名 key 上書きで運用する。 key / string 値はそのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。 const char* (寿命は呼び出し側が保証) で、中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。・中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。禁止。 Save/Load は INI 風 `<tag>:<key>=<value>` テキスト (UTF-8 / LF) で読み書きする。
