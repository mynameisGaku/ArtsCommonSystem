クラス / gameframework

acs::game::ABtDecorator

子を 1 つだけ持ち、その結果を EBtDecoratorOp で変換する装飾ゲーム世界に置く部品の単位。 位置やコンポーネントを持ち、親子のツリーで並ぶ。。 Inverter / ForceSuccess / ForceFailure / Repeat の 4 種を提供する。 Running は いずれの op でも素通しする (子が進行中なら decorator も進行中)。 子が未設定の 場合は Failure を返す (= 装飾対象が無いのでソフトフェイル)。 子のそのメモリ/資源を『誰が解放する責任を持つか』。 はっきりさせると安全。は decorator が握る (SetChild で move-in、既存の子は破棄して差し替え)。
