acs::game::AFollow2DComponent

参照したゲーム世界に置く部品の単位。 位置やコンポーネントを持ち、親子のツリーで並ぶ。へ追従する 2D ANode に付ける部品。 1 つの機能 (物理・描画・当たり判定など) を担い、組み合わせて挙動を作る。(オブジェクト参照プロパティのデモ)。 public メンバ + 単一継承なので ACS_RFIELD_REF / ACS_RFIELD_D で offset 反射でき、 authored 値(target ID / speed)が実体へ apply される(Play/standalone でも一致)。 OnUpdate で target ID を 2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。* へ解決し、speed[units/sec] で近づく。
