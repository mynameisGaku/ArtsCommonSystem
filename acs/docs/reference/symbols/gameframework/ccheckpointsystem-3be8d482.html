クラス / gameframework

acs::game::CCheckpointSystem

プラットフォーマー系の「死亡時に戻る復活ポイント」を管理する小型ある種類の状態 (cooldown / チェックポイント / カード等) をまとめて持ち、登録・更新・問い合わせの API を提供する小さなクラス。。 配置済み checkpoint を string id で識別し、現在 active な 1 つだけを保持して TriggerRespawn() で復活先座標 + level index を引き出す。 HP オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。は持たず 「どこに復活させるか」のみを管理する責務に絞る (CHealthSystem の DeathCallback から叩く想定)。 one_way / requires_unlock のON/OFF を表す印。 ここでは暗号化/圧縮の有無。を Activate 時に評価し、不正な 遷移は false 返却で弾く。 文字列は const char* そのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。、I/O は持たない。
