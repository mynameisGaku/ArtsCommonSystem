acs::game::editor_core::AEditorPanel

全エディタImGui で作る、デバッグや編集用の小さな子ウィンドウ(調整画面)。の抽象基底クラス。 各 panel (AHierarchyPanel / AInspectorPanel / AEditorToolbar 等) や複数の editor 群を統一的に配線するため、オブジェクトが生成→更新→破棄されるまでの一連の段階。 各段階にフック関数が対応する。 + 選択通知 + 各ウィジェットを画面のどこにどの大きさで置くかを決めて配置すること。 Layout で行う。永続化を共通化する。 Title() と DrawUI() は純粋仮想で各 panel 必須、それ以外の hook は 何もしない処理。 呼んでも安全で副作用が無いこと。 default を 持ち必要な panel だけ override する。 Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。::Begin/End の wrap は行わず派生側責務とし、 Workspace メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。は OnInit で受けて non-owning で保持する。
