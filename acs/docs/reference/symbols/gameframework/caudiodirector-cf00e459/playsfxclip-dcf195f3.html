acs::game::CAudioDirector::PlaySfxClip

raw 音声を一定間隔で数値化した生波形データ。 圧縮なしでそのまま再生できる形式。 の FAudioClipDesc を SFX one-shot として直接再生する。 volume は EffectiveSfxVolume * volume_scale で合成済 (duck は掛けない)。 clip: 再生する 音声を一定間隔で数値化した生波形データ。 圧縮なしでそのまま再生できる形式。 クリップ記述子。 volume_scale: この one-shot の追加ゲイン [0, ~] (0.0 以下で 何もしない処理。 呼んでも安全で副作用が無いこと。)。 pitch: 再生ピッチ (1.0 が等倍)。 戻り値: 再生 voice 実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。 (インターフェースの裏で実際に仕事をする具象実装。 ここでは OpenXR ローダ等の XR 実装本体。 未設定 / 不正 clip は kInvalidAudioVoice)。
