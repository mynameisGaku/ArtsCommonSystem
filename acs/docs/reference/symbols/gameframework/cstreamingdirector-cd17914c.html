acs::game::CStreamingDirector

同じリソースを「どう解釈して読むか」を表す窓。 1 つのテクスチャに SRV / RTV / DSV など複数のビューを作れる。アを中心とした矩形範囲のチャンクを load/unload 管理するディレクタ。 オブジェクトが生成→更新→破棄されるまでの一連の段階。 各段階にフック関数が対応する。は Init() → 毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。 SetViewerPos + Tick → ClearAll() (タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。終了時)。 Tick() は (1) 範囲内チャンクを Queued に挿入、(2) Loading 上限内で Queued→Loading→Loaded を進行、(3) 範囲外の Loaded を Unloading→Unloaded に遷移、を 行う。 SetAssetRegistry() で実 パスからアセットを読み込み、TSharedPtr でキャッシュ共有する中心クラス。 を差すと各チャンクが 1 1 まとまりのアセット集合をロード/アンロードする単位。 チャンクごとのアセットを束ねる。 を 実ロードし、未設定時は simulated load time で本命が使えない時の代替経路。 XR では HMD 未接続時に通常の 2D 画面描画へ切り替えること。する。 non-copy / non-move。
