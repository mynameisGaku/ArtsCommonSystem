リファレンス/gameframework/CScoreSystem
クラス / gameframework

acs::game::CScoreSystem

スコア累積 + コンボ計算 + マイルストン通知をまとめた高レベルある種類の状態 (cooldown / チェックポイント / カード等) をまとめて持ち、登録・更新・問い合わせの API を提供する小さなクラス。。 アーケード / 高速アクション系向け。 NotifyHit でコンボがインクリメントされ、 AddScore() 時にコンボから算出した倍率を掛けて加算する。 NotifyMiss() または combo_duration 内に次のヒットが無ければコンボがリセットされる。 倍率は entry に ×100 整数で記録し (Replay / Telemetry の偽差分回避)、category は所有しない const char*、entry log は max 100 件の capped append。 全 noexcept で非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。・ 非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。。
