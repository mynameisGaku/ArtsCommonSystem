クラス / gameframework

acs::game::modelview::AModelAnimationPanel

animation clip の再生制御 + timeline UI を提供する ModelViewer 用 panel。 editor_core::ACS の editor_core が提供するエディタパネルの抽象基底クラス。 Title / DrawUI / OnInit などを override し、CEditorWorkspace に登録して使う。 を継承し、clip 選択 dropdown / Play / Pause / Stop / Time slider / Loop checkbox / Speed slider / BlendWeight slider を Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 で画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。する。 clip メタ情報は SetClips で値中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。所有し、Tick(dt) で Playing 中の時刻を進めて 終端で OnFrameCallback を発火する。 実際の bone palette 計算や 画像処理に特化した演算装置。 描画はここで行われる。 反映は呼出側 (renderer + CAnimationPlayer) に委譲し、本 panel は時刻進行と UI control のみを持つ。
