クラス / gameframework

acs::game::AMeshComponent3D

2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。 に「何を描くか」を持たせるデータのみのANode に付ける部品。 1 つの機能 (物理・描画・当たり判定など) を担い、組み合わせて挙動を作る。 (画像処理に特化した演算装置。 描画はここで行われる。 非依存)。 プリミティブ種別 / メッシュパス / 色を保持するだけで画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。はしない。 外部実際に画面へ絵を出す描画システム本体。が タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。を走査して読み取る。 editor_abi の従来 3D ゲーム世界に置く部品の単位。 位置やコンポーネントを持ち、親子のツリーで並ぶ。と同じデータモデルなので、エンジンの 3D タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。グラフをエディタの編集対象に昇格させる土台になる。
