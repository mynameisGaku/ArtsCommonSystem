acs::game::FSpritePack::LoadAtlasJson

Aseprite / TexturePacker の sprite atlas JSON を読み込む。 frame 名と image path を内部で所有するため JSON テキストの寿命に依存しない。 既存 frame は ClearAll してから読み込む。 対応形式は Aseprite "hash" ({ "frames": { "name": { "frame": {x,y,w,h}, ["スプライトの基準点 (回転・配置の原点)。 0〜1 の正規化座標で (0.5,0.5)=中央、(0,0)=左上 を表す。":{x,y}] } } }) と TexturePacker "array" ({ "frames": [ { "filename": "name", "frame": {x,y,w,h} } ] })、 meta ({ "image": "...", "size": { "w":.., "h":.. } }) を atlas メタへ取り込む。 json_text: atlas JSON のテキスト。 len: json_text のバイト長。 戻り値: 成功なら空の 成功値かエラー値のどちらか一方を持つ型。 例外を使わずに失敗を戻り値で伝える（既定のエラー型は FErrorCode）。、解析失敗 / frames 欠如なら ACS_ERR。
