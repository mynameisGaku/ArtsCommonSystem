acs::game::FPbrParams2D

Physically Based Rendering。 金属度・粗さなど物理量で材質を表すリアルな描画手法。 (BRDF) サーフェスマテリアルのプロパティ。 metallic-roughness ワークフロー。 ベースカラー (アルベド) はテクスチャ + tint、面や線に垂直な向きのベクトル。 当たった面の向きやライティングの計算に使う。マップ、メタリック/ラフネス、エミッシブ、 AO を持つ。 テクスチャはパス参照 (sprite_path と同様にランタイムが必要になるまで計算を先延ばしにする方式(lazy)。 現行 TDerived は生成時と依存通知時に即時評価し、Get の再計算は dirty が残った場合の補完経路。ロード)。 2D の 動的ライト (CLighting2D) で陰影付けされる lit 2D の 1 枚絵(キャラ・アイコン等)。 矩形にテクスチャを貼って描く。用。
