acs::game::FWaterVolumeId

CWaterVolume を識別する packed 32bit handle (generational)。 各ウィジェットを画面のどこにどの大きさで置くかを決めて配置すること。 Layout で行う。は FShapeId と同一 (low24=index, high8=generation)。
