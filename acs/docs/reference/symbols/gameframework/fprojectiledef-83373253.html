acs::game::FProjectileDef

弾種毎の挙動パラメータ (RegisterDef で登録)。 1 つの弾種を「def」として事前登録し、Spawn 時に id で名前引きする。 多数の弾を 発射しても per-instance memory が小さく、同種の弾の挙動を一括変更できる。
