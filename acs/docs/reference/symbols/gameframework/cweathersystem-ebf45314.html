クラス / gameframework

acs::game::CWeatherSystem

天候モードを保持し、現在 → 目標天候の線形遷移と画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。修飾係数を提供するコンポーネントを持つエンティティ群を毎フレーム処理する関数(移動・AI など)。 CSystemScheduler で順に実行する。。 CAmbientDirector (時刻2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。) と直交し、天候ごとの ambient 倍率 / 粒子密度 / sky tint / 風強さ / 霧密度を 1 つの LUT から引いて current/target 間で 2 つの値の間を比率 t(0〜1)でまっすぐ補間する関数(線形補間)。 t=0 で始点、t=1 で終点。 する。 non-copy / non-move で AScene 等に値メンバとして持たせ、Tick(dt) で遷移を進める。
