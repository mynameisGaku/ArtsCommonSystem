メンバー関数 / gameframework

acs::game::CSceneNodeGraph::SweepSphereActiveRange

有効かつ可視なmesh boundsへworld空間の球を指定t区間だけsweepする。 node local Axis-Aligned Bounding Box。 軸に平行な直方体の境界ボックス。 当たり判定の粗い包囲に使う。をworld scaleに応じて保守的に拡張し、球中心rayとの最初の接触を返す。 回転と非一様scaleを扱い、角では安全側へ早く命中する場合がある。 radius 0はRaycastActiveRangeと同じ。 center_ray: world空間を移動する球中心ray。 距離としてtを使う場合はdirectionを正規化する。 radius: world空間の球半径。 有限かつ0以上。 minimum_t: 含める最小t。 有限かつ0以上。 maximum_t: 含める最大t。 有限かつminimum_t以上。 out_t: 非nullかつ命中時だけ最近hitのtを書き込む。 戻り値: 区間内で最も手前の有効mesh node。 キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。不正または外れはinvalid。
