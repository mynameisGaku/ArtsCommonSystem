acs::game::editor_core::CEditorWorkspace::Shutdown

登録済み全 panel に OnShutdown を呼んでから list を解放する。 CSelectionService 参照も解除する。 動作ON/OFF を表す印。 ここでは暗号化/圧縮の有無。類は再 Init で同じ host 設定を 引き継げるよう意図的にリセットしない。 多重 Shutdown 可。
