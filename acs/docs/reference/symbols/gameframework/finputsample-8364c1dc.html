acs::game::FInputSample

1 tick 分の raw キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。サンプル。 trivially-copyable な Plain Old Data。 コンストラクタ等の特別な振る舞いを持たない単純な構造体。 コピーが速く扱いやすい。。 末尾追加が速く要素は連続メモリに並ぶ。 コピー禁止・ムーブ専用。 に詰めて bulk memcpy で I/O できる。 `key_codes_changed[i]` は今 tick にオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。変化があった key code (Win32 VK_* 風 / SDL scancode 風 — 解釈はアプリ層に委ねる)、`key_states[i]` は同 index の press(1) / release(0) を表す。 未使用スロットは key_codes_changed = 0 で埋める 規約 (key code 0 は VK_NULL = 「無効キー」相当)。 最大 8 key までしか格納 できないが、同一 tick 内で 9 個以上のオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。変化が同時に起きるケースは事実上 発生しないので十分。
