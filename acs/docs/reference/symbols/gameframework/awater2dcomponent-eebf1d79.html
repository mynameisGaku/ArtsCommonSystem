クラス / gameframework

acs::game::AWater2DComponent

波打つ水面 + 干渉 (ripple / splash) + 水面を通った光が水底に作る、揺らめく網目状の明暗模様。を手続き生成する水ANode に付ける部品。 1 つの機能 (物理・描画・当たり判定など) を担い、組み合わせて挙動を作る。。 shape 指定 (矩形 / 楕円 / 川 / 多角形 / スプライン) で実三角形メッシュを焼く。 TopDown では 専用 画像処理に特化した演算装置。 描画はここで行われる。 水面効果が深さ・波・泡・水面を通った光が水底に作る、揺らめく網目状の明暗模様。・きらめき・リップルをピクセル単位で評価し、 SideView では上端を波で揺らし平面反射も行う。
