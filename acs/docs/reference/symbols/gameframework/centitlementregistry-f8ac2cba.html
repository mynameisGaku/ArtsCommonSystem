acs::game::CEntitlementRegistry

プレイヤーがコンテンツを「持っているか」を表す情報 (entitlement)。 DLC・シーズンパス・引換コード等。情報 (entitlement) をローカルに保持し問い合わせる読み込んだアセットをキー(FAssetId)で保持・共有し、再利用する管理表。 ACS では CAssetRegistry。。 DLC・シーズンパス・ゲームの性能に影響しない、見た目だけのアイテム (スキン・装飾)。 pay-to-win を避ける指針。パック等のプレイヤーがコンテンツを「持っているか」を表す情報 (entitlement)。 DLC・シーズンパス・引換コード等。をストア非依存で保持し、 IsActive()/HasAny() でゲームロジックから所持判定を行う。 Pillar S (ストア SDK) 側のPC に載っている GPU。 複数あれば高性能なものを優先選択できる。が取得結果を Add() で流し込む想定。 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。・非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。。
