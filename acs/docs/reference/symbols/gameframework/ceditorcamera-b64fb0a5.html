クラス / gameframework

acs::game::editor_core::CEditorCamera

2D pan-zoom と 3D 3D カメラが注視点(target)を中心に yaw / pitch / distance で周回する操作モデル。 を 1 クラスで扱う editor 共通の視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。コントローラ。 ModelViewer (3D) / LevelEditor (2D) / TilemapEditor 等が共有する。 editor 側はマウスキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。を HandleMouseキーボード・マウス・ゲームパッドの状態を問い合わせで読む静的クラス。 毎フレーム先頭で Update() を呼んでから状態を読む。 にそのまま流し込むだけで、3D 3D カメラが注視点(target)を中心に yaw / pitch / distance で周回する操作モデル。 (yaw + pitch + distance + target) / 2D pan-zoom (position + zoom_2d) が成立する。 Tick が `1 - exp(-rate*dt)` の framerate independent な指数2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。で raw target / zoom へ追従させる。 全 noexcept / 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。 / 非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。 / ACSの基盤コードと公開APIでは、可変長配列、文字列、所有権管理に TArray、FString、TUniquePtr などのACS型を使用する方針です。で、内部 state は Plain Old Data。 コンストラクタ等の特別な振る舞いを持たない単純な構造体。 コピーが速く扱いやすい。 のみ。
