acs::game::EColorblindMode

色覚補正モード。 実 LUT / GPU 上で頂点やピクセルを計算する小さなプログラム。 ACS では HLSL で書く。パラメータの解決はシーン描画後に画面全体へかける後処理(Bloom・トーンマップ・色調整など)。パスが担当し、本 決まった選択肢の集合を表す型(列挙)。 例: 上下左右のキー。 は どの補正を適用するかの選択値だけを表す。
