acs::game::ASpriteAnimComponent

時間→frame index の 経過時間から現在のアニメフレーム番号を計算する部品。 を sibling の ノードにスプライト (1 枚絵) を描画する部品。 に橋渡しする AComponent。 同じ 2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。 に付いた ノードにスプライト (1 枚絵) を描画する部品。 の UV サブ矩形を毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。書き換えて 2D の 1 枚絵(キャラ・アイコン等)。 矩形にテクスチャを貼って描く。シートアニメを再生する。 frame index→UV は m_FrameUvs に事前計算して持ち、 InitGrid はグリッドシートを等分計算、BeginFrames/AddFrameUv/EndFrames は任意 UV 列を積む。 sibling の lookup は add 順依存を避けるため最初の OnUpdate まで必要になるまで計算を先延ばしにする方式(lazy)。 現行 TDerived は生成時と依存通知時に即時評価し、Get の再計算は dirty が残った場合の補完経路。する。
