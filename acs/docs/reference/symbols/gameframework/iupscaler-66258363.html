acs::game::IUpscaler

解像度アップスケーラの抽象 interface (FSR / DLSS / XeSS)。 実際に画面へ絵を出す描画システム本体。が低解像度で画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。した最終バッファをターゲット解像度に拡大する後段ステージの 差し替え可能な境界面。 実装(backend)を後から入れ替えられるよう、インターフェースだけを切り出した接合点。。 具象は別モジュール (UpscalerFsr / UpscalerDlss / UpscalerXess) として SDK 依存込みで実装する。 オブジェクトが生まれてから壊れるまでの寿命。 これを過ぎたものを触ると危険。は Init(kind) で 1 度だけ初期化、Shutdown() で 1 度 だけ破棄し、kind 切替は Shutdown → Init(new_kind) の 2 段で行う。
