acs::game::CTweenManager

32bit の浮動小数(float 相当)。 座標・時間・係数など小数値に使う基本型。 / 2 次元ベクトル(x, y)。 2D の位置・速度・方向を表す基本型で、8 バイトと小さい。 / 3 次元ベクトル(x, y, z)。 3D の位置・方向・色などに使う最重要型で、SIMD演算に最適化されている。 変数を毎 Tick 2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。して書き戻す値書き戻し型 tween ある種類の状態 (cooldown / チェックポイント / カード等) をまとめて持ち、登録・更新・問い合わせの API を提供する小さなクラス。。 利用者の変数メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。を渡すと、Tick ごとに from→to の2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。値を target に書き込む。 Handle は (index, generation) で 「古くなって無効になった」状態。 例えば破棄された ANode を指したままのハンドルが stale。 世代付きハンドルでは世代不一致で検出する。 参照を検出する。 完了時はfloat / double など小数を表す数値型。 丸め誤差があるため == ではなく EXPECT_NEAR で許容誤差つきで比べる。誤差を残さず target に正確に to を書く。
