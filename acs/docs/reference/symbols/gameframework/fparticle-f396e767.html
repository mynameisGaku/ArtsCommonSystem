acs::game::FParticle

個別粒子の生データ。 画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。側はこの構造体を直接読み取り、age/lifetime から2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。係数を計算する。 position / velocity 以外は emitter から複製してきた瞬時パラメータで、emitter の def が後から変わっても放出済 particle は出生時の値で進む (自分が動くのに必要なデータを全部自分で持っていて、外部の状態に依存しないこと。 particle)。
