クラス / gameframework

acs::game::CHierarchyVisibilityBatch

DFS pre-order の階層可視性を一括評価して保持する。 親がキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。内で先行する通常経路は stack を使って線形時間で評価する。 順序が不正な要素だけ scalar 判定へ戻り、結果の互換性を維持する。
