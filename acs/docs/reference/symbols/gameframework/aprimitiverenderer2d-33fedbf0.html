acs::game::APrimitiveRenderer2D

プリミティブ形状を描く AComponent。 shape (Box / Circle / Triangle) を owner の world 位置・回転・拡縮をまとめた座標変換。 親子で合成すると階層的な配置になる。 で配置・回転して 多数のスプライトをまとめて効率よく描画する仕組み。 へ積む。 円・三角は三角形ファンで塗る。 エディタは shape を読んで画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。と コライダー形状を一致させる。
