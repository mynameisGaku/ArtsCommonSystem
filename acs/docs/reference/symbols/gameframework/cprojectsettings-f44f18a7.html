acs::game::CProjectSettings

プロジェクト設定のストア (ビルトインスキーマ + ユーザー定義、INI 読み書き)。 ResetToDefaults でスキーマ全項目を既定値で持ち、Load で INI の値を上書き + 未知のキーをユーザー定義として取り込む。 値は全て文字列で保持し、型付き Get* でパースして返す (パース失敗は既定値)。
