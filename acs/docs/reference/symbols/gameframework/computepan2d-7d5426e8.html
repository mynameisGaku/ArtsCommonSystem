acs::game::ComputePan2D

listener の向きを基準にした左右音を左右どちらのスピーカーへ振るか。 -1=左 / 0=中央 / +1=右。 [-1, +1] を返す。 forward = (cos angle, sin angle)、右手向きと大きさを持つ量。 2D/3D の位置・速度・方向を FVec2/FVec3 で表す。 right = (forward.y, -forward.x) (forward を時計回り 90° 回転)。 pan = dot(normalize(to_src), right) を [-1,1] に clamp。 真正面 / 真後ろ = 0、真右 = +1、真左 = -1。 listener に重なる点は 0。 listener_pos: listener の世界座標。 listener_angle_rad: listener の向き角 (ラジアン、Y+ up)。 source_pos: source の世界座標。 戻り値: 音を左右どちらのスピーカーへ振るか。 -1=左 / 0=中央 / +1=右。値 (-1=完全左, 0=正面/真後ろ, +1=完全右)。
