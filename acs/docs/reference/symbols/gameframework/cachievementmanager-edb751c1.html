acs::game::CAchievementManager

実績の定義 + 進捗管理 + Storefront SDK 統合を行う高レベルある種類の状態 (cooldown / チェックポイント / カード等) をまとめて持ち、登録・更新・問い合わせの API を提供する小さなクラス。。 ゲームロジックから進捗を流し込み、max_progress に達したら自動 unlock し、attach 済みの プラットフォーム SDK (Steam 等) への抽象橋渡しシーム。 があればSteam や各家庭機が提供する、実績・課金・マッチング等を扱う公式ライブラリ。 へ伝搬する。 定義 (immutable) と進捗 (mutable) を別 末尾追加が速く要素は連続メモリに並ぶ。 コピー禁止・ムーブ専用。 に 1:1 で持ち、id の線形検索で参照する。 Bridge 未 attach 時はローカル進捗のみ 追跡するオフラインモードで動作する。 全 noexcept・非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。・非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。。
