acs::game::FCheckpointId

チェックポイントの generational handle。 32bit packed = 24bit index + 8bit generation。 0 = invalid。 Unregister 後に slot が再利用されても、古い handle は generation 不一致で弾かれる。 FHealthId / FPickupId / FShapeId / シーン内の ANode を指す index(24bit) + generation(8bit) の packed ハンドル。 stale 検出に使う。 と同パターン。
