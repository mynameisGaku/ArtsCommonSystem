リファレンス/gameframework/CHungerSystem
クラス / gameframework

acs::game::CHungerSystem

複数 survivor の生存統計値 (空腹 / 喉 / 疲労 / 正気 / 体温 / Custom) を管理する。 slot+gen パターンで survivor を管理し、Tick で各 stat を秒単位に decay させて critical 閾値跨ぎを検出し、0 到達時は DamageCallback 経由で HP ダメージを通知する。 HP 自体は管理せず弱結合 bridge を取る。 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。・非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。 (末尾追加が速く要素は連続メモリに並ぶ。 コピー禁止・ムーブ専用。<FSurvivorSlot> が さらに 末尾追加が速く要素は連続メモリに並ぶ。 コピー禁止・ムーブ専用。<FStatState> を持つ二段ネスト構造のため)。
