acs::game::CPhotoMode::EFilterKind

色フィルタの種別。 実 LUT / GPU 上で頂点やピクセルを計算する小さなプログラム。 ACS では HLSL で書く。パラメータの解決はシーン描画後に画面全体へかける後処理(Bloom・トーンマップ・色調整など)。パスが担当し、 本クラスはどのフィルタが選ばれているかだけを保持する。
