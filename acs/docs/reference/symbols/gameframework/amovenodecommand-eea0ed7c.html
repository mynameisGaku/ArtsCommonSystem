acs::game::editor_core::AMoveNodeCommand

2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。 の position を変更する AEditorCommand 派生実装。 教科書的な使用例で、連続 drag を 1 件にまとめる CanMerge 実装も持つ。 マージ規約は、 同じ m_Target (raw pointer 一致) かつ同じ kind のとき MergeWith で m_NewPos を next の m_NewPos に置き換え、m_OldPos は最初の cmd のものを保つ (= Undo 1 回で初期位置に戻る)。 対象ゲーム世界に置く部品の単位。 位置やコンポーネントを持ち、親子のツリーで並ぶ。が既に Destroy 済みでも pointer 比較自体は安全だが、実 Execute / Undo 時に 対象が dangling だと UB になるため、editor 側で Destroy 時に undo stack を Clear する等の ハイレベルポリシーで防ぐ。
