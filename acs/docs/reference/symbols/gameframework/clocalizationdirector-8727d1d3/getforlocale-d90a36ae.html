acs::game::CLocalizationDirector::GetForLocale

指定 locale で key を引く (Default 本命が使えない時の代替経路。 XR では HMD 未接続時に通常の 2D 画面描画へ切り替えること。なし)。 当該 locale に無ければ key 自身を返す。 key == nullptr は空文字 "" を返す。 loc: 引く言語と地域の設定 (例: 日本語 / 英語)。 どの翻訳を出すかの選択キー。。 key: 引く文字列 ID。 戻り値: 翻訳済み文字列 (未登録なら key 自身、key==nullptr なら "")。
