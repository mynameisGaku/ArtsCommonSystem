クラス / gameframework

acs::game::CCombatStateMachine

タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。全体の戦闘ターン進行の局面(プレイヤーの番 / 敵の番など)。 ETurnPhase で表す。と連続脅威レベルを追跡する決められた状態のどれか 1 つにいて、入力で別の状態へ遷移する仕組み (state machine)。 戦闘フェーズ管理などに使う。。 ECombatState の 6 オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。を全 mutation を Notify 系および Reset 経由に閉じて遷移させ、敵検出 / 戦闘開始 / 終了 / ボス出現 / 撃破などを一元化する。 ThreatLevel() は state 既定値へ 指数減衰で追従する連続値 [0,1] で、バックグラウンドミュージック。 場面の間ずっとループで流す音楽。 intensity や ambient color に供給できる。 複数敵 を FEnemyAwareness の 末尾追加が速く要素は連続メモリに並ぶ。 コピー禁止・ムーブ専用。 で並列追跡し、OnStateChange ある出来事が起きた時に呼んでもらう関数。 で外部ディレクタ (Music / Ambient / UI) と疎結合に連動する (本クラスは下位リソースを直接知らない)。
