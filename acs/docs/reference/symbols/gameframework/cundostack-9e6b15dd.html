acs::game::editor_core::CUndoStack

全エディタが共有する undo / redo の中央ハブ。 AEditorCommand 派生インスタンスを 2 本の LIFO 関数の呼び出しに沿って自動で確保/解放される高速なメモリ。 寿命はスコープに縛られる。 (undo / redo) に コピー不可・ムーブのみで、スコープを抜けると自動解放。 で所有し、Push で 1 操作分を実行・登録、Undo / Redo で巻き戻し / やり直しする。 連続 drag 等の merge も Push 時にここで判定する。 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。 / 非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。、全 noexcept、ACSの基盤コードと公開APIでは、可変長配列、文字列、所有権管理に TArray、FString、TUniquePtr などのACS型を使用する方針です。 (acs::末尾追加が速く要素は連続メモリに並ぶ。 コピー禁止・ムーブ専用。 + acs::コピー不可・ムーブのみで、スコープを抜けると自動解放。)。
