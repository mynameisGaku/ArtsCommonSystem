acs::game::editor_core::CEditorTheme

全エディタ panel が共通参照する Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 スタイル統一テーマ管理。 色パレット / spacing / font scale / corner radius を 1 ヶ所で管理し、起動時に Init() を呼ぶだけで全エディタが統一見た目になる。 色は ACS::4 次元ベクトル(x, y, z, w)。 RGBA 色や同次座標、行列との掛け算に使う。 で保持し、 ImVec4 への変換は .cpp 内のみ (ヘッダから <imgui.h> を漏らさない)。 テーマの色 / spacing / corner をまとめた既定スナップショット。 ACS では EEditorThemePreset(Dark / DarkBlue / Light など)。 / colors / font_scale / corner / spacing は人間可読の `.acstheme` テキストへ 永続化できる。 Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。::GetStyle() への適用は global 副作用なので非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。・非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。。
