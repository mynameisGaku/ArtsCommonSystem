acs::game::FShapeId

衝突形状を一意に指す実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。 (24bit index + 8bit generation を packed)。 0 = invalid。 slot を再利用しても generation が進むため、削除済みスロットを指す 古い handle は IsValid / Generation 照合で無効化される (シーン内の ANode を指す index(24bit) + generation(8bit) の packed ハンドル。 stale 検出に使う。 と同パターン)。
