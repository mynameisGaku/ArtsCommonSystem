acs::game::CUdpTransport::Connect

接続を張らずデータグラムを 1 通ずつ送る通信方式。 速いが到達・順序は保証されない。 関連語 TCP。 socket を用意し、送信先 endpoint を確定する。 WSAStartup (ref-count) → socket 生成 → 非ブロッキング化 → local port に bind → remote endpoint 保持。 多重 IBackendClient で送信先(サーバや出力ファイル)を開いて通信を始めること。 終了時は Disconnect。 は前の socket を閉じてから張り直す。 address: 送信先 192.168.0.1 のような 4 数値で表す主流のネットワークアドレス形式。 dotted-quad (例 "127.0.0.1")。 port: 送信先ポート。 戻り値: 成功なら空の 成功値かエラー値のどちらか一方を持つ型。 例外を使わずに失敗を戻り値で伝える（既定のエラー型は FErrorCode）。、失敗なら os_error 付きエラー。
