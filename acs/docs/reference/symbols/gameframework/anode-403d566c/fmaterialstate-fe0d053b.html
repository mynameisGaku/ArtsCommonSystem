acs::game::ANode::FMaterialState

この node に焼き込んだマテリアル効果のオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。 (多数のスプライトをまとめて効率よく描画する仕組み。 型に依存しない軽量 Plain Old Data。 コンストラクタ等の特別な振る舞いを持たない単純な構造体。 コピーが速く扱いやすい。)。 2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。.h を軽く保つため、効果プリセットの値だけをここに持つ (ESpriteEffect の整数値 + パラメータ)。 DrawTree が rc.Sprites().SetEffect へ渡す。
