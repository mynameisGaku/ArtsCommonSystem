acs::game::FTileId

1 セルを表すタイル ID (u16)。 0 を「空 (no tile)」として予約する。 65535 種類までのタイルを許容し、画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。側が atlas index として解釈するか辞書 lookup するかは利用者責任。 0 は背景透過扱いの空セルとして予約される。
