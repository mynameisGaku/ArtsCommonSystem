acs::game::CParticleEffectSystem

複数 emitter と共有 particle pool を束ねる軽量 sprite particle コンポーネントを持つエンティティ群を毎フレーム処理する関数(移動・AI など)。 CSystemScheduler で順に実行する。。 各 emitter は generational handle で参照され、固定容量の particle pool を共有する。 画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。 ライブラリの機能を外から使うための窓口(関数や型の取り決め)。 例: ネットワークは WinSock をくるんだ薄い API として提供される。 は一切呼ばず AllParticles() で生バッファを渡すのみ (画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。戦略は user 側)。 規則性のない数値。 敵の出現位置やドロップ抽選などに使う。は内部 LCG、寿命切れは active flag を落として pool へ返却する。
