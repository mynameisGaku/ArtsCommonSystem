acs::game::CCollisionWorld2D

一様グリッド broad-phase を持つ 2D 衝突判定の高レベル ライブラリの機能を外から使うための窓口(関数や型の取り決め)。 例: ネットワークは WinSock をくるんだ薄い API として提供される。。 形状 (軸並行の 2D 矩形コライダー（中心+半サイズ）。 最も軽い当たり判定。 / 2D の円コライダー（中心+半径）。 / 2D の凸多角形コライダー（最大 16 頂点）。 複雑な形のスプライトに。 / 回転できる 2D 矩形コライダー（OBB）。) を FShapeId で管理し、内部の SpatialGrid (cell_size 固定の一様グリッド) で O(N + K) 条件(指定コンポーネントを全部持つ)に合うエンティティを選んで反復する仕組み。 ECS の主役。を提供する (K = 結果数)。 narrow phase は math/Collision2D.h の既存関数を再利用する。 Add/Update/Remove で dirty ON/OFF を表す印。 ここでは暗号化/圧縮の有無。を立て、条件(指定コンポーネントを全部持つ)に合うエンティティを選んで反復する仕組み。 ECS の主役。直前にグリッドを必要になるまで計算を先延ばしにする方式(lazy)。 現行 TDerived は生成時と依存通知時に即時評価し、Get の再計算は dirty が残った場合の補完経路。再構築する。
