クラス / gameframework

acs::game::CPrivacyDirector

EU の一般データ保護規則。 解析データ収集前にユーザー同意 (consent) を要する。 同意が無ければ送信しない。 / CCPA の consent 管理ハブ。 個人情報・解析・広告・ゲーム内の出来事(クリア・購入・離脱など)を記録して集計する計測の仕組み。 改善のヒントを得るために使う。など同意が必要な機能を EConsentCategory に集約して 一元管理する。 事前同意の取得・カテゴリ別 on/off・ポリシー版の追跡・ローカル永続化を 共通基盤として提供する。 アプリ全体で 1 個運用される想定で、consent オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。が分裂しない よう non-copy / non-move。
