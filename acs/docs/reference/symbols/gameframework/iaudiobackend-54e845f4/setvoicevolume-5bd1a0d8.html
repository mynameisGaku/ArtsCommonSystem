acs::game::IAudioBackend::SetVoiceVolume

指定 voice の音量を変更する。 voice: 対象の voice 実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。 (無効 / 解放済なら 何もしない処理。 呼んでも安全で副作用が無いこと。)。 volume: 新しい音量 (範囲外は clamp 推奨)。
