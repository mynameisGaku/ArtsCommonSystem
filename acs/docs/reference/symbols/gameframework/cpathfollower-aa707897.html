acs::game::CPathFollower

waypoint 列を順に辿る経路追従。 現在の目標 waypoint への Arrive 操舵を返し、 arrive_radius 内に入ったら次へ進む。 最後に到達したら done=true。 オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。 (現在 index) は m_Index で保持する non-pure。 points は外部所有 (寿命に注意)。
