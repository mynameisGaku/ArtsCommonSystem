クラス / gameframework

acs::game::cinetimeline::ACinematicsTimelineEditorPanel

CCinematicsDirector を対話的に編集する timeline editor panel。 水平タイムライン + 5 種のトラック + タイムライン上の「この時刻にこれを起こす」を表す 1 点(時刻＋動作)。 並べてカットシーンを組む。マーカー + 再生制御を持つ 最小の cutscene エディタ。 ACS の editor_core が提供するエディタパネルの抽象基底クラス。 Title / DrawUI / OnInit などを override し、CEditorWorkspace に登録して使う。 を継承し、editor 専用のリッチな keyframe storage (FEditorKeyframe の 末尾追加が速く要素は連続メモリに並ぶ。 コピー禁止・ムーブ専用。) を panel 側で所有する。 Play 時に 各 keyframe を runtime 用 FTimelineKeyframe へ bake して director に流し込む。 編集対象の CCinematicsDirector は raw 参照で受け取り、寿命は caller 責任。
