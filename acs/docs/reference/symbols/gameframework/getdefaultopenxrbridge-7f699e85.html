acs::game::GetDefaultOpenXrBridge

既定 XR ランタイムや HMD を抽象化した共通インターフェース。 頭・手のポーズなどをこの型越しに叩き、具象 backend を差し替えて選ぶ。 を返す。 戻り値: 『既定の実装を返す関数』を後から登録する仕組み。 登録するとアプリ全体の既定実装が差し替わる。 登録済みならその実 bridge、未登録なら GetXr本物の代わりに置く最小実装。 依存ゼロでコンパイル・テストできる no-op 版。()。
