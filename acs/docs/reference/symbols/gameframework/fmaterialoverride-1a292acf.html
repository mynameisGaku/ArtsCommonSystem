acs::game::modelview::FMaterialOverride

1 つの material slot 分の Physically Based Rendering。 金属度・粗さなど物理量で材質を表すリアルな描画手法。 override データ。 is_overridden が false の slot は「元の material そのまま」を意味し、各値は default (= 物理的に neutral な値) で初期化される。 is_overridden が true になるのは ユーザーが UI 上のフィールドを 1 つでも触った時点で、Reset ボタンで false に戻す。 4 次元ベクトル(x, y, z, w)。 RGBA 色や同次座標、行列との掛け算に使う。 / 3 次元ベクトル(x, y, z)。 3D の位置・方向・色などに使う最重要型で、SIMD演算に最適化されている。 / 32bit の浮動小数(float 相当)。 座標・時間・係数など小数値に使う基本型。 / bool / u32 は全 trivially-constructible なため、 末尾追加が速く要素は連続メモリに並ぶ。 コピー禁止・ムーブ専用。<FMaterial基底クラスの仮想関数を派生クラスで上書き実装すること。> は Resize 時に MemSet ゼロ初期化される経路を安全に通る。
