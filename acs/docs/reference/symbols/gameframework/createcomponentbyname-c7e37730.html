acs::game::CreateComponentByName

反射名で Component を生成し コピー不可・ムーブのみで、スコープを抜けると自動解放。<AComponent> で返す (2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。::AttachComponent 用)。 name: 反射カタログの登録名 (= クラス名、AComponent::ReflectName と一致)。 戻り値: 生成したANode に付ける部品。 1 つの機能 (物理・描画・当たり判定など) を担い、組み合わせて挙動を作る。。 未登録 / 非 Component / default 構築不可 (Abstract) は空。
