ACS_REFLECT

型を反射 + グローバル自動登録する (グローバル空間に置く)。 通常は下の種類別コンパイル前に決まった形へ展開される短い記述(#define)。 定型コードを一行で書ける。を使う。 Type: 反射する型。 Category: ::acs::game::ETypeCategory の値。 @param ... ACS_RFIELD(...) のリスト (0 個でも可)。
