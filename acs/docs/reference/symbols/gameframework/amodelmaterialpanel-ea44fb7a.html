acs::game::modelview::AModelMaterialPanel

Physically Based Rendering。 金属度・粗さなど物理量で材質を表すリアルな描画手法。 material を slot 単位で live 編集する Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 ImGui で作る、デバッグや編集用の小さな子ウィンドウ(調整画面)。 (ACS の editor_core が提供するエディタパネルの抽象基底クラス。 Title / DrawUI / OnInit などを override し、CEditorWorkspace に登録して使う。 派生)。 現在 load された model の各 submesh / material slot に対して base color / metallic / roughness / normal strength / AO strength / emissive 等を編集し、値を FMaterial基底クラスの仮想関数を派生クラスで上書き実装すること。 として保持する。 実 shader への反映 (constant buffer write) は 行わず、MaterialChangeCallback 経由で呼び出し側に override 1 件分を通知する。
