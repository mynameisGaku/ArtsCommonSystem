クラス / gameframework

acs::game::CRigidWorld2D

2D 剛体ワールド。 動的円ボディと静的 Axis-Aligned Bounding Box。 軸に平行な直方体の境界ボックス。 当たり判定の粗い包囲に使う。 を保持し、毎ステップで重力積分 → 接触検出 → インパルス解決 → 位置補正を行う。 空間条件(指定コンポーネントを全部持つ)に合うエンティティを選んで反復する仕組み。 ECS の主役。 (point / ray / overlap) も提供する。
