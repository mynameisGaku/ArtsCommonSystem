acs::game::editor_core::AEditorCommand::MergeWith

CanMerge が true を返した直後に CUndoStack から呼ばれ、next を取り込む。 next の「new 値」を自分に取り込み (= 自分の new 値を next の new 値で上書きし)、 自分の old 値はそのまま保つ。 これで Undo 1 回で連続 drag 全体を巻き戻せる。 default は 何もしない処理。 呼んでも安全で副作用が無いこと。 (CanMerge が false なので呼ばれない想定)。 next: マージ元となる直後の command。
