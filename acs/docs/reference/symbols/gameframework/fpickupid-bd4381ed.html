acs::game::FPickupId

拾取アイテムの generational handle。 32bit packed = 下位 24bit index + 上位 8bit generation。 0 = invalid。 CCollisionWorld2D の FShapeId / 2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。 の シーン内の ANode を指す index(24bit) + generation(8bit) の packed ハンドル。 stale 検出に使う。 と同じパターンで、slot を再利用しても 古い handle は generation 不一致で無効化される。
