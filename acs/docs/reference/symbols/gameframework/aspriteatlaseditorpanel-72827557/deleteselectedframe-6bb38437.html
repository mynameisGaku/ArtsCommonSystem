acs::game::spriteatlas::ASpriteAtlasEditorPanel::DeleteSelectedFrame

選択中 frame を 1 枚のアトラスと名前付きフレーム矩形を持つデータ層。 から削除し、name pool slot を回収する。 1 枚のアトラスと名前付きフレーム矩形を持つデータ層。::RemoveFrame は name ベース (同名は全削除) のため、本 panel が `m_DefaultFrameNamePool` で命名した frame (name pointer 一致) のみ削除する契約で、 panel 外で追加された frame には触らない。 削除後は末尾 slot を空いた slot へ swap-fill して参照する frame の name pointer を repoint し、命名済個数を 1 減らす。 selection は前の index に詰める (空なら -1)。 未選択 / 範囲外 / pack 未注入は 何もしない処理。 呼んでも安全で副作用が無いこと。。
