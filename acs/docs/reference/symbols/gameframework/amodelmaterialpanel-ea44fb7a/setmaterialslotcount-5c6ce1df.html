acs::game::modelview::AModelMaterialPanel::SetMaterialSlotCount

material slot 数を設定する (model load 時に呼ぶ)。 末尾追加が速く要素は連続メモリに並ぶ。 コピー禁止・ムーブ専用。 を count 個に Resize し、各 slot の slot_index を 0..count-1 でフィルする。 既存 slot の値は維持されない (= 古い model の override が新 model に流れない) ため default 値で初期化される。 count = 0 で全 slot 解除 (= モデルアンロード相当)。 count: material slot 数 (kMaxSlots で clamp)。
