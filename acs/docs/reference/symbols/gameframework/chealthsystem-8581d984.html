acs::game::CHealthSystem

複数 entity の HP / ダメージ / 死亡 / 復活 / 無敵時間を一元管理する高レベル ライブラリの機能を外から使うための窓口(関数や型の取り決め)。 例: ネットワークは WinSock をくるんだ薄い API として提供される。。 slot+generation パターンの FHealthId で entity を識別し、ApplyDamage / Heal / Revive / SetInvulnerable 等を提供する。 死亡通知は DeathCallback で行う。 ゲームアプリの基底クラス。 CApplication を継承し、シーン管理・固定タイムステップ・シーン遷移を内蔵する。 / AScene 単位で 1 個 保持される想定の非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。・非中身をコピーせず所有権ごと移すこと。 大きなデータを安く引き渡せる。型。
