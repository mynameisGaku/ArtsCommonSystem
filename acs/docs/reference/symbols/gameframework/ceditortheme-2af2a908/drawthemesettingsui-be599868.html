acs::game::editor_core::CEditorTheme::DrawThemeSettingsUI

"Theme Settings" 独立 Dear ImGui の略称・名前空間。 ImGui::Begin() のように呼び出す。 window を画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。する。 内容: テーマの色 / spacing / corner をまとめた既定スナップショット。 ACS では EEditorThemePreset(Dark / DarkBlue / Light など)。 combo + 全カラー ColorEdit4 + font_scale / corner / spacing の SliderFloat + Save/Load ボタン (ファイルパスは固定で `data/editor/theme.acstheme` を使う)。 Editor 側の毎ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。 loop から 1 行で呼ぶ。
