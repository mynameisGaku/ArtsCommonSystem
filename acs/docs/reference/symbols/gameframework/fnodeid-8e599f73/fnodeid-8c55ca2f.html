acs::game::FNodeId::FNodeId

index (24bit) と generation (8bit) を pack して構築する。 index は & 0x00FFFFFFu でどのレイヤに反応するかをビットで指定する絞り込み。 立っているビットの相手だけが対象になる。されるため、24bit 超の値は上位が落ちる。 index: pool / SoA 配列の index (0 〜 16,777,215)。 gen: slot の再利用される番号(ID)に付ける通し番号。 古いハンドルと新しい中身を取り違えないための目印。カウンタ (0 〜 255)。
