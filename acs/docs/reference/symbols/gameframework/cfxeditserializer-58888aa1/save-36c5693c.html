acs::game::fxedit::CFxeditSerializer::Save

emitter 群を `.fxedit` テキストへ書き出す。 count が 0 のときはヘッダだけ書き出す。 checked atomic save を経由する。 file_path: 保存先 (Win32 wide path)。 defs: FParticleEmitterDef 配列 (count 個)。 count>0 のとき nullptr 不可。 names: emitter 名 (C 文字列) の配列。 個別要素 nullptr は "" 扱い。 count>0 で names メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。自体が nullptr の場合は kSub_NullArgs。 count: emitter 個数 (0 も valid)。 戻り値: 成功なら空の 成功値かエラー値のどちらか一方を持つ型。 例外を使わずに失敗を戻り値で伝える（既定のエラー型は FErrorCode）。、null 引数 / バッファ溢れ / I/O 失敗ならエラー。
