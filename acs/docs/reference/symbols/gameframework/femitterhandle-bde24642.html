acs::game::FEmitterHandle

emitter を指す 24bit index + 8bit gen を packed した opaque handle。 m_Packed == 0 を invalid と定義 (gen は常に 1 以上で配る)。 CSceneTimer 等と同一規約。 slot 再利用後の 「古くなって無効になった」状態。 例えば破棄された ANode を指したままのハンドルが stale。 世代付きハンドルでは世代不一致で検出する。 参照は IsValid + 内部の gen 一致で検出する。
