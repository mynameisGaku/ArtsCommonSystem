acs::game::FHealthId

HP 管理対象 entity の識別子。 32bit packed = 下位 24bit index + 上位 8bit generation。 0 は invalid 予約 (index 0 dummy)。 Despawn → slot 再利用しても、古い handle は generation 不一致で 弾かれる。
