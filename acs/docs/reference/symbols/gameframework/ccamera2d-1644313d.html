acs::game::CCamera2D

2D 視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。 (position / zoom / rotation、target 追従、screen shake、座標変換、bounds clamp)。 target 追従は framerate independent な指数 smoothing (1 - exp(-smoothing * dt))、 screen shake は Eiserloh 画面振動 (camera shake) の強さを表す [0,1] の連続値。 被弾などで加算し、毎フレーム減衰させる。 方式 (画面振動 (camera shake) の強さを表す [0,1] の連続値。 被弾などで加算し、毎フレーム減衰させる。² * amplitude * noise)、bounds clamp は SetBounds の rect 内に position を抑える。 EffectiveViewCenter() = position + shake_offset を 実際に画面へ絵を出す描画システム本体。ーが view 設定に使う。 CSceneServices 経由で PostUpdate に自動 tick される。
