acs::FAppConfig

メインループを回すアプリの基底クラス。 継承して OnStart/OnUpdate/OnRender/OnShutdown を実装する。::Run に渡す起動オプション一式。 OS が画面に出す四角い領域。 タイトルバーや × ボタンを持ち、ゲームの描画先になる。 ACS では FWindow。・ロガー・プログラムが使う記憶領域。 確保と解放の管理が性能と安全性を左右する。コンポーネントを持つエンティティ群を毎フレーム処理する関数(移動・AI など)。 CSystemScheduler で順に実行する。・ワーカースレッドを前もって用意し、タスクを投げて使い回す仕組み。 毎回スレッドを作るより軽い。・実際に画面へ絵を出す描画システム本体。・背景色の初期値を まとめて保持する集約 struct。 すべてのフィールドに既定値があり、`FAppConfig cfg{};` のまま Run に渡せば標準設定で起動できる。
