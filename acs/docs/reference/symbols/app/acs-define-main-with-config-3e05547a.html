ACS_DEFINE_MAIN_WITH_CONFIG

cfg_factory が返す FAppConfig で AppClass を起動するエントリポイントを生成する。 ACS_DEFINE_MAIN と同じだが、既定設定の代わりに cfg_factory() の戻り値を Run() に渡す。 AppClass: メインループを回すアプリの基底クラス。 継承して OnStart/OnUpdate/OnRender/OnShutdown を実装する。 を継承したアプリ型。 cfg_factory: FAppConfig を返す呼び出し可能オブジェクト (関数等)。
