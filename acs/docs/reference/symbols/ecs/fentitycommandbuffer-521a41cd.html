acs::FEntityCommandBuffer

ECS の構造変更 (Destroy / Add<T> / Remove<T>) を記録し、Flush() で CWorld へ一括適用する。 Query 反復中に安全へ構造変更するための必要になるまで計算を先延ばしにする方式(lazy)。 現行 TDerived は生成時と依存通知時に即時評価し、Get の再計算は dirty が残った場合の補完経路。バッファ。 記録順に適用する。 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。 (退避値とコマンド列を所有するため)。
