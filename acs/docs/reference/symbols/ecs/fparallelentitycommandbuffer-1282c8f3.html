acs::FParallelEntityCommandBuffer

EachParallel の fn から安全に構造変更を記録するための per-worker コマンドバッファ束。 ワーカー数 + 1 (非ワーカー用) 本の FEntityCommandBuffer を持ち、記録は 自1 つのプログラム内で同時に進む実行の流れ。 複数あると処理を並列にできる。専用スロットへデータを守るための『鍵』。 取った人だけが対象を触れ、他は解放されるまで待つ。なしで積む。 Flush は単一1 つのプログラム内で同時に進む実行の流れ。 複数あると処理を並列にできる。で全スロットを適用する。 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。。
