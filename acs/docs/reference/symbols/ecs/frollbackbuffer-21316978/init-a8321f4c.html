acs::FRollbackBuffer::Init

capacity 個のある瞬間の状態をまとめて切り取ったコピー。 ここでは 1 フレーム分の入力値の束。 slot を確保する。 既に初期化済みなら一度 Shutdown してから確保し直す (保存済み履歴は失われる)。 途中で確保に失敗した場合は確保済み分を解放し、未初期化オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。で false を返す (部分オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。は残さない)。 capacity: 保持する tick 数 (1 以上)。 戻り値: 全 slot を確保できたら true。 capacity == 0 または OOM は false。
