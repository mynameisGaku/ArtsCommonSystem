acs::FRollbackBuffer

CWorld ある瞬間の状態をまとめて切り取ったコピー。 ここでは 1 フレーム分の入力値の束。の固定容量複数スロットを順番に使い回すバッファ。 毎フレーム書き換える定数バッファを安全に更新するためにフレームインフライトと組み合わせる。 (rollback netcode のオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。履歴)。 直近 capacity tick 分の CWorld オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。を tick % capacity の slot に保持する。 SaveFrame で現在オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。を退避し、RestoreFrame で保存済み tick へ巻き戻す。 保存する CWorld の全ANode に付ける部品。 1 つの機能 (物理・描画・当たり判定など) を担い、組み合わせて挙動を作る。型は中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。構築可能である必要がある (CWorld::CopyFrom の契約)。 non-copy / non-move 型。
