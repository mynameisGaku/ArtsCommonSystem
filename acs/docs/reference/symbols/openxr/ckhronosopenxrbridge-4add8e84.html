Khronos Khronos 策定の XR(VR/AR)機器を扱う業界標準 API。 機種差をこの一枚で吸収する。 loader を抽象的な機能呼び出しを、実際のライブラリや OS API につなぐ実装側のこと。 差し替え可能。とする XR ランタイムや HMD を抽象化した共通インターフェース。 頭・手のポーズなどをこの型越しに叩き、具象 backend を差し替えて選ぶ。 の実装。 Init() で xrEnumerateInstanceExtensionProperties / xrCreateInstance を呼び、 loader/instance 差し替え可能な境界面。 実装(backend)を後から入れ替えられるよう、インターフェースだけを切り出した接合点。 だけを所有する。 session loop (xrCreateSession + frame/view/action loop) は graphics binding と Head-Mounted Display。 頭に被る VR/AR ディスプレイ(ヘッドセット)。 ランタイムを要求するため本 インターフェースの裏で実際に仕事をする具象実装。 ここでは OpenXR ローダ等の XR 実装本体。 では未実装で、HeadPose()/LeftController()/RightController() は常に原点 (未トラッキングのゼロ位置と向きをまとめた姿勢情報。 XR では頭や手の ポーズ を追跡する。) を返し IsTracking() は常に false を返す。 passthrough 拡張 (XR_FB_passthrough / XR_HTC_passthrough) の有無のみ検出する。
