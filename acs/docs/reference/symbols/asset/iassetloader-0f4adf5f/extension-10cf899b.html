acs::IAssetLoader::Extension

この特定のファイル形式を解析してアセットを作る部品。 IAssetLoader を実装しレジストリへ登録する。が担当する拡張子を返す ("dds", "png", "mesh" など)。 読み込んだアセットをキー(FAssetId)で保持・共有し、再利用する管理表。 ACS では CAssetRegistry。がこの文字列でパスの拡張子とマッチングする ("*" は全拡張子本命が使えない時の代替経路。 XR では HMD 未接続時に通常の 2D 画面描画へ切り替えること。)。 戻り値: 小文字 ASCII の拡張子文字列。
