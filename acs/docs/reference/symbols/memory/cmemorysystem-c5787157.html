クラス / memory

acs::CMemorySystem

メモリを目的・寿命で分けた論理ヒープ(Default/Permanent/Temp/Resource/Develop)。 CMemorySystem が各セグメントに独立した予算を持つ。別プログラムが使う記憶領域。 確保と解放の管理が性能と安全性を左右する。管理のファサード (mimalloc / frame arena + 予算 + 診断、全 static)。
