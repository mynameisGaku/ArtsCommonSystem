acs::CCrtDebugHeapDiagnostics::DumpProcessMemoryLeaks

`_CrtDumpMemoryLeaks` を直接実行し、戻り値を機械判定可能な結果として返す。 MSVC Debug CRT 専用。 通常は対象所有元の寿命に従い、共有機能の開始、更新、終了を管理する部品です。を終了した静止点で呼ぶ。 `bWriteMachineReadableLog` が true なら標準エラーとデバッガへ最終判定を1行出力する。 bWriteMachineReadableLog: 機械可読な最終判定を出力するか。 戻り値: 対応状況、検査完了、リーク検出の各オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。。
