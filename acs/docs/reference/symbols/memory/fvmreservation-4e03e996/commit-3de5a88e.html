acs::FVmReservation::Commit

指定範囲に物理ページを割り当てる (MEM_COMMIT)。 LRU ヒット時は VirtualAlloc を省略して再利用する。 Offset: 予約先頭からのオフセット (OS ページサイズの倍数)。 Size: コミットするバイト数 (1 ページ以上、OS ページサイズの倍数)。 戻り値: 成功なら空の 成功値かエラー値のどちらか一方を持つ型。 例外を使わずに失敗を戻り値で伝える（既定のエラー型は FErrorCode）。、不正範囲、キャッシュとの部分重複、OS 失敗ならエラー。
