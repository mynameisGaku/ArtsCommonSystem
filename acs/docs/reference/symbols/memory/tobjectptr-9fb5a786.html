acs::TObjectPtr

参照カウント管理されるオブジェクトの基底。 生ポインタからも強/弱参照を作れる。 への強参照 (対象を生かし続ける所有メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。)。 中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。で強そのオブジェクトを今いくつの所有者が指しているかの数。 0 になったら破棄する。 TSharedPtr が使う仕組み。を +1、破棄で -1 し、0 で対象を破棄する。 T: 所有する 参照カウント管理されるオブジェクトの基底。 生ポインタからも強/弱参照を作れる。 派生型。
