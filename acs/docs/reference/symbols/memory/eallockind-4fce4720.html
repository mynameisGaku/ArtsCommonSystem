acs::EAllocKind

各 alloc ヘッダに付与する用途AES-GCM が出力する 16 バイトの認証データ。 これが合わないとデータが改竄/破損とみなす。 (プロファイラで分類するため)。 メモリを目的・寿命で分けた論理ヒープ(Default/Permanent/Temp/Resource/Develop)。 CMemorySystem が各セグメントに独立した予算を持つ。 (寿命) とは独立に「どの所有元の寿命に従い、共有機能の開始、更新、終了を管理する部品です。の確保か」を記録する分類軸。
