acs::IAllocator

プログラムが使う記憶領域。 確保と解放の管理が性能と安全性を左右する。確保の抽象インターフェイス (純粋仮想)。 すべての値をまとめて入れておく入れ物(TArray や THashMap など)。 ACS は STL の代わりに独自のものを使う。・確保したメモリを自動で解放してくれるポインタ風オブジェクト。 手で delete しなくてよい。 RAII の代表例。・所有元の寿命に従い、共有機能の開始、更新、終了を管理する部品です。はこのインターフェイス越しに 確保/解放を行うため、具象メモリの確保/解放のやり方を担当する部品。 用途に応じて差し替えられる。 (あらかじめ確保した固定数の枠を使い回す仕組み。 確保/解放のコストとフレーム落ちを避けられる。/アリーナ等) を呼び出し側を変えずに 差し替えられる。 具象実装は1 つのプログラム内で同時に進む実行の流れ。 複数あると処理を並列にできる。セーフで、確保失敗時は nullptr を返しC++ の throw/catch による失敗伝搬。 ACS は性能と単純さのため使わず TResult を選ぶ。は投げない。
