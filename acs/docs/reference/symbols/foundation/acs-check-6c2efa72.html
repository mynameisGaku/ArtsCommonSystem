ACS_CHECK

常時有効コンパイル前に決まった形へ展開される短い記述(#define)。 定型コードを一行で書ける。 — リリースでも検査する不変条件用。 ACS_Ax86 CPU のSIMD命令セットの一系統。 SSE2 は 64bit で常に使える。RTS_ENABLED に関係なく必ず検査する。 安全性・正しさを保証する不変条件 (out-of-bounds, null deref 前段、 プロトコル違反、整合性破壊、セキュリティ前提など) に使う。 ACS_CHECK(expr): expr が偽なら必ず 回復不能な状況でログとスタックトレースを出してプロセスを終了させる最終経路。 通常はアサートから呼ばれる。 を呼ぶ (リリースでも除去されない)。 例: ACS_CHECK(buffer != nullptr); ACS_CHECK(size <= capacity);
