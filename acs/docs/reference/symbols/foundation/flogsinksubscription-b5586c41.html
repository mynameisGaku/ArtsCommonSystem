acs::FLogSinkSubscription

破棄時に 非同期でスレッド安全なログ出力クラス。 ACS_LOG_* マクロ経由で使う。 のログ値や配列の変化を受け取るためにコールバックを登録すること(Subscribe)。 要らなくなったら解除(Unsubscribe)する。を解除する移動専用そのメモリ/資源を『誰が解放する責任を持つか』。 はっきりさせると安全。。
