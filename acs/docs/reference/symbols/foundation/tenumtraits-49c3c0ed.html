acs::TEnumTraits

列挙型の名前表。 型を渡すだけで使える。 飛び番や各 bit に意味を割り当て、OR で複数の状態を 1 個の整数にまとめて持つ手法。 pause 理由や同意カテゴリの複合表現に使う。など自動走査に載らない列挙は、本型を後から指定できる部品。 TArray<int> は『int の配列』というように中身の型を差し替えられる。を 明示特殊化すれば同じ形のまま差し替えられる。 TEnum: 対象の列挙型。
