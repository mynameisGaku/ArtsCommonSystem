ACS_RTTI_ROOT

階層のルートクラスに置く。 virtual なアセットやローダの種類を表す数値(AssetType)。 文字列名のハッシュから作られる。 機構 (StaticClassId / GetClassId / IsA) を導入する。 Type: このクラス自身の型名。
