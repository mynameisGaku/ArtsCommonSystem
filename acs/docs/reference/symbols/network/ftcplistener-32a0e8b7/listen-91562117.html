acs::FTcpListener::Listen

指定アドレス/ポートで Listen を開始する。 socket→SO_REUSEADDR→bind→listen を実行する。 Cネットワーク機能全体の初期化／終了をまとめる入口クラス(WinSock の WSAStartup ラッパ)。 ソケットを使う前に一度 Init() を呼ぶ。::Init() 未呼び出し、 または各 Windows のソケット通信ライブラリ。 ACS の CNetwork はこれを薄くくるんでいる。 呼び出しの失敗時はエラーを返す。 addr: ソケットを特定のアドレス/ポートに結び付けて、そこで送受信できるようにすること。するアドレス (FIpAddress::Any() で全インターフェイス)。 port: 待ち受けるポート番号。 backlog: 接続キューの最大長 (既定 16)。 戻り値: 成功なら待ち受け中の FTCP 接続を待ち受ける側(サーバ)。 Accept() でクライアントの接続を 1 本ずつ受理して TcpConnection にする。、失敗ならエラー。
