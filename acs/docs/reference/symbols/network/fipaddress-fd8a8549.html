acs::FIpAddress

192.168.0.1 のような 4 数値で表す主流のネットワークアドレス形式。 アドレスとポートを保持する値型 (v1 では IPv4 を拡張した新しいアドレス形式。 ACS v1 では未対応。 未対応)。 octets[0..3] にドット区切り表記の各オクテットを格納し、port にポート番号を持つ。 既定値は 0.0.0.0:0。 Any()/Loopback()/FromString() で生成する。
