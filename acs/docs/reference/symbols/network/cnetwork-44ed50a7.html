acs::CNetwork

ネットワーク所有元の寿命に従い、共有機能の開始、更新、終了を管理する部品です。の初期化・終了を司る WSAStartup ラッパ。 全メンバが static。 多重 Init は内部のそのオブジェクトを今いくつの所有者が指しているかの数。 0 になったら破棄する。 TSharedPtr が使う仕組み。で安全に扱い、最後の Shutdown で 実際に WSACleanup を呼ぶ。 メインループを回すアプリの基底クラス。 継承して OnStart/OnUpdate/OnRender/OnShutdown を実装する。 は自動初期化しないので明示的に呼ぶこと。
