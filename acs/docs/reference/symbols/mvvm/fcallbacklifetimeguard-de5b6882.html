acs::mvvm_detail::FCallbackLifetimeGuard

ある出来事が起きた時に呼んでもらう関数。 実行中の owner 寿命を stack 上だけで監視する侵入型 guard。 owner は guard の先頭メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。だけをメンバに持ち、ある出来事が起きた時に呼んでもらう関数。 冒頭で本 guard を積む。 owner の destructor は InvalidateChain を最初に呼び、実行中 guard を dead にする。 ある出来事が起きた時に呼んでもらう関数。 は外部呼出しから復帰した直後に IsAlive だけを読み、dead なら owner へ 二度と触れず return する。 同じ storage に owner が placement-new されても、 old guard は head への参照を破棄済みなので新実体の chain を変更しない。 heap allocation は行わない。
