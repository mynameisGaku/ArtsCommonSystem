acs::TOneWayConvertBinder

src の変化を型変換して dst へ片方向に流すバインダ (異なる型)。 構築時に変換関数で src の現在値を変換して dst へ反映し、以後 src の変化のたびに 同じ変換を通して dst へ Set する。 dtor で src から Unsubscribe する。 Src: 監視元の値の型。 Dst: 反映先の値の型。
