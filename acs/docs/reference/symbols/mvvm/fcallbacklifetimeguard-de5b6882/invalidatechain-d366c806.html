acs::mvvm_detail::FCallbackLifetimeGuard::InvalidateChain

owner 上で実行中の guard をすべて dead にし、chain を空にする。 owner destructor の最初に呼ぶ。 同じ storage の新 owner が構築する chain と old stack frame を寿命分離するため、各 guard の head 参照も null にする。 head: owner 内の guard chain 先頭。
