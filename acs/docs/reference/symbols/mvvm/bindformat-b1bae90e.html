acs::mvvm::imgui::BindFormat

T監視できる 1 個の値。 Set で変えると購読者へ通知が飛ぶ。 MVVM の中核。 の現在値を printf 形式で表示する表示専用ラベル。 primary template は使われず、プリミティブ型ごとに ImguiObservable 同士を結びつけ、片方が変わると相手も自動で更新する MVVM のデータバインド。 双方向版は TwoWayBind。ings.cpp で明示特殊化する。 特殊化が primary template の使用前に見える必要があるため宣言をここに置く。 T: 表示する値の型。 fmt: 値を 1 つ受け取る printf 書式 (例: "HP: %d")。 v: 表示する T監視できる 1 個の値。 Set で変えると購読者へ通知が飛ぶ。 MVVM の中核。。
