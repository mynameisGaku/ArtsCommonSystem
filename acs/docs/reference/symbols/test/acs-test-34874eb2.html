ACS_TEST

ACS_TEST コンパイル前に決まった形へ展開される短い記述(#define)。 定型コードを一行で書ける。 静的なグローバルオブジェクトのコンストラクタで Register を呼ぶことで、 main 開始前にテスト一覧が構築される。
