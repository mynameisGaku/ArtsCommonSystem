acs::CSpriteCollider

2D の 1 枚絵(キャラ・アイコン等)。 矩形にテクスチャを貼って描く。のアルファチャンネルから形状に沿ったコライダーを生成する 2D コライダー。 不透明画素の境界から与えた点をすべて包む、へこみのない最小の形(輪ゴムで囲んだような外形)。 当たり判定で扱いやすい。 (Jarvis march、順序非依存で堅牢) と簡略化済み形の縁(ふち)をなぞった線。 凸包と違いへこみ(凹み)にも沿う。ポリゴン (Moore 近傍トレース + Douglas-Peucker 簡略化) を作る。 与えた点をすべて包む、へこみのない最小の形(輪ゴムで囲んだような外形)。 当たり判定で扱いやすい。は物理で扱いやすく常に有効、 形の縁(ふち)をなぞった線。 凸包と違いへこみ(凹み)にも沿う。は凹形状にも追従する。 座標はピクセル空間 (左上原点) で、単一連結成分・穴なしを前提。 ACS 規約に従い non-copy・全 noexcept・成功値かエラー値のどちらか一方を持つ型。 例外を使わずに失敗を戻り値で伝える（既定のエラー型は FErrorCode）。 を用いる純 中央演算装置。 対応するSIMD命令により計算速度が変わる。 ロジック。
