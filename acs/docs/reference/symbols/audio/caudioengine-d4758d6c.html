acs::CAudioEngine

Windows 標準の低レベル音声 API。 ACS の音声再生はこの上に実装されている。を使って音声の再生と停止を管理する。 内部オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。の寿命と発音枠を個別に処理が終わるまでその場で待つやり方。 結果がすぐ手に入る代わりに止まる。し、別1 つのプログラム内で同時に進む実行の流れ。 複数あると処理を並列にできる。からのShutdownを待ち合わせる。
