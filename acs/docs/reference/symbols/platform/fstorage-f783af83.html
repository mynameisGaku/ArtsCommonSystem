acs::FStorage

設定・セーブデータ用の key-value ストア (INI 風、フラット、UTF-8)。 key=value の平坦なエントリ列を保持し、ファイル/バイト列との間で読み書きする。 セクションは 持たず、"audio.master_volume" のような点区切りキーで名前の衝突を防ぐ入れ物。 acs::easy::OpenWindow の acs::easy の部分。を分ける想定。 値は内部で文字列 として保持し、Int/Float/Bool は文字列との相互変換で扱う。 non-copy・move-only。
