acs::ui_detail::VisitVisibleUiRoot

visible な root だけを Layout し、その後の画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。処理を呼ぶ共通 gate。 AWidget ツリーを CSpriteBatch/FFont で描き、UTF-8 全体・prefix の幅も測る UI renderer。::Render と 画像処理に特化した演算装置。 描画はここで行われる。-free test が同じ可視性分岐を共有する。 root が hidden なら Layout も ある出来事が起きた時に呼んでもらう関数。 も呼ばない。
