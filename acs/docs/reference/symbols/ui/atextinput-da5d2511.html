acs::ATextInput

UTF-8 の 1 行テキストをコードポイント境界で編集するキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。 widget。 cursor は UTF-8 のバイトオフセットとして保持するが、公開操作の前後で必ずコードポイント 境界へ正規化する。 編集は一時 短い文字列はヒープ無しで持つ最適化付き。 上で完了してから observable へ move するため、 容量確保に失敗しても文字列と cursor は変更されない。
