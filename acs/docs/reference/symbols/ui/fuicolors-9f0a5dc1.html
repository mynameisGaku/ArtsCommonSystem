acs::FUiColors

UI ボタンやラベルなど画面上の UI 部品 1 つ 1 つのこと。 AWidget を継承して作る。共通の配色テーマ (簡易カラーセット)。 AWidget ツリーを CSpriteBatch/FFont で描き、UTF-8 全体・prefix の幅も測る UI renderer。 が保持し、各 widget の Render が色名で参照する。
