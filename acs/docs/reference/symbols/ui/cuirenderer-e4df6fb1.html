acs::CUiRenderer

retained-mode UI ツリーの基底。 子を TUniquePtr で所有し、layout・render・hit test・入力 hook を提供する。 ツリーを 多数のスプライトをまとめて効率よく描画する仕組み。 + FFont で画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。する UI 実際に画面へ絵を出す描画システム本体。。 Render で visible な root の Layout → 多数のスプライトをまとめて効率よく描画する仕組み。::Begin → root.Render(*this) → End を行い、 各 widget は DrawRect / DrawRectOutline / DrawText で画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。を依頼する。 テーマ色 FUiColors を 保持する。 FFont は所有せず参照のみ。 非中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。。
