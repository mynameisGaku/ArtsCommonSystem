acs::easy::DrawBurnDissolve

紙が燃えて消える per-pixel ディゾルブを矩形に重ねる (どの抽象的な機能呼び出しを、実際のライブラリや OS API につなぐ実装側のこと。 差し替え可能。でも動く)。 画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。内容を先に描いてからこれを重ねると、progress 0→1 で燃え際 (白熱→橙→ 黒コゲ) が進みながら下の内容が現れる。 セル/ドットでなくピクセル単位なので高解像度。 @param x,y 矩形左上 (px)。 @param w,h 矩形サイズ (px)。 progress: 0=全部紙, 1=全部燃えて下が見える。 ember: 燃え際の基準色。 paper: 紙 (覆い) の色。 edge: 燃え際の帯幅 (既定 0.12)。 freq: ノイズ周波数 (既定 7。 大きいほど細かい炎縁)。 time: 炎ゆらぎ用の時間 (0 で静止)。 cells: ドット調の分割数 (0=なめらか最高解像度、N=N分割の四角ドット)。 戻り値: 画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。できたら true、効果が使えなければ false。
