クラス / threading

acs::CThreadPool

暇なワーカーが忙しいワーカーの未処理タスクを奪って実行し、全体の負荷を均す方式。型のワーカースレッドを前もって用意し、タスクを投げて使い回す仕組み。 毎回スレッドを作るより軽い。 (Chase-Lev SPMC deque + help-stealing wait)。 全メンバが static のプロセス内に 1 個だけ存在するインスタンス。 GetDefaultLuaVm() はこれを返す。。 各ワーカーはローカル deque を持ち、空になると 外部投入キューの drain → 他ワーカーからの steal → 短時間 park の順に動く。 Wait は 待機中もスティーリングに参加するため、ワーカー1 つのプログラム内で同時に進む実行の流れ。 複数あると処理を並列にできる。からの呼び出しでもデッドデータを守るための『鍵』。 取った人だけが対象を触れ、他は解放されるまで待つ。しない。
