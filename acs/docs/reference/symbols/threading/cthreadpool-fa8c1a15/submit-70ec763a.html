acs::CThreadPool::Submit

タスクを投入する。 counter が非 null なら受理が確定したタスクだけ自動で Add(1) される。 ワーカー1 つのプログラム内で同時に進む実行の流れ。 複数あると処理を並列にできる。からの投入は 自分のローカル deque へ、それ以外はグローバル投入キュー経由で入る。 エラー時はタスクを保持しないため、user のそのメモリ/資源を『誰が解放する責任を持つか』。 はっきりさせると安全。は呼び出し側に残る。 t: 投入するタスク (fn が null なら Threading エラー)。 戻り値: 成功なら空の 成功値かエラー値のどちらか一方を持つ型。 例外を使わずに失敗を戻り値で伝える（既定のエラー型は FErrorCode）。。 未初期化・null fn・ゲーム世界に置く部品の単位。 位置やコンポーネントを持ち、親子のツリーで並ぶ。確保失敗時はエラー。
