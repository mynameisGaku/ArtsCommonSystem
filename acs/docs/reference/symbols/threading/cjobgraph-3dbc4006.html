acs::CJobGraph

依存関係付きの並列タスクスケジューラ。 タスクを並列実行するスレッドプール(ワークスチール方式)。 上で動く DAG スケジューラ。 各並列実行する小さな仕事の単位。 依存関係を付けて CJobGraph で順序立てて走らせられる。は完了時に dependents の deps_remaining を複数スレッドから同時に触っても途中状態が見えず、分割されずに完了する操作。 TAtomic が代表。にデクリメントし、0 になったものを タスクを並列実行するスレッドプール(ワークスチール方式)。 へ 投入する fan-out 方式。 グラフは Submit 後は変更不可 (Add/AddDependency は Submit 前のみ)。 Reset で依存構造を保ったまま再実行できる。 中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。不可。
