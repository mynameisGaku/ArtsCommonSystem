acs::FRwLock

複数 reader の同時取得を許し writer はあるデータを一度に 1 スレッドだけが触れるように制限すること。 FMutex やロックで実現する。にする。 読み取りが多く書き込みが少ない データのスループット向上に使う。 Shared と Exclusive の再帰取得は不可で、公平性は OS 任せ (書き込み starvation の可能性あり)。 中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。不可。
