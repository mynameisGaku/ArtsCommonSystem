acs::CompilerBarrier

コンパイラのみのGPU リソースの用途状態を切り替える同期。 ACS では普段は内部で自動管理される。を張る (中央演算装置。 対応するSIMD命令により計算速度が変わる。 命令は出さない)。 コンパイラに対して「ここを跨いで命令を並び替えるな」という指示のみで、 ハードウェアのプログラムが使う記憶領域。 確保と解放の管理が性能と安全性を左右する。順序には影響しない。 MSVC は _ReadWriteBarrier が 廃止予定だが現状動作する。
