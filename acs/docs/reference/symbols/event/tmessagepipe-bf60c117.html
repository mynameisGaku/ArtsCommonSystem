acs::TMessagePipe<T, EMessagePipePolicy::Spsc, Capacity>

1 producer / 1 consumer 専用の固定容量 lock-free FIFO。 producer は Push 系、consumer は TryPop 系だけを呼ぶ。 head と tail は単調増加し、 配列 index だけを32 個の ON/OFF フラグを 1 つの整数に詰めたもの。 レイヤ (player/enemy/wall) を bit で表し、AND で「対象に含むか」を高速判定する。で折り返す。 Close は最後の Push 完了後に呼び、 Push と並行実行しない。 consumer は Close 観測後も残件を空になるまで取り出せる。 型と容量の誤用、C++ の throw/catch による失敗伝搬。 ACS は性能と単純さのため使わず TResult を選ぶ。を送出し得る値操作はコンパイル時に拒否する。
