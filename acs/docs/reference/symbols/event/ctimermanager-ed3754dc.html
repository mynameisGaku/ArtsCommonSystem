acs::CTimerManager

ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。単位の一回または周期時間を計る仕組み。 ACS では CClock（経過時間）と FFrameTimer（フレーム間 dt）。ーを同じ1 つのプログラム内で同時に進む実行の流れ。 複数あると処理を並列にできる。内で管理する。 Tickが戻るまでは、この管理器と呼出し対象の寿命を呼出し側で保つ必要がある。
