acs::assetpack::CAcpakReader

1 つの `.ACS のアセットアーカイブ形式(.acpak)。 出荷時に複数ファイルを 1 つにまとめる。` を開き、含まれる仮想ファイルを名前で取り出す .acpak などのアセットを読む側の部品。 pak をマウントして仮想ファイルを取り出す(対になる書き出し側が Writer)。。 header と file table を読み込み、各 path を内部の文字列 pool に保持する。 manifest 読み込み時に正規形 path の hash を一度だけ保持し、検索時は hash 一致候補だけを完全比較する。 ファイル実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。 + 文字列 pool + entry 配列を 所有するため non-copy / non-move で、固定アドレスでオブジェクトが生まれてから壊れるまでの寿命。 これを過ぎたものを触ると危険。を管理する。 シーン、コンポーネント、各ジャンル用機能、アセット読み書きの抽象 API など、ゲーム構築用の部品を提供する acs::game モジュールです。 の アセットパック(.acpak 等)からファイルを読み出す共通インターフェース。 Mount してパス指定で中身を取り出す。 とは独立に動作する。
