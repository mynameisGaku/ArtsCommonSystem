acs::assetpack::CAcpakWriter::Open

出力ファイルを開き、ヘッダのプレースホルダを書く (既存は上書き)。 CREATE_ALWAYS で開き、file_count / file_table_offset を 0 にしたヘッダを先に 書く (実値は Finalize で seek して上書き)。 成功すると以降 AddFile / Finalize が 呼べる。 flags は AcpakFlagNone / AcpakFlagCompressed / AcpakFlagEncrypted の 任意組み合わせ。 Encrypted を立てる場合は Open より前に SetKey() で鍵を設定する こと (鍵未設定でも Open 自体は成功し、Finalize 時に kAcpakSubCryptoKey を返す)。 既に Open オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。なら kAcpakSubAlreadyOpen、未知 flag bit は kAcpakSubBadFlags。 OutputPath: 出力する `.ACS のアセットアーカイブ形式(.acpak)。 出荷時に複数ファイルを 1 つにまとめる。` の UTF-16 パス。 Flags: 書き出しオプション (データを規則性を使って小さくすること。 ここでは LZ4 を使う。 / 鍵を知らないと中身を読めない形にデータを変換すること。)。 戻り値: 成功なら空の 成功値かエラー値のどちらか一方を持つ型。 例外を使わずに失敗を戻り値で伝える（既定のエラー型は FErrorCode）。、失敗ならエラー。
