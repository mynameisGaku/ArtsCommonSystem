acs::assetpack::CAcpakCrypto

256bit 鍵の共通鍵暗号化方式。 暗号化と同時に改竄検知(認証タグ)も行う AEAD。 鍵を知らないと中身を読めない形にデータを変換すること。 + パスワードを何千回も繰り返しハッシュして強い鍵を作る鍵導出方式。 総当たり攻撃を遅くする。 パスワードなど人間が覚えられる入力から、暗号用の鍵を計算で作ること。を提供する static 関数群。 全 ライブラリの機能を外から使うための窓口(関数や型の取り決め)。 例: ネットワークは WinSock をくるんだ薄い API として提供される。 が静的関数でオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。を持たず、呼び出し毎に Windows 標準の暗号 API(Cryptography Next Generation)。 外部ライブラリ無しで AES などが使える。 実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。を開いて閉じる。 .ACS のアセットアーカイブ形式(.acpak)。 出荷時に複数ファイルを 1 つにまとめる。 のロードは典型的に起動時 1 度 + 必要な範囲のアセットだけを動的にロード/アンロードして、メモリに収まらない大規模世界を扱う仕組み。読み出しなので、 実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。キャッシュは行わない。 インスタンス化はできない (ctor delete)。
