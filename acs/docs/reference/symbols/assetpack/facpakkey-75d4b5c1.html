acs::assetpack::FAcpakKey

AES-256 鍵 (256bit) を保持する Plain Old Data。 コンストラクタ等の特別な振る舞いを持たない単純な構造体。 コピーが速く扱いやすい。。 `AssetPack.md` の `ArchiveKey` と同じ各ウィジェットを画面のどこにどの大きさで置くかを決めて配置すること。 Layout で行う。。 CAcpakWriter / CAcpak.acpak などのアセットを読む側の部品。 pak をマウントして仮想ファイルを取り出す(対になる書き出し側が Writer)。 は事前に DeriveKey() で作成した本鍵を受け取り、内部で BCryptGenerateSymmetricKey に渡す。
