acs::assetpack::CAcpakWriter

複数のバラのファイルを 1 つの `.ACS のアセットアーカイブ形式(.acpak)。 出荷時に複数ファイルを 1 つにまとめる。` にまとめる Writer。 AddFile は実書き込みせず内部の pending list に仮想パスとデータを中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。し、 実書き込みは Finalize 内で一気に行う。 呼び出し側は AddFile 成功後にキーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。を 直ちに再利用または解放できる。 ツールビルド (パッキングコマンド) から使う想定で、ランタイムは CAcpak.acpak などのアセットを読む側の部品。 pak をマウントして仮想ファイルを取り出す(対になる書き出し側が Writer)。 だけで足りる。 実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。 + pending list を所有するため non-copy / non-move。
