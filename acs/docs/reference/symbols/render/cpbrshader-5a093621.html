acs::CPbrShader

Cook-Torrance BRDF (GGX + Smith + Schlick) Physically Based Rendering。 金属度・粗さなど物理量で材質を表すリアルな描画手法。 ライティングGPU 上で頂点やピクセルを計算する小さなプログラム。 ACS では HLSL で書く。。 Metalness/Roughness workflow でメッシュ (位置 + 面や線に垂直な向きのベクトル。 当たった面の向きやライティングの計算に使う。 + UV) を複数の太陽光のように無限遠から来る、向きだけを持つ平行光。/ ある位置から全方向に広がり、距離で減衰する光。/矩形 area light + 環境光で画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。する。 Image-Based Lighting。 環境マップを事前積分し、周囲全体からの光として材質に映り込ませる手法。 (irradiance/prefilter/BRDF LUT)、 SH9/probe grid ambient、normal map、Screen-Space Ambient Occlusion。 深度から隙間や接地部の遮蔽を求めて陰影を足す技法。/Screen-Space Global Illumination。 画面情報から 1 バウンスの間接光(色のにじみ)を加える技法。/Screen-Space Reflection。 画面に映っている情報だけから反射(映り込み)をリアルタイムに作る技法。/lightmap、Cascaded Shadow Map。 カメラの距離帯ごとに解像度の違うシャドウマップを使い、遠景まで鮮鋭な影を保つ。 shadow、 volumetric fog、emissive、clearcoat/anisotropy/sheen/iridescence/subsurface の 拡張マテリアルを束ね、per-frame / per-object の 2 シェーダに渡す小さなパラメータ群(行列・色・ライト等)を入れる GPU バッファ(cbuffer / CB)。で駆動する。
