acs::FDx12Shader

D3DCompile で DirectX 系のシェーダ言語(High-Level Shading Language)。 をコンパイルして保持する Direct3D 12。 Windows の低レベル GPU API。 ACS の Dx12* 系がネイティブ実装。 版GPU 上で頂点やピクセルを計算する小さなプログラム。 ACS では HLSL で書く。。 Init で desc.hlsl_source を D3DCompile に通し、結果のHLSL をコンパイルした GPU 向け中間表現(DXBC 等)。 パイプライン作成時に GPU へ渡す。 ID3DBlob を 単独所有する。 target 未指定時は stage から vs_5_1 / ps_5_1 / cs_5_1 を自動選択する。 Bytecode / BytecodeSize で blob の中身を返し、1 回の描画方式(VS+PS・頂点レイアウト・ブレンド・深度等)を丸ごと固めたオブジェクト。 PSO とも。作成時に抽象的な機能呼び出しを、実際のライブラリや OS API につなぐ実装側のこと。 差し替え可能。が 内部参照する。 IRhiShader を実装する final クラス。
