acs::CSsao

depth ベースの Screen-Space Ambient Occlusion (GTAO + contact shadow)。 各 pixel で view 向きと大きさを持つ量。 2D/3D の位置・速度・方向を FVec2/FVec3 で表す。に対する両側の horizon angle を screen-march で求め、 面や線に垂直な向きのベクトル。 当たった面の向きやライティングの計算に使う。を slice 平面に射影した角度を使って cosine-weighted visibility を analytical に 積分する (GTAO)。 同時に dir light 0 方向へ短距離 ray march して接地影 (contact shadow) を求める。 出力は R8G8B8A8_UNorm で .r=AO visibility、.g=contact shadow (ともに 1=照明 / 0=遮蔽)。 raw → depth-aware bilateral blur の 2 pass で生成し、OutputTexture() は blur 後を返す。
