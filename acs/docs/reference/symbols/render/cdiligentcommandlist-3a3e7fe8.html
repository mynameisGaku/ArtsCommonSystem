acs::CDiligentCommandList

Diligent Engine。 1 つの API で D3D12 / Vulkan 等を扱えるクロスバックエンド層。 ACS の Diligent* 系が利用する。 の IDeviceContext を薄くラップした即時GPU に送る描画命令を記録しておくバッファ。 最後にまとめて GPU へ投入する。実装。 Diligent Engine。 1 つの API で D3D12 / Vulkan 等を扱えるクロスバックエンド層。 ACS の Diligent* 系が利用する。 は IDeviceContext 自体がコマンドキューを持つ即時 ライブラリの機能を外から使うための窓口(関数や型の取り決め)。 例: ネットワークは WinSock をくるんだ薄い API として提供される。 なので、明示的な Begin/End は 何もしない処理。 呼んでも安全で副作用が無いこと。 で、Submit でのみ Flush + メモリ操作の順序を区切る境界。 これを跨いで読み書きが並び替えられないよう保証する。 Signal + ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。スロット前進を 行う。 RT 種別を跨ぐ pass (shadow / off-screen) の後に main pass へ復帰できるよう、 ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。冒頭で bind した swap chain / depth を記憶する。
