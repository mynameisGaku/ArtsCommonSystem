acs::CBlobShadow

光源計算なしの簡易ブロブ影 (足元の楕円)。 柔らかい楕円テクスチャを 1 枚持ち、多数のスプライトをまとめて効率よく描画する仕組み。 で暗く落とすだけの激軽な「足元の影」。 動的ライトを使わない/負荷を抑えたいときの fallback / 補助に使う。
