acs::CSky

手続き生成スカイ (色が滑らかに変化する塗り。 頂点カラーの補間で作れる。 + 太陽)。 テクスチャ (6 面の正方形テクスチャで全方位を覆う画像。 環境マップやスカイボックスに使う。) 不要で、ピクセルGPU 上で頂点やピクセルを計算する小さなプログラム。 ACS では HLSL で書く。が視線方向から天頂・地平線・ 地面の色を2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。して背景を描く。 タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。より先にフルスクリーン三角形で塗り、 深度の書き込み・テストは行わない (背景塗りなので既存深度を維持)。 太陽は視線と太陽 方向の角度で半径・ハローを付ける。 VS/PS/Pipeline State Object。 パイプラインの別名。/シェーダに渡す小さなパラメータ群(行列・色・ライト等)を入れる GPU バッファ(cbuffer / CB)。を単独所有する。
