acs::CSsgi::Render

Screen-Space Global Illumination。 画面情報から 1 バウンスの間接光(色のにじみ)を加える技法。 を計算して内部 RT に書く (raw → blur → temporal の 3 pass)。 device: 画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。に使う Render Hardware Interface。 DX12 / Vulkan / Diligent などの GPU API の違いを隠す、バックエンド非依存の薄い抽象層。 ACS では IRhiDevice 等がこれ。 GPU とのやり取りを表す IRhiDevice のこと。。 cl: コマンドを積むGPU に送る描画命令を記録しておくバッファ。 最後にまとめて GPU へ投入する。。 scene_color: 現在ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。の High Dynamic Range。 明暗の幅を float で広く保持する描画。 最後にトーンマップで表示用に圧縮する。 scene RT。 scene_depth: shader-visible depth (Screen-Space Reflection。 画面に映っている情報だけから反射(映り込み)をリアルタイムに作る技法。/Screen-Space Ambient Occlusion。 深度から隙間や接地部の遮蔽を求めて陰影を足す技法。 と同じ)。 normal_gbuffer: CMotionVector の world-space normal G-buffer (RGBA16F)。 view_proj: 現ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。の view * projection。 inv_view_proj: 現ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。 VP の逆 (depth+uv → world)。 prev_view_proj: 前ゲームループの 1 回分の更新＋描画。 1 秒に何フレーム回るかが FPS。の view_proj (temporal reproject 用)。 identity を渡すと reprojection 無効 (= 静的 accumulate)。 eye: 視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。の world pos。 intensity: indirect light の倍率 (0=無効、1=neutral、>1=強調)。 max_distance: ray march の世界距離上限 (世界座標、典型 5.0)。 motion_texture: 非 null なら temporal pass が depth reprojection ではなくこの motion vector で history を引く (動く mesh も ghost せず追従)。 CMotionVector::OutputTexture() を渡す。 null なら従来の camera-only depth reprojection。
