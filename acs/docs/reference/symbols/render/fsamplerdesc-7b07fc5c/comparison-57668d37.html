acs::FSamplerDesc::comparison

比較テクスチャをシェーダで読むときのフィルタ/アドレッシング設定。にするか（シャドウの SampleCmpLevelZero 用）。 true にすると HW 深度比較 PCF テクスチャをシェーダで読むときのフィルタ/アドレッシング設定。になる（フィルタは比較版＝タップごとに 2x2 バイリニア比較）。 比較関数は LessEqual 固定（lit ⇔ cmp ≤ stored_depth）。 GPU 上で頂点やピクセルを計算する小さなプログラム。 ACS では HLSL で書く。側は SamplerComparisonState で受け、SampleCmpLevelZero(s, uv, my_d - bias) で滑らかな p決まった選択肢の集合を表す型(列挙)。 例: 上下左右のキー。bra を得る。 通常テクスチャには使わない。
