acs::CStandardShader

標準ライティングGPU 上で頂点やピクセルを計算する小さなプログラム。 ACS では HLSL で書く。 (最大 4 灯の平行光源 + 4 灯のある位置から全方向に広がり、距離で減衰する光。 + Blinn-Phong)。 メッシュ (位置 + 面や線に垂直な向きのベクトル。 当たった面の向きやライティングの計算に使う。 + UV) を、複数の太陽光のように無限遠から来る、向きだけを持つ平行光。・ある位置から全方向に広がり、距離で減衰する光。・環境光・鏡面反射・ アルベドテクスチャ・光源視点の深度を焼いたテクスチャ。 各点が影かどうかを判定して影を落とす技法。 (Percentage-Closer Soft Shadows。 遮蔽物との距離に応じて影の縁をぼかし、柔らかい影(penumbra)を作る技法。) で画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。する。 VS/PS と1 回の描画方式(VS+PS・頂点レイアウト・ブレンド・深度等)を丸ごと固めたオブジェクト。 PSO とも。・ シェーダに渡す小さなパラメータ群(行列・色・ライト等)を入れる GPU バッファ(cbuffer / CB)。・1x1 白テクスチャを単独所有する。 Frame のオブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。 (視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。・各種ライト・ シャドウ) はメンバにキャッシュされ、SetLights / SetPointLights / SetShadowMap を 独立に呼んでも整合する Frame CB へ反映される。
