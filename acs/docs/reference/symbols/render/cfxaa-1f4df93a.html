acs::CFxaa

FXAA をフルスクリーン三角形 1 パスで掛けるポストエフェクト。 FXAA 3.11 の簡易品質版。 中心+対角 4 近傍の輝度からエッジ方向を推定し、 エッジに沿って 2/4 タップのブレンドを行う。 低コントラスト画素は早期 return で 素通しするため、ベタ塗り領域やテキストのにじみは最小限。 キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。サイズは GetDimensions で取得するので cbuffer 不要。
