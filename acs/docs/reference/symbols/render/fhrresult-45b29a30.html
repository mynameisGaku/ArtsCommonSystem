acs::FHrResult

失敗時に HRESULT を保持する小さな結果ラッパ。 Direct3D 12。 Windows の低レベル GPU API。 ACS の Dx12* 系がネイティブ実装。 ライブラリの機能を外から使うための窓口(関数や型の取り決め)。 例: ネットワークは WinSock をくるんだ薄い API として提供される。 の HRESULT を持ち回り、既存の 成功値かエラー値のどちらか一方を持つ型。 例外を使わずに失敗を戻り値で伝える（既定のエラー型は FErrorCode）。 との橋渡しに使う軽量型。
