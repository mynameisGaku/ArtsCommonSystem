acs::CDiligentDevice

Diligent Engine。 1 つの API で D3D12 / Vulkan 等を扱えるクロスバックエンド層。 ACS の Diligent* 系が利用する。 Engine 経由の Render Hardware Interface。 DX12 / Vulkan / Diligent などの GPU API の違いを隠す、バックエンド非依存の薄い抽象層。 ACS では IRhiDevice 等がこれ。 GPU とのやり取りを表す IRhiDevice のこと。実装 (D3D12 / Vulkan 両対応)。 GPU そのものを表す RHI の中心インターフェース。 あらゆる GPU リソースをここから作る。 を継承し、内部で IRenderDevice / IDeviceContext / IEngineFactory を保持する。 Diligent Engine。 1 つの API で D3D12 / Vulkan 等を扱えるクロスバックエンド層。 ACS の Diligent* 系が利用する。 の重い型 (RefCntAutoPtr) はヘッダに漏らさず生メモリ上の場所(アドレス)を指す値。 中身そのものではなく『在りか』を持つ。で保持し、オブジェクトが破棄される時に自動で呼ばれる後始末の関数(~ClassName)。で 明示的に Release() する。 抽象的な機能呼び出しを、実際のライブラリや OS API につなぐ実装側のこと。 差し替え可能。非依存で完結するため、ユーザーコードは CreateRhiDevice() 経由で GPU そのものを表す RHI の中心インターフェース。 あらゆる GPU リソースをここから作る。 実体を間接的に指す軽い識別子 (多くは整数)。 ポインタの代わりに使い、安全な再利用や stale 検出を可能にする。だけを受け取り、このヘッダを include する必要はない。
