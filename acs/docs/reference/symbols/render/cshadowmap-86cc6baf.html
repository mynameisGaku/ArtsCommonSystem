acs::CShadowMap

太陽光のように無限遠から来る、向きだけを持つ平行光。用の直交光源視点の深度を焼いたテクスチャ。 各点が影かどうかを判定して影を落とす技法。 (single cascade / Cascaded Shadow Map。 カメラの距離帯ごとに解像度の違うシャドウマップを使い、遠景まで鮮鋭な影を保つ。 atlas)。 cascade_count=1 では 1 枚の 2D 深度テクスチャにタイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。全体を 1 つの ortho 投影で描く (伝統的な single cascade)。 cascade_count>=2 では視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。 frustum を距離で 2-4 個に分割し、 近景は高解像度・遠景は広範囲を 1 枚の atlas (width = cascade_count * size、height = size) に並べる (Cascaded Shadow Map。 カメラの距離帯ごとに解像度の違うシャドウマップを使い、遠景まで鮮鋭な影を保つ。)。 画像処理に特化した演算装置。 描画はここで行われる。 リソースを単独所有する non-copy 型。
