acs::CAtmosphere

物理大気散乱を 中央演算装置。 対応するSIMD命令により計算速度が変わる。 で評価し equirect 画像へ焼くユーティリティ。 Rayleigh + Mie 単散乱を per-direction で評価し、 焼いた equirect 画像を CImageBasedLighting に渡すと env cubemap → irradiance → prefilter の Image-Based Lighting。 環境マップを事前積分し、周囲全体からの光として材質に映り込ませる手法。 chain が物理ベースの sky で構築できる。
