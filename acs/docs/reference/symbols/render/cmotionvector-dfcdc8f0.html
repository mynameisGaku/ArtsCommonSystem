acs::CMotionVector

motion vector + world-space normal の G-buffer geometry pass。 タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。の全 mesh を再ラスタライズし、Multiple Render Targets。 1 回の描画で複数のレンダーターゲットに同時出力すること。 2 枚 (motion RG16F + normal RGBA16F) を 書き出す。 motion は screen-space motion vector (prev_uv - curr_uv) で camera 動きと object 動きの両方を含み、Temporal Anti-Aliasing。 前フレームの結果と混ぜてジャギーを時間方向に均すアンチエイリアス。 が history を正確に reproject して ghost/trail を消す。 normal はメッシュを構成する点。 位置・法線・UV などの属性を持つ。面や線に垂直な向きのベクトル。 当たった面の向きやライティングの計算に使う。をピクセル2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。した world-space 面や線に垂直な向きのベクトル。 当たった面の向きやライティングの計算に使う。で、Screen-Space Reflection。 画面に映っている情報だけから反射(映り込み)をリアルタイムに作る技法。/Screen-Space Global Illumination。 画面情報から 1 バウンスの間接光(色のにじみ)を加える技法。/Screen-Space Ambient Occlusion。 深度から隙間や接地部の遮蔽を求めて陰影を足す技法。 が sample する。 CShadowMap と同じ Begin/DrawMesh/End パターンで、occlusion 用 depth を内部に持つ。
