acs::FDiligentPipeline

Diligent Engine。 1 つの API で D3D12 / Vulkan 等を扱えるクロスバックエンド層。 ACS の Diligent* 系が利用する。 の IPipelineState + IShaderResourceObservable 同士を結びつけ、片方が変わると相手も自動で更新する MVVM のデータバインド。 双方向版は TwoWayBind。ing をラップした1 回の描画方式(VS+PS・頂点レイアウト・ブレンド・深度等)を丸ごと固めたオブジェクト。 PSO とも。実装。 FPipelineDesc から Pipeline State Object。 パイプラインの別名。 を生成し、シェーダに渡す小さなパラメータ群(行列・色・ライト等)を入れる GPU バッファ(cbuffer / CB)。 / テクスチャの DirectX 系のシェーダ言語(High-Level Shading Language)。 リソース名を slot 別に 保持する。 CommandList の SetConstantBuffer / SetTexture はこの名前で Shader Resource Binding。 Diligent でシェーダにリソースを結び付ける仕組み。 名前ベースで lookup する。 変数を lookup する。 名前が未指定の slot は shader の reflection から補完し、それでも無ければ "cbN"/"tN" 形式の 本命が使えない時の代替経路。 XR では HMD 未接続時に通常の 2D 画面描画へ切り替えること。名を返す。
