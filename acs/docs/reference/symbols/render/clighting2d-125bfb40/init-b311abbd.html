acs::CLighting2D::Init

画像処理に特化した演算装置。 描画はここで行われる。 リソース (scene/occluder RT・1 回の描画方式(VS+PS・頂点レイアウト・ブレンド・深度等)を丸ごと固めたオブジェクト。 PSO とも。・シェーダに渡す小さなパラメータ群(行列・色・ライト等)を入れる GPU バッファ(cbuffer / CB)。) を確保する。 width/height が 0 のときは RT 作成を必要になるまで計算を先延ばしにする方式(lazy)。 現行 TDerived は生成時と依存通知時に即時評価し、Get の再計算は dirty が残った場合の補完経路。し、最初の有効サイズで Resize() が作る。 device: リソース生成に使う Render Hardware Interface。 DX12 / Vulkan / Diligent などの GPU API の違いを隠す、バックエンド非依存の薄い抽象層。 ACS では IRhiDevice 等がこれ。 GPU とのやり取りを表す IRhiDevice のこと。。 color_format: backbuffer の色1 ピクセル/要素のビット配置と型(RGBA8、HDR float、深度など)。 ACS では EFormat。 (scene/occluder RT と composite 出力をこれに合わせる)。 width: 初期幅 (px)。 height: 初期高さ (px)。 戻り値: 成功なら空の 成功値かエラー値のどちらか一方を持つ型。 例外を使わずに失敗を戻り値で伝える（既定のエラー型は FErrorCode）。、確保失敗ならエラー。
