acs::CHiZ::Init

画像処理に特化した演算装置。 描画はここで行われる。 リソースを確保する。 Hi-Z は内部で ceil(src_w / 8) x ceil(src_h / 8) サイズで確保される。 device: RT・1 回の描画方式(VS+PS・頂点レイアウト・ブレンド・深度等)を丸ごと固めたオブジェクト。 PSO とも。生成に使う Render Hardware Interface。 DX12 / Vulkan / Diligent などの GPU API の違いを隠す、バックエンド非依存の薄い抽象層。 ACS では IRhiDevice 等がこれ。 GPU とのやり取りを表す IRhiDevice のこと。。 src_width: キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。 scene_depth の幅。 src_height: キーボード・マウス・ゲームパッドからの操作。 ACS では CInput でその瞬間の状態を読む。 scene_depth の高さ。 戻り値: 成功なら空の 成功値かエラー値のどちらか一方を持つ型。 例外を使わずに失敗を戻り値で伝える（既定のエラー型は FErrorCode）。、確保失敗ならエラー。
