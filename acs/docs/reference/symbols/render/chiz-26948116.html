クラス / render

acs::CHiZ

scene_depth から 1/8 解像度を level 0 とする min-depth pyramid を焼く Hi-Z。 level 0 の各 texel は元 depth の 8x8 ブデータを守るための『鍵』。 取った人だけが対象を触れ、他は解放されるまで待つ。中の最近接値を持ち、後続 level は 直前 level の厳密な 2x2 min 縮約になる。 2 本の R32G32_Float texture に level を 偶奇で分けることで、同一 resource の Shader Resource View。 テクスチャ等をシェーダから読むためのビュー。/RTV 同時利用を避ける。
