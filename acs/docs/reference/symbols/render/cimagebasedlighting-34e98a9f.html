acs::CImageBasedLighting

Image-Based Lighting。 Physically Based Rendering。 金属度・粗さなど物理量で材質を表すリアルな描画手法。 の ambient 項を環境マップから事前積分した光で置き換える。 構成要素は BRDF LUT (256x256 RG16F、GGX split-sum の scale+bias)、環境 cubemap (1024x1024x6 R11G11B10_Float)、拡散 irradiance cubemap (64x64x6)、specular prefilter cubemap (512x512x6, 7 mip)。 Diligent Engine。 1 つの API で D3D12 / Vulkan 等を扱えるクロスバックエンド層。 ACS の Diligent* 系が利用する。 インターフェースの裏で実際に仕事をする具象実装。 ここでは OpenXR ローダ等の XR 実装本体。 専用の本実装で、raw-ImGui の描画を DirectX 12 経由で画面に出すための連携部分。 では 各 Build/Ensure が ACS_ERR(Render, 88) を返す (fake-success しない)。
