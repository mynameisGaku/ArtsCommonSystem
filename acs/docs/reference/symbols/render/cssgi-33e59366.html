acs::CSsgi

Screen-Space Global Illumination (1 バウンス indirect light)。 各ピクセルから面や線に垂直な向きのベクトル。 当たった面の向きやライティングの計算に使う。半球内に N 本のレイを screen-space で march し、ヒットした pixel の High Dynamic Range。 明暗の幅を float で広く保持する描画。 最後にトーンマップで表示用に圧縮する。 色を 1 バウンスの indirect light として集める。 Screen-Space Ambient Occlusion。 深度から隙間や接地部の遮蔽を求めて陰影を足す技法。 の構造に色サンプリングを 追加した発展版で、raw → depth-aware blur → temporal accumulation の 3 pass で構成する。 CPbrShader が結果を ambient/indirect 項に加算する。 8 step / 4 ray = 32 sample/pixel、 diffuse-ish な広い hemisphere に絞り、反射的なシャープなパスは捨てる。
