acs::FQuat

回転を表す4 つの数で 3D の回転を表す方式。 ジンバルロックがなく、回転の補間が滑らか。 ACS では FQuat。 (16 バイト整列、(x,y,z,w) 各ウィジェットを画面のどこにどの大きさで置くかを決めて配置すること。 Layout で行う。)。 既定は恒等回転 (0,0,0,1)。 内部演算は Microsoft の SIMD 数学ライブラリ。 ACS の Vec/Mat/Quat はこれに委譲して高速化している。 に委譲する。
