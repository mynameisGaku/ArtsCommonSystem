acs::FObb2

有向境界ボックス (回転できる矩形コライダー)。 中心 + 半サイズ + 回転角 (ラジアン、反時計回り +X→+Y) で表す。 幾何的には 4 メッシュを構成する点。 位置・法線・UV などの属性を持つ。のへこみのない多角形。 どの 2 点を結んでも内部に収まる。 当たり判定が単純で高速。なので、判定は ToPoly() で既存の凸ポリゴン 分離軸判定（Separating Axis Theorem）。 凸形状同士の重なりを「どこかの軸で離れているか」で調べる手法。 (2 形状が重なっているかを bool で返す判定関数。 / 重なった 2 形状を引き離す最小移動量(MTV)を求める関数。 めり込み解消に。 / RaycastConvexPoly2) に委譲する。 点内外判定だけは 有向境界ボックス（Oriented Bounding Box）。 回転を持てる矩形/直方体コライダー。 ローカル空間の軸並行比較で直接行う (高速・分岐少)。
