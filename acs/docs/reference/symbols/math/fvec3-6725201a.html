acs::FVec3

3 成分向きと大きさを持つ量。 2D/3D の位置・速度・方向を FVec2/FVec3 で表す。 (16 バイト、パッド付き、内部 1 命令で複数のデータをまとめて計算する CPU 機能。 ベクトル計算を高速化する。)。 4 番目の要素 m_Pad は常に 0。 4 次元ベクトル(x, y, z, w)。 RGBA 色や同次座標、行列との掛け算に使う。 と互換の各ウィジェットを画面のどこにどの大きさで置くかを決めて配置すること。 Layout で行う。にすることで XMLoadFloat4A が使え、ロード/ストアが高速になる。
