専門用語

ACSの文書とAPI説明で使用する用語をまとめています。各リファレンスページでは、用語にカーソルを重ねるかフォーカスすると短い説明を確認できます。

669 用語

用語

A*
(エースター) グリッドやグラフ上で最短経路を効率よく求める定番アルゴリズム。 実コスト + ゴールまでの推定値で探索する。
AABB
Axis-Aligned Bounding Box。 軸に平行な直方体の境界ボックス。 当たり判定の粗い包囲に使う。
AAudioAsset
wav/mp3/flac/ogg を統一 PCM として読み込んだ音声アセット(asset モジュール)。 CAudioEngine に渡して再生する。
ABinaryAsset
生バイト列をそのまま持つ最小アセット(フォールバック)。
AButton
click 完了を TObservable<bool> の pulse として公開する UI button。
accent
UI の強調色(CheckMark / SliderGrab / TabActive など)。 ACS のブランド色相当。
ACheckbox
真偽値を click で反転し、label と observable state を持つ UI checkbox。
AContainer
親の矩形を全ての子へ渡す、描画を持たない重ね合わせ用 panel。
acpak
ACS のアセットアーカイブ形式(.acpak)。 出荷時に複数ファイルを 1 つにまとめる。
adapter
別システム (ここでは在庫システム) との橋渡しをする差し替え可能な関数群。 これ経由にすることで本体が在庫の実装に依存しない。
AEditorPanel
ACS の editor_core が提供するエディタパネルの抽象基底クラス。 Title / DrawUI / OnInit などを override し、CEditorWorkspace に登録して使う。
AES-256-GCM
256bit 鍵の共通鍵暗号化方式。 暗号化と同時に改竄検知(認証タグ)も行う AEAD。
AImageAsset
画像 1 枚分の CPU 側ピクセルデータを持つアセット。
ALabel
TObservable<FString> の text を表示する UI label。
AMeshAsset
頂点+インデックス+サブメッシュからなる単一メッシュのアセット。
ANode
2D/3D 共通シーングラフの唯一のノード。 AddComponent で ASprite2DComponent 等の部品を付ける。
AObject
参照カウント管理されるオブジェクトの基底。 生ポインタからも強/弱参照を作れる。
AP
アクションポイント。 ターン制で各陣営が 1 ターンに使える行動予算。 CTurnManager が管理する。
API
ライブラリの機能を外から使うための窓口(関数や型の取り決め)。 例: ネットワークは WinSock をくるんだ薄い API として提供される。
AppState
シーンを跨いで残しておきたい永続状態 (所持金・セーブデータ等) を型消去で 1 個保持する仕組み。
AScene2D
Camera2D と Physics2D を既定要求する AScene の空派生。 描画資源は CGame が共有し、AScene が FRenderContext へ配線する。
ASlider
指定範囲の連続値を drag で編集し、TObservable<f32> で公開する UI slider。
ASprite2DComponent
ノードにスプライト (1 枚絵) を描画する部品。
ASpriteAnimComponent
スプライトの UV 矩形を毎フレーム書き換えてスプライトシートアニメ(コマ送り)を再生するコンポーネント。
AssetType
アセット型を識別する 32-bit の数値 ID。
AStackPanel
子ウィジェットを縦または横へ spacing/padding 付きで並べる layout panel。
ATextAsset
UTF-8 テキストを保持するアセット。
ATextInput
UTF-8 codepoint 境界を守る cursor 挿入・削除・移動と byte 上限を持つ 1 行入力欄。
ATilemapComponent
タイルマップを画面に描画するコンポーネント。
AVX
SSE の後継のSIMD命令セット。 AVX2 などより広い幅で計算できる。
AWidget
retained-mode UI ツリーの基底。 子を TUniquePtr で所有し、layout・render・hit test・入力 hook を提供する。
backend
インターフェースの裏で実際に仕事をする具象実装。 ここでは OpenXR ローダ等の XR 実装本体。
BGM
バックグラウンドミュージック。 場面の間ずっとループで流す音楽。
Bind
Observable 同士を結びつけ、片方が変わると相手も自動で更新する MVVM のデータバインド。 双方向版は TwoWayBind。
BLENDINDICES
スキンメッシュ頂点が影響を受けるボーンの番号を持つ HLSL セマンティック。 GPU スキニングで ボーンパレットを引くのに使う。
Bloom
明るい部分を周囲ににじませて発光感を出すポストプロセス効果。
BOM
テキスト先頭に付く文字コードの目印。 ACS のsource・文書・build設定は UTF-8 BOMなしを正本にします。 改行は通常 LF、Windows shellだけ CRLFです。
breadcrumb
クラッシュ前に何が起きていたかを時系列で残す短いログ。 クラッシュ報告に添付して原因追跡に使う。
BSP
Binary Space Partitioning。 空間を再帰的に 2 分割していく手法。 ダンジョン生成では領域を割って各リーフに部屋を置く。
BVH
図形を空間的にまとめて階層の木にした構造(Bounding Volume Hierarchy)。 レイキャストや重なり判定を高速化する。
callback
ある出来事が起きた時に呼んでもらう関数。
CAnimationCurveArchive
FAnimationCurve の固定幅 little-endian 永続化 codec。 version・exact size・CRC・全 key を検証し、復元は transactional に行う。
CAnimationGraph
3D スケルトンアニメ向けのステートマシン型ブレンドグラフ。 どの clip をどの比率で再生するかを制御する。
CApplication
メインループを回すアプリの基底クラス。 継承して OnStart/OnUpdate/OnRender/OnShutdown を実装する。
CAS
Compare-And-Swap。 『今の値が期待通りなら新しい値に書き換える』をアトミックに行う基本操作。
CAssetBrowser
editor_core のアセットブラウザパネル。 ファイル選択を OnAssetSelected で各パネルに通知し、拡張子で mesh / texture などに分類する。
CAssetBundle
1 まとまりのアセット集合をロード/アンロードする単位。 チャンクごとのアセットを束ねる。
CAssetRegistry
パスからアセットを読み込み、TSharedPtr でキャッシュ共有する中心クラス。
CAudioEngine
音声再生の中心となるエンジン。 AAudioAsset を鳴らし、音量・停止・一時停止を扱う。 内部は XAudio2。
CBeatGrid
リズムゲームの checked 譜面読み込みと timing 判定。 通常 note に加え、PressLane/ReleaseLane で hold の head/tail を 1 回だけ集計する。
CCamera2D
2D カメラ。 位置/ズーム/回転、ターゲット追従、画面振動、world↔screen 座標変換を持つ。
CCameraShakePresets
『爆発/地震/着弾』などジャンル別の画面振動パラメータを名前付きで提供する preset ライブラリ。
CCharacterCustomizer
キャラの見た目(cosmetic)だけを slot 単位で着せ替えするマネージャ。 戦闘性能はいじらない設計。
CDebugDraw
1 フレーム分のデバッグ線分(線/AABB/円/十字)を溜めるだけのimmediate-modeバッファ。 実描画は描画側が行う。
CDialogueLocalizer
会話の各行を翻訳キー扱いにして、現在のロケールで翻訳を解決しコールバックへ渡す多言語化の橋渡し。
CDialogueScript
ノベル/アドベンチャー向けのシーンスクリプト再生機。 セリフ・選択肢・ジャンプを命令列で宣言的に組むステートマシン。
CDungeonGenerator
2D グリッドに部屋と廊下を配置する BSP(空間二分割)ダンジョン生成器。 シードで結果を再現できる。
CEditorCamera
editor_core のエディタ用カメラ。 3D orbit / pan / dolly 操作と ViewMatrix / ProjectionMatrix の取得を提供し、各パネルが値メンバとして所有する。
CFixedStepClock
可変な経過秒を固定更新回数と描画補間率へ変換する、利用側所有の決定論的な時計。
CGame
ゲームアプリの基底クラス。 CApplication を継承し、シーン管理・固定タイムステップ・シーン遷移を内蔵する。
CHotReloadWatcher
Windows 開発ビルドの非同期 directory watcher と bounded event queue。 再 import や MessageBroker publish は上位側で接続する。
CInspectorSeam
ANode から FInspectableObject / FInspectableField 配列を解決する seam。 AInspectorPanel が provider 解決元として消費する。
CJobGraph
依存関係付きのジョブを並列実行するスケジューラ。
CKhronosOpenXrBridge
OpenXR 公式ローダ(Khronos loader)を使った実backend。 HMD や手のポーズを提供する。
CLocalMatchmaker
サーバ無しで同一プロセス内のプレイヤーを組ませる IMatchmaker 実装。
Clock
起動からの経過時間を秒・ミリ秒・ティックで取れる高精度タイマ(すべて静的関数)。
CLogger
非同期でスレッド安全なログ出力クラス。 ACS_LOG_* マクロ経由で使う。
CMemorySystem
メモリを目的・寿命別のセグメントに分け、各領域に独立予算を持たせるメモリ管理の中枢。
CMessageBroker
型ごとにイベントを同期配信するpub/subバス。 1 スレッド内で使う。
CNG
Windows 標準の暗号 API(Cryptography Next Generation)。 外部ライブラリ無しで AES などが使える。
collide-and-slide
壁にぶつかった時、止まるのではなく壁に沿って滑るように動く衝突応答。 キャラ移動の自然さに効く。
Connect
IBackendClient で送信先(サーバや出力ファイル)を開いて通信を始めること。 終了時は Disconnect。
COrbitCameraController3D
3D orbit camera の入力・状態・固定時間から次状態を決定し、snapshot検証、描画補間、障害物距離と明示時間からpresentation eye/look-atを計算する。
CPU
中央演算装置。 対応するSIMD命令により計算速度が変わる。
CPUID
CPU 自身に対応命令セットを問い合わせる命令。 Cpu() が起動時に使う。
CrashReporter
gameframework のクラッシュ報告 seam 一式（stub・provider・ハンドラ）。 crashwin が実 backend を供給する。
CRC32
データから計算する 32bit のチェック値。 破損や改竄の検出に使う。
CSceneClock
シーン単位の論理時間を刻むクロック。 pause・スロー・倍速を反映した dt を Tween やタイマーに供給する。
CSceneNodeGraph
root ANodeと世代付きpoolを所有し、scene非依存の構造更新、検索、3D bounds queryを提供する。
CSequenceRunner
複数の FSequence を同時に再生・管理する実行係。 Start で所有して走らせ、毎フレーム Tick で進める。
CSettings
音量・解像度・キー設定などゲームをまたいで残したい値を型付き key-value で持つ小さなストア。 INI 風テキストで保存/読込できる。
CSM
Cascaded Shadow Map。 カメラの距離帯ごとに解像度の違うシャドウマップを使い、遠景まで鮮鋭な影を保つ。
CSpriteAnimator
経過時間から現在のアニメフレーム番号を計算する部品。
CSpriteBatch
多数のスプライトをまとめて効率よく描画する仕組み。
CSPRNG
暗号に使える品質の乱数生成器(Cryptographically Secure PRNG)。 nonce 生成などに使う。
CThreadPool
タスクを並列実行するスレッドプール(ワークスチール方式)。
CTurnManager
ターン制ゲームの進行を管理する部品。 複数の陣営を行動順で並べ、各陣営が AP(行動ポイント)予算で行動する。
CUiLayer
シーンに数個のボタン/テキストを貼り付けるための薄い UI 層。 シーンのライフサイクルに合わせて呼ぶだけで最小 UI が作れる。
CUiRenderer
AWidget ツリーを CSpriteBatch/FFont で描き、UTF-8 全体・prefix の幅も測る UI renderer。
CViewModel
MVVM のビューモデル(VM)の基底クラス。 継承して TObservable なプロパティを並べ、画面に見せたい状態をまとめる。
CWaveSpawner
敵のウェーブ(波状の出現)を管理する部品。 複数の波をキューに並べ、全滅したら次の波へ進める状態機械を内蔵する。
CWindowsCrashReporter
Windows 専用のクラッシュ報告 backend。 DbgHelp でミニダンプと人間が読めるテキスト報告書を書き出す。
DbgHelp
Windows 標準のデバッグ支援ライブラリ。 MiniDumpWriteDump でミニダンプを生成できる。
DDA
Dynamic Difficulty Adjustment。 プレイヤーの腕前に応じてゲーム難易度を自動で調整する仕組み。
Dear ImGui
C++ 向けの定番GUIライブラリ。 毎フレーム関数を呼ぶだけでパネルやスライダーを描ける『即時モード GUI』。 デバッグ用 UI に最適。
death cam
プレイヤーが死んだ瞬間に、致命傷を与えた相手をズームしながら映す演出カメラ。
DefaultAllocator
既定のアロケータ。 指定なしの確保で使われる。
Derived
依存する Observable から値を計算し、依存が変わった時だけ再計算する派生値。 菱形依存でも二重計算を避ける。
DI
Dependency Injection(依存性注入)。 使う実装を外から差し込み、呼び出し側を具体実装に依存させない設計。 CScriptHost は VM を差し替え可能にする。
Diligent
Diligent Engine。 1 つの API で D3D12 / Vulkan 等を扱えるクロスバックエンド層。 ACS の Diligent* 系が利用する。
DirectX 12
Windows の低レベル描画API。 GPU を細かく制御できる代わりに手間も多い。 ACS が裏で使う。
DirectXMath
Microsoft の SIMD 数学ライブラリ。 ACS の Vec/Mat/Quat はこれに委譲して高速化している。
DLL
実行時に読み込む共有ライブラリ(Windows の動的リンクライブラリ)。 例: ONNX Runtime の本体を DLL として読み込む。
dolly
カメラを前後に寄せる / 引く操作。 3D では target からの distance、2D では zoom_2d を変化させる。
DOM
Document Object Model。 文書(JSON 等)を木構造のオブジェクト群としてメモリ上に表現したもの。
Drag Source
ImGui のドラッグ & ドロップで、つかんで運ばれる側(payload を提供する元)。 受け側は BeginDragDropTarget で受け取る。
drawer
inspector 上で 1 つの property を描画する関数。 ACS では DrawerFn(関数ポインタ)で表現し CPropertyDrawerRegistry に登録する。
DX12
Direct3D 12。 Windows の低レベル GPU API。 ACS の Dx12* 系がネイティブ実装。
DX12 backend
ImGui の描画を DirectX 12 経由で画面に出すための連携部分。
EArrayChange
TObservableArray の変更種別(追加/削除/書換/全消去)を表す列挙。
EAssetState
アセットのロード状態を表す列挙。
EEditorState
AEditorToolbar が持つ editor の再生状態列挙 (Playing / Paused / Stepping)。
EFormat
ピクセルフォーマット(1 ピクセルのビット配置)を表す論理的なenum。 DX12 / Vulkan で共通の名前で扱える。
enum
決まった選択肢の集合を表す型(列挙)。 例: 上下左右のキー。
EPixelFormat
画像のピクセルフォーマットを表す列挙。
Err
TResult が失敗を表す側。 err.subcode で原因を見分ける。 成功側は Ok。
ESampleFormat
音声サンプルの形式(16-bit 整数 / 32-bit float)を表す列挙。
ETurnPhase
ターン進行のフェーズ(プレイヤーの番/敵の番など)を表すenum。 値はセーブ/リプレイに書ける安定値。
Event
ウィンドウや入力で起きた『出来事』1 つ分を表す構造体。 種別に応じて中のunionの対応フィールドだけが有効になる。
EXPECT_NEAR
2 値の差が許容誤差以内かを確かめるテスト用マクロ。 浮動小数の比較に使う。
f32
32bit の浮動小数(float 相当)。 座標・時間・係数など小数値に使う基本型。
FAabb2
軸並行の 2D 矩形コライダー（中心+半サイズ）。 最も軽い当たり判定。
FAabb3
軸並行の 3D ボックスコライダー。
FAcpakKey
acpak の暗号化/復号に使う 256bit(32 バイト)の鍵。
fallback chain
複数の font face を優先順位付きで並べ、ある文字が前の face に無ければ次の face で補う仕組み。 CJK や emoji を別 face で埋める用途に使う。
FAnimation
1 つのボーンアニメーション(尺と時刻ごとの姿勢キー)。
FAnimationCurve
キーを打って『時間 → 値』を補間する編集可能なカーブ。 checked 更新・評価、Clamp/Loop/PingPong、33 種の easing preset に対応する。
FAssetFuture
非同期ロードの結果を後で受け取るためのハンドル(フューチャ)。
FAssetId
パス文字列をハッシュした 64-bit のアセット識別子。 同じパスなら必ず同じ ID。
FAudioListener
音を聞く側 (プレイヤーの耳) の位置と向き。
FAudioSource3D
3D 空間内の音源 1 個 (位置 / 音量 / 減衰)。
FBone
スキンメッシュの 1 本のボーン(名前・親・バインド姿勢)。
FBuffDef
バフ 1 種の定義(id・種別・持続秒・効果量・スタック方針など)。 RegisterBuff で登録する。
FCircle
2D の円コライダー（中心+半径）。
FComponentOps
型を消去したコンポーネントのサイズ・破棄・ムーブなどの操作束。
FConvexPoly2
2D の凸多角形コライダー（最大 16 頂点）。 複雑な形のスプライトに。
FCrashContext
クラッシュ 1 件分の文脈（例外種別・メッセージ・スタック・シーン名等）をまとめた構造体（gameframework 側）。
FCurveKey
FAnimationCurve の 1 key。 有限な time/value/tangent と入口・出口の補間方式を保持する。
FEntityId
1 つのエンティティを指す軽量な識別子。 index と generation の組。
FErrorCode
ACS の標準エラー型。 カテゴリ・サブコード・OS エラー値・メッセージ・発生位置をまとめて持つ POD。
FHotReloadEvent
watcher が所有する UTF-8 path、monotonic timestamp、削除 flag を持つ 1 件の変更通知。
FieldChangeCallback
AInspectorPanel が field 編集時に外部へ変更を通知する raw 関数ポインタ型 (undo / 永続化への委譲口)。
fire rate
1 秒あたりの発射回数。 連射間隔 = 1.0 / fire rate で決まる。
FMat4
4x4 行列。 平行移動・回転・拡大縮小、ビュー変換、投影変換を 1 つにまとめて表せる。 3D 描画の心臓部。
FMathDispatch
CPU 機能に応じてバッチ演算の最適実装を選ぶ仕組み。
FMeshVertex
ACS 標準の頂点(位置+法線+UV)。 FVec3 が 16B 整列のため sizeof=48 バイト。
FMlModelHandle
読み込んだ ML モデルを指す不透明な識別子(中身は u64)。 backend が変わってもゲーム側コードを書き換えずに済むための窓口。 0 は無効を表す。
FMutex
一度に1つのスレッドだけが保護区間へ入れる、ACSの排他ロックです。
FNodeId
シーン内の ANode を指す index(24bit) + generation(8bit) の packed ハンドル。 stale 検出に使う。
FObb2
回転できる 2D 矩形コライダー（OBB）。
FOrbitCameraInputActionSet3D
6個の名前付き action を、固定 tick や replay から評価できる3D orbit camera入力へ変換する。
FPanic
回復不能な状況でログとスタックトレースを出してプロセスを終了させる最終経路。 通常はアサートから呼ばれる。
FPlane
3D の無限平面（法線+距離）。 地面や壁の近似に。
FrameTimer
フレームごとの経過秒(デルタタイム)を計るタイマ。 毎フレーム Tick() を呼ぶと前回からの経過秒を返す。
FRay2
2D のレイ（始点+方向）。 射撃や視線の判定に。
FRay3
3D のレイ（始点+方向）。 ピッキングや弾道に。
FRwLock

差し替え可能な境界面。 実装(backend)を後から入れ替えられるよう、インターフェースだけを切り出した接合点。

自分が動くのに必要なデータを全部自分で持っていて、外部の状態に依存しないこと。

疎な参照表と密な値配列を組み合わせ、追加/削除/検索を O(1)、全走査をキャッシュ効率良くするデータ構造。

ACSの基盤コードと公開APIでは、可変長配列、文字列、所有権管理に TArray、FString、TUniquePtr などのACS型を使用する方針です。
Storage
設定やセーブデータ用の key-value ストア(INI 形式)。 音量・解像度・進行度などを人間が読める形で永続化する。
Stub
本物の代わりに置く最小実装。 依存ゼロでコンパイル・テストできる no-op 版。
subcode
エラーコードの細目番号。 ACS の Result が持つ FErrorCode.subcode で、どの段階・原因の失敗かを区別する。 AssetPack は 1300 番台を使う。
SystemFn
ECS のシステム関数の型 void(*)(World&, f32 dt)。 World とデルタタイムを受け取り毎フレーム呼ばれる処理単位。
SystemScheduler
SystemFn を登録し、毎フレーム登録順にまとめて呼ぶ実行器。 複数システムを一括で回すのに使う。
TAA
Temporal Anti-Aliasing。 前フレームの結果と混ぜてジャギーを時間方向に均すアンチエイリアス。
TArray
末尾追加が速く要素は連続メモリに並ぶ。 コピー禁止・ムーブ専用。
TAtomic
ロックなしで安全に共有できる小さな値。
TCP
相手と接続を張り、順序どおり・確実にデータを届ける通信方式。 取りこぼしが許されない用途向け。 関連語 UDP。
TcpConnection
確立済みの TCP 接続 1 本。 順序どおり確実にデータを送受信でき、デストラクタで自動切断する。 コピー不可・ムーブのみ。
TcpListener
TCP 接続を待ち受ける側(サーバ)。 Accept() でクライアントの接続を 1 本ずつ受理して TcpConnection にする。
TDefaultConverter
Bind が使う組込みの型変換テーブル(数値・bool・文字列の主要ペア)。
tilemap
タイルを格子状に敷き詰めて作る 2D マップ。 FTilemap は複数レイヤのタイル ID 配列を持つ。
time_scale
時間の流れる倍率。 1=通常、0=停止、>1=早送り、<1=スロー。 CSceneClock がこれを掛けて scaled な時間を作る。
TObservableArray
要素の追加・削除・変更を通知する配列。 リスト UI の差分更新向け。
tombstone
削除済みスロットの目印。 ACS の THashMap はこれを残さず後方シフトで詰める。
TOneWayBinder
Observable 同士を片方向(src→dst)で同期させる小さなクラス。
TOneWayConvertBinder
型を変換しながら片方向同期させるバインダ。
transform
位置・回転・拡縮をまとめた座標変換。 親子で合成すると階層的な配置になる。
trauma
画面振動 (camera shake) の強さを表す [0,1] の連続値。 被弾などで加算し、毎フレーム減衰させる。
TResult
成功値かエラー値のどちらか一方を持つ型。 例外を使わずに失敗を戻り値で伝える（既定のエラー型は FErrorCode）。
TSharedPtr
複数で共有するスマートポインタ。 参照カウントが 0 で自動解放。
TSparseSet
ACS の Sparse Set 実装。 エンティティ番号→コンポーネント値の高速対応表。
TTF
TrueType フォントのファイル形式。 ACS は TTF/OTF を GPU アトラスに焼いて文字を描く。
TUniquePtr
コピー不可・ムーブのみで、スコープを抜けると自動解放。
TWeakPtr
TSharedPtr への弱参照。 寿命を延ばさず生死だけ見る。
Tween
値を時間で滑らかに補間する仕組み。 UI・カメラ・演出・シーン遷移に使う。
u64
64bit の符号なし整数(0 以上)。 サイズ・ハンドル・大きな個数などに使う基本型。
UDP
接続を張らずデータグラムを 1 通ずつ送る通信方式。 速いが到達・順序は保証されない。 関連語 TCP。
UGC
User Generated Content。 ユーザーが作った MOD / ステージ等のコンテンツ。 Workshop 等で配布される。
union
同じメモリ領域を複数の型で共用する仕組み。 FEvent は種別ごとに有効なフィールドだけを使う。
use-after-free
すでに解放したメモリを誤って使ってしまうバグ。 世代付きハンドルなどで検出・防止する。
UTF-8 cursor
ATextInput が UTF-8 の byte offset とコードポイント境界を対応付けて保持する編集位置。
UV 座標
テクスチャ上のどこを貼るかを示す 0..1 の 2 次元座標。
ViewModel
MVVM の橋渡し層。 実型 CViewModel と TObservable で状態を公開し、View(画面)がそれを購読して自動反映する。
VM
Virtual Machine。 スクリプトを読み込んで実行する仮想機械。 CLuaVm は Lua の VM。
VSync
画面のリフレッシュに描画提示を同期させ、ティアリングを防ぐ設定。
WEIGHT
スキンメッシュ頂点が各ボーンから受ける影響度(重み)を持つ HLSL セマンティック。 合計 1 になるよう正規化される。
Widget
UI 部品の総称。 ACS の実型 AWidget は子を TUniquePtr で所有してツリーを作り、配置・描画・クリック判定・入力の仮想メソッドを持つ。
Win32 backend
ImGui がマウス・キーボード入力を Windows から受け取るための連携部分。
WinSock
Windows のソケット通信ライブラリ。 ACS の CNetwork はこれを薄くくるんでいる。
Workshop
ユーザー作成コンテンツ(UGC, MOD やマップ等)を配布・購読する Steam の仕組み。
XAudio2
Windows 標準の低レベル音声 API。 ACS の音声再生はこの上に実装されている。
べき等
同じ操作を何度繰り返しても結果が変わらない性質。 未接続で Disconnect() しても安全、など。
アサート
条件が偽ならその場でプログラムを止めてバグを知らせる仕組み（ACS_ASSERT 等）。
アセット
ゲームで使う画像・音・モデル・データなどの素材ファイル。
アダプタ
PC に載っている GPU。 複数あれば高性能なものを優先選択できる。
アトミック
複数スレッドから同時に触っても途中状態が見えず、分割されずに完了する操作。 TAtomic が代表。
アトミック書き込み
一時ファイルに書いてから rename する等で、途中クラッシュでも本ファイルを壊さない保存手法。
アトラス
多数の小画像(グリフやタイル)を 1 枚にまとめたテクスチャ。 UV で各部分を取り出す。
アドレッシング
UV が 0..1 の外に出たときの扱い(繰り返し・鏡像・端固定・境界色)。
アロケータ
メモリの確保/解放のやり方を担当する部品。 用途に応じて差し替えられる。
アーカイブ
複数のファイルを 1 つにまとめた書庫ファイル。 .acpak はその一種。
イニシアチブ
ターン制での行動順を決める値。 大きいほど先に行動できる。
イプシロン
浮動小数の比較に使う非常に小さな許容誤差。 kEpsilon = 1e-6。
イベント
『× ボタンが押された』『キーが押された』のような、その瞬間に起きた出来事の通知。 ACS では FEvent として届く。
インターフェース
実装を差し替えられるようにするための約束事(純粋仮想クラス)。 I で始まる。
インデックス
頂点配列のどの点で三角形を作るかを示す番号の列。 同じ頂点を使い回せる。
イージング
トゥイーンの加減速カーブ。 Linear(等速)や InOutSine(ゆっくり始まりゆっくり終わる)など。
ウィジェット
ボタンやラベルなど画面上の UI 部品 1 つ 1 つのこと。 AWidget を継承して作る。
ウィンドウ
OS が画面に出す四角い領域。 タイトルバーや × ボタンを持ち、ゲームの描画先になる。 ACS では FWindow。
ウェーブ
敵が波状にまとまって出現する単位。 倒しきると次の波へ進む。 CWaveSpawner が管理する。
エスケープ
" や改行などの特殊文字を、壊れないよう安全な表現に置き換えること。
エラーコード
失敗の種類を表す値。 ACS では Result と組で扱う。
エリアライト
面(矩形等)から放射される光。 点光源より柔らかい陰影になる。
エンコード
データを送受信 / 保存用の形式(ここではフレーム化したバイト列)に変換すること。 逆はデコード。
エンティティ
ゲームの登場物を表すただの ID(番号)。 データ自体は持たず、コンポーネントを付けて意味を与える。
オイラー角
向きを pitch/yaw/roll の 3 つの回転角で表す方式。 直感的だが gimbal lock の弱点がある。
オブジェクトプール
オブジェクトを毎回 new/delete せず、あらかじめ確保した固定数を使い回す手法。 確保コストと断片化を抑える。
カメラ
視点。 world↔screen の座標変換(ビュー/投影)を作る。 2D は CCamera2D。
ガンマ
表示用の非線形な明るさ変換(sRGB)。 リニア計算後に適用する。
キューブマップ
6 面の正方形テクスチャで全方位を覆う画像。 環境マップやスカイボックスに使う。
キーフレーム
タイムライン上の「この時刻にこれを起こす」を表す 1 点(時刻＋動作)。 並べてカットシーンを組む。
ギズモ
viewport 上で選択 ANode の Transform(移動 / 回転 / 拡縮)を直接ドラッグ操作するハンドル。 ACS では CEditorGizmo が実装する。
クエリ
条件(指定コンポーネントを全部持つ)に合うエンティティを選んで反復する仕組み。 ECS の主役。
クォータニオン
4 つの数で 3D の回転を表す方式。 ジンバルロックがなく、回転の補間が滑らか。 ACS では FQuat。
クランプ
値を指定範囲内に収めること。 Saturate は 0〜1 に収める。
クロージャ
周囲の変数を一緒に持ち運べる関数オブジェクト。 ACS は STL を使わないので、代わりに関数ポインタ + void* user_data で文脈を渡す。
グラデーション
色が滑らかに変化する塗り。 頂点カラーの補間で作れる。
ゲームパッド
コントローラ。 ACS は XInput 互換でボタンやスティック（軸）を読む。
ゲームフレームワーク
ゲーム作りに必要な土台(描画・入力・音・シーン管理など)をまとめて提供する部品集。 エンジンより薄く、自由度が高い。
コスメティック
ゲームの性能に影響しない、見た目だけのアイテム (スキン・装飾)。 pay-to-win を避ける指針。
コピー
中身をそっくり複製すること。 ACS では高コストや所有権の事故を避けるため、多くの型でコピーを禁止しムーブのみ許す。
コマンドリスト
GPU に送る描画命令を記録しておくバッファ。 最後にまとめて GPU へ投入する。
コンテナ
値をまとめて入れておく入れ物(TArray や THashMap など)。 ACS は STL の代わりに独自のものを使う。
コンパイル時ハッシュ
文字列をコンパイル時に数値へ変換する手法。 実行時の文字列比較を避けて高速化する。
コンピュート
描画ではなく汎用計算を行うシェーダステージ(コンピュートシェーダ)。
コンポーネント
ANode に付ける部品。 1 つの機能 (物理・描画・当たり判定など) を担い、組み合わせて挙動を作る。
コースティクス
水面を通った光が水底に作る、揺らめく網目状の明暗模様。
コールバック
あとで呼んでもらうために登録しておく関数。 ACS では関数ポインタ + void* ユーザーデータの形を取る(STL 不依存方針)。
サブサーフェス
肌や蝋のように光が表面下で散乱して透ける質感(subsurface scattering)。
サブシステム
所有元の寿命に従い、共有機能の開始、更新、終了を管理する部品です。
サンプラ
テクスチャをシェーダで読むときのフィルタ/アドレッシング設定。
サービス
シーンが必要に応じて使う共通機能 (時間・補間・入力・カメラ・物理など) の単位。
シェーダ
GPU 上で頂点やピクセルを計算する小さなプログラム。 ACS では HLSL で書く。
シザー
この矩形の外側のピクセルを描かないクリッピング設定。
システム
コンポーネントを持つエンティティ群を毎フレーム処理する関数(移動・AI など)。 CSystemScheduler で順に実行する。
シャッフル
要素の並びをランダムに入れ替えること。
シャドウパス
影を作るために、シーンを光源から見た深度だけ先に描いておく描画工程。 後の主描画で影の濃さに使う。
シャドウマップ
光源視点の深度を焼いたテクスチャ。 各点が影かどうかを判定して影を落とす技法。
シリアライザ
オブジェクトの中身をファイルに保存できる形へ書き出し、また読み戻す部品。
シリアライズ
状態を保存や通信に使えるバイト列またはテキストへ変換する処理です。
シングルトン
プロセス内に 1 個だけ存在するインスタンス。 GetDefaultLuaVm() はこれを返す。
シーク
再生位置を任意の時点へ飛ばすこと (スクラブバー操作など)。
シーケンス
時間順に処理を並べて演出やイベントを組み立てる仕組み。
シード
乱数生成の初期値。 同じシードからは同じ乱数列が得られる。
シーム
プラットフォーム固有 SDK との結合点を抽象化した純粋仮想インターフェース。 ゲーム側はこれ越しに呼び、実装をビルド時に差し替える。
シーム(seam)
実装本体を切り離して差し替え可能にする「継ぎ目」。 インターフェースだけを置き、具象は別モジュールで注入する。 テストや SDK 隔離に使う。
シーン
タイトル・ゲーム本編・リザルトのような、画面の一場面とその進行をまとめた単位。
シーンクロック
シーンごとの時間管理。 時間スケールや一時停止を扱う。
ジョブ
並列実行する小さな仕事の単位。 依存関係を付けて CJobGraph で順序立てて走らせられる。
ジンバルロック
オイラー角で回転を表す時、特定の角度で 1 軸ぶんの自由度が失われる現象。 クォータニオンなら起きない。
スタック
関数の呼び出しに沿って自動で確保/解放される高速なメモリ。 寿命はスコープに縛られる。
スタックトレース
ある時点でどの関数からどの関数が呼ばれてきたか、という呼び出し履歴。 クラッシュ原因の追跡に使う。
スタブ
本実装の代わりに置く「中身が空 / 常に失敗を返す」仮実装。 未統合の backend のフォールバックや、上位層のテストに使う。
ステンシル
ピクセルごとの整数マスク。 任意形状の描画範囲制限(くり抜き)に使う。
ステンシルマスク
ステンシルバッファを使い、任意形状で描画範囲を切り抜く手法。
ステートマシン
「状態」と「状態間の遷移」で動きを記述する仕組み。 Idle→Walk→Jump のようにキャラの挙動管理に使う。
ストリーミング
必要な範囲のアセットだけを動的にロード/アンロードして、メモリに収まらない大規模世界を扱う仕組み。
スナップショット
ある瞬間の状態をまとめて切り取ったコピー。 ここでは 1 フレーム分の入力値の束。
スプライト
2D の 1 枚絵(キャラ・アイコン等)。 矩形にテクスチャを貼って描く。
スプライトバッチ
多数の 2D 画像をまとめて効率よく描画する仕組み。
スポーンルール
ウェーブ内で「どの敵を・何体・どの間隔で・どこに」湧かせるかの 1 設定。 FSpawnRule。
スマートポインタ
確保したメモリを自動で解放してくれるポインタ風オブジェクト。 手で delete しなくてよい。 RAII の代表例。
スレッド
1 つのプログラム内で同時に進む実行の流れ。 複数あると処理を並列にできる。
スレッドプール
ワーカースレッドを前もって用意し、タスクを投げて使い回す仕組み。 毎回スレッドを作るより軽い。
スワップチェイン
画面に表示する複数のバックバッファを回しながら、描画と表示を分けて行う仕組み。
スワップチェーン
描画した絵を画面に出すための表裏のバッファ列。 作成にウィンドウの NativeHandle() を渡す。
セグメント
メモリを目的・寿命で分けた論理ヒープ(Default/Permanent/Temp/Resource/Develop)。 CMemorySystem が各セグメントに独立した予算を持つ。
セッション
ML ランタイムが推論を実行するための作業単位(モデル・実行環境を束ねたもの)。
セマンティック
頂点要素の役割を示す HLSL の名前(POSITION / TEXCOORD / COLOR 等)。
ソケット
ネットワーク通信の出入口となる OS の口。 ここを通じてデータを送受信する。
タイプライタ
テキストを 1 文字ずつ順に表示していく演出。 会話やノベルでよく使う。
タイマ
時間を計る仕組み。 ACS では CClock（経過時間）と FFrameTimer（フレーム間 dt）。
タグ
AES-GCM が出力する 16 バイトの認証データ。 これが合わないとデータが改竄/破損とみなす。
ダッキング
ある音を目立たせるため、一時的に別の音 (主に BGM) の音量を下げる手法。
ダングリング
破棄済みのメモリを指したままのポインタ。 触ると未定義動作。 これを避けるため ACS は世代付きハンドルを多用する。
ティック
高精度タイマ（QPC）が刻む最小単位の時間。 TicksPerSecond() で秒に換算する。
ティント
画像に色を掛け合わせて見た目の色を変えること。 点滅やダメージ表現に使う。
テクスチャビュー
テクスチャに対するビュー。 シェーダ読取(SRV)・描画先(RTV)・深度(DSV)などの用途別に作る。
テレメトリ
ゲーム内の出来事(クリア・購入・離脱など)を記録して集計する計測の仕組み。 改善のヒントを得るために使う。
テンプレート
型を後から指定できる部品。 TArray<int> は『int の配列』というように中身の型を差し替えられる。
テンポラル
複数フレームにわたって結果を累積/平均し、ノイズやジャギーを減らす手法。
ディスクリプタ
テクスチャやバッファを GPU から参照するための小さな「住所メモ」。 ディスクリプタヒープに並べて使う。
ディスクリプタヒープ
ディスクリプタを並べて確保しておく GPU 上の表。 SRV/RTV/DSV など種類別に持つ。
デコード
エンコードされたデータを元の形(ここでは int16 PCM)に戻すこと。
デストラクタ
オブジェクトが破棄される時に自動で呼ばれる後始末の関数(~ClassName)。
デバイス
GPU とのやり取りを表す IRhiDevice のこと。
デルタタイム
前フレームから今フレームまでの経過秒（dt）。 速度 × dt で動かすとフレームレートに依存しない。
データグラム
UDP で送受信する 1 通分のデータの塊。 それ単体で届き、順序は保証されない。
データバインド
TObservable な状態と UI を結びつけ、変更を自動で反映させる MVVM の仕組み。
データ競合
複数スレッドが同じ変数を同時に読み書きして結果が壊れること。 アトミックや排他で防ぐ。
トゥイーン
ある値を一定時間かけて始点から終点へなめらかに変化させる仕組み。 イージングで変化カーブを指定する。
トリガ
重なりだけを検出する当たり判定。 物理の押し戻しはせず「触れたか」だけを通知する。 関連語は トリガワールド。
トリガワールド

レンダラ
実際に画面へ絵を出す描画システム本体。
レーティング

ロック

ロックステップ
全プレイヤーが同じ入力フレームを共有して同期する決定論シミュレーション方式。
ローカライズ
ゲームのテキストやリソースを言語・地域ごとに切り替えること (多言語化、i18n)。
ローダ
特定のファイル形式を解析してアセットを作る部品。 IAssetLoader を実装しレジストリへ登録する。

ワイヤーフレーム

ワールド行列
オブジェクト固有の座標を、ゲーム世界の共通座標へ移す行列（移動・回転・拡大の合成）。
一括反映
すべての検証に成功した後だけ変更をまとめて反映する処理です。
上限付き
件数、容量、時間などに明示的な最大値がある状態です。

凸包

列挙(enum)

参照カウント

古い参照

同期

型消去

境界検査

増分凸包

外積

安全側で失敗
検証できない場合は処理を止め、既存状態を維持する方針です。
完了カウンタ
残タスク数を数える値。 0 になったら処理完了とみなす同期用カウンタ。
完全転送

定数バッファ
シェーダに渡す小さなパラメータ群(行列・色・ライト等)を入れる GPU バッファ(cbuffer / CB)。
差し替え境界
実装を交換できるように設けた接続点です。
弱参照

後勝ち
同じ登録を複数回行った時、最後に登録した内容が有効になること。
復号

所有型
保持する値を自身の状態として管理し、必要な確保と解放を型の寿命に合わせて行う ACS の型。
所有権

投影行列

抗力
水中で速度に逆らう減速力(-velocity × drag)。 水の粘性的な抵抗を表す。
排他
あるデータを一度に 1 スレッドだけが触れるように制限すること。 FMutex やロックで実現する。
推論
学習済みモデルに入力を与えて出力(予測・分類など)を計算すること。 学習(training)ではなく実行(inference)の側。
描画
画面に絵(図形・画像・文字)を出すこと。 レンダリングとも言う。
既定 provider
明示指定が無い時に使われる既定の実装を返す登録関数。 後勝ちで差し替えられる。
暗号化
鍵を知らないと中身を読めない形にデータを変換すること。
有向光源
太陽光のように無限遠から来る、向きだけを持つ平行光。
有限オートマトン
決められた状態のどれか 1 つにいて、入力で別の状態へ遷移する仕組み (state machine)。 戦闘フェーズ管理などに使う。
未定義動作
C++ 規格が結果を保証しない操作(配列外アクセス・寿命切れポインタ等)。 最適化で表面化しやすい。
条件変数
ある条件が満たされるまでスレッドを眠らせ、別スレッドの通知で起こす待ち合わせの仕組み。
検査付き操作
入力を検証し、失敗時は既存状態を変えない操作です。
検証用固定データ
同じ条件を再現するために固定した試験入力です。
権利
プレイヤーがコンテンツを「持っているか」を表す情報 (entitlement)。 DLC・シーズンパス・引換コード等。
機械学習
データから規則を自動で学習させ、未知の入力に対して予測や判断をさせる技術。 略して ML。
正射影
距離に関係なく同じ大きさで映す投影。 2D ゲームや UI、見下ろし視点に使う。
正本
ほかの表現を照合または再生成する基準データです。
決定的
同じ入力なら必ず同じ結果になる性質。 乱数や時刻に依存せず、テストや再現がしやすい。
決定論
同じ入力なら必ず同じ結果になる性質。 replay / netcode / record-replay の同期で必須。 ML 推論や浮動小数のドライバ差はこれを壊すので隔離する。
法線
面や線に垂直な向きのベクトル。 当たった面の向きやライティングの計算に使う。
浮力
水中の物体を上向きに押し上げる力。 ACS では水深 × 強さ × 質量の簡易モデルで近似する。
浮動小数
float / double など小数を表す数値型。 丸め誤差があるため == ではなく EXPECT_NEAR で許容誤差つきで比べる。
点光源
ある位置から全方向に広がり、距離で減衰する光。
状態
オブジェクトが取りうる局面を区別した値(例: Idle / Spawning)。 状態機械の各点。
状態 holder
状態 (フラグや値) を保持するだけのクラス。 実際の処理 (時間停止や描画) は呼び出し側が行う、という責務分離の設計。
状態機械
限られた状態と、その間の遷移ルールで動きを表す仕組み。 ステートマシンとも。
球面線形補間
クォータニオンの回転を一定速度で滑らかに補間する方法（slerp）。 向きのアニメーションに使う。
球面調和
方向ごとの光を少数の係数(SH)で表す近似。 間接光(irradiance)の圧縮表現に使う。
発生位置
問題が起きたソース上の場所（ファイル名・行・関数名）。 FSourceLoc が表す。
空間グリッド
2D 空間を格子セルに区切り、形状を重なるセルに登録しておく仕組み (SpatialGrid)。 近くのセルだけ調べれば候補が絞れるので当たり判定が速くなる (broad-phase)。
空間グリッド (SpatialGrid)
空間を格子に区切り、近くにある物だけを速く探せるようにする仕組み。 重なり検索に使う。
範囲制限
値を指定した下限と上限の内側へ収める処理です。
結線
部品同士をつなぎ込む(実装を既定の口に登録する)こと。 これで上位が下位に直接依存せず使える。
統計値(Stat)
Steam 側で永続化される数値。 累計キル数やプレイ時間など。 実績の達成条件にも使う。
線分プリミティブ
2 つの端点と色からなる 1 本の線。 デバッグ描画の最小単位。
線形探索
先頭から順に 1 つずつ比較して目的の要素を探す単純な探索。
線形補間
2 値の間を一定割合 t(0〜1) で混ぜる（lerp）。 t=0 で始点、t=1 で終点。 滑らかな移動・色変化に。
自動露出
シーンの明るさを測り露出を自動調整する、目の順応(eye adaptation)を模した処理。
菱形依存
A が B と C に影響し、B と C が両方 D に影響する依存形。 TDerived は依存通知ごとに即時再計算するため、D が中間状態と最終状態を複数回観測し得る。 原子的な一括更新が必要なら外側で batch 化する。
行優先
行列をメモリに行ごとに並べる方式（row-major）。 ACS は行優先で、HLSL(列優先)へ送る前に Transpose する。
行列
複数の変換（移動・回転・拡大）をまとめて表す数値の表。 3D では FMat4(4x4)。 ベクトルに掛けて座標変換する。
補間
2 つの値 (ここでは前後の snapshot) の間を滑らかにつないで中間の状態を作ること。 少し過去の時刻を狙うことで通信ジッタを吸収する。
解凍
圧縮したデータを元に戻すこと。
購読
値や配列の変化を受け取るためにコールバックを登録すること(Subscribe)。 要らなくなったら解除(Unsubscribe)する。
転置
行列の行と列を入れ替える操作。
輪郭
形の縁(ふち)をなぞった線。 凸包と違いへこみ(凹み)にも沿う。
逆行列
ある変換を打ち消す行列。 スクリーン→ワールド変換などに使う。
透視投影
遠くの物ほど小さく見える、人間の目に近い投影。 3D ゲームの基本。
連想配列
キーから値を引く入れ物。 ハッシュで高速に検索する(THashMap)。
連結リスト
各要素が「次の要素」への参照を持って数珠つなぎになったデータ構造。 テストケースを順に辿るのに使う。
遅延
必要になるまで計算を先延ばしにする方式(lazy)。 現行 TDerived は生成時と依存通知時に即時評価し、Get の再計算は dirty が残った場合の補完経路。
選択肢
会話などで提示する分岐の候補。 プレイヤーが選ぶと進行が分かれる。
鍵
暗号化/復号に使う秘密のデータ。 ACS では 256bit(32 バイト)の FAcpakKey。
鍵導出
パスワードなど人間が覚えられる入力から、暗号用の鍵を計算で作ること。
関数ポインタ
関数そのものを指し示す値。 あとで fn() のように呼び出せる。 テスト本体を一覧に登録する仕組みに使う。
非同期
処理の完了を待たずに先へ進み、結果は後で受け取るやり方。 重い読み込みなどで画面を止めない。
非所有
そのポインタ/参照は対象を所有しておらず、寿命管理 (解放) は別の誰かが行うこと。 non-owning。
非所有ビュー
中身を所有(確保/解放)せず、既存データをポインタ+長さで参照するだけの軽い型。 元データより長生きさせないこと。
非所有参照
対象を所有せず、所有元より長く保持してはいけない参照です。
頂点
メッシュを構成する点。 位置・法線・UV などの属性を持つ。
高さフォグ
高さが低いほど濃くなる指数フォグ(霧)。 遠景や谷間の空気感を出す。
