# `Project Launcher` の応答性

`Project Launcher` は、ファイルシステムの読取りと書込みを作業スレッドで実行し、WPF の `Dispatcher` では表示状態と終了判定だけを更新します。

## 排他操作と結果の公開

作成、読込み、削除など状態を変更する操作は、`ProjectLauncherAsyncGate` の単調増加する世代番号で識別します。同時に実行できる変更操作は1件だけで、実行中の重複要求は開始しません。

作業スレッドの結果は、次の条件をすべて満たす場合だけ `Dispatcher` へ公開します。

- `Project Launcher` が読込み済みで、終了要求が出ていない。
- ウィンドウの寿命を表す取消しが有効である。
- 操作チケットが現在の世代と一致する。
- `Dispatcher` が停止していない。

成功結果は、現在世代の排他操作を完了し、`_allowClose` を設定し、`SelectedProject` を確定してから、最後に `DialogResult=true` を設定します。`DialogResult` の設定はウィンドウを同期的に閉じるため、選択結果より先に設定しません。

## 終了時の順序

操作中に終了が要求された場合は、結果の公開を直ちに禁止します。進行中のファイル書込みを途中で強制終了せず、作業スレッドの終了処理を待ってからウィンドウを閉じます。終了後は寿命の取消しと `ProjectLauncherAsyncGate.Dispose()` によって世代を進め、遅れて到着した結果を無効化します。

失敗、取消し、古い世代の結果は、`SelectedProject`、`DialogResult`、最近使用したプロジェクト一覧を変更しません。

## 最近使用したプロジェクト

`%APPDATA%\AcsEditor\recents.txt` は、最大512 KiBの厳密な UTF-8 の通常ファイルとして読み取ります。再解析ポイント、読取中の長さ変更、不正な UTF-8、解析失敗がある場合は、部分結果を使わず空の一覧として扱います。

作業スレッドは、重複を除いた最大10件について存在確認まで完了し、1つの結果配列を作ります。`Dispatcher` は現在の世代を再確認してから一覧を1回で置き換えます。1件ずつ途中公開しないため、古い一覧、新しい一覧、存在確認前の項目が混在しません。存在しない通常パスは `MISSING` として表示しますが、その項目からプロジェクトを開きません。

## 失敗表示

作業スレッドの例外は、現在世代の操作に限って `Dispatcher` へ戻し、操作単位の診断として表示します。失敗した操作の途中結果を選択状態や最近使用したプロジェクト一覧へ公開しません。

## 検証

```pwsh
AcsEditor.exe --project-launcher-responsiveness-selftest
```

自己検査は、排他操作、世代の無効化、成功結果の確定順、終了中の公開拒否、作業スレッドの完了待ち、最近使用したプロジェクト一覧の一括公開と空一覧への安全な失敗を検証します。
