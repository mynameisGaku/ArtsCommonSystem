# ACS 画像

ACS の実行画面と検証画像を用途別に保存します。

| ディレクトリ | 内容 |
|---|---|
| `captures/raw/` | ACS が出力した無加工の画面 |
| `captures/edited/` | 掲載向けに編集した画面 |
| `captures/edited/editor/mobile/` | 狭い画面で主要操作を読み取れるよう、ACS Editor の注目範囲を切り出した画面 |
| `captures/edited/water/` | 水面プロファイルを並べて用途を比較する概要画像 |

Editor の掲載用画像は元画像の画面内容を画素単位で保持します。枠と余白は画面の外側にだけ追加し、UI の文字、数値、配置、色、状態は変更しません。狭い画面向け画像も元画像の範囲を切り出すだけです。水面の概要画像は用途の比較に使い、波形、深度順、透過、境界の判定には `captures/raw/water/` の実行画面を使います。
