# 雲の完成密度LODに関する調査記録

調査日: 2026-09-08

対象は、非線形な密度生成後の空間集約、密度積分の保存、雲と空が混在する場合の透過率平均に限定する。一次資料をネットで並列に確認した文献評価であり、ACSの実装監査・修正記録ではない。引用数や著名さを正しさの根拠には用いていない。

文献調査時点では主担当のCPU/GPU集約カーネルは検証中だった。後続の実行結果は[検証記録](CloudPerformanceVerification.md)を参照する。本書の文献評価だけでは修正済み・実装完了・描画品質合格を意味しない。以下の実行結果は、文献調査担当が一時的なJavaScriptのメモリ上で行った独立計算であり、ACS、各ライブラリ、実GPUを実行した結果ではない。

## 保存対象と処理順序

以下は資料の直接引用ではなく、今回の独立導出と採用判断である。

- 密度積分: `M = ∫Ω ρ(x) dV`。密度が物理的な質量密度なら質量に相当する。
- 占有体積: `Vocc = ∫Ω 1[ρ(x) > 0] dV`。密度積分とは異なる。
- 透過率: 光線ごとの `τr = ∫r μ(s) ds` に対する `Tr = exp(-τr)`。`μ`は単位長さ当たりの消散係数である。

完成密度を `ρ(x) = F(n(x), m(x), …)`、空間平均を`R`とすると、完成密度LODの対象は`R[F]`である。非線形な生成処理を平均と交換した`F(R[n], R[m], …)`では一般に一致しない。独立反例として、等体積の入力`n = 0.25, 0.75`、`F(n) = max(n - 0.5, 0)`では、完成後平均は`0.125`、平均後生成は`0`となる。

密度1の子セル1個を、体積8倍の親全域の密度`1/8`へ集約すると、密度積分は保存されても占有体積は増える。また、3Dセル平均は各光線の線積分を一般には保存しない。密度積分・占有体積・透過率を別々の検証対象とする。

## 1. AMReX: 体積重み付き集約

版: **26.09**。確認箇所: `AMReX_MultiFabUtil_3D_C.H`の`amrex_avgdown`、`amrex_avgdown_with_vol`。

[公式実装](https://raw.githubusercontent.com/AMReX-Codes/amrex/26.09/Src/Base/AMReX_MultiFabUtil_3D_C.H)

資料の内容: 前者は子セル値の算術平均、後者は値とセル体積の積を合計し、体積総和で割る。雲の非線形生成順序を検証した資料ではない。

実装を数式へ書き直すと、`ρP = Σi(Vi ρi) / VP`、`VP = Σi Vi`。ここから`VP ρP = Σi(Vi ρi)`が独立に導ける。子が親領域を重複・欠落なく分割し、同じ意味の密度を持つことが条件である。等体積の8子なら`ρP = Σi ρi / 8`であり、空の子も分母に含める。

独立テストの期待値:

- 8子中1子だけ密度1: 親密度は`1/8`。非ゼロの子だけで平均すると失敗する。
- 子体積`1, 3`、密度`0, 1`: 親密度は`0.75`。単純平均`0.5`では密度積分を保存しない。
- 同一領域の直接集約と階層集約: 丸め誤差を除いて同じ密度積分となること。これは主担当へ渡す検証条件で、ACSでの合格結果ではない。

採用: **完成密度のセル平均という契約を採用する**。入力が点サンプルなら、まず保証できるのは離散和の保存であり、連続した完成密度に対する精度は別途収束確認が必要。占有体積・輪郭・透過率の保存は保証しない。

## 2. OpenVDB: 27点の重み付き縮小

版: **v13.0.0**。確認箇所: `MultiResGrid.h`の`RestrictOp::run`、`MaskOp`、`grid(size_t)`。

[公式実装](https://raw.githubusercontent.com/AcademySoftwareFoundation/openvdb/v13.0.0/openvdb/openvdb/tools/MultiResGrid.h)

資料の内容: 各軸の重み`h = [1, 2, 1] / 4`を掛け合わせる27点の縮小と、各軸2倍の格子間隔を使う。式への書き直しは`(Rρ)j = Σa,b,c ha hb hc ρ(2j + (a,b,c))`、各添字は`-1, 0, 1`。親を構成する8子だけの平均とは異なり、隣接する出力の集約範囲が重なる。

独立導出: 集約を行列`A`で表すと、定数維持は`A 1 = 1`、密度積分保存は`Vc^T A = Vf^T`であり、別の条件である。重みの和が1という確認だけでは保存性を証明できない。

独立計算: 周期境界の`8×8×8`格子を各軸2分の1へ縮小し、単独インパルスを8通りの偶奇位置に配置して27点式を列挙した。全ケースで体積を掛けた総和は1。一方、全座標が偶数なら粗格子1点に`1/8`、全座標が奇数なら8点に各`1/64`となった。全域保存と、親ごとの8子平均の一致は別である。

保留: **8子集約カーネルへの直接置換は保留する**。採用には集約範囲・格子位置・境界処理の仕様が必要。有限領域や疎な領域で必要な出力点を切り落とす場合にも保存するかが反証テストとなる。周期境界の結果をそのまま一般化しない。

## 3. Jaraboほか: 透過率平均とガンマ分布近似

Adrian Jarabo, Carlos Aliaga, Diego Gutierrez, *A Radiative Transfer Framework for Spatially-Correlated Materials* (2018)。確認版: **arXiv:1805.02651v1**。確認箇所: **§5.1 式(13)–(15)、§5.2 式(16)、(19)–(20)、§7の限界**。

[著者版本文](https://arxiv.org/pdf/1805.02651v1)

資料の主張: 式(13)は光線ごとの入射輝度と透過率を積分する。§5.1の局所的な一様性等の仮定に加え、§5.2では入射光と消散係数の分布の独立性を仮定し、式(16)を`T̄(s) = ∫ exp(-μs) pμ(μ) dμ`とする。入射輝度が異なり、密度と相関する場合は、単純な面積平均だけでは式(15)の輝度重みを再現できない。

式(19)は分布をガンマ分布で近似する。平均`m = E[μ]`、分散`v = Var(μ)`へ記号を統一した式(20)の等価形は、`TΓ(s) = (1 + vs/m)^(-m²/v)`。一定の断面積を前提とする。この形はガンマ分布の仮定下で成立し、任意の分布に対する恒等式ではない。著者も§7で分布選択と、不均質な領域間の相関を扱う実装の限界を述べている。

独立検証: ガンマ分布の形状2・率1・断面積1について、式(16)の積分を区間`[0, 60]`、120000分割の複合Simpson法で計算した。距離`0, 0.1, 1, 10`における式(20)との差は`1.4×10^-13`以下だった。これは当該条件の数値照合結果であり、一般的な誤差保証ではない。

### 二値の並列・直列反例

以下は今回の独立導出。直進する非散乱光、一定の入射輝度、長さ1、雲の消散係数10、空の消散係数0とする。

| 配置・計算 | 透過率 |
|---|---:|
| 並列: 半数の光線が全長を空、半数が全長を雲として通る | `(1 + exp(-10)) / 2 = 0.500023` |
| 並列配置を平均消散係数5で置換 | `exp(-5) = 0.006738` |
| 並列配置の平均5・分散25を合わせたガンマ近似 | `1/6 = 0.166667` |
| 直列: 全光線が雲を半分、空を半分通る | `exp(-5) = 0.006738` |

並列と直列は同じ総密度・占有体積でも透過率が異なる。並列配置の長さを延ばすと真の透過率は空の割合`0.5`に残るが、ガンマ近似は0へ向かう。これは同じ平均・分散を持つ任意の雲・空混合へ近似を一般化できない反例であり、式(16)自体の反証ではない。

採用: **光線ごとの透過率を平均する原則と、この反例を検証基準に使う**。保留: **ガンマ近似を完成密度LODへ直接導入すること**。平均・分散の一致だけでは、空の割合や光線に沿う配置を保存できない。

## 主担当への検証上の境界

`E光線[exp(-τ)] ≥ exp(-E光線[τ])`は光線間の平均に関する不等式で、光学的厚さ`τ`が一定なら等号となる。密度LODの平均式そのものを否定する根拠にはならない。

固定した1本の光線では、線上の平均消散係数を正確に保存すれば、`T = exp(-∫0^L μ(s) ds) = exp(-L μ̄線)`は正確である。3Dセル平均の保存から、この線積分の保存や画素の透過率平均の保存は導けない。

完成密度の生成順序、密度積分の保存、透過率平均を別々に検証する。本記録の採用判断は仕様上の判断であり、文献の式から主担当カーネルの最終Green、実GPUでの一致、実画像の品質を推定しない。それらは別の実行証拠で確認する。
