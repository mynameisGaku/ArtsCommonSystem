# ArtsCommonSystem
## ACS
Arts Common System(以下acs)は、[ArtsCollegeYokohama](https://www.kccollege.ac.jp/)のStudentによるゲーム開発用コアシステムです。
acsは、ゲーム開発を目的として作成された、コアシステムであり、ライブラリではありません。
ゲーム開発における様々な便利機能を搭載していく予定で、これらはどんなプロジェクトにおいても機能します。
機能のモジュール化なども目指しており、必要な機能のみを搭載したacsの運用なども視野に入れています。

## Developer
本プロジェクトは、3人の学生により開発されています。

## Goal
本プロジェクトは、ゲーム開発をより楽しく、便利に行えることを目標としております。
